Everdisk 是由 Everappz 开发的 iPhone 和 iPad 无线驱动器应用。它将您的设备变为一个中心，与本地网络上的任何设备共享文件、照片、视频和音乐，无需账户、无需云端，也无需在另一端安装额外的应用。该应用同时运行四台服务器 - DLNA 用于智能电视和媒体播放器，HTTP 用于任何网页浏览器，WebDAV 用于 Finder、Windows 和 Linux，FTP 用于文件应用和高级用户 - 因此每台设备都以自己喜欢的方式连接。您可以通过 DLNA 将照片、视频和音乐直接投屏到智能电视，并带有预览缩略图；共享一个可在任何浏览器中打开的简单链接，以浏览和下载您的文件；或将您的设备挂载为网络驱动器，双向拖放文件。当没有 Wi-Fi 时，您可以用 USB 线缆连接到 Mac，以比 Wi-Fi 更快的速度传输文件，即使在飞机上或受限网络中也可以。Everdisk 还可连接到您网络上的 DLNA、WebDAV、FTP 和 SFTP 服务器，以浏览、流式播放和下载其中的文件。内置的文件管理器可让您以列表或网格浏览，创建文件夹，重命名、移动、复制、压缩和解压，以及删除。您可以将纸质文档扫描为干净的 PDF，打开 PDF 或照片并用内置编辑器进行标注 - 绘图、高亮、添加文字和签名，更改会保存回文件 - 并使用一整套 PDF 工具来压缩文件，将文字识别 (OCR) 为可搜索的 PDF，添加或移除打开密码，查看权限，编辑文档元数据，以及扁平化注释和表单字段。您还可以在迷你播放器中播放音频并全屏观看视频，并以原始质量或更兼容的格式通过网络共享您完整的照片和音乐库。一切都保留在您的本地网络上，永远不会接触互联网，您可以用登录名和密码保护访问，并一键屏蔽任何设备。Everdisk 可在 App Store 免费下载，并提供可选的一次性 Premium 终身购买。

  常见问题
{{< /hextra/section-headline >}}

<div class="hx:mt-6"></div>

<div class="hx:w-full">
{{% details title="什么是 Everdisk？" closed="true" %}}
Everdisk 将您的 iPhone 或 iPad 变为无线驱动器，同时也是一个可连接到您其他设备的中心。<br>
您可以与网络上的任何设备共享文件、照片、视频和音乐，从其他服务器浏览和流式播放，并直接在设备上管理一切。<br>
无需账户、无需云端，另一端也无需安装额外的应用 - 只需点击「开始」即可就绪。<br><br>

该应用同时运行四台服务器，因此每台设备都以自己喜欢的方式连接：智能电视通过 DLNA，计算机和网页浏览器通过 HTTP，Finder、Windows 和 Linux 通过 WebDAV，文件应用通过 FTP。
{{% /details %}}

{{% details title="Everdisk 如何工作？" closed="true" %}}
当您点击「开始」时，Everdisk 会开始共享您选定的内容，并同时运行四台服务器，以便不同的设备以各自喜欢的方式连接。<br><br>

- <strong>DLNA</strong> 让智能电视和媒体播放器自动查找您的照片、视频和音乐，并以预览缩略图显示它们。<br>
- <strong>HTTP</strong> 为任何人提供一个可在网页浏览器中打开的简单链接，以浏览、预览和下载您的文件，无需安装任何东西。<br>
- <strong>WebDAV</strong> 让您的设备在 Finder、Windows 或 Linux 中显示为普通的网络驱动器，因此您可以双向拖放文件。<br>
- <strong>FTP</strong> 适用于文件应用和高级用户。<br><br>

Everdisk 还能反向连接到您网络上的 DLNA、WebDAV、FTP 和 SFTP 服务器，因此您可以浏览它们的文件夹，流式播放音频和视频，并在服务器允许时下载或管理文件。一切都保留在您的本地网络上，永远不会接触互联网。
{{% /details %}}

{{% details title="Everdisk 是免费的吗？" closed="true" %}}
是的。Everdisk 可免费下载，您可以免费将设备变为无线驱动器，以四种方式共享文件，连接到其他服务器，并使用内置的文件管理器。<br><br>

有一项可选的一次性 <strong>Premium 终身</strong> 购买 - 单次付款，无订阅 - 可解锁无限共享文件夹和已保存连接、照片和视频转换、自定义端口、自动开始共享以及设备自定义。它与您的 Apple ID 绑定，因此您可以使用「恢复购买」在其他设备上解锁。价格可能因您所在的国家或地区而异。
{{% /details %}}

{{% details title="我如何从计算机连接？" closed="true" %}}
Everdisk 让您的设备通过 WebDAV 显示为普通的网络驱动器。<br><br>

- 在 <strong>Mac</strong> 上，打开 Finder，选择 <em>前往 → 连接服务器</em>，然后输入应用中显示的 WebDAV 地址。<br>
- 在 <strong>Windows</strong> 上，使用相同的 WebDAV 地址映射网络驱动器。<br>
- 在 <strong>Linux</strong> 上，从您的文件管理器连接到 WebDAV 地址。<br><br>

连接后，您可以双向拖放：将文件从计算机复制到设备，或将它们取回。如果您不想挂载驱动器，也可以在任何网页浏览器中打开 HTTP 链接。
{{% /details %}}

{{% details title="我如何投屏到电视？" closed="true" %}}
确保您的电视或媒体播放器与您的设备处于同一 Wi-Fi 网络，然后在 Everdisk 中点击「开始」，并共享您的照片、视频或音乐。<br><br>

您的设备会自动出现在电视的媒体服务器列表中，并带有预览缩略图。在电视上打开它，在大屏幕上尽情享受您的媒体库 - 无需线缆，也无需额外应用。
{{% /details %}}

{{% details title="我如何在网页浏览器中打开文件？" closed="true" %}}
点击「开始」，Everdisk 会为 HTTP 服务器提供一个简单的网址。<br><br>

将该链接分享给同一网络上的任何人。他们可在任何网页浏览器中打开它，以整洁的网格或列表浏览您的文件，在全屏图库中查看照片，在内置播放器中播放音乐，并下载任何内容。他们那端无需安装任何东西，这使其成为将文件传递给另一台手机或计算机的最快方式。
{{% /details %}}

{{% details title="Everdisk 在没有 Wi-Fi 的情况下能工作吗？" closed="true" %}}
可以。用给设备充电的同一根 USB 线缆将其连接到 Mac，文件直接通过线缆传输，比 Wi-Fi 更快。<br><br>

由于它不依赖无线网络，因此在飞机上、酒店里或任何屏蔽了 Wi-Fi 共享的受限或公共网络中都能继续工作。
{{% /details %}}

{{% details title="我可以用 Everdisk 连接到什么？" closed="true" %}}
Everdisk 也是您网络上其他设备的客户端。您可以查找并连接到 <strong>DLNA</strong>、<strong>WebDAV</strong>、<strong>FTP</strong> 和 <strong>SFTP</strong> 服务器，包括 NAS 设备和媒体服务器。<br><br>

连接后，您可以浏览它们的文件夹，流式播放音频和视频，下载文件，并在服务器允许时创建文件夹、上传、重命名、移动或删除。
{{% /details %}}

{{% details title="我可以扫描文档并处理 PDF 吗？" closed="true" %}}
可以。Everdisk 可以用相机扫描纸质文档 - 它会自动查找边缘，拉直每一页，并将它们保存为干净的多页 PDF，直接存到您的设备上。<br><br>

您还可以打开 PDF (或照片) 并直接在内置查看器中<strong>标注</strong> - 绘图、高亮、添加文字和形状，并用手指添加签名 - 您的更改会保存回文件。<br><br>

除此之外，Everdisk 还包含一整套 <strong>PDF 工具</strong>，可从「文件」浏览器中 PDF 的 <strong>•••</strong> 菜单打开：<br>
• <strong>压缩</strong> - 缩小 PDF，保存前会显示估算大小。<br>
• <strong>文字识别 (OCR)</strong> - 将扫描件转为可搜索的 PDF，或将文字导出为 .txt 文件。<br>
• <strong>密码</strong> - 设置、更改或移除打开 PDF 所需的密码。<br>
• <strong>权限</strong> - 查看 PDF 允许的操作 (打印、复制等)。<br>
• <strong>编辑元数据</strong> - 更改或清除标题、作者、关键词和其他文档信息。<br>
• <strong>扁平化</strong> - 将注释和表单条目固化到页面中，使其无法更改。
{{% /details %}}

{{% details title="Everdisk 私密安全吗？" closed="true" %}}
一切都保留在您的本地网络上，永远不会接触互联网，因此您的文件永远不会离开家。中间没有账户也没有云端。<br><br>

您可以用登录名和密码保护访问，因此已连接的设备必须输入相同的详细信息才能看到您的文件，并且您可以一键屏蔽您网络上的任何设备。为了获得最佳隐私，请仅在您连接到已知且信任的 Wi-Fi 网络时才开启共享。
{{% /details %}}

{{% details title="用文件管理器可以做什么？" closed="true" %}}
Everdisk 为设备上的一切包含一个完整的文件管理器。<br><br>

您可以以列表或网格浏览，创建文件夹，重命名、移动、复制、压缩和解压，以及删除。您还可以连接设备上任何位置的文件夹并直接在应用中使用它们，然后与其他所有内容一起通过网络共享。
{{% /details %}}

{{% details title="我可以在应用内播放音乐吗？" closed="true" %}}
可以。点击任何音频文件，它会在迷你播放器中播放，该播放器在您继续浏览时始终停留在屏幕底部。<br><br>

迷你播放器带有完整的队列，支持随机播放和重复播放 (关闭、全部或单曲)，以及显示真实标题、艺术家和专辑的锁屏和媒体键控制。点击或向上滑动可打开完整播放器，向下滑动可将其缩小，同时音频继续播放。点击文件夹中的一首曲目会将整个文件夹作为队列播放。<br><br>

音频可从您的本地文件、已连接的文件夹、您的「音乐」库以及您在「设备」标签上连接的服务器播放。
{{% /details %}}

{{% details title="我可以在应用中观看视频吗？" closed="true" %}}
可以。点击视频即可全屏播放。Everdisk 使用内置的系统视频播放器，因此您可获得熟悉的控制，包括 AirPlay、Picture in Picture 和播放速度。<br><br>

视频可从您的本地文件和已连接的文件夹播放，或从您在「设备」标签上连接的设备直接流式播放，因此您无需先下载整个文件。
{{% /details %}}

{{% details title="我如何查看照片？" closed="true" %}}
打开「文档」标签并切换到「照片」模式以浏览您的照片和视频。点击照片可全屏打开，您可以在其中缩放、在照片间滑动以及共享。<br><br>

您的照片还会在电视上通过 DLNA 以及在网页浏览器中显示真实的预览缩略图，它们会在全屏图库中打开，支持滑动、双指缩放和幻灯片放映。带有位置数据的照片和视频会在其「信息」屏幕上显示带图钉的地图。
{{% /details %}}
