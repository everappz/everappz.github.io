Everdisk 是 Everappz 为 iPhone 和 iPad 打造的无线硬盘应用。它把你的设备变成一个中枢，与本地网络上的任何设备共享文件、照片、视频和音乐，无需账户、无需云端，另一端也不用安装任何应用。应用会同时运行四种服务器 - DLNA 适用于智能电视和媒体播放器，HTTP 适用于任意浏览器，WebDAV 适用于 Finder、Windows 和 Linux，FTP 适用于文件类应用和进阶用户 - 因此每台设备都能用自己喜欢的方式连接。你可以通过 DLNA 把照片、视频和音乐直接投到智能电视上，还带预览缩略图；也可以分享一个简单链接，在任意浏览器中打开就能浏览和下载你的文件；或者把设备挂载为网络硬盘，双向拖放文件。没有 Wi-Fi 时，你还能用 USB 线连接 Mac，比 Wi-Fi 更快地传输文件，哪怕在飞机上或受限网络中也能用。Everdisk 还能连接到你网络上的 DLNA、WebDAV、FTP 和 SFTP 服务器，浏览、播放和下载它们的文件。内置文件管理器支持列表或网格浏览、新建文件夹、重命名、移动、复制、压缩解压和删除。你可以把纸质文档扫描成清晰的 PDF，打开 PDF 或照片并用内置编辑器标注 - 绘图、高亮、添加文字和签名，修改会保存回原文件 - 还能使用整套 PDF 工具来压缩文件、把文字识别 (OCR) 成可搜索的 PDF、添加或移除打开密码、查看权限、编辑文档元数据以及扁平化批注和表单字段。你也可以在迷你播放器中播放音频、全屏观看视频，并以原始画质或更兼容的格式在网络上共享完整的照片和音乐库。一切都留在本地网络上，绝不接触互联网，你还可以用登录名和密码保护访问权限，并一键拦截任何设备。Everdisk 可在 App Store 免费下载，另可选购一次性的 Premium Lifetime。

{{% details title="Everdisk 是什么？" closed="true" %}}
Everdisk 把你的 iPhone 或 iPad 变成一块无线硬盘，同时也是连接你其他设备的中枢。<br>
你可以与网络上的任何设备共享文件、照片、视频和音乐，浏览并播放其他服务器上的内容，还能直接在设备上管理一切。<br>
无需账户、无需云端，另一端也不用安装任何应用 - 只需点击开始，即刻就绪。<br><br>

应用会同时运行四种服务器，让每台设备都用自己喜欢的方式连接：智能电视走 DLNA，电脑和浏览器走 HTTP，Finder、Windows 和 Linux 走 WebDAV，文件类应用走 FTP。
{{% /details %}}

{{% details title="Everdisk 如何工作？" closed="true" %}}
当你点击开始，Everdisk 会开始共享你所选的内容，并同时运行四种服务器，让不同设备用各自偏好的方式连接。<br><br>

- <strong>DLNA</strong> 让智能电视和媒体播放器自动找到你的照片、视频和音乐，并带预览缩略图显示。<br>
- <strong>HTTP</strong> 给任何人一个简单链接，在浏览器中打开就能浏览、预览和下载你的文件，无需安装任何东西。<br>
- <strong>WebDAV</strong> 让你的设备在 Finder、Windows 或 Linux 中显示为普通网络硬盘，方便双向拖放文件。<br>
- <strong>FTP</strong> 适用于文件类应用和进阶用户。<br><br>

Everdisk 还能反向连接到你网络上的 DLNA、WebDAV、FTP 和 SFTP 服务器，让你浏览它们的文件夹、播放音频和视频，并在服务器允许时下载或管理文件。一切都留在本地网络上，绝不接触互联网。
{{% /details %}}

{{% details title="Everdisk 免费吗？" closed="true" %}}
免费。Everdisk 可免费下载，你无需付费就能把设备变成无线硬盘、四种方式共享文件、连接其他服务器，并使用内置文件管理器。<br><br>

另可选购一次性的 <strong>Premium Lifetime</strong> - 单次付款，没有订阅 - 它解锁无限共享文件夹和保存的连接、照片和视频转换、自定义端口、自动开始共享以及设备自定义。它与你的 Apple ID 绑定，你可以用「恢复购买」在其他设备上解锁。价格可能因你所在国家或地区而异。
{{% /details %}}

{{% details title="如何从电脑连接？" closed="true" %}}
Everdisk 通过 WebDAV 让你的设备显示为普通网络硬盘。<br><br>

- 在 <strong>Mac</strong> 上，打开 Finder，选择 <em>前往 → 连接服务器</em>，然后输入应用中显示的 WebDAV 地址。<br>
- 在 <strong>Windows</strong> 上，用相同的 WebDAV 地址映射网络硬盘。<br>
- 在 <strong>Linux</strong> 上，从你的文件管理器连接到 WebDAV 地址。<br><br>

连接后，你可以双向拖放：把文件从电脑复制到设备，或再取回来。如果你不想挂载硬盘，也可以在任意浏览器中打开 HTTP 链接。
{{% /details %}}

{{% details title="如何投屏到电视？" closed="true" %}}
确保你的电视或媒体播放器与你的设备在同一个 Wi-Fi 网络中，然后在 Everdisk 里共享好照片、视频或音乐后点击开始。<br><br>

你的设备会自动出现在电视的媒体服务器列表中，还带预览缩略图。在电视上打开它，就能在大屏上尽情享受你的媒体库 - 无需数据线，也无需额外应用。
{{% /details %}}

{{% details title="如何在浏览器中打开我的文件？" closed="true" %}}
点击开始，Everdisk 会给你一个简单的 HTTP 服务器网址。<br><br>

把这个链接分享给同一网络上的任何人。他们在任意浏览器中打开，就能以整洁的网格或列表浏览你的文件、在全屏图库中查看照片、在内置播放器中播放音乐，并下载任何内容。他们那端无需安装任何东西，因此这是把文件递给另一部手机或电脑的最快方式。
{{% /details %}}

{{% details title="Everdisk 没有 Wi-Fi 也能用吗？" closed="true" %}}
能。用平时充电的那根 USB 线把设备连到 Mac，文件就会直接通过数据线传输，比 Wi-Fi 更快。<br><br>

由于不依赖无线网络，它在飞机上、酒店里，或任何屏蔽 Wi-Fi 共享的受限或公共网络中都照常好用。
{{% /details %}}

{{% details title="Everdisk 能连接到哪些设备？" closed="true" %}}
Everdisk 同时也是你网络上其他设备的客户端。你可以查找并连接到 <strong>DLNA</strong>、<strong>WebDAV</strong>、<strong>FTP</strong> 和 <strong>SFTP</strong> 服务器，包括 NAS 设备和媒体服务器。<br><br>

连接后，你可以浏览它们的文件夹、播放音频和视频、下载文件，并在服务器允许时新建文件夹、上传、重命名、移动或删除。
{{% /details %}}

{{% details title="我能扫描文档并处理 PDF 吗？" closed="true" %}}
可以。Everdisk 能用相机扫描纸质文档 - 它会自动识别边缘、拉直每一页，并直接在设备上保存为清晰的多页 PDF。<br><br>

你也可以打开 PDF (或照片) 并直接在内置查看器中<strong>标注</strong> - 绘图、高亮、添加文字和形状，并用手指添加签名 - 你的修改会保存回原文件。<br><br>

除此之外，Everdisk 还包含整套 <strong>PDF 工具</strong>，从文件浏览器中 PDF 的 <strong>•••</strong> 菜单打开：<br>
• <strong>压缩</strong> - 缩小 PDF，保存前会显示预估大小。<br>
• <strong>文字识别 (OCR)</strong> - 把扫描件变成可搜索的 PDF，或把文字导出为 .txt 文件。<br>
• <strong>密码</strong> - 设置、更改或移除打开 PDF 所需的密码。<br>
• <strong>权限</strong> - 查看 PDF 允许哪些操作 (打印、复制等)。<br>
• <strong>编辑元数据</strong> - 更改或清除标题、作者、关键词和其他文档信息。<br>
• <strong>扁平化</strong> - 把批注和表单内容固化到页面上，使其无法再被更改。
{{% /details %}}

{{% details title="Everdisk 私密安全吗？" closed="true" %}}
一切都留在本地网络上，绝不接触互联网，所以你的文件永远不出家门。中间没有账户，也没有云端。<br><br>

你可以用登录名和密码保护访问权限，让连接的设备必须输入相同信息才能看到你的文件，还能一键拦截你网络上的任何设备。为获得最佳隐私保护，请只在连接到你熟悉且信任的 Wi-Fi 网络时才开启共享。
{{% /details %}}

{{% details title="文件管理器能做什么？" closed="true" %}}
Everdisk 为你设备上的一切内容提供了完整的文件管理器。<br><br>

你可以列表或网格浏览、新建文件夹、重命名、移动、复制、压缩解压和删除。你还能连接设备上任意位置的文件夹，直接在应用内使用，然后与其他内容一起通过网络共享。
{{% /details %}}

{{% details title="我能在应用内播放音乐吗？" closed="true" %}}
可以。点击任意音频文件，它就会在停靠于屏幕底部的迷你播放器中播放，同时你还能继续浏览。<br><br>

迷你播放器有完整的队列，支持随机和循环 (关闭、全部或单曲)，锁屏和媒体键控制会显示真实的标题、艺术家和专辑。点击或上滑打开完整播放器，下滑将其缩小，音频会继续播放。点击文件夹中的一首曲目，就会把整个文件夹作为队列播放。<br><br>

音频可来自你的本地文件、连接的文件夹、你的音乐库，以及你在设备标签页上连接的服务器。
{{% /details %}}

{{% details title="我能在应用内观看视频吗？" closed="true" %}}
可以。点击视频即可全屏播放。Everdisk 使用内置的系统视频播放器，因此你能获得熟悉的控制，包括 AirPlay、Picture in Picture 和播放速度。<br><br>

视频可来自你的本地文件和连接的文件夹，也可直接从你在设备标签页上连接的设备流式播放，因此无需先下载整个文件。
{{% /details %}}

{{% details title="如何查看我的照片？" closed="true" %}}
打开文档标签页并切换到照片模式，即可浏览你的照片和视频。点击照片可全屏打开，在这里你可以缩放、在照片间滑动切换以及分享。<br><br>

你的照片还会通过 DLNA 在电视上、以及在浏览器中显示真实的预览缩略图，并在全屏图库中打开，支持滑动、双指缩放和幻灯片播放。带有位置信息的照片和视频，会在其信息页上显示带定位标记的地图。
{{% /details %}}
