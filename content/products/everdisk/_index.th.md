Everdisk คือแอปไดรฟ์ไร้สายสำหรับ iPhone และ iPad พัฒนาโดย Everappz มันเปลี่ยนอุปกรณ์ของคุณให้เป็นศูนย์กลางที่แชร์ไฟล์ รูปภาพ วิดีโอ และเพลงกับทุกอย่างบนเครือข่ายท้องถิ่นของคุณ โดยไม่ต้องมีบัญชี ไม่ต้องใช้คลาวด์ และไม่ต้องติดตั้งแอปเพิ่มบนอีกฝั่ง แอปนี้รันห้าเซิร์ฟเวอร์พร้อมกัน - DLNA สำหรับสมาร์ททีวีและเครื่องเล่นมีเดีย, HTTP สำหรับเว็บเบราว์เซอร์ใดก็ได้, WebDAV สำหรับ Finder, Windows และ Linux, SMB สำหรับไดรฟ์เครือข่ายบน Mac, Windows และ Linux (พร้อมการเข้ารหัส SMB3 ที่เลือกได้) และ FTP สำหรับแอปจัดการไฟล์และผู้ใช้ระดับสูง - ทุกอุปกรณ์จึงเชื่อมต่อได้ในแบบที่ถนัด คุณสามารถสตรีมรูปภาพ วิดีโอ และเพลงตรงขึ้นสมาร์ททีวีผ่าน DLNA พร้อมภาพตัวอย่าง แชร์ลิงก์ง่าย ๆ ที่เปิดในเบราว์เซอร์ใดก็ได้เพื่อเรียกดูและดาวน์โหลดไฟล์ของคุณ หรือเชื่อมต่ออุปกรณ์เป็นไดรฟ์เครือข่ายแล้วลากไฟล์ได้ทั้งสองทิศทาง คุณยังเชื่อมต่อผ่าน SMB ได้ ซึ่งเป็นไดรฟ์เครือข่ายสำหรับ Mac, Windows และ Linux ที่ปรากฏขึ้นเองในแถบข้าง Finder บน Mac และเปิดการเข้ารหัส SMB3 (AES) เพื่อไม่ให้ใครก็ตามบนเครือข่ายเดียวกันอ่านการถ่ายโอนของคุณได้ เมื่อไม่มี Wi-Fi คุณสามารถต่อกับ Mac ด้วยสาย USB แล้วย้ายไฟล์ได้เร็วกว่า Wi-Fi แม้อยู่บนเครื่องบินหรือบนเครือข่ายที่ถูกล็อก Everdisk ยังเชื่อมต่อกับเซิร์ฟเวอร์ DLNA, WebDAV, FTP, SFTP และ SMB บนเครือข่ายของคุณ - รวมถึง Mac, พีซี Windows, เครื่อง Linux และไดรฟ์ NAS - เพื่อเรียกดู สตรีม และดาวน์โหลดไฟล์ของเซิร์ฟเวอร์เหล่านั้น ตัวจัดการไฟล์ในตัวให้คุณเรียกดูแบบรายการหรือกริด สร้างโฟลเดอร์ เปลี่ยนชื่อ ย้าย คัดลอก บีบอัดและแตกไฟล์ zip และลบได้ คุณสามารถสแกนเอกสารกระดาษให้เป็น PDF ที่เรียบร้อย เปิด PDF หรือรูปภาพแล้วมาร์กอัปด้วยเครื่องมือแก้ไขในตัว - วาด ไฮไลต์ เพิ่มข้อความและลายเซ็น โดยบันทึกการเปลี่ยนแปลงกลับลงไฟล์ - และใช้เครื่องมือ PDF ครบชุดเพื่อบีบอัดไฟล์ จดจำข้อความ (OCR) ให้เป็น PDF ที่ค้นหาได้ เพิ่มหรือลบรหัสผ่านเปิดไฟล์ ตรวจสอบสิทธิ์การใช้งาน แก้ไขข้อมูลเมตาของเอกสาร และรวมคำอธิบายประกอบและช่องฟอร์มเข้าด้วยกัน คุณยังเล่นเสียงในเครื่องเล่นขนาดเล็กและดูวิดีโอแบบเต็มจอได้ พร้อมแชร์คลังรูปภาพและเพลงทั้งหมดผ่านเครือข่ายในคุณภาพต้นฉบับหรือรูปแบบที่เข้ากันได้มากกว่า ทุกอย่างอยู่บนเครือข่ายท้องถิ่นของคุณและไม่เคยแตะต้องอินเทอร์เน็ต คุณสามารถป้องกันการเข้าถึงด้วยล็อกอินและรหัสผ่าน และบล็อกอุปกรณ์ใดก็ได้ด้วยการแตะเพียงครั้งเดียว Everdisk ดาวน์โหลดฟรีบน App Store พร้อมตัวเลือกซื้อ Premium Lifetime แบบจ่ายครั้งเดียว

{{% details title="Everdisk คืออะไร?" closed="true" %}}
Everdisk เปลี่ยน iPhone หรือ iPad ของคุณให้เป็นไดรฟ์ไร้สาย และเป็นศูนย์กลางที่เชื่อมต่อกับอุปกรณ์อื่น ๆ ของคุณด้วย<br>
คุณสามารถแชร์ไฟล์ รูปภาพ วิดีโอ และเพลงกับทุกอย่างบนเครือข่าย เรียกดูและสตรีมจากเซิร์ฟเวอร์อื่น และจัดการทุกอย่างบนอุปกรณ์ของคุณได้เลย<br>

แอปนี้รันห้าเซิร์ฟเวอร์พร้อมกัน ทุกอุปกรณ์จึงเชื่อมต่อได้ในแบบที่ถนัด: สมาร์ททีวีผ่าน DLNA, คอมพิวเตอร์และเว็บเบราว์เซอร์ผ่าน HTTP, Finder, Windows และ Linux ผ่าน WebDAV, ไดรฟ์เครือข่ายผ่าน SMB (พร้อมการเข้ารหัสที่เลือกได้) และแอปจัดการไฟล์ผ่าน FTP

{{% details title="Everdisk ทำงานอย่างไร?" closed="true" %}}
เมื่อคุณแตะ Start Everdisk จะเริ่มแชร์เนื้อหาที่คุณเลือกและรันห้าเซิร์ฟเวอร์พร้อมกัน เพื่อให้อุปกรณ์ต่าง ๆ เชื่อมต่อได้ในแบบที่ถนัด<br><br>

- <strong>DLNA</strong> ให้สมาร์ททีวีและเครื่องเล่นมีเดียค้นหารูปภาพ วิดีโอ และเพลงของคุณอัตโนมัติ และแสดงพร้อมภาพตัวอย่าง<br>
- <strong>HTTP</strong> ให้ลิงก์ง่าย ๆ แก่ใครก็ได้เพื่อเปิดในเว็บเบราว์เซอร์ เรียกดู ดูตัวอย่าง และดาวน์โหลดไฟล์ของคุณ โดยไม่ต้องติดตั้งอะไร<br>
- <strong>WebDAV</strong> ทำให้อุปกรณ์ของคุณปรากฏเป็นไดรฟ์เครือข่ายทั่วไปใน Finder, Windows หรือ Linux คุณจึงลากไฟล์ได้ทั้งสองทิศทาง<br>
- <strong>SMB</strong> ทำให้อุปกรณ์ของคุณเป็นไดรฟ์เครือข่ายบน Mac, Windows และ Linux - บน Mac จะปรากฏขึ้นเองในแถบข้าง Finder - และเป็นการเชื่อมต่อเดียวที่คุณเข้ารหัสได้ด้วยการเข้ารหัส SMB3 (AES)<br>
- <strong>FTP</strong> ใช้งานได้กับแอปจัดการไฟล์และผู้ใช้ระดับสูง<br><br>

Everdisk ยังเชื่อมต่ออีกทางหนึ่งด้วย ไปยังเซิร์ฟเวอร์ DLNA, WebDAV, FTP, SFTP และ SMB บนเครือข่ายของคุณ - รวมถึง Mac, พีซี Windows, เครื่อง Linux และไดรฟ์ NAS - คุณจึงเรียกดูโฟลเดอร์ สตรีมเสียงและวิดีโอ และดาวน์โหลดหรือจัดการไฟล์ได้เมื่อเซิร์ฟเวอร์อนุญาต ทุกอย่างอยู่บนเครือข่ายท้องถิ่นของคุณและไม่เคยแตะต้องอินเทอร์เน็ต

{{% details title="Everdisk ฟรีหรือไม่?" closed="true" %}}
ใช่ Everdisk ดาวน์โหลดฟรี และคุณสามารถเปลี่ยนอุปกรณ์ของคุณให้เป็นไดรฟ์ไร้สาย แชร์ไฟล์ห้าทาง เชื่อมต่อกับเซิร์ฟเวอร์อื่น และใช้ตัวจัดการไฟล์ในตัวได้โดยไม่มีค่าใช้จ่าย<br><br>

มีตัวเลือกซื้อ <strong>Premium Lifetime</strong> แบบจ่ายครั้งเดียว - จ่ายเพียงครั้งเดียวไม่มีการสมัครสมาชิก - ที่ปลดล็อกโฟลเดอร์แชร์และการเชื่อมต่อที่บันทึกไว้แบบไม่จำกัด การแปลงรูปภาพ &amp; วิดีโอ การเข้ารหัส SMB3 (AES) พอร์ตแบบกำหนดเอง การเริ่มแชร์อัตโนมัติ และการปรับแต่งอุปกรณ์ มันผูกกับ Apple ID ของคุณ คุณจึงใช้ กู้คืนการซื้อ เพื่อปลดล็อกบนอุปกรณ์อื่นของคุณได้ ราคาอาจแตกต่างกันไปตามประเทศหรือภูมิภาคของคุณ
{{% /details %}}

{{% details title="ฉันจะเชื่อมต่อจากคอมพิวเตอร์ได้อย่างไร?" closed="true" %}}
Everdisk ทำให้อุปกรณ์ของคุณปรากฏเป็นไดรฟ์เครือข่ายทั่วไปผ่าน WebDAV<br><br>

- บน <strong>Mac</strong> เปิด Finder เลือก <em>Go → Connect to Server</em> แล้วป้อนที่อยู่ WebDAV ที่แสดงในแอป<br>
- บน <strong>Windows</strong> แมปไดรฟ์เครือข่ายโดยใช้ที่อยู่ WebDAV เดียวกัน<br>
- บน <strong>Linux</strong> เชื่อมต่อกับที่อยู่ WebDAV จากตัวจัดการไฟล์ของคุณ<br><br>

เมื่อเชื่อมต่อแล้ว คุณสามารถลากแล้ววางได้ทั้งสองทิศทาง: คัดลอกไฟล์จากคอมพิวเตอร์ไปยังอุปกรณ์ หรือดึงกลับมา คุณยังเปิดลิงก์ HTTP ในเว็บเบราว์เซอร์ใดก็ได้ หากไม่อยากเชื่อมต่อเป็นไดรฟ์
{{% /details %}}

{{% details title="ฉันใช้ SMB และเข้ารหัสการเชื่อมต่อได้ไหม?" closed="true" %}}
ได้ นอกจาก WebDAV แล้ว Everdisk ยังแชร์ผ่าน <strong>SMB</strong> - ไดรฟ์เครือข่ายสำหรับ Mac, Windows และ Linux (แสดงในแอปเป็นการเชื่อมต่อ <strong>คอมพิวเตอร์ (ขั้นสูง)</strong>) บน Mac จะปรากฏขึ้นเองในแถบข้าง Finder ใต้ Locations ส่วนบน Windows ให้เปิดใน File Explorer ด้วยที่อยู่ <code>smb://</code> ที่แสดงในแอป<br><br>

SMB ยังเป็นการเชื่อมต่อเดียวที่คุณ <strong>เข้ารหัส</strong> ได้ ตั้งล็อกอินและรหัสผ่าน แล้วเปิด <strong>ต้องใช้การเข้ารหัส SMB</strong> ในการตั้งค่า เพื่อปกป้องการถ่ายโอนทุกครั้งด้วย <strong>การเข้ารหัส SMB3 (AES)</strong> เพื่อไม่ให้ใครก็ตามบนเครือข่ายเดียวกันอ่านไฟล์ของคุณได้ การเชื่อมต่อที่เข้ารหัสไม่สามารถไม่ระบุตัวตนได้ จึงต้องมีล็อกอินและรหัสผ่าน และคุณต้องมีไคลเอนต์ที่รองรับ SMB3 - Finder บน Mac รุ่นใหม่ หรือ Windows 10 ขึ้นไป
{{% /details %}}

{{% details title="ฉันจะสตรีมขึ้นทีวีได้อย่างไร?" closed="true" %}}
ตรวจสอบให้แน่ใจว่าทีวีหรือเครื่องเล่นมีเดียกับอุปกรณ์ของคุณอยู่บนเครือข่าย Wi-Fi เดียวกัน จากนั้นแตะ Start ใน Everdisk โดยแชร์รูปภาพ วิดีโอ หรือเพลงของคุณไว้<br><br>

อุปกรณ์ของคุณจะปรากฏเองในรายการมีเดียเซิร์ฟเวอร์บนทีวี พร้อมภาพตัวอย่างครบ เปิดบนทีวีแล้วเพลิดเพลินกับคลังของคุณบนจอใหญ่ - ไม่ต้องใช้สายและไม่ต้องมีแอปเพิ่ม
{{% /details %}}

{{% details title="ฉันจะเปิดไฟล์ในเว็บเบราว์เซอร์ได้อย่างไร?" closed="true" %}}
แตะ Start แล้ว Everdisk จะให้ที่อยู่เว็บง่าย ๆ สำหรับเซิร์ฟเวอร์ HTTP<br><br>

แชร์ลิงก์นั้นกับใครก็ได้บนเครือข่ายเดียวกัน เขาเปิดในเว็บเบราว์เซอร์ใดก็ได้เพื่อเรียกดูไฟล์ของคุณแบบกริดหรือรายการที่เรียบร้อย ดูรูปในแกลเลอรีเต็มจอ เล่นเพลงในเครื่องเล่นในตัว และดาวน์โหลดอะไรก็ได้ ไม่ต้องติดตั้งอะไรบนเครื่องของเขา จึงเป็นวิธีที่เร็วที่สุดในการส่งไฟล์ให้อีกโทรศัพท์หรือคอมพิวเตอร์
{{% /details %}}

{{% details title="Everdisk ใช้งานได้โดยไม่มี Wi-Fi หรือไม่?" closed="true" %}}
ได้ ต่ออุปกรณ์ของคุณเข้ากับ Mac ด้วยสาย USB เส้นเดียวกับที่คุณใช้ชาร์จ แล้วไฟล์จะวิ่งตรงผ่านสาย เร็วกว่า Wi-Fi<br><br>

เพราะไม่ต้องพึ่งเครือข่ายไร้สาย มันจึงยังใช้ได้บนเครื่องบิน ในโรงแรม หรือบนเครือข่ายที่ถูกล็อกหรือสาธารณะที่การแชร์ผ่าน Wi-Fi ถูกบล็อก
{{% /details %}}

{{% details title="ฉันเชื่อมต่อกับอะไรได้บ้างด้วย Everdisk?" closed="true" %}}
Everdisk ยังเป็นไคลเอนต์สำหรับอุปกรณ์อื่นบนเครือข่ายของคุณด้วย คุณสามารถค้นหาและเชื่อมต่อกับเซิร์ฟเวอร์ <strong>DLNA</strong>, <strong>WebDAV</strong>, <strong>FTP</strong>, <strong>SFTP</strong> และ <strong>SMB</strong> รวมถึง Mac, พีซี Windows, เครื่อง Linux, อุปกรณ์ NAS และมีเดียเซิร์ฟเวอร์<br><br>

เมื่อเชื่อมต่อแล้ว คุณสามารถเรียกดูโฟลเดอร์ สตรีมเสียงและวิดีโอ ดาวน์โหลดไฟล์ และสร้างโฟลเดอร์ อัปโหลด เปลี่ยนชื่อ ย้ายหรือลบได้เมื่อเซิร์ฟเวอร์อนุญาต
{{% /details %}}

{{% details title="ฉันสแกนเอกสารและทำงานกับ PDF ได้ไหม?" closed="true" %}}
ได้ Everdisk สามารถสแกนเอกสารกระดาษด้วยกล้องของคุณ - หาขอบให้อัตโนมัติ ปรับทุกหน้าให้ตรง และบันทึกเป็น PDF หลายหน้าที่เรียบร้อยบนอุปกรณ์ของคุณได้เลย<br><br>

คุณยังเปิด PDF (หรือรูปภาพ) แล้ว <strong>มาร์กอัป</strong> ในโปรแกรมดูในตัวได้เลย - วาด ไฮไลต์ เพิ่มข้อความและรูปทรง และเซ็นชื่อด้วยนิ้ว - และการเปลี่ยนแปลงของคุณจะบันทึกกลับลงไฟล์<br><br>

ยิ่งไปกว่านั้น Everdisk มี <strong>เครื่องมือ PDF</strong> ครบชุด เปิดจากเมนู <strong>•••</strong> ของ PDF ในตัวเรียกดู Files:<br>
• <strong>บีบอัด</strong> - ย่อ PDF ให้เล็กลง พร้อมแสดงขนาดโดยประมาณก่อนบันทึก<br>
• <strong>การรู้จำข้อความ (OCR)</strong> - เปลี่ยนไฟล์สแกนให้เป็น PDF ที่ค้นหาได้ หรือส่งออกข้อความเป็นไฟล์ .txt<br>
• <strong>รหัสผ่าน</strong> - ตั้ง เปลี่ยน หรือลบรหัสผ่านที่ต้องใช้เปิด PDF<br>
• <strong>สิทธิ์</strong> - ตรวจสอบว่า PDF อนุญาตอะไรบ้าง (พิมพ์ คัดลอก และอื่น ๆ)<br>
• <strong>แก้ไขข้อมูลเมตา</strong> - เปลี่ยนหรือล้างชื่อเรื่อง ผู้เขียน คำสำคัญ และข้อมูลเอกสารอื่น ๆ<br>
• <strong>ทำให้แบนราบ</strong> - ฝังคำอธิบายประกอบและรายการในฟอร์มลงในหน้าเพื่อไม่ให้แก้ไขได้อีก
{{% /details %}}

{{% details title="Everdisk เป็นส่วนตัวและปลอดภัยหรือไม่?" closed="true" %}}
ทุกอย่างอยู่บนเครือข่ายท้องถิ่นของคุณและไม่เคยแตะต้องอินเทอร์เน็ต ไฟล์ของคุณจึงไม่เคยออกจากบ้าน ไม่มีบัญชีและไม่มีคลาวด์อยู่ตรงกลาง<br><br>

คุณสามารถป้องกันการเข้าถึงด้วยล็อกอินและรหัสผ่าน อุปกรณ์ที่เชื่อมต่อจึงต้องกรอกรายละเอียดเดียวกันก่อนจึงจะเห็นไฟล์ของคุณ และคุณสามารถบล็อกอุปกรณ์ใดก็ได้บนเครือข่ายด้วยการแตะเพียงครั้งเดียว เพื่อความเป็นส่วนตัวที่ดีที่สุด ให้เปิดการแชร์เฉพาะขณะที่คุณเชื่อมต่อกับเครือข่าย Wi-Fi ที่คุณรู้จักและไว้ใจ
{{% /details %}}

{{% details title="ฉันทำอะไรได้บ้างด้วยตัวจัดการไฟล์?" closed="true" %}}
Everdisk มีตัวจัดการไฟล์ครบครันสำหรับทุกอย่างบนอุปกรณ์ของคุณ<br><br>

คุณสามารถเรียกดูแบบรายการหรือกริด สร้างโฟลเดอร์ เปลี่ยนชื่อ ย้าย คัดลอก บีบอัดและแตกไฟล์ zip และลบได้ คุณยังเชื่อมต่อโฟลเดอร์จากที่ใดก็ได้บนอุปกรณ์ของคุณและทำงานกับมันในแอปได้เลย แล้วแชร์ผ่านเครือข่ายควบคู่ไปกับทุกอย่าง
{{% /details %}}

{{% details title="ฉันเล่นเพลงในแอปได้ไหม?" closed="true" %}}
ได้ แตะไฟล์เสียงใดก็ได้แล้วมันจะเล่นในเครื่องเล่นขนาดเล็กที่ค้างอยู่ด้านล่างของหน้าจอขณะที่คุณเรียกดูต่อ<br><br>

เครื่องเล่นขนาดเล็กมีคิวเต็มรูปแบบพร้อมสลับเพลงและเล่นซ้ำ (ปิด ทั้งหมด หรือหนึ่งเพลง) และปุ่มควบคุมบนหน้าจอล็อกและปุ่มมีเดียที่แสดงชื่อ ศิลปิน และอัลบั้มจริง แตะหรือปัดขึ้นเพื่อเปิดเครื่องเล่นเต็มรูปแบบ และปัดลงเพื่อย่อขณะที่เสียงยังเล่นต่อ การแตะเพลงหนึ่งในโฟลเดอร์จะเล่นทั้งโฟลเดอร์เป็นคิว<br><br>

เสียงเล่นได้จากไฟล์ในเครื่อง โฟลเดอร์ที่เชื่อมต่อ คลังเพลงของคุณ และเซิร์ฟเวอร์ที่คุณเชื่อมต่อในแท็บอุปกรณ์
{{% /details %}}

{{% details title="ฉันดูวิดีโอในแอปได้ไหม?" closed="true" %}}
ได้ แตะวิดีโอเพื่อเล่นแบบเต็มจอ Everdisk ใช้เครื่องเล่นวิดีโอในตัวของระบบ คุณจึงได้ปุ่มควบคุมที่คุ้นเคย รวมถึง AirPlay, Picture in Picture และความเร็วในการเล่น<br><br>

วิดีโอเล่นได้จากไฟล์ในเครื่องและโฟลเดอร์ที่เชื่อมต่อ หรือสตรีมตรงจากอุปกรณ์ที่คุณเชื่อมต่อในแท็บอุปกรณ์ คุณจึงไม่ต้องดาวน์โหลดทั้งไฟล์ก่อน
{{% /details %}}

{{% details title="ฉันจะดูรูปภาพของฉันได้อย่างไร?" closed="true" %}}
เปิดแท็บเอกสาร แล้วสลับไปโหมดรูปภาพ เพื่อเรียกดูรูปภาพและวิดีโอของคุณ แตะรูปเพื่อเปิดแบบเต็มจอ ที่ซึ่งคุณสามารถซูม ปัดระหว่างรูป และแชร์ได้<br><br>

รูปภาพของคุณยังแสดงภาพตัวอย่างจริงบนทีวีผ่าน DLNA และในเว็บเบราว์เซอร์ ที่ซึ่งมันเปิดในแกลเลอรีเต็มจอพร้อมการปัด บีบเพื่อซูม และสไลด์โชว์ รูปภาพและวิดีโอที่มีข้อมูลตำแหน่งจะแสดงแผนที่พร้อมหมุดในหน้าจอข้อมูล
{{% /details %}}
