Everdisk เป็นแอปไดรฟ์ไร้สายสำหรับ iPhone และ iPad ที่พัฒนาโดย Everappz มันเปลี่ยนอุปกรณ์ของคุณให้เป็นศูนย์กลางที่แชร์ไฟล์ รูปภาพ วิดีโอ และเพลงกับทุกสิ่งบนเครือข่ายท้องถิ่นของคุณ โดยไม่ต้องมีบัญชี ไม่ต้องใช้คลาวด์ และไม่ต้องติดตั้งแอปเพิ่มเติมที่ฝั่งอื่น แอปนี้รันสี่เซิร์ฟเวอร์พร้อมกัน - DLNA สำหรับสมาร์ททีวีและเครื่องเล่นสื่อ, HTTP สำหรับเว็บเบราว์เซอร์ใดก็ได้, WebDAV สำหรับ Finder, Windows และ Linux และ FTP สำหรับแอปไฟล์และผู้ใช้ระดับสูง - ดังนั้นทุกอุปกรณ์จึงเชื่อมต่อได้ตามที่ต้องการ คุณสามารถสตรีมรูปภาพ วิดีโอ และเพลงตรงไปยังสมาร์ททีวีผ่าน DLNA พร้อมภาพตัวอย่างขนาดย่อ แชร์ลิงก์ง่ายๆ ที่เปิดในเบราว์เซอร์ใดก็ได้เพื่อเรียกดูและดาวน์โหลดไฟล์ของคุณ หรือเมาต์อุปกรณ์ของคุณเป็นไดรฟ์เครือข่ายและลากไฟล์ได้ทั้งสองทิศทาง เมื่อไม่มี Wi-Fi คุณสามารถเชื่อมต่อกับ Mac ด้วยสาย USB และย้ายไฟล์เร็วกว่า Wi-Fi แม้บนเครื่องบินหรือเครือข่ายที่ถูกล็อก Everdisk ยังเชื่อมต่อกับเซิร์ฟเวอร์ DLNA, WebDAV, FTP และ SFTP บนเครือข่ายของคุณเพื่อเรียกดู สตรีม และดาวน์โหลดไฟล์ของพวกเขา ตัวจัดการไฟล์ในตัวช่วยให้คุณเรียกดูแบบรายการหรือตาราง สร้างโฟลเดอร์ เปลี่ยนชื่อ ย้าย คัดลอก zip และ unzip และลบ คุณสามารถสแกนเอกสารกระดาษเป็น PDF ที่สะอาด เปิด PDF หรือรูปภาพและมาร์กอัปด้วยเครื่องมือแก้ไขในตัว - วาด ไฮไลต์ เพิ่มข้อความและลายเซ็น โดยการเปลี่ยนแปลงจะถูกบันทึกกลับไปยังไฟล์ - และใช้เครื่องมือ PDF ครบชุดเพื่อบีบอัดไฟล์ รู้จำข้อความ (OCR) เป็น PDF ที่ค้นหาได้ เพิ่มหรือลบรหัสผ่านเปิด ตรวจสอบสิทธิ์ แก้ไขข้อมูลเมตาของเอกสาร และรวมชั้นคำอธิบายประกอบและฟิลด์ฟอร์ม คุณยังสามารถเล่นเสียงในมินิเพลเยอร์และดูวิดีโอแบบเต็มหน้าจอ และแชร์คลังรูปภาพและเพลงทั้งหมดของคุณผ่านเครือข่ายในคุณภาพต้นฉบับหรือรูปแบบที่เข้ากันได้มากกว่า ทุกอย่างอยู่บนเครือข่ายท้องถิ่นของคุณและไม่เคยแตะอินเทอร์เน็ต และคุณสามารถป้องกันการเข้าถึงด้วยล็อกอินและรหัสผ่านและบล็อกอุปกรณ์ใดก็ได้ด้วยการแตะเพียงครั้งเดียว Everdisk ดาวน์โหลดได้ฟรีบน App Store พร้อมตัวเลือกการซื้อ Premium Lifetime แบบครั้งเดียว

{{% details title="Everdisk คืออะไร?" closed="true" %}}
Everdisk เปลี่ยน iPhone หรือ iPad ของคุณให้เป็นไดรฟ์ไร้สายและศูนย์กลางที่เชื่อมต่อกับอุปกรณ์อื่นๆ ของคุณด้วย<br>
คุณสามารถแชร์ไฟล์ รูปภาพ วิดีโอ และเพลงของคุณกับทุกสิ่งบนเครือข่ายของคุณ เรียกดูและสตรีมจากเซิร์ฟเวอร์อื่น และจัดการทุกอย่างตรงบนอุปกรณ์ของคุณ<br>
ไม่มีบัญชี ไม่มีคลาวด์ และไม่ต้องติดตั้งแอปเพิ่มเติมที่ฝั่งอื่น - คุณเพียงแตะ Start แล้วคุณก็พร้อม<br><br>

แอปนี้รันสี่เซิร์ฟเวอร์พร้อมกัน ดังนั้นทุกอุปกรณ์จึงเชื่อมต่อได้ตามที่ต้องการ: สมาร์ททีวีผ่าน DLNA, คอมพิวเตอร์และเว็บเบราว์เซอร์ผ่าน HTTP, Finder, Windows และ Linux ผ่าน WebDAV และแอปไฟล์ผ่าน FTP
{{% /details %}}

{{% details title="Everdisk ทำงานอย่างไร?" closed="true" %}}
เมื่อคุณแตะ Start Everdisk จะเริ่มแชร์เนื้อหาที่คุณเลือกและรันสี่เซิร์ฟเวอร์พร้อมกัน ดังนั้นอุปกรณ์ต่างๆ จึงเชื่อมต่อได้ในแบบที่พวกเขาต้องการ<br><br>

- <strong>DLNA</strong> ให้สมาร์ททีวีและเครื่องเล่นสื่อค้นหารูปภาพ วิดีโอ และเพลงของคุณโดยอัตโนมัติและแสดงพร้อมภาพตัวอย่างขนาดย่อ<br>
- <strong>HTTP</strong> ให้ทุกคนได้ลิงก์ง่ายๆ ที่พวกเขาสามารถเปิดในเว็บเบราว์เซอร์เพื่อเรียกดู ดูตัวอย่าง และดาวน์โหลดไฟล์ของคุณ โดยไม่ต้องติดตั้ง<br>
- <strong>WebDAV</strong> ทำให้อุปกรณ์ของคุณปรากฏเป็นไดรฟ์เครือข่ายปกติใน Finder, Windows หรือ Linux ดังนั้นคุณจึงลากไฟล์ได้ทั้งสองทิศทาง<br>
- <strong>FTP</strong> ทำงานกับแอปไฟล์และผู้ใช้ระดับสูง<br><br>

Everdisk ยังเชื่อมต่อในทางกลับกันไปยังเซิร์ฟเวอร์ DLNA, WebDAV, FTP และ SFTP บนเครือข่ายของคุณ ดังนั้นคุณจึงเรียกดูโฟลเดอร์ของพวกเขา สตรีมเสียงและวิดีโอ และดาวน์โหลดหรือจัดการไฟล์เมื่อเซิร์ฟเวอร์อนุญาต ทุกอย่างอยู่บนเครือข่ายท้องถิ่นของคุณและไม่เคยแตะอินเทอร์เน็ต
{{% /details %}}

{{% details title="Everdisk ฟรีไหม?" closed="true" %}}
ใช่ Everdisk ดาวน์โหลดได้ฟรี และคุณสามารถเปลี่ยนอุปกรณ์ของคุณให้เป็นไดรฟ์ไร้สาย แชร์ไฟล์ของคุณสี่ทาง เชื่อมต่อกับเซิร์ฟเวอร์อื่น และใช้ตัวจัดการไฟล์ในตัวได้โดยไม่มีค่าใช้จ่าย<br><br>

มีตัวเลือกการซื้อ <strong>Premium Lifetime</strong> แบบครั้งเดียว - การชำระเงินครั้งเดียวโดยไม่มีการสมัครสมาชิก - ที่ปลดล็อกโฟลเดอร์ที่แชร์และการเชื่อมต่อที่บันทึกไว้ไม่จำกัด, การแปลงรูปภาพ &amp; วิดีโอ, พอร์ตแบบกำหนดเอง, เริ่มการแชร์อัตโนมัติ และการปรับแต่งอุปกรณ์ มันผูกกับ Apple ID ของคุณ ดังนั้นคุณจึงใช้ Restore Purchases เพื่อปลดล็อกบนอุปกรณ์อื่นของคุณได้ ราคาอาจแตกต่างกันไปขึ้นอยู่กับประเทศหรือภูมิภาคของคุณ
{{% /details %}}

{{% details title="ฉันจะเชื่อมต่อจากคอมพิวเตอร์ของฉันได้อย่างไร?" closed="true" %}}
Everdisk ทำให้อุปกรณ์ของคุณปรากฏเป็นไดรฟ์เครือข่ายปกติผ่าน WebDAV<br><br>

- บน <strong>Mac</strong> เปิด Finder เลือก <em>Go → Connect to Server</em> และป้อนที่อยู่ WebDAV ที่แสดงในแอป<br>
- บน <strong>Windows</strong> แมปไดรฟ์เครือข่ายโดยใช้ที่อยู่ WebDAV เดียวกัน<br>
- บน <strong>Linux</strong> เชื่อมต่อกับที่อยู่ WebDAV จากตัวจัดการไฟล์ของคุณ<br><br>

เมื่อเชื่อมต่อแล้ว คุณสามารถลากและวางได้ทั้งสองทิศทาง: คัดลอกไฟล์จากคอมพิวเตอร์ไปยังอุปกรณ์ของคุณ หรือดึงกลับมา คุณยังสามารถเปิดลิงก์ HTTP ในเว็บเบราว์เซอร์ใดก็ได้หากคุณไม่ต้องการเมาต์ไดรฟ์
{{% /details %}}

{{% details title="ฉันจะสตรีมไปยังทีวีของฉันได้อย่างไร?" closed="true" %}}
ตรวจสอบให้แน่ใจว่าทีวีหรือเครื่องเล่นสื่อและอุปกรณ์ของคุณอยู่บนเครือข่าย Wi-Fi เดียวกัน จากนั้นแตะ Start ใน Everdisk โดยแชร์รูปภาพ วิดีโอ หรือเพลงของคุณ<br><br>

อุปกรณ์ของคุณจะปรากฏด้วยตัวเองในรายการเซิร์ฟเวอร์สื่อบนทีวี พร้อมภาพตัวอย่างขนาดย่อ เปิดมันบนทีวีแล้วเพลิดเพลินกับคลังของคุณบนจอใหญ่ - ไม่ต้องใช้สายและไม่ต้องมีแอปเพิ่มเติม
{{% /details %}}

{{% details title="ฉันจะเปิดไฟล์ของฉันในเว็บเบราว์เซอร์ได้อย่างไร?" closed="true" %}}
แตะ Start แล้ว Everdisk จะให้ที่อยู่เว็บง่ายๆ สำหรับเซิร์ฟเวอร์ HTTP<br><br>

แชร์ลิงก์นั้นกับใครก็ได้บนเครือข่ายเดียวกัน พวกเขาเปิดมันในเว็บเบราว์เซอร์ใดก็ได้เพื่อเรียกดูไฟล์ของคุณในตารางหรือรายการที่สะอาด ดูรูปภาพในแกลเลอรีเต็มหน้าจอ เล่นเพลงในเครื่องเล่นในตัว และดาวน์โหลดอะไรก็ได้ ไม่ต้องติดตั้งอะไรที่ฝั่งพวกเขา ซึ่งทำให้เป็นวิธีที่เร็วที่สุดในการส่งไฟล์ไปยังโทรศัพท์หรือคอมพิวเตอร์อีกเครื่อง
{{% /details %}}

{{% details title="Everdisk ทำงานได้โดยไม่มี Wi-Fi หรือไม่?" closed="true" %}}
ใช่ เชื่อมต่ออุปกรณ์ของคุณกับ Mac ด้วยสาย USB เดียวกันกับที่คุณใช้ชาร์จ แล้วไฟล์เคลื่อนที่ตรงผ่านสาย เร็วกว่า Wi-Fi<br><br>

เนื่องจากมันไม่ขึ้นอยู่กับเครือข่ายไร้สาย มันจึงยังคงทำงานบนเครื่องบิน ในโรงแรม หรือบนเครือข่ายที่ถูกล็อกหรือสาธารณะใดก็ตามที่การแชร์ Wi-Fi ถูกบล็อก
{{% /details %}}

{{% details title="ฉันเชื่อมต่อกับอะไรได้บ้างด้วย Everdisk?" closed="true" %}}
Everdisk ยังเป็นไคลเอนต์สำหรับอุปกรณ์อื่นบนเครือข่ายของคุณด้วย คุณสามารถค้นหาและเชื่อมต่อกับเซิร์ฟเวอร์ <strong>DLNA</strong>, <strong>WebDAV</strong>, <strong>FTP</strong> และ <strong>SFTP</strong> รวมถึงอุปกรณ์ NAS และเซิร์ฟเวอร์สื่อ<br><br>

เมื่อเชื่อมต่อแล้ว คุณสามารถเรียกดูโฟลเดอร์ของพวกเขา สตรีมเสียงและวิดีโอ ดาวน์โหลดไฟล์ และสร้างโฟลเดอร์ อัปโหลด เปลี่ยนชื่อ ย้าย หรือลบเมื่อเซิร์ฟเวอร์อนุญาต
{{% /details %}}

{{% details title="ฉันสแกนเอกสารและทำงานกับ PDF ได้ไหม?" closed="true" %}}
ใช่ Everdisk สามารถสแกนเอกสารกระดาษด้วยกล้องของคุณ - มันหาขอบให้อัตโนมัติ ปรับทุกหน้าให้ตรง และบันทึกเป็น PDF หลายหน้าที่สะอาดตรงบนอุปกรณ์ของคุณ<br><br>

คุณยังสามารถเปิด PDF (หรือรูปภาพ) และ <strong>มาร์กอัป</strong> ได้ในตัวแสดงในตัวเลย - วาด ไฮไลต์ เพิ่มข้อความและรูปทรง และเพิ่มลายเซ็นด้วยนิ้วของคุณ - และการเปลี่ยนแปลงของคุณจะถูกบันทึกกลับไปยังไฟล์<br><br>

นอกจากนั้น Everdisk ยังมี <strong>เครื่องมือ PDF</strong> ครบชุด เปิดจากเมนู <strong>•••</strong> ของ PDF ในเบราว์เซอร์ Files:<br>
• <strong>บีบอัด</strong> - ลดขนาด PDF โดยแสดงขนาดโดยประมาณก่อนที่คุณจะบันทึก<br>
• <strong>การรู้จำข้อความ (OCR)</strong> - เปลี่ยนภาพสแกนเป็น PDF ที่ค้นหาได้ หรือส่งออกข้อความเป็นไฟล์ .txt<br>
• <strong>รหัสผ่าน</strong> - ตั้ง เปลี่ยน หรือลบรหัสผ่านที่จำเป็นสำหรับการเปิด PDF<br>
• <strong>สิทธิ์</strong> - ตรวจสอบสิ่งที่ PDF อนุญาต (การพิมพ์ การคัดลอก และอื่นๆ)<br>
• <strong>แก้ไขข้อมูลเมตา</strong> - เปลี่ยนหรือล้างชื่อเรื่อง ผู้เขียน คีย์เวิร์ด และข้อมูลเอกสารอื่นๆ<br>
• <strong>รวมชั้น</strong> - ฝังคำอธิบายประกอบและรายการฟอร์มลงในหน้าเพื่อไม่ให้เปลี่ยนแปลงได้
{{% /details %}}

{{% details title="Everdisk เป็นส่วนตัวและปลอดภัยไหม?" closed="true" %}}
ทุกอย่างอยู่บนเครือข่ายท้องถิ่นของคุณและไม่เคยแตะอินเทอร์เน็ต ดังนั้นไฟล์ของคุณจึงไม่เคยออกจากบ้าน ไม่มีบัญชีและไม่มีคลาวด์อยู่ตรงกลาง<br><br>

คุณสามารถป้องกันการเข้าถึงด้วยล็อกอินและรหัสผ่าน ดังนั้นอุปกรณ์ที่เชื่อมต่อต้องกรอกรายละเอียดเดียวกันก่อนจึงจะเห็นไฟล์ของคุณได้ และคุณสามารถบล็อกอุปกรณ์ใดก็ได้บนเครือข่ายของคุณด้วยการแตะเพียงครั้งเดียว เพื่อความเป็นส่วนตัวที่ดีที่สุด เปิดการแชร์เฉพาะเมื่อคุณเชื่อมต่อกับเครือข่าย Wi-Fi ที่คุณรู้จักและไว้วางใจ
{{% /details %}}

{{% details title="ฉันทำอะไรได้บ้างกับตัวจัดการไฟล์?" closed="true" %}}
Everdisk มีตัวจัดการไฟล์ครบครันสำหรับทุกอย่างบนอุปกรณ์ของคุณ<br><br>

คุณสามารถเรียกดูแบบรายการหรือตาราง สร้างโฟลเดอร์ เปลี่ยนชื่อ ย้าย คัดลอก zip และ unzip และลบ คุณยังสามารถเชื่อมต่อโฟลเดอร์จากที่ใดก็ได้บนอุปกรณ์ของคุณและทำงานกับพวกมันในแอปเลย แล้วแชร์ผ่านเครือข่ายพร้อมกับทุกสิ่งอื่น
{{% /details %}}

{{% details title="ฉันเล่นเพลงในแอปได้ไหม?" closed="true" %}}
ใช่ แตะไฟล์เสียงใดก็ได้แล้วมันจะเล่นในมินิเพลเยอร์ที่อยู่ด้านล่างของหน้าจอในขณะที่คุณเรียกดูต่อไป<br><br>

มินิเพลเยอร์มีคิวครบครันพร้อมสุ่มและเล่นซ้ำ (ปิด ทั้งหมด หรือหนึ่ง) และการควบคุมหน้าจอล็อกและปุ่มสื่อที่แสดงชื่อ ศิลปิน และอัลบั้มจริง แตะหรือปัดขึ้นเพื่อเปิดเครื่องเล่นเต็มรูปแบบ และปัดลงเพื่อย่อมันในขณะที่เสียงยังคงเล่นอยู่ การแตะหนึ่งแทร็กในโฟลเดอร์จะเล่นทั้งโฟลเดอร์เป็นคิว<br><br>

เสียงเล่นจากไฟล์ในเครื่องของคุณ โฟลเดอร์ที่เชื่อมต่อ คลังเพลงของคุณ และเซิร์ฟเวอร์ที่คุณเชื่อมต่อในแท็บ Devices
{{% /details %}}

{{% details title="ฉันดูวิดีโอในแอปได้ไหม?" closed="true" %}}
ใช่ แตะวิดีโอเพื่อเล่นแบบเต็มหน้าจอ Everdisk ใช้เครื่องเล่นวิดีโอของระบบในตัว ดังนั้นคุณจึงได้การควบคุมที่คุ้นเคย รวมถึง AirPlay, Picture in Picture และความเร็วในการเล่น<br><br>

วิดีโอเล่นจากไฟล์ในเครื่องและโฟลเดอร์ที่เชื่อมต่อของคุณ หรือสตรีมตรงจากอุปกรณ์ที่คุณเชื่อมต่อในแท็บ Devices ดังนั้นคุณจึงไม่ต้องดาวน์โหลดไฟล์ทั้งหมดก่อน
{{% /details %}}

{{% details title="ฉันจะดูรูปภาพของฉันได้อย่างไร?" closed="true" %}}
เปิดแท็บ Documents และสลับไปยังโหมด Photos เพื่อเรียกดูรูปภาพและวิดีโอของคุณ แตะรูปภาพเพื่อเปิดแบบเต็มหน้าจอ ที่ซึ่งคุณสามารถซูม ปัดระหว่างรูปภาพ และแชร์<br><br>

รูปภาพของคุณยังแสดงภาพตัวอย่างขนาดย่อจริงบนทีวีผ่าน DLNA และในเว็บเบราว์เซอร์ ที่ซึ่งพวกมันเปิดในแกลเลอรีเต็มหน้าจอพร้อมปัด บีบเพื่อซูม และสไลด์โชว์ รูปภาพและวิดีโอที่มีข้อมูลตำแหน่งจะแสดงแผนที่พร้อมหมุดในหน้าจอ Info ของพวกมัน
{{% /details %}}
