Everdisk は Everappz が開発した iPhone と iPad 向けのワイヤレスドライブアプリです。デバイスを、ローカルネットワーク上のあらゆるものとファイル、写真、動画、音楽を共有するハブに変えます。アカウントもクラウドも不要で、相手側に追加でインストールするアプリもありません。このアプリは 4 つのサーバーを同時に実行します。スマート TV とメディアプレーヤー向けの DLNA、あらゆる Web ブラウザ向けの HTTP、Finder、Windows、Linux 向けの WebDAV、ファイルアプリとパワーユーザー向けの FTP で、どのデバイスも好みの方法で接続します。プレビューサムネイル付きで写真、動画、音楽を DLNA 経由でスマート TV へ直接ストリーミングしたり、任意のブラウザで開いてファイルを閲覧・ダウンロードできるシンプルなリンクを共有したり、デバイスをネットワークドライブとしてマウントして両方向にファイルをドラッグしたりできます。Wi-Fi がないときは、USB ケーブルで Mac に接続すれば、飛行機の中やロックされたネットワークでも Wi-Fi より速くファイルを移動できます。Everdisk はネットワーク上の DLNA、WebDAV、FTP、SFTP サーバーにも接続して、それらのファイルを閲覧、ストリーミング、ダウンロードできます。内蔵のファイルマネージャーでは、リストまたはグリッドでの閲覧、フォルダーの作成、名前変更、移動、コピー、圧縮と解凍、削除ができます。紙の書類をきれいな PDF にスキャンしたり、PDF や写真を開いて内蔵エディターでマークアップ（描画、ハイライト、テキストや署名の追加、変更はファイルに保存）したり、PDF ツール一式を使ってファイルを圧縮したり、テキストを認識（OCR）して検索可能な PDF にしたり、開くためのパスワードを追加・削除したり、権限を確認したり、書類メタデータを編集したり、注釈やフォームフィールドを平坦化したりできます。ミニプレーヤーで音声を再生し、動画を全画面で視聴でき、写真と音楽のライブラリ全体をオリジナル画質またはより互換性のある形式でネットワーク経由で共有できます。すべてはローカルネットワーク上にとどまり、インターネットに触れることはありません。ログインとパスワードでアクセスを保護し、どのデバイスもワンタップでブロックできます。Everdisk は App Store で無料でダウンロードでき、任意の 1 回限りの Premium Lifetime 購入があります。

{{% details title="Everdisk とは何ですか?" closed="true" %}}
Everdisk は iPhone または iPad をワイヤレスドライブに、そしてあなたの他のデバイスにも接続するハブに変えます。<br>
ファイル、写真、動画、音楽をネットワーク上のあらゆるものと共有し、他のサーバーから閲覧・ストリーミングし、すべてをデバイス上で直接管理できます。<br>
アカウントもクラウドも不要で、相手側に追加でインストールするアプリもありません。Start をタップするだけで準備完了です。<br><br>

このアプリは 4 つのサーバーを同時に実行するので、どのデバイスも好みの方法で接続します：DLNA でスマート TV、HTTP でコンピューターと Web ブラウザ、WebDAV で Finder、Windows、Linux、FTP でファイルアプリ。
{{% /details %}}

{{% details title="Everdisk はどのように動作しますか?" closed="true" %}}
Start をタップすると、Everdisk は選んだコンテンツの共有を開始し、4 つのサーバーを一度に実行するので、さまざまなデバイスが好みの方法で接続できます。<br><br>

- <strong>DLNA</strong> はスマート TV やメディアプレーヤーが写真、動画、音楽を自動的に見つけ、プレビューサムネイル付きで表示できるようにします。<br>
- <strong>HTTP</strong> は誰でも Web ブラウザで開いてファイルを閲覧、プレビュー、ダウンロードできるシンプルなリンクを提供します。インストールするものはありません。<br>
- <strong>WebDAV</strong> はデバイスを Finder、Windows、Linux で通常のネットワークドライブとして表示させ、両方向にファイルをドラッグできるようにします。<br>
- <strong>FTP</strong> はファイルアプリやパワーユーザーと連携します。<br><br>

Everdisk は逆方向にも、ネットワーク上の DLNA、WebDAV、FTP、SFTP サーバーに接続するので、それらのフォルダーを閲覧し、音声と動画をストリーミングし、サーバーが許可する場合はファイルをダウンロード・管理できます。すべてはローカルネットワーク上にとどまり、インターネットに触れることはありません。
{{% /details %}}

{{% details title="Everdisk は無料ですか?" closed="true" %}}
はい。Everdisk は無料でダウンロードでき、デバイスをワイヤレスドライブに変え、ファイルを 4 つの方法で共有し、他のサーバーに接続し、内蔵のファイルマネージャーを無料で使えます。<br><br>

任意の 1 回限りの <strong>Premium Lifetime</strong> 購入 - サブスクリプションなしの 1 回の支払い - があり、無制限の共有フォルダーと保存済み接続、写真 &amp; 動画の変換、カスタムポート、自動共有開始、デバイスのカスタマイズがアンロックされます。Apple ID に紐付けられているので、Restore Purchases を使って他のデバイスでアンロックできます。価格はお住まいの国や地域によって異なる場合があります。
{{% /details %}}

{{% details title="コンピューターからどうやって接続しますか?" closed="true" %}}
Everdisk はデバイスを WebDAV で通常のネットワークドライブとして表示させます。<br><br>

- <strong>Mac</strong> では Finder を開き、<em>Go → Connect to Server</em> を選び、アプリに表示された WebDAV アドレスを入力します。<br>
- <strong>Windows</strong> では、同じ WebDAV アドレスを使ってネットワークドライブを割り当てます。<br>
- <strong>Linux</strong> では、ファイルマネージャーから WebDAV アドレスに接続します。<br><br>

接続したら、両方向にドラッグ&ドロップできます：コンピューターからデバイスへファイルをコピーしたり、逆に取り戻したりできます。ドライブをマウントしたくない場合は、任意の Web ブラウザで HTTP リンクを開くこともできます。
{{% /details %}}

{{% details title="TV へどうやってストリーミングしますか?" closed="true" %}}
TV やメディアプレーヤーとデバイスが同じ Wi-Fi ネットワーク上にあることを確認してから、写真、動画、音楽を共有した状態で Everdisk の Start をタップします。<br><br>

デバイスがプレビューサムネイル付きで、TV のメディアサーバーの一覧に自動的に表示されます。TV でそれを開いて、大画面でライブラリを楽しみましょう。ケーブルも追加のアプリも必要ありません。
{{% /details %}}

{{% details title="Web ブラウザでどうやってファイルを開きますか?" closed="true" %}}
Start をタップすると、Everdisk が HTTP サーバー用のシンプルな Web アドレスを提供します。<br><br>

同じネットワーク上の誰とでもそのリンクを共有します。相手は任意の Web ブラウザで開いて、きれいなグリッドやリストでファイルを閲覧し、全画面ギャラリーで写真を表示し、内蔵プレーヤーで音楽を再生し、何でもダウンロードできます。相手側にインストールするものはないので、別のスマートフォンやコンピューターにファイルを渡す最速の方法です。
{{% /details %}}

{{% details title="Everdisk は Wi-Fi なしで動作しますか?" closed="true" %}}
はい。充電に使うのと同じ USB ケーブルでデバイスを Mac に接続すると、ファイルはケーブルを直接通り、Wi-Fi より速く移動します。<br><br>

ワイヤレスネットワークに依存しないため、飛行機の中、ホテル、Wi-Fi 共有がブロックされたロックされた、または公共のネットワークでも機能し続けます。
{{% /details %}}

{{% details title="Everdisk で何に接続できますか?" closed="true" %}}
Everdisk はネットワーク上の他のデバイスのクライアントでもあります。NAS デバイスやメディアサーバーを含む <strong>DLNA</strong>、<strong>WebDAV</strong>、<strong>FTP</strong>、<strong>SFTP</strong> サーバーを見つけて接続できます。<br><br>

接続したら、それらのフォルダーを閲覧し、音声と動画をストリーミングし、ファイルをダウンロードし、サーバーが許可する場合はフォルダーの作成、アップロード、名前変更、移動、削除ができます。
{{% /details %}}

{{% details title="書類をスキャンして PDF を操作できますか?" closed="true" %}}
はい。Everdisk はカメラで紙の書類をスキャンできます。自動的に端を見つけ、すべてのページをまっすぐにし、きれいな複数ページ PDF としてデバイス上に直接保存します。<br><br>

PDF（または写真）を開いて内蔵ビューアで直接 <strong>マークアップ</strong> することもできます。指で描画、ハイライト、テキストと図形の追加、署名の追加ができ、変更はファイルに保存されます。<br><br>

さらに、Everdisk には、Files ブラウザで PDF の <strong>•••</strong> メニューから開くフル機能の <strong>PDF ツール</strong> が含まれています。<br>
• <strong>圧縮</strong> - PDF を小さくします。保存前に推定サイズが表示されます。<br>
• <strong>テキスト認識 (OCR)</strong> - スキャンを検索可能な PDF に変えるか、テキストを .txt ファイルにエクスポートします。<br>
• <strong>パスワード</strong> - PDF を開くために必要なパスワードを設定、変更、削除します。<br>
• <strong>権限</strong> - PDF が許可する内容（印刷、コピーなど）を確認します。<br>
• <strong>メタデータ編集</strong> - タイトル、作成者、キーワード、その他の書類情報を変更またはクリアします。<br>
• <strong>平坦化</strong> - 注釈やフォーム入力をページに焼き込んで、変更できないようにします。
{{% /details %}}

{{% details title="Everdisk はプライベートで安全ですか?" closed="true" %}}
すべてはローカルネットワーク上にとどまり、インターネットに触れることはないので、ファイルが家を出ることはありません。間にアカウントもクラウドもありません。<br><br>

ログインとパスワードでアクセスを保護できるので、接続されたデバイスはファイルを見る前に同じ情報を入力する必要があり、ネットワーク上のどのデバイスもワンタップでブロックできます。最善のプライバシーのために、知っていて信頼できる Wi-Fi ネットワークに接続しているときだけ共有をオンにしてください。
{{% /details %}}

{{% details title="ファイルマネージャーで何ができますか?" closed="true" %}}
Everdisk にはデバイス上のすべてのためのフル機能のファイルマネージャーが含まれています。<br><br>

リストまたはグリッドで閲覧し、フォルダーの作成、名前変更、移動、コピー、圧縮と解凍、削除ができます。デバイス上のどこからでもフォルダーを接続してアプリ内で直接操作し、他のすべてと並べてネットワーク経由で共有することもできます。
{{% /details %}}

{{% details title="アプリ内で音楽を再生できますか?" closed="true" %}}
はい。任意の音声ファイルをタップすると、閲覧を続けている間も画面下部にとどまるミニプレーヤーで再生されます。<br><br>

ミニプレーヤーには、シャッフルとリピート（オフ、すべて、1 曲）付きのフルキュー、そして実際のタイトル、アーティスト、アルバムを表示するロック画面とメディアキーのコントロールがあります。タップまたは上にスワイプするとフルプレーヤーが開き、下にスワイプすると音声を再生したまま縮小します。フォルダー内の 1 つのトラックをタップすると、フォルダー全体がキューとして再生されます。<br><br>

音声はローカルファイル、接続されたフォルダー、Music ライブラリ、Devices タブで接続するサーバーから再生されます。
{{% /details %}}

{{% details title="アプリで動画を視聴できますか?" closed="true" %}}
はい。動画をタップして全画面で再生します。Everdisk は内蔵のシステム動画プレーヤーを使うので、AirPlay、Picture in Picture、再生速度を含むおなじみのコントロールが得られます。<br><br>

動画はローカルファイルと接続されたフォルダーから再生したり、Devices タブで接続するデバイスから直接ストリーミングしたりできるので、ファイル全体を先にダウンロードする必要はありません。
{{% /details %}}

{{% details title="写真をどうやって表示しますか?" closed="true" %}}
Documents タブを開いて Photos モードに切り替えると、写真と動画を閲覧できます。写真をタップすると全画面で開き、ズーム、写真間のスワイプ、共有ができます。<br><br>

写真は DLNA で TV に、そして Web ブラウザにも実際のプレビューサムネイルを表示し、そこではスワイプ、ピンチによるズーム、スライドショーができる全画面ギャラリーで開きます。位置情報のある写真と動画は、Info 画面にピン付きの地図を表示します。
{{% /details %}}
