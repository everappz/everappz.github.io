Everdisk는 Everappz가 개발한 iPhone과 iPad용 무선 드라이브 앱입니다. 계정, 클라우드, 상대편에 설치할 추가 앱 없이 로컬 네트워크의 모든 기기와 파일, 사진, 동영상, 음악을 공유하는 허브로 기기를 바꿔줍니다. 이 앱은 네 개의 서버를 동시에 실행합니다 - 스마트 TV와 미디어 플레이어를 위한 DLNA, 모든 웹 브라우저를 위한 HTTP, Finder와 Windows, Linux를 위한 WebDAV, 파일 앱과 고급 사용자를 위한 FTP - 그래서 모든 기기가 자기가 원하는 방식으로 연결됩니다. DLNA를 통해 미리보기 썸네일과 함께 사진, 동영상, 음악을 스마트 TV로 바로 스트리밍하거나, 모든 브라우저에서 열리는 간단한 링크를 공유하여 파일을 탐색하고 다운로드하거나, 기기를 네트워크 드라이브로 마운트하여 양방향으로 파일을 드래그할 수 있습니다. Wi-Fi가 없을 때는 USB 케이블로 Mac에 연결하여 Wi-Fi보다 빠르게 파일을 옮길 수 있으며, 비행기 안이나 잠긴 네트워크에서도 가능합니다. Everdisk는 또한 네트워크의 DLNA, WebDAV, FTP, SFTP 서버에 연결하여 파일을 탐색하고 스트리밍하고 다운로드합니다. 내장 파일 관리자로 목록 또는 그리드로 탐색하고, 폴더를 만들고, 이름을 바꾸고, 이동, 복사, zip과 unzip, 삭제할 수 있습니다. 종이 문서를 깔끔한 PDF로 스캔하고, PDF나 사진을 열어 내장 편집기로 마크업할 수 있으며 - 그리기, 강조, 텍스트와 서명 추가, 변경 사항은 파일에 다시 저장됨 - 파일을 압축하고, 텍스트를 인식(OCR)하여 검색 가능한 PDF로 만들고, 열기 암호를 추가하거나 제거하고, 권한을 검토하고, 문서 메타데이터를 편집하고, 주석과 양식 필드를 평면화하는 전체 PDF 도구 세트를 사용할 수 있습니다. 또한 미니 플레이어로 오디오를 재생하고 전체 화면으로 동영상을 보며, 전체 사진 및 음악 라이브러리를 원본 품질 또는 더 호환되는 형식으로 네트워크를 통해 공유할 수 있습니다. 모든 것은 로컬 네트워크에 머물며 인터넷에 절대 닿지 않고, 로그인과 암호로 접근을 보호하고 한 번의 탭으로 어떤 기기든 차단할 수 있습니다. Everdisk는 App Store에서 무료로 다운로드할 수 있으며 선택적으로 일회성 Premium Lifetime 구매가 가능합니다.

네트워크의 모든 것과 파일, 사진, 동영상, 음악을 공유하고, 다른 서버에서 탐색하고 스트리밍하며, 기기에서 바로 모든 것을 관리할 수 있습니다.<br>

{{% details title="Everdisk는 어떻게 작동하나요?" closed="true" %}}
시작을 탭하면 Everdisk는 선택한 콘텐츠를 공유하기 시작하고 네 개의 서버를 동시에 실행하여 여러 기기가 각자 선호하는 방식으로 연결될 수 있습니다.<br><br>

- <strong>DLNA</strong>는 스마트 TV와 미디어 플레이어가 사진, 동영상, 음악을 자동으로 찾아 미리보기 썸네일과 함께 표시하게 합니다.<br>

- <strong>FTP</strong>는 파일 앱과 고급 사용자에게 적합합니다.<br><br>

Everdisk는 반대 방향으로도 연결됩니다. 네트워크의 DLNA, WebDAV, FTP, SFTP 서버에 연결하여 폴더를 탐색하고, 오디오와 동영상을 스트리밍하고, 서버가 허용할 때 파일을 다운로드하거나 관리할 수 있습니다. 모든 것은 로컬 네트워크에 머물며 인터넷에 절대 닿지 않습니다.

또한 PDF(또는 사진)를 열어 내장 뷰어에서 바로 <strong>마크업</strong>할 수 있습니다 - 그리기, 강조, 텍스트와 도형 추가, 손가락으로 서명 추가 - 변경 사항은 파일에 다시 저장됩니다.<br><br>

• <strong>권한</strong> - PDF가 허용하는 것을 검토합니다 (인쇄, 복사 등).<br>
• <strong>메타데이터 편집</strong> - 제목, 작성자, 키워드 및 기타 문서 정보를 변경하거나 지웁니다.<br>
• <strong>평면화</strong> - 주석과 양식 입력을 페이지에 새겨 넣어 변경할 수 없게 합니다.
{{% /details %}}

{{% details title="Everdisk는 비공개이고 안전한가요?" closed="true" %}}
모든 것은 로컬 네트워크에 머물며 인터넷에 절대 닿지 않으므로 파일이 집을 떠나지 않습니다. 중간에 계정도 클라우드도 없습니다.<br><br>

로그인과 암호로 접근을 보호하여 연결된 기기가 파일을 보기 전에 같은 정보를 입력하게 할 수 있으며, 한 번의 탭으로 네트워크의 어떤 기기든 차단할 수 있습니다. 최상의 개인정보 보호를 위해 알고 신뢰하는 Wi-Fi 네트워크에 연결되어 있을 때만 공유를 켜세요.
{{% /details %}}

{{% details title="파일 관리자로 무엇을 할 수 있나요?" closed="true" %}}
Everdisk는 기기의 모든 것을 위한 완전한 파일 관리자를 포함합니다.<br><br>

목록 또는 그리드로 탐색하고, 폴더를 만들고, 이름을 바꾸고, 이동, 복사, zip과 unzip, 삭제할 수 있습니다. 또한 기기의 어디에서나 폴더를 연결하여 앱에서 바로 작업하고, 다른 모든 것과 함께 네트워크로 공유할 수 있습니다.
{{% /details %}}

{{% details title="앱 안에서 음악을 재생할 수 있나요?" closed="true" %}}
네. 오디오 파일을 탭하면 탐색을 계속하는 동안 화면 하단에 머무는 미니 플레이어에서 재생됩니다.<br><br>

미니 플레이어에는 셔플과 반복(끄기, 전체, 하나)이 있는 완전한 대기열과, 실제 제목, 아티스트, 앨범을 표시하는 잠금 화면 및 미디어 키 컨트롤이 있습니다. 탭하거나 위로 스와이프하여 전체 플레이어를 열고, 아래로 스와이프하여 오디오가 계속 재생되는 동안 축소하세요. 폴더에서 한 트랙을 탭하면 전체 폴더가 대기열로 재생됩니다.<br><br>

오디오는 로컬 파일, 연결된 폴더, 음악 라이브러리, 그리고 장치 탭에서 연결하는 서버에서 재생됩니다.
{{% /details %}}

{{% details title="앱에서 동영상을 볼 수 있나요?" closed="true" %}}
네. 동영상을 탭하면 전체 화면으로 재생됩니다. Everdisk는 내장 시스템 동영상 플레이어를 사용하므로 AirPlay, Picture in Picture, 재생 속도를 포함한 익숙한 컨트롤을 사용할 수 있습니다.<br><br>

동영상은 로컬 파일과 연결된 폴더에서 재생되거나, 장치 탭에서 연결하는 기기에서 바로 스트리밍되므로 전체 파일을 먼저 다운로드할 필요가 없습니다.
{{% /details %}}

{{% details title="사진을 어떻게 보나요?" closed="true" %}}
문서 탭을 열고 사진 모드로 전환하여 사진과 동영상을 탐색하세요. 사진을 탭하면 전체 화면으로 열리며 확대하고, 사진 사이를 스와이프하고, 공유할 수 있습니다.<br><br>

사진은 DLNA를 통해 TV에서, 그리고 웹 브라우저에서도 실제 미리보기 썸네일을 표시하며, 스와이프, 핀치 확대, 슬라이드쇼가 가능한 전체 화면 갤러리에서 열립니다. 위치 데이터가 있는 사진과 동영상은 정보 화면에 핀이 있는 지도를 표시합니다.
{{% /details %}}
