Everdisk adalah aplikasi drive nirkabel untuk iPhone dan iPad yang dikembangkan oleh Everappz. Aplikasi ini mengubah perangkat Anda menjadi pusat yang membagikan file, foto, video, dan musik ke apa pun di jaringan lokal Anda, tanpa akun, tanpa cloud, dan tanpa aplikasi tambahan yang perlu dipasang di sisi lain. Aplikasi ini menjalankan empat server sekaligus - DLNA untuk smart TV dan pemutar media, HTTP untuk peramban web mana pun, WebDAV untuk Finder, Windows dan Linux, serta FTP untuk aplikasi file dan pengguna tingkat lanjut - sehingga setiap perangkat terhubung dengan caranya sendiri. Anda dapat melakukan streaming foto, video, dan musik langsung ke smart TV melalui DLNA dengan thumbnail pratinjau, membagikan tautan sederhana yang bisa dibuka di peramban mana pun untuk menjelajahi dan mengunduh file Anda, atau memasang perangkat Anda sebagai network drive dan menyeret file ke kedua arah. Ketika tidak ada Wi-Fi, Anda dapat terhubung ke Mac dengan kabel USB dan memindahkan file lebih cepat daripada Wi-Fi, bahkan di dalam pesawat atau di jaringan terkunci. Everdisk juga terhubung ke server DLNA, WebDAV, FTP, dan SFTP di jaringan Anda untuk menjelajahi, streaming, dan mengunduh file mereka. Pengelola file bawaan memungkinkan Anda menjelajah dalam tampilan daftar atau kisi, membuat folder, mengganti nama, memindahkan, menyalin, zip dan unzip, serta menghapus. Anda dapat memindai dokumen kertas menjadi PDF yang bersih, membuka PDF atau foto dan menandainya dengan editor bawaan - menggambar, menyorot, menambahkan teks dan tanda tangan, dengan perubahan yang disimpan kembali ke file - serta menggunakan rangkaian alat PDF lengkap untuk mengompres file, mengenali teks (OCR) menjadi PDF yang dapat dicari, menambah atau menghapus kata sandi pembuka, meninjau izin, mengedit metadata dokumen, dan meratakan anotasi serta bidang formulir. Anda juga dapat memutar audio di pemutar mini dan menonton video layar penuh, serta membagikan seluruh pustaka foto dan musik Anda melalui jaringan dalam kualitas asli atau format yang lebih kompatibel. Semuanya tetap berada di jaringan lokal Anda dan tidak pernah menyentuh internet, dan Anda dapat melindungi akses dengan login dan kata sandi serta memblokir perangkat apa pun dengan satu ketukan. Everdisk dapat diunduh gratis di App Store dengan pembelian Premium Lifetime satu kali yang bersifat opsional.

{{% details title="Apa itu Everdisk?" closed="true" %}}
Everdisk mengubah iPhone atau iPad Anda menjadi drive nirkabel dan pusat yang juga terhubung ke perangkat Anda yang lain.<br>
Anda dapat membagikan file, foto, video, dan musik Anda ke apa pun di jaringan Anda, menjelajahi dan streaming dari server lain, serta mengelola semuanya langsung di perangkat Anda.<br>
Tidak ada akun, tidak ada cloud, dan tidak ada aplikasi tambahan yang perlu dipasang di sisi lain - Anda cukup mengetuk Mulai dan Anda siap.<br><br>

Aplikasi ini menjalankan empat server sekaligus, sehingga setiap perangkat terhubung dengan caranya sendiri: smart TV melalui DLNA, komputer dan peramban web melalui HTTP, Finder, Windows dan Linux melalui WebDAV, serta aplikasi file melalui FTP.
{{% /details %}}

{{% details title="Bagaimana cara kerja Everdisk?" closed="true" %}}
Saat Anda mengetuk Mulai, Everdisk mulai membagikan konten yang Anda pilih dan menjalankan empat server sekaligus sehingga berbagai perangkat dapat terhubung dengan cara yang mereka sukai.<br><br>

- <strong>DLNA</strong> memungkinkan smart TV dan pemutar media menemukan foto, video, dan musik Anda secara otomatis dan menampilkannya dengan thumbnail pratinjau.<br>
- <strong>HTTP</strong> memberi siapa pun tautan sederhana yang dapat mereka buka di peramban web untuk menjelajahi, melihat pratinjau, dan mengunduh file Anda, tanpa perlu memasang apa pun.<br>
- <strong>WebDAV</strong> membuat perangkat Anda muncul sebagai network drive biasa di Finder, Windows atau Linux sehingga Anda dapat menyeret file ke kedua arah.<br>
- <strong>FTP</strong> bekerja dengan aplikasi file dan pengguna tingkat lanjut.<br><br>

Everdisk juga terhubung ke arah sebaliknya, ke server DLNA, WebDAV, FTP dan SFTP di jaringan Anda, sehingga Anda dapat menjelajahi folder mereka, streaming audio dan video, serta mengunduh atau mengelola file jika server mengizinkannya. Semuanya tetap berada di jaringan lokal Anda dan tidak pernah menyentuh internet.
{{% /details %}}

{{% details title="Apakah Everdisk gratis?" closed="true" %}}
Ya. Everdisk dapat diunduh gratis dan Anda dapat mengubah perangkat Anda menjadi drive nirkabel, membagikan file Anda dengan empat cara, terhubung ke server lain, serta menggunakan pengelola file bawaan tanpa biaya.<br><br>

Ada pembelian <strong>Premium Lifetime</strong> satu kali yang bersifat opsional - sekali bayar tanpa langganan - yang membuka folder bersama dan koneksi tersimpan tanpa batas, konversi foto &amp; video, port kustom, mulai berbagi otomatis, dan kustomisasi perangkat. Pembelian ini terikat dengan Apple ID Anda, sehingga Anda dapat menggunakan Pulihkan Pembelian untuk membukanya di perangkat Anda yang lain. Harga dapat bervariasi tergantung negara atau wilayah Anda.
{{% /details %}}

{{% details title="Bagaimana cara terhubung dari komputer saya?" closed="true" %}}
Everdisk membuat perangkat Anda muncul sebagai network drive biasa melalui WebDAV.<br><br>

- Di <strong>Mac</strong>, buka Finder, pilih <em>Go → Connect to Server</em>, lalu masukkan alamat WebDAV yang ditampilkan di aplikasi.<br>
- Di <strong>Windows</strong>, petakan network drive menggunakan alamat WebDAV yang sama.<br>
- Di <strong>Linux</strong>, terhubung ke alamat WebDAV dari pengelola file Anda.<br><br>

Setelah terhubung, Anda dapat menyeret dan melepas ke kedua arah: salin file dari komputer Anda ke perangkat Anda, atau tarik kembali. Anda juga dapat membuka tautan HTTP di peramban web mana pun jika Anda lebih suka tidak memasang drive.
{{% /details %}}

{{% details title="Bagaimana cara streaming ke TV saya?" closed="true" %}}
Pastikan TV atau pemutar media Anda dan perangkat Anda berada di jaringan Wi-Fi yang sama, lalu ketuk Mulai di Everdisk dengan foto, video atau musik Anda dibagikan.<br><br>

Perangkat Anda akan muncul dengan sendirinya dalam daftar server media di TV, lengkap dengan thumbnail pratinjau. Bukalah di TV dan nikmati pustaka Anda di layar besar - tanpa kabel dan tanpa aplikasi tambahan.
{{% /details %}}

{{% details title="Bagaimana cara membuka file saya di peramban web?" closed="true" %}}
Ketuk Mulai dan Everdisk memberi Anda alamat web sederhana untuk server HTTP.<br><br>

Bagikan tautan itu dengan siapa pun di jaringan yang sama. Mereka membukanya di peramban web mana pun untuk menjelajahi file Anda dalam kisi atau daftar yang rapi, melihat foto di galeri layar penuh, memutar musik di pemutar bawaan, dan mengunduh apa pun. Tidak ada yang perlu dipasang di sisi mereka, yang menjadikannya cara tercepat untuk memberikan file ke ponsel atau komputer lain.
{{% /details %}}

{{% details title="Apakah Everdisk berfungsi tanpa Wi-Fi?" closed="true" %}}
Ya. Hubungkan perangkat Anda ke Mac dengan kabel USB yang sama yang Anda gunakan untuk mengisi daya, dan file berpindah langsung melalui kabel, lebih cepat daripada Wi-Fi.<br><br>

Karena tidak bergantung pada jaringan nirkabel, ini tetap berfungsi di dalam pesawat, di hotel, atau di jaringan terkunci atau publik mana pun tempat berbagi Wi-Fi diblokir.
{{% /details %}}

{{% details title="Apa saja yang dapat saya hubungkan dengan Everdisk?" closed="true" %}}
Everdisk juga merupakan klien untuk perangkat lain di jaringan Anda. Anda dapat menemukan dan terhubung ke server <strong>DLNA</strong>, <strong>WebDAV</strong>, <strong>FTP</strong> dan <strong>SFTP</strong>, termasuk perangkat NAS dan server media.<br><br>

Setelah terhubung, Anda dapat menjelajahi folder mereka, streaming audio dan video, mengunduh file, serta membuat folder, mengunggah, mengganti nama, memindahkan atau menghapus jika server mengizinkannya.
{{% /details %}}

{{% details title="Bisakah saya memindai dokumen dan bekerja dengan PDF?" closed="true" %}}
Ya. Everdisk dapat memindai dokumen kertas dengan kamera Anda - menemukan tepinya secara otomatis, meluruskan setiap halaman, dan menyimpannya sebagai PDF multi-halaman yang bersih langsung di perangkat Anda.<br><br>

Anda juga dapat membuka PDF (atau foto) dan <strong>menandainya</strong> langsung di penampil bawaan - menggambar, menyorot, menambahkan teks dan bentuk, serta menambahkan tanda tangan dengan jari Anda - dan perubahan Anda disimpan kembali ke file.<br><br>

Selain itu, Everdisk menyertakan rangkaian <strong>Alat PDF</strong> lengkap, yang dibuka dari menu <strong>•••</strong> pada PDF di penjelajah File:<br>
• <strong>Kompres</strong> - perkecil PDF, dengan perkiraan ukuran yang ditampilkan sebelum Anda menyimpan.<br>
• <strong>Pengenalan Teks (OCR)</strong> - ubah hasil pindaian menjadi PDF yang dapat dicari, atau ekspor teks ke file .txt.<br>
• <strong>Kata Sandi</strong> - atur, ubah atau hapus kata sandi yang diperlukan untuk membuka PDF.<br>
• <strong>Izin</strong> - tinjau apa yang diizinkan oleh PDF (pencetakan, penyalinan, dan lainnya).<br>
• <strong>Edit Metadata</strong> - ubah atau hapus judul, penulis, kata kunci dan info dokumen lainnya.<br>
• <strong>Ratakan</strong> - tanamkan anotasi dan entri formulir ke dalam halaman sehingga tidak dapat diubah.
{{% /details %}}

{{% details title="Apakah Everdisk pribadi dan aman?" closed="true" %}}
Semuanya tetap berada di jaringan lokal Anda dan tidak pernah menyentuh internet, sehingga file Anda tidak pernah meninggalkan rumah. Tidak ada akun dan tidak ada cloud di tengahnya.<br><br>

Anda dapat melindungi akses dengan login dan kata sandi sehingga perangkat yang terhubung harus memasukkan detail yang sama sebelum dapat melihat file Anda, dan Anda dapat memblokir perangkat apa pun di jaringan Anda dengan satu ketukan. Untuk privasi terbaik, aktifkan berbagi hanya saat Anda terhubung ke jaringan Wi-Fi yang Anda kenal dan percayai.
{{% /details %}}

{{% details title="Apa yang dapat saya lakukan dengan pengelola file?" closed="true" %}}
Everdisk menyertakan pengelola file lengkap untuk semua yang ada di perangkat Anda.<br><br>

Anda dapat menjelajah dalam daftar atau kisi, membuat folder, mengganti nama, memindahkan, menyalin, zip dan unzip, serta menghapus. Anda juga dapat menghubungkan folder dari mana saja di perangkat Anda dan mengerjakannya langsung di dalam aplikasi, lalu membagikannya melalui jaringan bersama semua yang lainnya.
{{% /details %}}

{{% details title="Bisakah saya memutar musik di dalam aplikasi?" closed="true" %}}
Ya. Ketuk file audio apa pun dan file itu diputar di pemutar mini yang tetap berada di bagian bawah layar sementara Anda terus menjelajah.<br><br>

Pemutar mini memiliki antrean penuh dengan acak dan ulang (mati, semua, atau satu), serta kontrol layar kunci dan tombol media yang menampilkan judul, artis dan album yang sebenarnya. Ketuk atau geser ke atas untuk membuka pemutar penuh, dan geser ke bawah untuk mengecilkannya sementara audio terus diputar. Mengetuk satu trek dalam folder akan memutar seluruh folder sebagai antrean.<br><br>

Audio diputar dari file lokal Anda, folder yang terhubung, pustaka Musik Anda, dan server yang Anda hubungkan pada tab Perangkat.
{{% /details %}}

{{% details title="Bisakah saya menonton video di dalam aplikasi?" closed="true" %}}
Ya. Ketuk video untuk memutarnya layar penuh. Everdisk menggunakan pemutar video sistem bawaan, sehingga Anda mendapatkan kontrol yang familier, termasuk AirPlay, Picture in Picture, dan kecepatan pemutaran.<br><br>

Video diputar dari file lokal dan folder yang terhubung, atau di-streaming langsung dari perangkat yang Anda hubungkan pada tab Perangkat, sehingga Anda tidak perlu mengunduh seluruh file terlebih dahulu.
{{% /details %}}

{{% details title="Bagaimana cara melihat foto saya?" closed="true" %}}
Buka tab Dokumen dan beralih ke mode Foto untuk menjelajahi foto dan video Anda. Ketuk foto untuk membukanya layar penuh, tempat Anda dapat memperbesar, menggeser antar foto, dan membagikan.<br><br>

Foto Anda juga menampilkan thumbnail pratinjau asli di TV melalui DLNA dan di peramban web, tempat foto tersebut terbuka di galeri layar penuh dengan geser, cubit untuk memperbesar, dan tayangan slide. Foto dan video yang memiliki data lokasi menampilkan peta dengan pin pada layar Info-nya.
{{% /details %}}
