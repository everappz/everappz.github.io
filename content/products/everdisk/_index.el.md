Μπορείτε επίσης να ανοίξετε ένα PDF (ή μια φωτογραφία) και να το <strong>επισημειώσετε</strong> μέσα στον ενσωματωμένο προβολέα - να σχεδιάσετε, να επισημάνετε, να προσθέσετε κείμενο και σχήματα, και να προσθέσετε υπογραφή με το δάχτυλό σας - και οι αλλαγές σας αποθηκεύονται πίσω στο αρχείο.<br><br>

Επιπλέον, το Everdisk περιλαμβάνει ένα πλήρες σετ <strong>Εργαλείων PDF</strong>, που ανοίγει από το μενού <strong>•••</strong> ενός PDF στον περιηγητή αρχείων:<br>
• <strong>Συμπίεση</strong> - μικραίνει ένα PDF, με εκτιμώμενο μέγεθος να εμφανίζεται πριν την αποθήκευση.<br>
• <strong>Αναγνώριση κειμένου (OCR)</strong> - μετατρέπει μια σάρωση σε PDF με δυνατότητα αναζήτησης, ή εξάγει το κείμενο σε αρχείο .txt.<br>
• <strong>Κωδικός</strong> - ορίστε, αλλάξτε ή αφαιρέστε τον κωδικό που απαιτείται για το άνοιγμα του PDF.<br>
• <strong>Δικαιώματα</strong> - ελέγξτε τι επιτρέπει το PDF (εκτύπωση, αντιγραφή και άλλα).<br>
• <strong>Επεξεργασία μεταδεδομένων</strong> - αλλάξτε ή διαγράψτε τον τίτλο, τον συγγραφέα, τις λέξεις-κλειδιά και άλλες πληροφορίες του εγγράφου.<br>
• <strong>Ισοπέδωση</strong> - ενσωματώνει επισημειώσεις και καταχωρήσεις φόρμας στη σελίδα ώστε να μην μπορούν να αλλάξουν.
{{% /details %}}

{{% details title="Είναι ιδιωτικό και ασφαλές το Everdisk;" closed="true" %}}
Όλα παραμένουν στο τοπικό σας δίκτυο και δεν αγγίζουν ποτέ το διαδίκτυο, οπότε τα αρχεία σας δεν φεύγουν ποτέ από το σπίτι. Δεν υπάρχουν λογαριασμοί ούτε cloud στη μέση.<br><br>

Μπορείτε να προστατέψετε την πρόσβαση με όνομα χρήστη και κωδικό ώστε οι συνδεδεμένες συσκευές να πρέπει να εισάγουν τα ίδια στοιχεία πριν δουν τα αρχεία σας, και μπορείτε να αποκλείσετε οποιαδήποτε συσκευή στο δίκτυό σας με ένα άγγιγμα. Για τη μέγιστη ιδιωτικότητα, ενεργοποιήστε την κοινή χρήση μόνο όταν είστε συνδεδεμένοι σε ένα δίκτυο Wi-Fi που γνωρίζετε και εμπιστεύεστε.
{{% /details %}}

{{% details title="Τι μπορώ να κάνω με τον διαχειριστή αρχείων;" closed="true" %}}
Το Everdisk περιλαμβάνει έναν πλήρη διαχειριστή αρχείων για όλα όσα βρίσκονται στη συσκευή σας.<br><br>

Μπορείτε να περιηγηθείτε σε λίστα ή πλέγμα, να δημιουργήσετε φακέλους, να μετονομάσετε, να μετακινήσετε, να αντιγράψετε, να κάνετε zip και unzip, και να διαγράψετε. Μπορείτε επίσης να συνδέσετε φακέλους από οπουδήποτε στη συσκευή σας και να δουλέψετε με αυτούς μέσα στην εφαρμογή, και έπειτα να τους μοιραστείτε στο δίκτυο μαζί με όλα τα υπόλοιπα.
{{% /details %}}

{{% details title="Μπορώ να ακούσω μουσική μέσα στην εφαρμογή;" closed="true" %}}
Ναι. Πατήστε οποιοδήποτε αρχείο ήχου και παίζει στο mini player που παραμένει στο κάτω μέρος της οθόνης ενώ συνεχίζετε να περιηγείστε.<br><br>

Το mini player διαθέτει πλήρη ουρά με τυχαία σειρά και επανάληψη (καμία, όλα ή ένα), καθώς και χειριστήρια στην οθόνη κλειδώματος και στα πλήκτρα πολυμέσων που δείχνουν τον πραγματικό τίτλο, τον καλλιτέχνη και το άλμπουμ. Πατήστε ή σύρετε προς τα πάνω για να ανοίξετε το πλήρες player, και σύρετε προς τα κάτω για να το σμικρύνετε ενώ ο ήχος συνεχίζει να παίζει. Πατώντας ένα κομμάτι σε έναν φάκελο, παίζει ολόκληρος ο φάκελος ως ουρά.<br><br>

Ο ήχος παίζει από τα τοπικά σας αρχεία, τους συνδεδεμένους φακέλους, τη συλλογή Music σας και τους διακομιστές που συνδέεστε στην καρτέλα Συσκευές.
{{% /details %}}

{{% details title="Μπορώ να παρακολουθήσω βίντεο στην εφαρμογή;" closed="true" %}}
Ναι. Πατήστε ένα βίντεο για να παίξει σε πλήρη οθόνη. Το Everdisk χρησιμοποιεί τον ενσωματωμένο player βίντεο του συστήματος, οπότε έχετε τα οικεία χειριστήρια, συμπεριλαμβανομένων των AirPlay, Picture in Picture και ταχύτητας αναπαραγωγής.<br><br>

Τα βίντεο παίζουν από τα τοπικά σας αρχεία και τους συνδεδεμένους φακέλους, ή μεταδίδονται απευθείας από μια συσκευή που συνδέεστε στην καρτέλα Συσκευές, ώστε να μην χρειάζεται να κατεβάσετε πρώτα ολόκληρο το αρχείο.
{{% /details %}}

{{% details title="Πώς βλέπω τις φωτογραφίες μου;" closed="true" %}}
Ανοίξτε την καρτέλα Έγγραφα και μεταβείτε στη λειτουργία Φωτογραφίες για να περιηγηθείτε στις φωτογραφίες και τα βίντεό σας. Πατήστε μια φωτογραφία για να την ανοίξετε σε πλήρη οθόνη, όπου μπορείτε να κάνετε ζουμ, να σύρετε ανάμεσα στις φωτογραφίες και να τις μοιραστείτε.<br><br>

Οι φωτογραφίες σας εμφανίζουν επίσης πραγματικές μικρογραφίες προεπισκόπησης σε τηλεόραση μέσω DLNA και σε έναν browser, όπου ανοίγουν σε συλλογή πλήρους οθόνης με σάρωση, ζουμ με τσίμπημα και προβολή διαφανειών. Οι φωτογραφίες και τα βίντεο που έχουν δεδομένα τοποθεσίας εμφανίζουν έναν χάρτη με μια πινέζα στην οθόνη Πληροφοριών τους.
{{% /details %}}
