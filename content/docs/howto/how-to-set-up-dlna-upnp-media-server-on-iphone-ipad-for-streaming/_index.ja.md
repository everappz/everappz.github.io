DLNA (UPnP AV とも呼ばれます) は、ほとんどのスマート TV を支える縁の下の力持ちです。これは、TV やメディアプレーヤーが同じ Wi-Fi 上のメディアライブラリを見つけて再生できるようにする共通言語で、TV 側に何もインストールする必要はありません。iPhone や iPad をそのライブラリとして動かせれば、写真・動画・音楽が自動的に大画面に表示されます。

このガイドでは、[Everdisk](/products/everdisk) を使って iPhone や iPad を DLNA/UPnP メディアサーバーに変える方法と、そのライブラリをスマート TV、ゲーム機、VLC、Kodi、パソコン、Android スマホ、そしてもう 1 台の iPhone から開く方法を紹介します。すべてはローカルの Wi-Fi 内で動くので、どこにもアップロードされません。

## 必要なもの

- [Everdisk](https://apps.apple.com/app/apple-store/id6751851132?pt=95781850&ct=everappzcom&mt=8) をインストールした iPhone または iPad。
- お使いのデバイスと**同じ Wi-Fi ネットワーク**にある TV、プレーヤー、またはパソコン。
- 再生したい写真・動画・音楽が、すでに iPhone 内にあること (写真アプリ、ミュージックアプリ、または Everdisk の書類フォルダー内)。

## Everdisk で DLNA サーバーを設定する

### ステップ 1: 共有する内容を選ぶ

Everdisk を開き、**共有**タブに移動します。**共有する内容**をタップしてコンテンツを選びます。

- **すべての写真ライブラリへのアクセスを許可**をオンにするとすべてのアルバムを共有でき、**写真を追加**をタップすれば一部だけ選べます。
- **すべての音楽ライブラリへのアクセスを許可**をオンにすると曲を共有でき、**曲を追加**をタップすれば選んで共有できます。
- **フォルダを追加**や**ファイルを追加**で、任意のフォルダーやファイルを加えられます。アプリ自身の書類フォルダーは既定で共有されています。

共有を開始するには、少なくとも 1 つの項目を選んでおく必要があります。

### ステップ 2: TV とメディアセンター (DLNA) をオンにする

**設定**、**共有**、**接続**の順に進みます。**TV とメディアセンター**がオンになっていることを確認してください。既定でオンになっており、DLNA のタグが付いています。これが TV やプレーヤーが探すサーバーです。

### ステップ 3: 共有を開始する

**共有**タブに戻り、大きな**スタート**ボタンをタップします。これでお使いのデバイスは Wi-Fi 上のメディアサーバーになりました。他のデバイスからは、アプリでデバイス名として表示されているわかりやすい名前 (変更するまでは「Speedy-Hare」のような名前) で表示されます。

DLNA ストリーミングは常に開放されているので、TV 側でパスワードを入力する必要はありません。iOS は完全にバックグラウンドに回ったアプリを一時停止するため、視聴中は Everdisk を画面に開いたままにしてください。

## スマート TV で再生する

これが最も一般的なケースで、たいてい 30 秒ほどで済みます。

1. TV を iPhone と**同じ Wi-Fi** に接続します。
2. TV に内蔵のメディアプレーヤーを開きます。名前はメーカーによって異なり、**Media Player**、**Gallery**、**SmartShare** (LG)、**AllShare** や **SmartThings** (Samsung)、**Content Share**、**SimplyShare** などです。
3. メディアサーバーやソースの一覧を探します。そこにお使いのデバイスが名前で表示されます。
4. それを選び、写真・動画・音楽の中を進んで、再生を押します。

プレビューサムネイルが自動的に表示されるので、目的の旅行アルバムや映画を迷わずに見つけられます。

### どの TV が使えるか

**Samsung、LG、Sony BRAVIA、Panasonic (VIERA ファームウェア)、Philips、Hisense** のほとんどの TV は DLNA を内蔵しており、すぐに使えます。**PlayStation や Xbox のゲーム機、ほとんどの AV レシーバー**も同様です。

一部のプラットフォームは非対応です: **Roku TV、Amazon Fire TV、Vizio SmartCast、そしてメーカー独自のメディアアプリがない素の Google TV** です。お使いの TV がこれらのいずれかで、デバイスを見つけられない場合、たいていそれが原因です。これらの TV では、VLC や Kodi のような DLNA プレーヤーアプリをインストールするか、[WebDAV 設定ガイド](/docs/howto/how-to-set-up-webdav-server-on-iphone-ipad-for-file-access-and-sharing/)を使って Web ブラウザ経由でファイルにアクセスしてください。

一部のメーカーは公式の DLNA ロゴを外した後も DLNA を動作させ続けているので、見当たらないように見えても、上に挙げたメディアプレーヤー名を探してみてください。

## Windows、Mac、Linux の VLC や Kodi で再生する

VLC と Kodi は無料で、あらゆるデスクトップシステムで動き、DLNA をしっかり扱えます。パソコンで Everdisk のライブラリを開くための信頼できる方法です。

**VLC (Windows、Mac、Linux):**

1. VLC を開きます。
2. プレイリストを表示します (Windows と Linux では **Ctrl+L** を押し、Mac では表示メニューから **Playlist** を開きます)。
3. サイドバーで、ローカルネットワークの下にある **Universal Plug'n'Play** を開きます。
4. 一覧にお使いのデバイスが表示されます。そこに入ってファイルを選びます。

**Kodi (Windows、Mac、Linux):**

1. **Videos**、**Music**、または **Pictures** に進み、次に **Files**、そして **Add source** (または **Browse**) を選びます。
2. **UPnP devices** を選びます。
3. お使いのデバイスを選んでライブラリを閲覧します。

Windows では **Windows Media Player** を開き、サイドバーの **Other Libraries** を展開すると、そこにお使いのデバイスが表示されます。

## Android で再生する

Android のスマホやタブレットにはシステムの DLNA ブラウザがないので、アプリを使います:

- **VLC for Android**: サイドメニューを開いて **Local Network** をタップすると、UPnP サーバーの下にお使いのデバイスが表示されます。
- **BubbleUPnP** や類似の UPnP アプリ: サーバー一覧にお使いのデバイスが表示され、これらのアプリは再生を TV へ送ることもできます。

## 別の iPhone や iPad で再生する

2 台のデバイスで 1 つのライブラリを。たとえば写真が iPhone にあり、それを iPad で見たいとします。

- 一番簡単なのは、2 台目のデバイスで Everdisk 自身の**デバイス**タブを使う方法です。Everdisk は DLNA クライアントとしてもサーバーとしても動きます。iPad で Everdisk を開いて**デバイス**に移動すると、**利用可能なデバイス**の下に iPhone が表示されます。タップして閲覧・再生します。
- VLC や UPnP ブラウザなど、iOS 向けの DLNA プレーヤーアプリでも使えます。そのローカルネットワークの表示を開いて iPhone を選びます。

## ゲーム機で再生する

- **PlayStation 5 と 4**: **Media** アプリ (メディアギャラリー) を開くと、閲覧できるメディアサーバーとしてお使いのデバイスが表示されます。
- **Xbox**: DLNA に対応したメディアプレーヤーアプリを使い、サーバー一覧からお使いのデバイスを選びます。

## デバイスが一覧に表示されない場合

一部のプレーヤーでは、検出を待つ代わりにアドレスでメディアサーバーを追加できます。Everdisk の**共有**画面で、DLNA のカードには `/device-desc.xml` で終わるデバイス記述アドレスが表示されます。そのアドレスをプレーヤーのサーバー追加欄に入力してください。

それでも表示されない場合は、次の 3 点を確認します。両方のデバイスが同じ Wi-Fi にあること (デバイス間の通信をブロックするゲストネットワークではないこと)、Everdisk が開かれていて共有が開始されていること、そして設定で **TV とメディアセンター**がオンになっていることです。

## 動画が再生されない場合

DLNA はファイルをそのままの形で TV に渡すため、TV 側がそれをデコードできる必要があります。クリップが再生を拒否する場合、その形式がその TV でサポートされていない可能性が高いです。対処法は 2 つあります:

- **設定**、**共有**、**動画**の順に開き、**画質**を下げます。すると Everdisk がストリーミングしながら動画をより互換性の高い形式に変換します。(変換は Premium 機能です。)
- または、Everdisk のブラウザリンクを使って同じファイルを Web ブラウザで開きます。こちらは形式への対応がより柔軟です。

## 実際の活用シーン

- **家族の映画の夜。** スマホで撮った動画を、ケーブルや Apple TV なしでリビングの TV で再生できます。
- **旅行の写真を大画面で。** TV で写真ライブラリを開き、その場にいる全員で旅行の写真をスワイプして見られます。
- **パーティーの BGM。** DLNA スピーカーや AV レシーバーを音楽ライブラリに向けて流しっぱなしにできます。
- **ホテルの TV で視聴。** メディアプレーヤーを備えた TV なら、両方のデバイスを部屋の Wi-Fi につなげば見られます。

## いくつかのヒント

- ストリーミング中は Everdisk を開いたままにしてください。スマホを長時間ロックすると、iOS がアプリを一時停止して再生が止まることがあります。
- 長い映画を見るときはスマホを電源につないでおきましょう。
- 最速のストリーミングのために、設定で**形式**と**画質**を**オリジナル**のままにし、特定の TV があるファイルでうまくいかないときだけ下げてください。
- DLNA はストリーミング専用です。TV 側の誰も、あなたのファイルを変更したり削除したりできません。双方向のファイル転送には、代わりに [SMB](/docs/howto/how-to-set-up-smb-server-on-iphone-ipad-for-file-sharing/)、[WebDAV](/docs/howto/how-to-set-up-webdav-server-on-iphone-ipad-for-file-access-and-sharing/)、[FTP](/docs/howto/how-to-set-up-ftp-server-on-iphone-ipad-for-file-transfers/) のサーバーを使ってください。

## よくある質問

{{% details title="DLNA と UPnP の違いは何ですか?" closed="true" %}}
両者は密接に関係しています。UPnP は基盤となるネットワーク規格で、DLNA はその上に作られたメディアプロファイルで、TV やプレーヤーが写真・動画・音楽を共有・再生するために使います。日常的には両者は同じ意味で使われます。Everdisk で TV とメディアセンターをオンにすると、お使いのデバイスは、どの DLNA クライアントからも閲覧できる DLNA/UPnP メディアサーバーになります。
{{% /details %}}

{{% details title="TV に何かインストールする必要はありますか?" closed="true" %}}
いいえ。TV が DLNA に対応していれば、Wi-Fi 上でお使いのデバイスを見つけられるメディアプレーヤーがすでに備わっています。インストールが必要なのは、コンテンツを持つ iPhone や iPad に Everdisk を入れることだけです。TV が DLNA に対応していない場合は、それに接続したデバイスに VLC や Kodi のようなプレーヤーをインストールしてください。
{{% /details %}}

{{% details title="iPhone が TV に表示されないのはなぜですか?" closed="true" %}}
両方のデバイスが同じ Wi-Fi ネットワークにあるか確認してください。ゲストネットワークや一部のオフィス・ホテルのネットワークは、デバイス同士が見えないようにブロックしており、これが DLNA を妨げます。次に、Everdisk が開かれていて共有が開始されていること、そして設定、共有、接続で TV とメディアセンターがオンになっていることを確認してください。それでも TV が見つけられない場合は、/device-desc.xml で終わるデバイス記述アドレスを使ってサーバーを手動で追加してください。
{{% /details %}}

{{% details title="DLNA ストリーミングにパスワードは必要ですか?" closed="true" %}}
いいえ。DLNA はオンの間、同じ Wi-Fi 上の誰に対しても常に開放されているため、TV 側にログインはありません。信頼できる家庭内ネットワークなら問題ありません。信頼できないネットワークでは、使い終わったら TV とメディアセンターをオフにするか、代わりに暗号化付きの SMB サーバーを使ってください。
{{% /details %}}

{{% details title="Chromecast や Roku へストリーミングできますか?" closed="true" %}}
Chromecast と Roku は初期状態では DLNA プレーヤーとして動作しないので、お使いのデバイスを直接見つけられません。回避策として、スマホに VLC や BubbleUPnP のようなキャスト対応の DLNA アプリをインストールし、そこから Chromecast や Roku へ再生を送ります。他のほとんどのスマート TV では、こうした手間なしに DLNA が動きます。
{{% /details %}}

{{% details title="動画が音声なしで再生される、または開けません。どうすればよいですか?" closed="true" %}}
それは TV がデコードできない形式です。Everdisk で設定、共有、動画を開き、画質を下げると、アプリがストリーミングしながら動画をより互換性の高い形式に変換します。ブラウザリンクを使って同じファイルを開くこともでき、こちらはより多くの形式に対応します。
{{% /details %}}

{{% details title="動画だけでなく音楽もストリーミングできますか?" closed="true" %}}
はい。すべての音楽ライブラリへのアクセスを許可をオンにするか、特定の曲を追加してから共有を開始します。曲は、アートワークやトラック情報とともに、どの DLNA スピーカー・AV レシーバー・TV にも表示されます。音楽は常にオリジナル画質で共有されます。
{{% /details %}}

{{% details title="視聴中はアプリを開いたままにしておく必要がありますか?" closed="true" %}}
はい。iPhone がサーバーとして動作しており、iOS は完全にバックグラウンドに長時間回ったアプリを一時停止します。ストリーミング中は Everdisk を画面に開いたままにし、長時間のセッションでは電源につないでください。
{{% /details %}}

{{% details title="1 台の iPhone から別の iPad へストリーミングするにはどうしますか?" closed="true" %}}
iPhone で共有を開始し、次に iPad で Everdisk を開いてデバイスタブに移動します。iPhone がメディアサーバーとして利用可能なデバイスの下に表示されます。タップして閲覧・再生します。Everdisk は DLNA クライアントとサーバーの両方として動くので、別のアプリは必要ありません。
{{% /details %}}

{{% details title="Everdisk は無料ですか?" closed="true" %}}
はい。Everdisk は無料でダウンロードでき、DLNA メディアサーバーも含まれています。任意の買い切りの Premium Lifetime を購入すると、古い TV 向けの写真・動画変換、カスタムポートなどの追加機能が使えます。お支払いなしで DLNA ストリーミングの設定と利用ができます。
