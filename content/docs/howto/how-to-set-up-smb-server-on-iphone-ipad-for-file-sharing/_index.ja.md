SMB は macOS、Windows、Linux、そしてほぼすべてのネットワークドライブ (NAS) に組み込まれたファイル共有のしくみです。別のパソコンの共有フォルダーに接続したときに、Finder やエクスプローラーで普通のディスクのように開けるのは、SMB が働いているからです。[Everdisk](/products/everdisk) を使えば、iPhone や iPad に SMB 共有を置けるので、スマホ自体が、他のデバイスから閲覧・コピー元・コピー先として使えるネットワークドライブとして表示されます。

これは、iPhone を Web ページではなく本物のドライブのように動かしたいときに選ぶべき方法です。高速で、双方向にドラッグ&ドロップでき、Everdisk の中ですべての転送を暗号化できる唯一の接続タイプです。このガイドでは、設定方法と、Mac、別の iPhone や iPad、Linux、Android、Windows からの接続方法を解説します。

## 必要なもの

- [Everdisk](https://apps.apple.com/app/apple-store/id6751851132?pt=95781850&ct=everappzcom&mt=8) をインストールした iPhone または iPad。
- **同じ Wi-Fi ネットワーク**上の別のデバイス。
- 共有したいファイル。Everdisk の書類フォルダー内、または追加したフォルダー内にあること。

## Everdisk で SMB サーバーを設定する

### ステップ 1: 共有する内容と書き込みを許可する相手を選ぶ

Everdisk を開き、**共有**タブに移動して、**共有する内容**をタップします。書類フォルダーは既定で共有されています。**フォルダを追加**や**ファイルを追加**でさらに加えられるほか、写真や音楽のライブラリを使いたい場合はそれらもオンにできます。

他のデバイスにファイルの閲覧だけを許可するか、変更も許可するかを決めます。**設定**、**共有**、**アクセス**の順に開き、**ファイルの編集**を設定します。オンにすると、接続したデバイスがスマホにファイルをコピーしたり、名前の変更や削除ができます。オフにすると、共有は読み取り専用になります。

ログインが必要な場合は、同じアクセス画面で**ログイン**と**パスワード**を設定します。両方を空のままにすると、ゲストアクセスを許可します。

### ステップ 2: SMB サーバーをオンにする

**設定**、**共有**、**接続**の順に進み、**コンピュータ（詳細）**をオンにします。これが SMB サーバーです (SMB のタグが付いています)。

### ステップ 3: 共有を開始してアドレスを控える

**共有**タブに戻り、**スタート**をタップします。**接続方法**のセクションに SMB アドレスが表示されます。次のような形です:

```
smb://192.168.1.20:4455/Share
```

このアドレスについて知っておくべきことが 3 つあります:

- コロンの後ろの数字が**ポート**です。Everdisk は既定で **4455** を使います。
- 共有名は **Share** です。
- 最初の部分は Wi-Fi 上での iPhone のアドレスなので、ネットワークによって異なります。

デバイスが接続している間は Everdisk を開いたままにしてください。iOS はバックグラウンドに長く留まったアプリを一時停止するためです。

## Mac から接続する

macOS は SMB をネイティブに扱えるので、これが最もスムーズなケースです。

一番手早い方法: **Finder** を開き、サイドバーの**場所**または**ネットワーク**を確認します。Everdisk は Wi-Fi 上で自らを告知するので、iPhone がそこに自動的に表示されることがよくあります。それをクリックし、**別名で接続**をクリックして**ゲスト**を選ぶか、ログインを入力します。

手動で接続するには:

1. Finder で**移動**を選び、次に**サーバへ接続**を選びます (または **Command と K** を押します)。
2. Everdisk に表示された SMB アドレス (例: `smb://192.168.1.20:4455/Share`) を入力します。
3. **接続**をクリックし、**ゲスト**を選ぶか、**ログイン**と**パスワード**を入力します。

iPhone が Finder のウィンドウで開きます。他のドライブと同じように、ドラッグでファイルを出し入れできます (ファイルの編集がオンの場合)。

## 別の iPhone や iPad から接続する

iOS と iPadOS は、内蔵の**ファイル**アプリで SMB 共有を開けるので、スマホ間の転送がすっきりと手早く行えます。

2 台目のデバイスで:

1. **ファイル**アプリを開きます。
2. **その他**ボタン (iPhone では右上の 3 つの点) をタップし、**サーバへ接続**を選びます。
3. Everdisk の SMB アドレス (例: `smb://192.168.1.20:4455/Share`) を入力します。
4. **ゲスト**を選ぶか、**登録ユーザ**を選んでログインを入力します。
5. 共有がファイルの場所の下に表示されます。どちらの方向にも閲覧・コピーできます。

2 台目のデバイスで Everdisk 自身の**デバイス**タブを使うこともできます。これには SMB クライアントが含まれています。Everdisk を開いて**デバイス**に移動し、**新しい接続**をタップして **SMB** を選び、アドレスを入力します。

## Linux から接続する

1. ファイルマネージャー (GNOME では Files/Nautilus、KDE では Dolphin) を開きます。
2. **Other Locations** または **Connect to Server** を選びます。
3. アドレス (例: `smb://192.168.1.20:4455/Share`) を入力します。
4. ゲストとして接続するか、ログインを入力します。

ターミナルから `smbclient //192.168.1.20/Share -p 4455` を実行し、求められたらログインを入力することもできます。

## Android から接続する

Android にはシステムの SMB ブラウザがないので、SMB に対応したファイルマネージャーを使います:

1. **CX File Explorer**、**Solid Explorer**、**X-plore File Manager** のようなアプリをインストールします。
2. 新しい **SMB** または **LAN** 接続を追加します。
3. ホスト (iPhone の Wi-Fi アドレス) を入力し、**ポートを 4455 に**設定し、共有名を **Share** にします。
4. ゲストまたはログインで接続し、閲覧・コピーします。

## Windows から接続する

Windows は SMB 共有を読めますが、あらかじめ知っておくべき注意点が 1 つあります。内蔵のエクスプローラーは標準ポートの SMB としか通信できず、パス内にカスタムポートを入力できません。Everdisk はポート 4455 を使います。そのため、単純な**ネットワークドライブの割り当て**では届かないことがよくあります。

Windows では 2 つの良い選択肢があります:

- カスタムポートを設定できるファイルマネージャーや SMB クライアントを使い、iPhone のアドレスにポート **4455** と共有名 **Share** を指定します。
- または、Everdisk の他のサーバーを使って Windows から接続します。[WebDAV 設定](/docs/howto/how-to-set-up-webdav-server-on-iphone-ipad-for-file-access-and-sharing/)と [FTP 設定](/docs/howto/how-to-set-up-ftp-server-on-iphone-ipad-for-file-transfers/)はどちらも Windows のエクスプローラーからうまく動き、ブラウザリンクはどのブラウザでも使えます。

どうしてもネットワークドライブの割り当てを試したい場合は、**エクスプローラー**を開いて **PC** を右クリックし、**ネットワークドライブの割り当て**を選んで、Everdisk に表示されたホストと共有名を入力します。接続できない場合は上記のポートの制限が原因なので、WebDAV または FTP に切り替えてください。

## 信頼できない Wi-Fi のために暗号化をオンにする

SMB は、すべての転送を暗号化できる唯一の Everdisk 接続です。これは、カフェやオフィスのネットワークのように、完全には管理できない Wi-Fi で重要になります。

1. **設定**、**共有**、**アクセス**で、**ログイン**と**パスワード**を設定します。暗号化された接続は匿名にできないため、この手順は必須です。
2. **設定**、**共有**で、**SMB 暗号化を必須にする**をオンにします。
3. 変更を反映させるため、共有をいったん停止して再度開始します。

これで、すべての SMB 転送が **SMB3 暗号化 (AES)** で保護されます。接続するデバイスは SMB3 に対応している必要があり、最新の Mac の Finder や Windows 10 以降はどちらも対応しています。SMB 暗号化は買い切りの Premium 購入に含まれます。

## 読み取り専用か、読み書きか

設定、共有、アクセスの**ファイルの編集**スイッチが、SMB を含むすべてのサーバーについてこれを制御します。オンにすると、接続したデバイスはアップロード・名前の変更・削除ができます。オフにすると、閲覧とスマホからのファイルのコピーだけができます。何も変更されたくない相手にファイルを渡すときは、読み取り専用を選んでください。

## 実際の活用シーン

- **Mac から iPhone に大きなフォルダーを移動。** Finder のウィンドウにドラッグするだけで、Web アップロードより速く移せます。
- **1 日分の写真や動画をスマホから取り出す。** iTunes やケーブルなしでノート PC に移せます。
- **2 台の iPhone の間でファイルをやり取り。** ファイルアプリを通して、どちら側にも 3 つ目のアプリを入れずに行えます。
- **ファイルをその場で扱う。** Mac のアプリでスマホから書類を直接開いて、保存し直せます。

## いくつかのヒント

- デバイスが接続している間は Everdisk を開いたままにしてください。スマホを長時間ロックすると、アプリが一時停止して接続が切れることがあります。
- Finder のサイドバーで Mac がスマホを見つけられない場合は、サーバへ接続で完全な smb アドレスを使って手動で接続してください。
- 大きな転送で最速を得るには、設定で写真と動画の画質をオリジナルのままにしてください。
- 信頼できないネットワークでは、SMB 暗号化を必須にするをオンにし、作業中は他のサーバーをオフにしてください。

{{% details title="Windows から iPhone の SMB 共有に接続できますか?" closed="true" %}}

{{% details title="iPhone は Mac の Finder のサイドバーに自動的に表示されますか?" closed="true" %}}

{{% /details %}}

{{% details title="SMB を使うのにパスワードは必要ですか?" closed="true" %}}
いいえ、ログインは任意です。ゲストアクセスを許可するには、設定、共有、アクセスでログインとパスワードを空のままにしてください。接続にサインインさせたい場合は設定します。ログインとパスワードが必須になるのは、SMB 暗号化を必須にするをオンにしたときだけです。暗号化された接続は匿名にできないためです。
{{% /details %}}

{{% details title="SMB 接続は暗号化されていますか?" closed="true" %}}
暗号化できます。SMB は暗号化に対応する唯一の Everdisk 接続です。ログインとパスワードを設定してから、設定、共有で SMB 暗号化を必須にするをオンにします。すると、すべての転送が SMB3 (AES) で保護されます。相手のデバイスは SMB3 に対応している必要があり、最新の Mac や Windows 10 以降は対応しています。暗号化は Premium 機能です。
{{% /details %}}

{{% details title="SMB 経由で私のファイルを変更したり削除したりされることはありますか?" closed="true" %}}

{{% /details %}}

{{% details title="SMB 接続が切れたのはなぜですか?" closed="true" %}}
iPhone がサーバーで、iOS はバックグラウンドに長く留まったアプリを一時停止します。デバイスが接続している間は Everdisk を画面に開いたままにし、長時間の転送中はスマホを電源につないでください。また、両方のデバイスが同じ Wi-Fi にとどまっていることも確認してください。
{{% /details %}}

{{% details title="SMB、WebDAV、FTP のどれを使うべきですか?" closed="true" %}}
