SMB는 macOS, Windows, Linux, 그리고 거의 모든 네트워크 드라이브(NAS)에 내장된 파일 공유 방식입니다. 다른 컴퓨터의 공유 폴더에 연결했을 때 Finder나 파일 탐색기에서 일반 디스크처럼 열린다면, 그것이 바로 SMB가 하는 일입니다. [Everdisk](/products/everdisk)로 iPhone이나 iPad에 SMB 공유를 올려 두면, 휴대폰 자체가 네트워크 드라이브로 나타나 다른 기기가 둘러보고, 복사해 오고, 복사해 넣을 수 있습니다.

iPhone을 웹 페이지가 아니라 제대로 된 드라이브처럼 다루고 싶을 때 선택할 방법입니다. 빠르고, 양방향으로 끌어다 놓을 수 있으며, Everdisk에서 모든 전송을 암호화할 수 있는 유일한 연결 방식입니다. 이 가이드는 설정 방법과 Mac, 다른 iPhone이나 iPad, Linux, Android, Windows에서 연결하는 방법을 다룹니다.

## 필요한 것

- [Everdisk](https://apps.apple.com/app/apple-store/id6751851132?pt=95781850&ct=everappzcom&mt=8)가 설치된 iPhone이나 iPad.
- **같은 Wi-Fi 네트워크**에 있는 다른 기기.
- 공유하려는 파일이 Everdisk 문서 폴더나 추가한 폴더에 있어야 합니다.

## Everdisk에서 SMB 서버 설정하기

### 1단계: 공유할 항목과 쓰기 권한 정하기

Everdisk를 열고 **공유** 탭으로 가서 **공유할 항목**을 탭하세요. 문서 폴더는 기본으로 공유됩니다. **폴더 추가**와 **파일 추가**로 더 추가하고, 사진이나 음악 보관함도 이용할 수 있게 하려면 켜세요.

다른 기기가 파일을 읽기만 할 수 있게 할지, 변경도 할 수 있게 할지 정하세요. **설정**으로 가서 **공유**, 그다음 **접근 권한**으로 이동해 **파일 편집**을 설정하세요. 켜 두면 연결된 기기가 휴대폰에 파일을 복사하고 이름을 바꾸거나 삭제할 수 있습니다. 꺼 두면 공유는 읽기 전용이 됩니다.

로그인을 원한다면 같은 접근 권한 화면에서 **로그인**과 **비밀번호**를 설정하세요. 둘 다 비워 두면 게스트 접근을 허용합니다.

### 2단계: SMB 서버 켜기

**설정**으로 가서 **공유**, 그다음 **연결**로 이동해 **컴퓨터(고급)**을 켜세요. 그것이 SMB 서버입니다(SMB 태그가 붙습니다).

### 3단계: 공유 시작하고 주소 확인하기

**공유** 탭으로 돌아가 **시작**을 탭하세요. 이제 **연결 방법** 섹션에 SMB 주소가 표시됩니다. 다음과 같이 생겼습니다.

```
smb://192.168.1.20:4455/Share
```

그 주소에 대해 알아 둘 세 가지가 있습니다.

- 콜론 뒤의 숫자는 **포트**입니다. Everdisk는 기본으로 **4455**를 사용합니다.
- 공유 이름은 **Share**입니다.
- 앞부분은 Wi-Fi에서 iPhone의 주소이므로 네트워크마다 다릅니다.

기기가 연결되어 있는 동안에는 Everdisk를 열어 두세요. iOS는 백그라운드에 너무 오래 있는 앱을 일시정지하기 때문입니다.

## Mac에서 연결하기

macOS가 SMB를 기본으로 지원하기 때문에 가장 매끄러운 경우입니다.

가장 빠른 방법은 **Finder**를 열고 사이드바에서 **위치** 또는 **네트워크** 아래를 보는 것입니다. Everdisk가 Wi-Fi에서 자신을 알리므로 iPhone이 종종 저절로 거기에 나타납니다. 클릭한 뒤 **다른 이름으로 연결**을 클릭하고 **게스트**를 고르거나 로그인을 입력하세요.

직접 연결하려면:

1. Finder에서 **이동**을 선택한 뒤 **서버에 연결**(또는 **Command와 K**를 누르세요)을 선택하세요.
2. Everdisk에 표시된 SMB 주소를 입력하세요. 예: `smb://192.168.1.20:4455/Share`.
3. **연결**을 클릭한 뒤 **게스트**를 고르거나 **로그인**과 **비밀번호**를 입력하세요.

iPhone이 Finder 창에 열립니다. 다른 드라이브와 똑같이 끌어서 파일을 넣거나 빼세요(파일 편집이 켜져 있을 때).

## 다른 iPhone이나 iPad에서 연결하기

iOS와 iPadOS는 내장 **파일** 앱에서 SMB 공유를 열 수 있어 휴대폰끼리의 전송이 깔끔하고 빠릅니다.

두 번째 기기에서:

1. **파일** 앱을 여세요.
2. **더 보기** 버튼(iPhone에서는 오른쪽 위의 점 세 개)을 탭하고 **서버에 연결**을 선택하세요.
3. Everdisk의 SMB 주소를 입력하세요. 예: `smb://192.168.1.20:4455/Share`.
4. **게스트** 또는 **등록된 사용자**를 고르고 로그인을 입력하세요.
5. 파일의 위치 아래에 공유가 나타납니다. 둘러보고 양방향으로 복사하세요.

두 번째 기기에서 Everdisk 자체의 **기기** 탭을 사용할 수도 있습니다. SMB 클라이언트가 들어 있습니다. Everdisk를 열고 **기기**로 가서 **새 연결**을 탭하고 **SMB**를 고른 뒤 주소를 입력하세요.

## Linux에서 연결하기

1. 파일 관리자를 여세요(GNOME에서는 Files/Nautilus, KDE에서는 Dolphin).
2. **Other Locations** 또는 **Connect to Server**를 선택하세요.
3. 주소를 입력하세요. 예: `smb://192.168.1.20:4455/Share`.
4. 게스트로 연결하거나 로그인을 입력하세요.

터미널에서는 `smbclient //192.168.1.20/Share -p 4455`를 실행하고 물어볼 때 로그인을 입력할 수도 있습니다.

## Android에서 연결하기

Android에는 시스템 SMB 브라우저가 없으므로 SMB를 지원하는 파일 관리자를 사용하세요.

1. **CX File Explorer**, **Solid Explorer** 또는 **X-plore File Manager** 같은 앱을 설치하세요.
2. 새 **SMB** 또는 **LAN** 연결을 추가하세요.
3. 호스트(iPhone의 Wi-Fi 주소)를 입력하고 **포트를 4455**로, 공유 이름을 **Share**로 설정하세요.
4. 게스트나 로그인으로 연결한 뒤 둘러보고 복사하세요.

## Windows에서 연결하기

Windows는 SMB 공유를 읽을 수 있지만, 미리 알아 둘 만한 한 가지 걸림돌이 있습니다. 내장 파일 탐색기는 표준 포트에서만 SMB와 통신하며 경로에 사용자 지정 포트를 입력하지 못하는데, Everdisk는 포트 4455를 사용합니다. 그래서 일반적인 **네트워크 드라이브 연결** 방식으로는 종종 닿지 못합니다.

Windows에서는 좋은 선택지가 두 가지 있습니다.

- 사용자 지정 포트를 설정할 수 있는 파일 관리자나 SMB 클라이언트를 사용해, iPhone의 주소에 포트 **4455**와 공유 이름 **Share**를 지정하세요.
- 또는 Everdisk의 다른 서버 중 하나로 Windows에서 연결하세요. [WebDAV 설정](/docs/howto/how-to-set-up-webdav-server-on-iphone-ipad-for-file-access-and-sharing/)과 [FTP 설정](/docs/howto/how-to-set-up-ftp-server-on-iphone-ipad-for-file-transfers/)은 모두 Windows 파일 탐색기에서 잘 작동하며, 브라우저 링크는 어떤 브라우저에서도 됩니다.

그래도 네트워크 드라이브 연결을 시도하고 싶다면 **파일 탐색기**를 열고 **내 PC**를 마우스 오른쪽 버튼으로 클릭한 뒤 **네트워크 드라이브 연결**을 선택하고, Everdisk에 표시된 호스트와 공유 이름을 입력하세요. 연결되지 않으면 위에서 설명한 포트 제한 때문이므로 WebDAV나 FTP로 전환하세요.

## 신뢰할 수 없는 Wi-Fi를 위한 암호화 켜기

SMB는 모든 전송을 암호화할 수 있는 유일한 Everdisk 연결이며, 이는 카페나 사무실 네트워크처럼 완전히 통제하지 못하는 Wi-Fi에서 중요합니다.

1. **설정**, **공유**, **접근 권한**에서 **로그인**과 **비밀번호**를 설정하세요. 암호화된 연결은 익명일 수 없으므로 이 단계는 필수입니다.
2. **설정**, **공유**에서 **SMB 암호화 요구**를 켜세요.
3. 변경 사항이 적용되도록 공유를 중지했다가 다시 시작하세요.

그러면 모든 SMB 전송이 **SMB3 암호화(AES)**로 보호됩니다. 연결하는 기기가 SMB3를 지원해야 하며, 최신 Mac의 Finder와 Windows 10 이상이 모두 지원합니다. SMB 암호화는 일회성 Premium 구매에 포함됩니다.

## 읽기 전용 또는 읽기 및 쓰기

설정, 공유, 접근 권한의 **파일 편집** 스위치가 SMB를 포함한 모든 서버에 대해 이를 제어합니다. 켜면 연결된 기기가 업로드하고, 이름을 바꾸고, 삭제할 수 있습니다. 끄면 둘러보고 휴대폰에서 파일을 복사해 가는 것만 할 수 있습니다. 무언가 바꾸지 않기를 바라는 상대에게 파일을 건넬 때는 읽기 전용을 고르세요.

## 사람들이 실제로 쓰는 방법

- **Mac에서 큰 폴더를 iPhone으로 옮기기.** Finder 창으로 끌어다 놓으면 웹 업로드보다 빠릅니다.
- **하루치 사진과 동영상을 휴대폰에서 빼내기.** iTunes나 케이블 없이 노트북으로 가져오세요.
- **두 iPhone 사이에서 파일 보내기.** 파일 앱을 통해 양쪽에 다른 앱 없이 됩니다.
- **파일을 제자리에서 작업하기.** Mac의 앱에서 휴대폰의 문서를 바로 열어 다시 저장하세요.

## 몇 가지 팁

- 기기가 연결되어 있는 동안 Everdisk를 열어 두세요. 휴대폰을 오래 잠가 두면 앱이 일시정지되어 연결이 끊길 수 있습니다.
- Mac이 Finder 사이드바에서 휴대폰을 보지 못하면, 서버에 연결과 전체 smb 주소로 직접 연결하세요.
- 대용량 전송에서 최고의 속도를 내려면 설정에서 사진과 동영상 품질을 원본으로 유지하세요.
- 신뢰할 수 없는 네트워크에서는 SMB 암호화 요구를 켜고, 작업하는 동안 다른 서버는 꺼 두세요.

허용할 때만 그렇습니다. 설정, 공유, 접근 권한의 파일 편집 스위치가 이를 제어합니다. 켜면 연결된 기기가 업로드하고, 이름을 바꾸고, 삭제할 수 있습니다. 끄면 공유가 읽기 전용이 되어 다른 사람은 둘러보고 휴대폰에서 파일을 복사해 갈 수는 있어도 아무것도 바꿀 수 없습니다.

{{% details title="SMB 연결이 왜 끊겼나요?" closed="true" %}}
iPhone이 서버이고, iOS는 백그라운드에 너무 오래 있는 앱을 일시정지합니다. 기기가 연결되어 있는 동안 Everdisk를 화면에 열어 두고, 긴 전송 중에는 휴대폰을 전원에 연결하세요. 두 기기가 계속 같은 Wi-Fi에 있었는지도 확인하세요.
{{% /details %}}

{{% details title="SMB, WebDAV, FTP 중 무엇을 써야 하나요?" closed="true" %}}
Mac, 다른 iPhone, Linux 또는 NAS에서 휴대폰을 진짜 네트워크 드라이브처럼 다루고 싶고 암호화를 원할 때는 SMB를 쓰세요. Windows에서도 잘 되는 네트워크 드라이브를 원할 때는 WebDAV를 쓰세요. 오래된 기기와 앱과의 가장 넓은 호환성을 원할 때는 FTP를 쓰세요. Everdisk는 이 모두를 동시에 실행할 수 있으므로 하나에 묶이지 않습니다.
{{% /details %}}

{{% details title="Everdisk는 무료인가요?" closed="true" %}}
네, Everdisk는 무료로 내려받을 수 있으며 SMB 서버가 포함되어 있습니다. 선택 사항인 일회성 Premium 구매는 SMB 암호화, 사용자 지정 포트, 그 밖의 몇 가지 추가 기능을 더합니다. 결제 없이 SMB를 설정하고 파일을 공유할 수 있습니다.
