SMB คือการแชร์ไฟล์ที่มีในตัว macOS, Windows และ Linux รวมถึงในไดรฟ์เครือข่าย (NAS) เกือบทุกตัว เมื่อคุณเชื่อมต่อกับโฟลเดอร์ที่แชร์บนคอมพิวเตอร์อีกเครื่องและมันเปิดขึ้นเหมือนดิสก์ทั่วไปใน Finder หรือ File Explorer นั่นคือ SMB ที่กำลังทำงานอยู่ ด้วย [Everdisk](/products/everdisk) คุณสามารถวางการแชร์ SMB บน iPhone หรือ iPad ของคุณได้ โทรศัพท์เองจึงปรากฏเป็นไดรฟ์เครือข่ายที่อุปกรณ์อื่นเรียกดู คัดลอกออกมา และคัดลอกเข้าไปได้

นี่คือตัวเลือกที่ควรเลือกเมื่อคุณต้องการให้ iPhone ทำตัวเหมือนไดรฟ์จริง ๆ ไม่ใช่หน้าเว็บ มันเร็ว ลากแล้ววางได้ทั้งสองทาง และเป็นการเชื่อมต่อประเภทเดียวใน Everdisk ที่เข้ารหัสการถ่ายโอนทุกครั้งได้ คู่มือนี้ครอบคลุมการตั้งค่าและวิธีเชื่อมต่อจาก Mac, iPhone หรือ iPad อีกเครื่อง, Linux, Android และ Windows

## สิ่งที่คุณต้องมี

- iPhone หรือ iPad ที่ติดตั้ง [Everdisk](https://apps.apple.com/app/apple-store/id6751851132?pt=95781850&ct=everappzcom&mt=8) แล้ว
- อุปกรณ์อีกเครื่องบน **เครือข่าย Wi-Fi เดียวกัน**
- ไฟล์ที่คุณต้องการแชร์ ในโฟลเดอร์เอกสารของ Everdisk หรือในโฟลเดอร์ที่คุณเพิ่ม

## ตั้งค่าเซิร์ฟเวอร์ SMB ใน Everdisk

### ขั้นที่ 1: เลือกสิ่งที่จะแชร์และใครเขียนได้

เปิด Everdisk ไปที่แท็บ **การแชร์** แล้วแตะ **สิ่งที่จะแชร์** โฟลเดอร์เอกสารถูกแชร์เป็นค่าเริ่มต้น เพิ่มเติมด้วย **เพิ่มโฟลเดอร์** และ **เพิ่มไฟล์** และเปิดคลังรูปภาพหรือเพลงของคุณหากต้องการให้ใช้งานได้ด้วย

ตัดสินใจว่าอุปกรณ์อื่นอ่านไฟล์ของคุณได้อย่างเดียว หรือเปลี่ยนแปลงได้ด้วย เปิด **การตั้งค่า** จากนั้น **การแชร์** แล้ว **การเข้าถึง** แล้วตั้งค่า **การแก้ไขไฟล์** เมื่อเปิดไว้ อุปกรณ์ที่เชื่อมต่อสามารถคัดลอกไฟล์ลงโทรศัพท์และเปลี่ยนชื่อหรือลบได้ เมื่อปิดไว้ การแชร์จะเป็นแบบอ่านอย่างเดียว

หากต้องการให้ล็อกอิน ให้ตั้ง **ชื่อผู้ใช้** และ **รหัสผ่าน** บนหน้าจอ การเข้าถึง เดียวกัน ปล่อยทั้งสองช่องว่างไว้เพื่ออนุญาตการเข้าถึงแบบแขก

### ขั้นที่ 2: เปิดเซิร์ฟเวอร์ SMB

ไปที่ **การตั้งค่า** จากนั้น **การแชร์** แล้ว **การเชื่อมต่อ** แล้วเปิด **คอมพิวเตอร์ (ขั้นสูง)** นั่นคือเซิร์ฟเวอร์ SMB (มันมีป้าย SMB)

### ขั้นที่ 3: เริ่มแชร์และจดที่อยู่

กลับไปที่แท็บ **การแชร์** แล้วแตะ **Start** ส่วน **วิธีเชื่อมต่อ** จะแสดงที่อยู่ SMB มันมีหน้าตาแบบนี้:

```
smb://192.168.1.20:4455/Share
```

สามสิ่งที่ควรรู้เกี่ยวกับที่อยู่นั้น:

- ตัวเลขหลังโคลอนคือ **พอร์ต** Everdisk ใช้ **4455** เป็นค่าเริ่มต้น
- การแชร์ชื่อว่า **Share**
- ส่วนแรกคือที่อยู่ของ iPhone บน Wi-Fi ดังนั้นมันจะต่างกันไปบนเครือข่ายของคุณ

เปิด Everdisk ค้างไว้ขณะที่อุปกรณ์เชื่อมต่ออยู่ เพราะ iOS จะหยุดพักแอปที่อยู่เบื้องหลังนานเกินไป

## เชื่อมต่อจาก Mac

นี่คือกรณีที่ราบรื่นที่สุด เพราะ macOS รองรับ SMB โดยกำเนิด

วิธีที่เร็วที่สุด: เปิด **Finder** แล้วดูในแถบข้างใต้ **Locations** หรือ **Network** Everdisk ประกาศตัวเองบน Wi-Fi ดังนั้น iPhone ของคุณมักปรากฏตรงนั้นเอง คลิกที่มัน จากนั้นคลิก **Connect As** แล้วเลือก **Guest** หรือกรอกล็อกอินของคุณ

การเชื่อมต่อด้วยตนเอง:

1. ใน Finder เลือก **Go** จากนั้น **Connect to Server** (หรือกด **Command และ K**)
2. พิมพ์ที่อยู่ SMB ที่แสดงใน Everdisk เช่น `smb://192.168.1.20:4455/Share`
3. คลิก **Connect** จากนั้นเลือก **Guest** หรือกรอก **ชื่อผู้ใช้** และ **รหัสผ่าน** ของคุณ

iPhone ของคุณจะเปิดในหน้าต่าง Finder คัดลอกไฟล์เข้าหรือออกด้วยการลาก เหมือนไดรฟ์อื่นทุกประการ (หาก การแก้ไขไฟล์ เปิดอยู่)

## เชื่อมต่อจาก iPhone หรือ iPad อีกเครื่อง

iOS และ iPadOS เปิดการแชร์ SMB ในแอป **Files** ในตัวได้ ซึ่งทำให้การถ่ายโอนระหว่างโทรศัพท์เรียบร้อยและรวดเร็ว

บนอุปกรณ์เครื่องที่สอง:

1. เปิดแอป **Files**
2. แตะปุ่ม **more** (จุดสามจุด ด้านบนขวาบน iPhone) แล้วเลือก **Connect to Server**
3. ป้อนที่อยู่ SMB จาก Everdisk เช่น `smb://192.168.1.20:4455/Share`
4. เลือก **Guest** หรือ **Registered User** แล้วกรอกล็อกอินของคุณ
5. การแชร์จะปรากฏใต้ Locations ใน Files เรียกดูและคัดลอกได้ทั้งสองทิศทาง

คุณยังใช้แท็บ **อุปกรณ์** ของ Everdisk เองบนอุปกรณ์เครื่องที่สองได้ ซึ่งมีไคลเอนต์ SMB รวมอยู่ด้วย เปิด Everdisk ไปที่ **อุปกรณ์** แตะ **การเชื่อมต่อใหม่** เลือก **SMB** แล้วป้อนที่อยู่

## เชื่อมต่อจาก Linux

1. เปิดตัวจัดการไฟล์ของคุณ (Files/Nautilus บน GNOME, Dolphin บน KDE)
2. เลือก **Other Locations** หรือ **Connect to Server**
3. ป้อนที่อยู่ เช่น `smb://192.168.1.20:4455/Share`
4. เชื่อมต่อเป็นแขก หรือกรอกล็อกอินของคุณ

จากเทอร์มินัลคุณยังรัน `smbclient //192.168.1.20/Share -p 4455` แล้วกรอกล็อกอินเมื่อถูกถามได้

## เชื่อมต่อจาก Android

Android ไม่มีตัวเรียกดู SMB ของระบบ จึงต้องใช้ตัวจัดการไฟล์ที่รองรับ SMB:

1. ติดตั้งแอปเช่น **CX File Explorer**, **Solid Explorer** หรือ **X-plore File Manager**
2. เพิ่มการเชื่อมต่อ **SMB** หรือ **LAN** ใหม่
3. ป้อนโฮสต์ (ที่อยู่ Wi-Fi ของ iPhone) ตั้ง **พอร์ตเป็น 4455** และชื่อการแชร์ **Share**
4. เชื่อมต่อเป็นแขกหรือด้วยล็อกอินของคุณ แล้วเรียกดูและคัดลอก

## เชื่อมต่อจาก Windows

Windows อ่านการแชร์ SMB ได้ แต่มีข้อควรรู้ล่วงหน้าอยู่อย่างหนึ่ง File Explorer ในตัวสื่อสารกับ SMB บนพอร์ตมาตรฐานเท่านั้นและไม่ให้คุณพิมพ์พอร์ตแบบกำหนดเองในเส้นทาง ในขณะที่ Everdisk ใช้พอร์ต 4455 ดังนั้นวิธี **Map network drive** ธรรมดามักเข้าถึงไม่ได้

คุณมีสองตัวเลือกที่ดีบน Windows:

- ใช้ตัวจัดการไฟล์หรือไคลเอนต์ SMB ที่ให้คุณตั้งพอร์ตแบบกำหนดเอง แล้วชี้ไปที่ที่อยู่ของ iPhone ด้วยพอร์ต **4455** และชื่อการแชร์ **Share**
- หรือเชื่อมต่อจาก Windows โดยใช้เซิร์ฟเวอร์อื่นของ Everdisk แทน ทั้ง [การตั้งค่า WebDAV](/docs/howto/how-to-set-up-webdav-server-on-iphone-ipad-for-file-access-and-sharing/) และ [การตั้งค่า FTP](/docs/howto/how-to-set-up-ftp-server-on-iphone-ipad-for-file-transfers/) ต่างก็ทำงานได้ดีจาก Windows File Explorer และลิงก์เบราว์เซอร์ใช้งานได้ในเบราว์เซอร์ใด ๆ

หากคุณอยากลอง Map network drive: เปิด **File Explorer** คลิกขวา **This PC** เลือก **Map network drive** แล้วป้อนโฮสต์และชื่อการแชร์ที่แสดงใน Everdisk หากเชื่อมต่อไม่ได้ นั่นคือข้อจำกัดเรื่องพอร์ตข้างต้น ให้เปลี่ยนไปใช้ WebDAV หรือ FTP

## เปิดการเข้ารหัสสำหรับ Wi-Fi ที่ไม่ไว้ใจ

SMB เป็นการเชื่อมต่อเดียวของ Everdisk ที่เข้ารหัสการถ่ายโอนทุกครั้งได้ ซึ่งสำคัญบน Wi-Fi ที่คุณควบคุมได้ไม่เต็มที่ เช่น ร้านกาแฟหรือเครือข่ายสำนักงาน

1. ใน **การตั้งค่า**, **การแชร์**, **การเข้าถึง** ให้ตั้ง **ชื่อผู้ใช้** และ **รหัสผ่าน** การเชื่อมต่อที่เข้ารหัสไม่สามารถไม่ระบุตัวตนได้ ขั้นตอนนี้จึงจำเป็น
2. ใน **การตั้งค่า**, **การแชร์** ให้เปิด **ต้องใช้การเข้ารหัส SMB**
3. หยุดและเริ่มแชร์อีกครั้งเพื่อให้การเปลี่ยนแปลงมีผล

จากนั้นการถ่ายโอน SMB ทุกครั้งจะได้รับการปกป้องด้วย **การเข้ารหัส SMB3 (AES)** อุปกรณ์ที่เชื่อมต่อต้องรองรับ SMB3 ซึ่ง Finder บน Mac รุ่นใหม่และ Windows 10 ขึ้นไปต่างก็รองรับ การเข้ารหัส SMB เป็นส่วนหนึ่งของการซื้อ Premium แบบจ่ายครั้งเดียว

## อ่านอย่างเดียว หรืออ่านและเขียน

สวิตช์ **การแก้ไขไฟล์** ใน การตั้งค่า, การแชร์, การเข้าถึง ควบคุมสิ่งนี้สำหรับทุกเซิร์ฟเวอร์ รวมถึง SMB เปิดไว้แล้วอุปกรณ์ที่เชื่อมต่อสามารถอัปโหลด เปลี่ยนชื่อ และลบได้ ปิดไว้แล้วพวกเขาเรียกดูและคัดลอกไฟล์ออกจากโทรศัพท์ได้เท่านั้น เลือกอ่านอย่างเดียวเมื่อคุณส่งไฟล์ให้ใครที่คุณไม่ต้องการให้เปลี่ยนแปลงอะไร

## วิธีที่ผู้คนใช้งานในชีวิตจริง

- **ย้ายโฟลเดอร์ใหญ่ลง iPhone จาก Mac** ด้วยการลากมันเข้าหน้าต่าง Finder ซึ่งเร็วกว่าการอัปโหลดผ่านเว็บ
- **ดึงรูปภาพและวิดีโอทั้งวันออกจากโทรศัพท์** ไปยังแล็ปท็อปโดยไม่ต้องใช้ iTunes หรือสาย
- **ส่งไฟล์ระหว่าง iPhone สองเครื่อง** ผ่านแอป Files โดยไม่ต้องมีแอปที่สามบนฝั่งใด
- **ทำงานกับไฟล์ในที่เดิม** เปิดเอกสารตรงจากโทรศัพท์ในแอปบน Mac แล้วบันทึกกลับ

## เคล็ดลับเล็กน้อย

- เปิด Everdisk ค้างไว้ขณะที่อุปกรณ์เชื่อมต่ออยู่ การล็อกโทรศัพท์เป็นเวลานานอาจหยุดพักแอปและตัดการเชื่อมต่อ
- หาก Mac มองไม่เห็นโทรศัพท์ในแถบข้าง Finder ให้เชื่อมต่อด้วยตนเองด้วย Connect to Server และที่อยู่ smb เต็ม
- เพื่อความเร็วที่ดีที่สุดในการถ่ายโอนขนาดใหญ่ ให้ตั้งคุณภาพรูปภาพและวิดีโอไว้ที่ Original ในการตั้งค่า
- บนเครือข่ายที่ไม่ไว้ใจ ให้เปิด ต้องใช้การเข้ารหัส SMB และปิดเซิร์ฟเวอร์อื่นขณะที่คุณทำงาน

Windows File Explorer เชื่อมต่อกับ SMB บนพอร์ตมาตรฐานเท่านั้นและไม่รับพอร์ตแบบกำหนดเองในเส้นทาง ในขณะที่ Everdisk ใช้พอร์ต 4455 ดังนั้นวิธี Map network drive ธรรมดามักเข้าถึงไม่ได้ ให้ใช้ตัวจัดการไฟล์ที่ตั้งพอร์ตแบบกำหนดเองได้ หรือเชื่อมต่อจาก Windows ด้วย WebDAV, FTP หรือลิงก์เบราว์เซอร์แทน ทั้งหมดนั้นทำงานได้จาก Windows โดยไม่มีปัญหาเรื่องพอร์ต
{{% /details %}}

{{% details title="ฉันจะแชร์ไฟล์ระหว่าง iPhone สองเครื่องด้วย SMB ได้อย่างไร?" closed="true" %}}
เริ่มเซิร์ฟเวอร์ SMB บน iPhone เครื่องแรกใน Everdisk บน iPhone เครื่องที่สอง ให้เปิดแอป Files แตะปุ่ม more เลือก Connect to Server แล้วป้อนที่อยู่ smb ที่แสดงใน Everdisk (เช่น smb://192.168.1.20:4455/Share) เชื่อมต่อเป็น Guest หรือด้วยล็อกอินของคุณ แล้วการแชร์จะปรากฏใน Files คุณยังใช้แท็บ อุปกรณ์ ของ Everdisk เองบนโทรศัพท์เครื่องที่สองได้
{{% /details %}}

{{% details title="iPhone ของฉันปรากฏในแถบข้าง Mac Finder อัตโนมัติหรือไม่?" closed="true" %}}
โดยปกติใช่ Everdisk ประกาศการแชร์ SMB บน Wi-Fi ของคุณ ดังนั้น iPhone ของคุณมักปรากฏใต้ Locations หรือ Network ในแถบข้าง Finder คลิกที่มันแล้วเลือก Connect As จากนั้น Guest หรือล็อกอินของคุณ หากไม่ปรากฏ ให้เชื่อมต่อด้วยตนเองด้วย Go, Connect to Server และที่อยู่ smb เต็ม
{{% /details %}}

{{% details title="ฉันต้องใช้รหัสผ่านเพื่อใช้ SMB หรือไม่?" closed="true" %}}
ไม่ ล็อกอินเป็นทางเลือก ปล่อย ชื่อผู้ใช้ และ รหัสผ่าน ว่างไว้ใน การตั้งค่า, การแชร์, การเข้าถึง เพื่ออนุญาตการเข้าถึงแบบแขก ตั้งค่าหากคุณต้องการให้การเชื่อมต่อลงชื่อเข้าใช้ จำเป็นต้องมีชื่อผู้ใช้และรหัสผ่านเฉพาะเมื่อคุณเปิด ต้องใช้การเข้ารหัส SMB เพราะการเชื่อมต่อที่เข้ารหัสไม่สามารถไม่ระบุตัวตนได้
{{% /details %}}

{{% details title="การเชื่อมต่อ SMB เข้ารหัสหรือไม่?" closed="true" %}}
เข้ารหัสได้ SMB เป็นการเชื่อมต่อเดียวของ Everdisk ที่รองรับการเข้ารหัส ตั้งชื่อผู้ใช้และรหัสผ่าน แล้วเปิด ต้องใช้การเข้ารหัส SMB ใน การตั้งค่า, การแชร์ จากนั้นการถ่ายโอนทุกครั้งจะได้รับการปกป้องด้วย SMB3 (AES) อุปกรณ์อีกเครื่องต้องรองรับ SMB3 ซึ่ง Mac รุ่นใหม่และ Windows 10 ขึ้นไปรองรับ การเข้ารหัสเป็นฟีเจอร์ Premium
{{% /details %}}

{{% details title="ผู้อื่นเปลี่ยนหรือลบไฟล์ของฉันผ่าน SMB ได้ไหม?" closed="true" %}}
ได้เฉพาะเมื่อคุณอนุญาต สวิตช์ การแก้ไขไฟล์ ใน การตั้งค่า, การแชร์, การเข้าถึง ควบคุมสิ่งนี้ เมื่อเปิดไว้ อุปกรณ์ที่เชื่อมต่อสามารถอัปโหลด เปลี่ยนชื่อ และลบได้ เมื่อปิดไว้ การแชร์จะเป็นแบบอ่านอย่างเดียว และผู้อื่นเรียกดูและคัดลอกไฟล์ออกจากโทรศัพท์ได้แต่เปลี่ยนแปลงอะไรไม่ได้
{{% /details %}}

{{% details title="ทำไมการเชื่อมต่อ SMB ของฉันหลุด?" closed="true" %}}
iPhone ของคุณเป็นเซิร์ฟเวอร์ และ iOS จะหยุดพักแอปที่อยู่เบื้องหลังนานเกินไป เปิด Everdisk ค้างไว้บนหน้าจอขณะที่อุปกรณ์เชื่อมต่ออยู่ และเสียบโทรศัพท์เข้ากับที่ชาร์จระหว่างการถ่ายโอนยาว ๆ ตรวจสอบด้วยว่าทั้งสองอุปกรณ์ยังอยู่บน Wi-Fi เดียวกัน
{{% /details %}}
