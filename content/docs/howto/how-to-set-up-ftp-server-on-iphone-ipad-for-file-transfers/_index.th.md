FTP คือตัวช่วยเก่าแก่ที่เชื่อถือได้ในการโอนไฟล์ มันอยู่มาหลายทศวรรษ ซึ่งเป็นเหตุผลว่าทำไมมันจึงมีประโยชน์มาก: เกือบทุกอย่างที่สื่อสารกับเซิร์ฟเวอร์ได้ก็เข้าใจมัน กล้อง สมาร์ททีวี เราเตอร์ ไดรฟ์เครือข่าย เครื่องมืออัตโนมัติ และแอป FTP บนเดสก์ท็อปทุกตัวรองรับ FTP ด้วย [Everdisk](/products/everdisk) คุณสามารถรันเซิร์ฟเวอร์ FTP บน iPhone หรือ iPad ของคุณได้ โทรศัพท์จึงกลายเป็นที่ที่อุปกรณ์และแอปเหล่านั้นเชื่อมต่อและย้ายไฟล์ได้

เลือกใช้ FTP เมื่อตัวเลือกอื่นไม่เหมาะ เช่น อุปกรณ์รุ่นเก่าหรือแอปที่รู้จักการเชื่อมต่อผ่าน FTP เท่านั้น คู่มือนี้ครอบคลุมการตั้งค่าและวิธีเชื่อมต่อจาก Mac, Windows, แอป FTP, Linux, Android และ iPhone อีกเครื่อง

## สิ่งที่คุณต้องมี

- iPhone หรือ iPad ที่ติดตั้ง [Everdisk](https://apps.apple.com/app/apple-store/id6751851132?pt=95781850&ct=everappzcom&mt=8) แล้ว
- คอมพิวเตอร์ แอป หรืออุปกรณ์บน **เครือข่าย Wi-Fi เดียวกัน**
- ไฟล์ที่คุณต้องการแชร์ ในโฟลเดอร์เอกสารของ Everdisk หรือในโฟลเดอร์ที่คุณเพิ่ม

## ตั้งค่าเซิร์ฟเวอร์ FTP ใน Everdisk

### ขั้นที่ 1: เลือกสิ่งที่จะแชร์และตั้งค่าการเข้าถึง

เปิด Everdisk ไปที่แท็บ **การแชร์** แล้วแตะ **สิ่งที่จะแชร์** โฟลเดอร์เอกสารถูกแชร์เป็นค่าเริ่มต้น เพิ่มเติมด้วย **เพิ่มโฟลเดอร์** และ **เพิ่มไฟล์**

เปิด **การตั้งค่า** จากนั้น **การแชร์** แล้ว **การเข้าถึง** เปิด **การแก้ไขไฟล์** หากคุณต้องการให้ผู้คนอัปโหลด เปลี่ยนชื่อ และลบได้ หรือปิดไว้เพื่ออนุญาตให้ดาวน์โหลดอย่างเดียว ตั้ง **ชื่อผู้ใช้** และ **รหัสผ่าน** หากคุณต้องการให้ลงชื่อเข้าใช้ หรือปล่อยว่างไว้เพื่อให้ทุกคนเชื่อมต่อเป็นแขกได้

### ขั้นที่ 2: เปิดเซิร์ฟเวอร์ FTP

ไปที่ **การตั้งค่า** จากนั้น **การแชร์** แล้ว **การเชื่อมต่อ** แล้วเปิด **แอปและอุปกรณ์อื่นๆ** นั่นคือเซิร์ฟเวอร์ FTP (มันมีป้าย FTP)

### ขั้นที่ 3: เริ่มแชร์และจดที่อยู่

กลับไปที่แท็บ **การแชร์** แล้วแตะ **Start** ส่วน **วิธีเชื่อมต่อ** จะแสดงที่อยู่ FTP มันมีหน้าตาแบบนี้:

```
ftp://192.168.1.20:2121
```

ตัวเลขหลังโคลอนคือ **พอร์ต** ซึ่งเป็น **2121** เป็นค่าเริ่มต้น ส่วนแรกคือที่อยู่ของ iPhone บน Wi-Fi ดังนั้นของคุณจะต่างออกไป เปิด Everdisk ค้างไว้บนหน้าจอขณะที่อุปกรณ์เชื่อมต่ออยู่

## เชื่อมต่อจาก Mac

1. เปิด **Finder** เลือก **Go** จากนั้น **Connect to Server** (หรือกด **Command และ K**)
2. พิมพ์ที่อยู่ FTP ที่แสดงใน Everdisk เช่น `ftp://192.168.1.20:2121`
3. คลิก **Connect** จากนั้นเลือก **Guest** หรือกรอก **ชื่อผู้ใช้** และ **รหัสผ่าน** ของคุณ

Finder จะเมาต์การแชร์ FTP คุณจึงเรียกดูและคัดลอกไฟล์ไปยัง Mac ได้ หมายเหตุว่า Finder เปิด FTP แบบอ่านอย่างเดียว เมื่อคุณต้องการอัปโหลดจาก Mac ให้ใช้แอป FTP ตามที่อธิบายไว้ด้านล่าง

## เชื่อมต่อจาก Windows

1. เปิด **File Explorer** แล้วคลิกแถบที่อยู่ด้านบน
2. พิมพ์ที่อยู่ FTP จาก Everdisk เช่น `ftp://192.168.1.20:2121` แล้วกด **Enter**
3. กรอก **ชื่อผู้ใช้** และ **รหัสผ่าน** หากคุณตั้งไว้ หรือดำเนินการต่อเป็นแขก

ไฟล์ที่แชร์จะปรากฏในหน้าต่างและคุณคัดลอกไปยังพีซีได้

## เชื่อมต่อด้วยแอป FTP (FileZilla, Cyberduck)

สำหรับการอัปโหลดและการควบคุมเต็มรูปแบบ แอป FTP คือเครื่องมือที่ดีที่สุด **FileZilla** และ **Cyberduck** ฟรีและทำงานได้บน Windows, Mac และ Linux

1. เปิดแอปแล้วสร้างการเชื่อมต่อใหม่
2. ตั้ง **Host** เป็นที่อยู่ Wi-Fi ของ iPhone และ **Port** เป็น **2121**
3. สำหรับล็อกอิน ให้กรอก **ชื่อผู้ใช้** และ **รหัสผ่าน** ของคุณ หรือเลือก **Anonymous** หากคุณไม่ได้ตั้งไว้
4. เชื่อมต่อ แล้วลากไฟล์ได้ทั้งสองทิศทาง (การอัปโหลดต้องเปิด การแก้ไขไฟล์)

## เชื่อมต่อจาก Linux

1. เปิดตัวจัดการไฟล์ของคุณแล้วเลือก **Connect to Server** หรือ **Other Locations**
2. ป้อนที่อยู่ เช่น `ftp://192.168.1.20:2121`
3. เชื่อมต่อเป็นแขก หรือด้วยล็อกอินของคุณ

คุณยังใช้ไคลเอนต์ FTP ของ Linux ใด ๆ จากเทอร์มินัลได้ โดยชี้ไปที่โฮสต์เดียวกันและพอร์ต 2121

## เชื่อมต่อจาก Android

Android ไม่มีตัวเรียกดู FTP ของระบบ จึงต้องใช้แอป:

1. ติดตั้งไคลเอนต์ FTP เช่น **AndFTP**, **FTPCafe** หรือตัวจัดการไฟล์ที่รองรับ FTP อย่าง **Solid Explorer**
2. เพิ่มการเชื่อมต่อด้วยโฮสต์ **พอร์ต 2121** และล็อกอินของคุณหรือ Anonymous
3. เรียกดูและโอน

## เชื่อมต่อจาก iPhone หรือ iPad อีกเครื่อง

แอป Files ของ iOS ไม่มีไคลเอนต์ FTP รวมอยู่ด้วย จึงให้ใช้อย่างใดอย่างหนึ่งต่อไปนี้บนอุปกรณ์เครื่องที่สอง:

- **แท็บ อุปกรณ์ ของ Everdisk เอง** เปิด Everdisk ไปที่ **อุปกรณ์** แตะ **การเชื่อมต่อใหม่** เลือก **FTP** แล้วป้อนที่อยู่ เช่น `ftp://192.168.1.20:2121` นี่คือเส้นทางที่ง่ายที่สุด
- **แอป FTP เฉพาะทาง** สำหรับ iOS โดยใช้โฮสต์ พอร์ต 2121 และล็อกอินเดียวกัน

## เชื่อมต่ออุปกรณ์อื่น: กล้อง ทีวี เราเตอร์ และ NAS

นี่คือจุดที่ FTP โดดเด่น อุปกรณ์หลายอย่างมีไคลเอนต์ FTP ในตัวที่ส่งหรือดึงไฟล์ได้:

- **กล้อง** ที่อัปโหลดรูปภาพผ่าน FTP ส่งรูปตรงไปยัง iPhone ของคุณได้
- **สมาร์ททีวี เราเตอร์ กล่อง NAS และเครื่องมืออัตโนมัติ** ที่รองรับ FTP เชื่อมต่อได้ในแบบเดียวกัน

ชี้พวกมันไปที่ที่อยู่ Wi-Fi ของ iPhone พอร์ต **2121** และล็อกอินของคุณ (หรือ Anonymous) โดยใช้ที่อยู่ที่แสดงใน Everdisk

## อ่านอย่างเดียว หรืออ่านและเขียน

สวิตช์ **การแก้ไขไฟล์** ใน การตั้งค่า, การแชร์, การเข้าถึง ควบคุมสิ่งนี้ เปิดให้ผู้คนอัปโหลด เปลี่ยนชื่อ และลบได้ ปิดหมายความว่าพวกเขาดาวน์โหลดได้อย่างเดียว เลือกอ่านอย่างเดียวเมื่อคุณส่งไฟล์ออกไปและไม่ต้องการให้อะไรบนโทรศัพท์ถูกเปลี่ยนแปลง

## วิธีที่ผู้คนใช้งานในชีวิตจริง

- **เชื่อมต่อ FileZilla กับ iPhone ของคุณ** แล้วส่งไฟล์ชุดหนึ่งลงโทรศัพท์ในครั้งเดียว
- **ให้แอปหรืออุปกรณ์เก่าที่พูดได้แต่ FTP** เข้าถึงไฟล์ของคุณเมื่อไม่มีอะไรอื่นเชื่อมต่อได้
- **รับรูปภาพจากกล้อง** ที่อัปโหลดผ่าน FTP
- **ย้ายไฟล์ระหว่าง iPhone และ iPad** โดยใช้แท็บ อุปกรณ์ ของ Everdisk บนอุปกรณ์ที่รับ

## เคล็ดลับเล็กน้อย

- เปิด Everdisk ค้างไว้ขณะที่อุปกรณ์เชื่อมต่ออยู่ เพราะ iOS จะหยุดพักแอปเบื้องหลังหลังจากผ่านไปสักพัก
- หากต้องการอัปโหลดจาก Mac ให้ใช้ FileZilla หรือ Cyberduck แทน Finder เพราะ Finder เปิด FTP แบบอ่านอย่างเดียว
- ปล่อยล็อกอินว่างไว้เพื่อความเข้ากันได้กว้างที่สุด แล้วเชื่อมต่อเป็น Anonymous ซึ่งไคลเอนต์ FTP ส่วนใหญ่มีให้
- FTP ไม่เข้ารหัสการรับส่งข้อมูล บนเครือข่ายที่คุณไม่ไว้ใจ ให้ใช้ [เซิร์ฟเวอร์ SMB พร้อมการเข้ารหัส](/docs/howto/how-to-set-up-smb-server-on-iphone-ipad-for-file-sharing/) แทน

FTP แบบธรรมดาไม่เข้ารหัสการรับส่งข้อมูล จึงควรถือว่ามันเป็นเครื่องมือสำหรับเครือข่ายที่คุณไว้ใจ เช่น Wi-Fi ที่บ้าน บนเครือข่ายที่คุณควบคุมไม่ได้ ให้ใช้เซิร์ฟเวอร์ SMB โดยเปิด ต้องใช้การเข้ารหัส SMB ซึ่งปกป้องการถ่ายโอนทุกครั้ง
{{% /details %}}

{{% details title="อุปกรณ์ไหนเชื่อมต่อผ่าน FTP ได้บ้าง?" closed="true" %}}
เกือบทุกอย่างที่มีไคลเอนต์ FTP ซึ่งรวมถึงคอมพิวเตอร์ Mac, Windows และ Linux แอป FTP อย่าง FileZilla และ Cyberduck ตัวจัดการไฟล์ Android และฮาร์ดแวร์เช่นกล้อง สมาร์ททีวี เราเตอร์ กล่อง NAS และเครื่องมืออัตโนมัติ การเข้าถึงที่กว้างขวางนั้นคือเหตุผลหลักในการเลือก FTP
{{% /details %}}
