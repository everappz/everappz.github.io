FTP はファイル転送の昔ながらの定番です。何十年も使われてきましたが、それこそが便利な理由です。サーバーと通信できるものなら、ほぼ何でも FTP を理解します。カメラ、スマート TV、ルーター、ネットワークドライブ、自動化ツール、そしてあらゆるデスクトップの FTP アプリが FTP を話します。[Everdisk](/products/everdisk) を使えば、iPhone や iPad で FTP サーバーを動かせるので、スマホがそれらのデバイスやアプリの接続先となり、ファイルを移動できる場所になります。

FTP は、他の選択肢が合わないとき、たとえば古いデバイスや FTP でしか接続できないアプリのために使います。このガイドでは、設定方法と、Mac、Windows、FTP アプリ、Linux、Android、2 台目の iPhone からの接続方法を解説します。

## 必要なもの

- [Everdisk](https://apps.apple.com/app/apple-store/id6751851132?pt=95781850&ct=everappzcom&mt=8) をインストールした iPhone または iPad。
- **同じ Wi-Fi ネットワーク**上のパソコン、アプリ、またはデバイス。
- 共有したいファイル。Everdisk の書類フォルダー内、または追加したフォルダー内にあること。

## Everdisk で FTP サーバーを設定する

### ステップ 1: 共有する内容を選んでアクセスを設定する

Everdisk を開き、**共有**タブに移動して、**共有する内容**をタップします。書類フォルダーは既定で共有されています。**フォルダを追加**や**ファイルを追加**でさらに加えられます。

**設定**、**共有**、**アクセス**の順に開きます。相手にアップロード・名前の変更・削除を許可したい場合は**ファイルの編集**をオンに、ダウンロードのみを許可する場合はオフにします。サインインさせたい場合は**ログイン**と**パスワード**を設定し、誰でもゲストとして接続できるようにする場合は空のままにします。

### ステップ 2: FTP サーバーをオンにする

**設定**、**共有**、**接続**の順に進み、**その他のアプリやデバイス**をオンにします。これが FTP サーバーです (FTP のタグが付いています)。

### ステップ 3: 共有を開始してアドレスを控える

**共有**タブに戻り、**スタート**をタップします。**接続方法**のセクションに FTP アドレスが表示されます。次のような形です:

```
ftp://192.168.1.20:2121
```

コロンの後ろの数字が**ポート**で、既定では **2121** です。最初の部分は Wi-Fi 上での iPhone のアドレスなので、あなたの場合は異なります。デバイスが接続している間は Everdisk を画面に開いたままにしてください。

## Mac から接続する

1. **Finder** を開き、**移動**を選び、次に**サーバへ接続**を選びます (または **Command と K** を押します)。
2. Everdisk に表示された FTP アドレス (例: `ftp://192.168.1.20:2121`) を入力します。
3. **接続**をクリックし、**ゲスト**を選ぶか、**ログイン**と**パスワード**を入力します。

Finder が FTP 共有をマウントするので、閲覧して Mac にファイルをコピーできます。ただし Finder は FTP を読み取り専用で開くことに注意してください。Mac からアップロードしたいときは、後述のように FTP アプリを使ってください。

## Windows から接続する

1. **エクスプローラー**を開き、上部のアドレスバーをクリックします。
2. Everdisk の FTP アドレス (例: `ftp://192.168.1.20:2121`) を入力し、**Enter** を押します。
3. 設定した場合は**ログイン**と**パスワード**を入力するか、ゲストとして続行します。

共有されたファイルがウィンドウに表示され、PC にコピーできます。

## FTP アプリで接続する (FileZilla、Cyberduck)

アップロードや細かい制御には、FTP アプリが最適なツールです。**FileZilla** と **Cyberduck** は無料で、Windows、Mac、Linux で動きます。

1. アプリを開いて新しい接続を作成します。
2. **Host** を iPhone の Wi-Fi アドレスに、**Port** を **2121** に設定します。
3. ログインには**ログイン**と**パスワード**を入力するか、設定していない場合は **Anonymous** を選びます。
4. 接続して、双方向にファイルをドラッグします (アップロードにはファイルの編集がオンである必要があります)。

## Linux から接続する

1. ファイルマネージャーを開き、**Connect to Server** または **Other Locations** を選びます。
2. アドレス (例: `ftp://192.168.1.20:2121`) を入力します。
3. ゲストとして接続するか、ログインで接続します。

ターミナルから任意の Linux FTP クライアントを使い、同じホストとポート 2121 に向けることもできます。

## Android から接続する

Android にはシステムの FTP ブラウザがないので、アプリを使います:

1. **AndFTP**、**FTPCafe** のような FTP クライアント、または **Solid Explorer** のような FTP 対応のファイルマネージャーをインストールします。
2. ホスト、**ポート 2121**、そしてログインまたは Anonymous で接続を追加します。
3. 閲覧して転送します。

## 別の iPhone や iPad から接続する

iOS のファイルアプリには FTP クライアントが含まれていないので、2 台目のデバイスで次のいずれかを使います:

- **Everdisk 自身のデバイスタブ。** Everdisk を開き、**デバイス**に移動して、**新しい接続**をタップし、**FTP** を選んでアドレス (例: `ftp://192.168.1.20:2121`) を入力します。これが一番簡単な方法です。
- **iOS 向けの専用 FTP アプリ。** 同じホスト、ポート 2121、ログインを使います。

## 他の機器を接続する: カメラ、TV、ルーター、NAS

ここが FTP の真価を発揮するところです。多くのデバイスには、ファイルを送受信できる FTP クライアントが内蔵されています:

- **FTP で写真をアップロードするカメラ**は、それらを iPhone へ直接送れます。
- FTP に対応した**スマート TV、ルーター、NAS ボックス、自動化ツール**も、同じように接続できます。

Everdisk に表示されたアドレスを使って、iPhone の Wi-Fi アドレス、ポート **2121**、そしてログイン (または Anonymous) をそれらに指定してください。

## 読み取り専用か、読み書きか

設定、共有、アクセスの**ファイルの編集**スイッチがこれを制御します。オンにすると、相手はアップロード・名前の変更・削除ができます。オフにすると、ダウンロードだけができます。ファイルを渡すだけで、スマホ上のものを何も変更されたくないときは、読み取り専用を選んでください。

## 実際の活用シーン

- **FileZilla を iPhone に接続。** 一度にまとめてファイルをスマホに送り込めます。
- **FTP でしか話せない古いアプリやデバイス**に、他の方法では接続できないときにファイルへ到達させます。
- **FTP でアップロードするカメラから写真を受け取る。**
- **iPhone と iPad の間でファイルを移動。** 受け取る側のデバイスで Everdisk のデバイスタブを使います。

## いくつかのヒント

- デバイスが接続している間は Everdisk を開いたままにしてください。iOS はしばらくするとバックグラウンドのアプリを一時停止するためです。
- Mac からアップロードするには、Finder ではなく FileZilla や Cyberduck を使ってください。Finder は FTP を読み取り専用で開くためです。
- 最も幅広い互換性のためにログインを空のままにし、ほとんどの FTP クライアントが備える Anonymous として接続してください。
- FTP は通信を暗号化しません。信頼できないネットワークでは、代わりに [暗号化付きの SMB サーバー](/docs/howto/how-to-set-up-smb-server-on-iphone-ipad-for-file-sharing/)を使ってください。

共有を開始すると、Everdisk が共有画面にアドレスを表示します。ftp://192.168.1.20:2121 のような形です。2121 は Everdisk が FTP に使うポートで、最初の部分は Wi-Fi 上での iPhone のアドレスなので、あなたの場合は異なります。

{{% details title="FileZilla や Cyberduck を iPhone に接続するにはどうしますか?" closed="true" %}}
アプリを開いて新しい接続を作成します。Host を iPhone の Wi-Fi アドレスに、Port を 2121 に設定します。ログインとパスワードを入力するか、Everdisk で設定していない場合は Anonymous を選びます。接続すると、ファイルの編集がオンのときは双方向にファイルをドラッグできます。

{{% details title="Windows から iPhone の FTP に接続できますか?" closed="true" %}}
はい。エクスプローラーを開き、アドレスバーをクリックして、Everdisk の FTP アドレス (例: ftp://192.168.1.20:2121) を入力し、Enter を押します。設定した場合はログインを入力するか、ゲストとして続行します。アップロードやより細かい制御には、代わりに FileZilla のような FTP アプリを使ってください。
{{% /details %}}

{{% details title="FTP にログインは必要ですか?" closed="true" %}}
いいえ、ログインは任意です。設定、共有、アクセスでログインとパスワードを空のままにし、ほとんどの FTP クライアントが備える Anonymous として接続してください。まずサインインさせたい場合はログインを設定します。
{{% /details %}}

{{% details title="FTP でダウンロードはできるのにアップロードできないのはなぜですか?" closed="true" %}}
よくある理由は 2 つあります。1 つ目は、アップロード・名前の変更・削除を許可するには、設定、共有、アクセスのファイルの編集スイッチがオンである必要があること。2 つ目は、Mac の Finder が FTP を読み取り専用で開くことです。アップロードしたいときは FileZilla や Cyberduck のような FTP アプリを使ってください。
{{% /details %}}

{{% details title="2 台の iPhone の間で FTP を使えますか?" closed="true" %}}
はい。1 台目の iPhone で FTP サーバーを開始します。2 台目で Everdisk を開き、デバイスタブに移動して、新しい接続をタップし、FTP を選び、1 台目のスマホに表示されたアドレスを入力します。iOS のファイルアプリには FTP クライアントが含まれていないため、iOS 向けの専用 FTP アプリでも使えます。
{{% /details %}}

{{% details title="FTP は安全ですか?" closed="true" %}}
プレーンな FTP は通信を暗号化しないので、自宅の Wi-Fi のような信頼できるネットワーク向けのツールとして扱ってください。管理していないネットワークでは、SMB 暗号化を必須にするをオンにした SMB サーバーを使ってください。これはすべての転送を保護します。
{{% /details %}}

{{% details title="どのデバイスが FTP で接続できますか?" closed="true" %}}
FTP クライアントを備えたものなら、ほぼ何でも接続できます。Mac、Windows、Linux のパソコン、FileZilla や Cyberduck のような FTP アプリ、Android のファイルマネージャー、そしてカメラ、スマート TV、ルーター、NAS ボックス、自動化ツールのようなハードウェアも含まれます。その幅広い対応が、FTP を選ぶ主な理由です。
{{% /details %}}

{{% details title="FTP 接続が切れたのはなぜですか?" closed="true" %}}
iPhone がサーバーで、iOS はバックグラウンドに長く留まったアプリを一時停止します。デバイスが接続している間は Everdisk を画面に開いたままにし、長時間の転送中は電源につないでください。また、両方のデバイスが同じ Wi-Fi にとどまっていることも確認してください。
{{% /details %}}
