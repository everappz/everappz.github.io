Λειτουργεί πάνω από το ίδιο διαδικτυακό πρωτόκολλο που χρησιμοποιεί το πρόγραμμα περιήγησής σας, γι' αυτό ταξιδεύει καλά ανάμεσα σε Mac, Windows και Linux χωρίς ειδικά προγράμματα οδήγησης. Με το [Everdisk](/products/everdisk) μπορείτε να τρέξετε έναν διακομιστή WebDAV στο iPhone ή στο iPad σας, ώστε το τηλέφωνο να εμφανίζεται ως δίσκος στον οποίο μπορείτε να περιηγηθείτε, να αντιγράψετε από αυτόν και να αντιγράψετε προς αυτόν από σχεδόν οποιονδήποτε υπολογιστή.

Το WebDAV είναι η καλύτερη επιλογή όταν στην εικόνα υπάρχουν Windows, γιατί η File Explorer των Windows συνδέεται σε αυτό καθαρά. Αυτός ο οδηγός καλύπτει τη ρύθμιση και πώς να συνδεθείτε από Mac, Windows, Linux, Android και ένα δεύτερο iPhone.

## Ρυθμίστε τον διακομιστή WebDAV στο Everdisk

### Βήμα 1: Επιλέξτε τι θα μοιραστείτε και ορίστε την πρόσβαση

Ανοίξτε το Everdisk, μεταβείτε στην καρτέλα **Κοινή χρήση** και πατήστε **Τι να μοιραστείς**. Ο φάκελος Έγγραφα μοιράζεται από προεπιλογή. Προσθέστε περισσότερα με τα **Προσθήκη φακέλου** και **Προσθήκη αρχείου**.

Ανοίξτε τις **Ρυθμίσεις**, έπειτα την **Κοινή χρήση** και την **Πρόσβαση**. Ενεργοποιήστε την **Επεξεργασία αρχείων** αν θέλετε οι συνδεδεμένοι υπολογιστές να αντιγράφουν αρχεία στο τηλέφωνό σας και να τα μετονομάζουν ή να τα διαγράφουν, ή απενεργοποιήστε την για έναν δίσκο μόνο για ανάγνωση. Ορίστε ένα **Όνομα σύνδεσης** και έναν **Κωδικό** εδώ αν θέλετε σύνδεση με λογαριασμό, ή αφήστε τα κενά για πρόσβαση επισκέπτη.

### Βήμα 2: Ενεργοποιήστε τον διακομιστή WebDAV

Μεταβείτε στις **Ρυθμίσεις**, έπειτα στην **Κοινή χρήση** και στις **Συνδέσεις**, και ενεργοποιήστε τον **Υπολογιστής**. Αυτός είναι ο διακομιστής WebDAV (φέρει την ετικέτα WebDAV).

### Βήμα 3: Ξεκινήστε την κοινή χρήση και σημειώστε τη διεύθυνση

Επιστρέψτε στην καρτέλα **Κοινή χρήση** και πατήστε **Έναρξη**. Η ενότητα **Πώς να συνδεθείς** εμφανίζει τη διεύθυνση WebDAV. Μοιάζει κάπως έτσι:

```
http://192.168.1.20:8080
```

Ο αριθμός μετά την άνω και κάτω τελεία είναι η **θύρα**, που είναι **8080** από προεπιλογή. Το πρώτο μέρος είναι η διεύθυνση του iPhone σας στο Wi-Fi, οπότε η δική σας θα διαφέρει. Κρατήστε το Everdisk ανοιχτό στην οθόνη όσο μια συσκευή είναι συνδεδεμένη.

## Σύνδεση από Mac

1. Ανοίξτε το **Finder**, επιλέξτε **Μετάβαση**, έπειτα **Σύνδεση με διακομιστή** (ή πατήστε **Command και K**).
2. Πληκτρολογήστε τη διεύθυνση WebDAV που εμφανίζεται στο Everdisk, για παράδειγμα `http://192.168.1.20:8080`.
3. Κάντε κλικ στο **Σύνδεση**, έπειτα επιλέξτε **Επισκέπτης** ή εισάγετε το **Όνομα σύνδεσης** και τον **Κωδικό** σας.

Το iPhone σας ανοίγει σε ένα παράθυρο του Finder και συμπεριφέρεται σαν κανονικός φάκελος. Αντιγράψτε αρχεία προς οποιαδήποτε κατεύθυνση αν η Επεξεργασία αρχείων είναι ενεργή.

## Σύνδεση από Windows

Τα Windows διαθέτουν ενσωματωμένο πελάτη WebDAV, οπότε αυτό λειτουργεί από την File Explorer.

1. Ανοίξτε την **File Explorer**, κάντε δεξί κλικ στο **This PC** στην πλαϊνή μπάρα και επιλέξτε **Add a network location** (μπορείτε επίσης να χρησιμοποιήσετε το **Map network drive**).
2. Όταν σας ζητηθεί η διεύθυνση, πληκτρολογήστε την ίδια διεύθυνση WebDAV από το Everdisk, για παράδειγμα `http://192.168.1.20:8080`, έπειτα κάντε κλικ στο **Next**.
3. Εισάγετε το **Όνομα σύνδεσης** και τον **Κωδικό** σας, αν ορίσατε.

Η συσκευή εμφανίζεται τότε κάτω από το This PC ως δικτυακή τοποθεσία που μπορείτε να ανοίξετε και από την οποία να αντιγράψετε αρχεία. Αν τα Windows αρνηθούν να συνδεθούν την πρώτη φορά, βεβαιωθείτε ότι η υπηρεσία **WebClient** εκτελείται (αναζητήστε Services στο μενού Start, βρείτε το WebClient και ρυθμίστε το να ξεκινά), έπειτα δοκιμάστε ξανά.

## Σύνδεση από Linux

1. Ανοίξτε τον διαχειριστή αρχείων σας και επιλέξτε **Connect to Server** ή **Other Locations**.
2. Εισάγετε τη διεύθυνση με πρόθεμα WebDAV, για παράδειγμα `dav://192.168.1.20:8080` (χρησιμοποιήστε `davs://` μόνο αν ρυθμίσατε TLS).
3. Συνδεθείτε ως επισκέπτης ή εισάγετε το όνομα σύνδεσής σας.

## Σύνδεση από Android

Το Android δεν διαθέτει περιηγητή WebDAV συστήματος, οπότε χρησιμοποιήστε έναν διαχειριστή αρχείων που το υποστηρίζει:

1. Εγκαταστήστε μια εφαρμογή όπως το **Solid Explorer** ή το **CX File Explorer**.
2. Προσθέστε μια νέα σύνδεση **WebDAV**.
3. Εισάγετε τον host και τη **θύρα 8080**, επιλέξτε το σχήμα `http` και προσθέστε το όνομα σύνδεσής σας αν ορίσατε.

Αυτή είναι η πιο απλή διαδρομή και δεν χρειάζεται τίποτα επιπλέον.
