WebDAV เปลี่ยนโฟลเดอร์ให้เป็นไดรฟ์เครือข่ายที่คอมพิวเตอร์เปิดในตัวจัดการไฟล์ปกติได้ มันทำงานผ่านโปรโตคอลเว็บเดียวกับที่เบราว์เซอร์ของคุณใช้ ซึ่งเป็นเหตุผลว่าทำไมมันจึงเดินทางข้าม Mac, Windows และ Linux ได้ดีโดยไม่ต้องใช้ไดรเวอร์พิเศษ ด้วย [Everdisk](/products/everdisk) คุณสามารถรันเซิร์ฟเวอร์ WebDAV บน iPhone หรือ iPad ของคุณได้ โทรศัพท์จึงปรากฏเป็นไดรฟ์ที่คุณเรียกดู คัดลอกออกมา และคัดลอกเข้าไปได้จากคอมพิวเตอร์เกือบทุกเครื่อง

WebDAV เป็นตัวเลือกที่ดีที่สุดเมื่อมี Windows เข้ามาเกี่ยวข้อง เพราะ Windows File Explorer เชื่อมต่อกับมันได้อย่างราบรื่น คู่มือนี้ครอบคลุมการตั้งค่าและวิธีเชื่อมต่อจาก Mac, Windows, Linux, Android และ iPhone อีกเครื่อง

## สิ่งที่คุณต้องมี

- iPhone หรือ iPad ที่ติดตั้ง [Everdisk](https://apps.apple.com/app/apple-store/id6751851132?pt=95781850&ct=everappzcom&mt=8) แล้ว
- คอมพิวเตอร์หรืออุปกรณ์อีกเครื่องบน **เครือข่าย Wi-Fi เดียวกัน**
- ไฟล์ที่คุณต้องการแชร์ ในโฟลเดอร์เอกสารของ Everdisk หรือในโฟลเดอร์ที่คุณเพิ่ม

## ตั้งค่าเซิร์ฟเวอร์ WebDAV ใน Everdisk

### ขั้นที่ 1: เลือกสิ่งที่จะแชร์และตั้งค่าการเข้าถึง

เปิด Everdisk ไปที่แท็บ **การแชร์** แล้วแตะ **สิ่งที่จะแชร์** โฟลเดอร์เอกสารถูกแชร์เป็นค่าเริ่มต้น เพิ่มเติมด้วย **เพิ่มโฟลเดอร์** และ **เพิ่มไฟล์**

เปิด **การตั้งค่า** จากนั้น **การแชร์** แล้ว **การเข้าถึง** เปิด **การแก้ไขไฟล์** หากคุณต้องการให้คอมพิวเตอร์ที่เชื่อมต่อคัดลอกไฟล์ลงโทรศัพท์และเปลี่ยนชื่อหรือลบได้ หรือปิดไว้เพื่อให้เป็นไดรฟ์อ่านอย่างเดียว ตั้ง **ชื่อผู้ใช้** และ **รหัสผ่าน** ที่นี่หากคุณต้องการให้ลงชื่อเข้าใช้ หรือปล่อยว่างไว้เพื่อการเข้าถึงแบบแขก

### ขั้นที่ 2: เปิดเซิร์ฟเวอร์ WebDAV

ไปที่ **การตั้งค่า** จากนั้น **การแชร์** แล้ว **การเชื่อมต่อ** แล้วเปิด **คอมพิวเตอร์** นั่นคือเซิร์ฟเวอร์ WebDAV (มันมีป้าย WebDAV)

### ขั้นที่ 3: เริ่มแชร์และจดที่อยู่

กลับไปที่แท็บ **การแชร์** แล้วแตะ **Start** ส่วน **วิธีเชื่อมต่อ** จะแสดงที่อยู่ WebDAV มันมีหน้าตาแบบนี้:

```
http://192.168.1.20:8080
```

ตัวเลขหลังโคลอนคือ **พอร์ต** ซึ่งเป็น **8080** เป็นค่าเริ่มต้น ส่วนแรกคือที่อยู่ของ iPhone บน Wi-Fi ดังนั้นของคุณจะต่างออกไป เปิด Everdisk ค้างไว้บนหน้าจอขณะที่อุปกรณ์เชื่อมต่ออยู่

## เชื่อมต่อจาก Mac

1. เปิด **Finder** เลือก **Go** จากนั้น **Connect to Server** (หรือกด **Command และ K**)
2. พิมพ์ที่อยู่ WebDAV ที่แสดงใน Everdisk เช่น `http://192.168.1.20:8080`
3. คลิก **Connect** จากนั้นเลือก **Guest** หรือกรอก **ชื่อผู้ใช้** และ **รหัสผ่าน** ของคุณ

iPhone ของคุณจะเปิดในหน้าต่าง Finder และทำตัวเหมือนโฟลเดอร์ทั่วไป คัดลอกไฟล์ได้ทั้งสองทิศทางหาก การแก้ไขไฟล์ เปิดอยู่

## เชื่อมต่อจาก Windows

Windows มีไคลเอนต์ WebDAV ในตัว จึงทำงานได้จาก File Explorer

1. เปิด **File Explorer** คลิกขวา **This PC** ในแถบข้าง แล้วเลือก **Add a network location** (คุณยังใช้ **Map network drive** ได้ด้วย)
2. เมื่อถูกถามที่อยู่ ให้พิมพ์ที่อยู่ WebDAV เดียวกันจาก Everdisk เช่น `http://192.168.1.20:8080` แล้วคลิก **Next**
3. กรอก **ชื่อผู้ใช้** และ **รหัสผ่าน** หากคุณตั้งไว้

จากนั้นอุปกรณ์จะปรากฏใต้ This PC เป็นตำแหน่งเครือข่ายที่คุณเปิดและคัดลอกไฟล์ออกมาได้ หาก Windows ปฏิเสธการเชื่อมต่อครั้งแรก ตรวจสอบให้แน่ใจว่าบริการ **WebClient** กำลังทำงานอยู่ (ค้นหา Services ในเมนู Start หา WebClient แล้วตั้งให้เริ่มทำงาน) จากนั้นลองอีกครั้ง

## เชื่อมต่อจาก Linux

1. เปิดตัวจัดการไฟล์ของคุณแล้วเลือก **Connect to Server** หรือ **Other Locations**
2. ป้อนที่อยู่พร้อมคำนำหน้า WebDAV เช่น `dav://192.168.1.20:8080` (ใช้ `davs://` เฉพาะเมื่อคุณตั้งค่า TLS)
3. เชื่อมต่อเป็นแขก หรือกรอกล็อกอินของคุณ

## เชื่อมต่อจาก Android

Android ไม่มีตัวเรียกดู WebDAV ของระบบ จึงต้องใช้ตัวจัดการไฟล์ที่รองรับมัน:

1. ติดตั้งแอปเช่น **Solid Explorer** หรือ **CX File Explorer**
2. เพิ่มการเชื่อมต่อ **WebDAV** ใหม่
3. ป้อนโฮสต์และ **พอร์ต 8080** เลือกสคีม `http` และเพิ่มล็อกอินของคุณหากตั้งไว้

## เชื่อมต่อจาก iPhone หรือ iPad อีกเครื่อง

แอป Files ของ iOS ไม่มีไคลเอนต์ WebDAV รวมอยู่ด้วย จึงให้ใช้อย่างใดอย่างหนึ่งต่อไปนี้:

- **แท็บ อุปกรณ์ ของ Everdisk เอง** บนอุปกรณ์เครื่องที่สอง ให้เปิด Everdisk ไปที่ **อุปกรณ์** แตะ **การเชื่อมต่อใหม่** เลือก **WebDAV** แล้วป้อนที่อยู่ เช่น `http://192.168.1.20:8080` นี่คือเส้นทางที่ง่ายที่สุดและไม่ต้องมีอะไรเพิ่ม
- **แอป WebDAV** เช่น Documents by Readdle ซึ่งเพิ่มการเชื่อมต่อ WebDAV ด้วยที่อยู่และล็อกอินเดียวกันได้

## อยากได้ลิงก์ด่วนแทนไดรฟ์?

หากคุณเพียงต้องการหยิบไฟล์อย่างรวดเร็วและไม่อยากเมาต์ไดรฟ์เลย ให้เปิดการเชื่อมต่อ **เบราว์เซอร์** ใน การตั้งค่า, การแชร์, การเชื่อมต่อ จากนั้น Everdisk จะให้ที่อยู่เว็บที่คุณเปิดในเบราว์เซอร์ใดก็ได้บนอุปกรณ์ใดก็ได้เพื่อเรียกดูและดาวน์โหลดไฟล์ของคุณ มันเป็นวิธีที่เร็วที่สุดในการส่งไฟล์ให้พีซี Windows, Chromebook หรือโทรศัพท์ของเพื่อน

## อ่านอย่างเดียว หรืออ่านและเขียน

สวิตช์ **การแก้ไขไฟล์** ใน การตั้งค่า, การแชร์, การเข้าถึง ตัดสินสิ่งนี้ เปิดหมายความว่าคอมพิวเตอร์ที่เชื่อมต่อสามารถอัปโหลด เปลี่ยนชื่อ และลบได้ ปิดหมายความว่าไดรฟ์เป็นแบบอ่านอย่างเดียว ผู้อื่นจึงดูและคัดลอกไฟล์ของคุณได้แต่เปลี่ยนแปลงไม่ได้

## วิธีที่ผู้คนใช้งานในชีวิตจริง

- **คัดลอกไฟล์ลง iPhone จากพีซี Windows** ด้วยการแมปมันเป็นตำแหน่งเครือข่ายแล้วลากข้ามมา
- **ถ่ายรูปภาพและเอกสารลงแล็ปท็อป** โดยใช้ตัวจัดการไฟล์ที่คุณรู้จักอยู่แล้ว ไม่ต้องใช้สายและไม่ต้องใช้ iTunes
- **แก้ไขเอกสารในที่เดิม** จาก Mac ของคุณ เปิดมันตรงจากโทรศัพท์แล้วบันทึกกลับ
- **ย้ายโฟลเดอร์ระหว่าง iPhone และ iPad** โดยใช้แท็บ อุปกรณ์ ของ Everdisk บนอุปกรณ์ที่รับ

## เคล็ดลับเล็กน้อย

- เปิด Everdisk ค้างไว้ขณะที่อุปกรณ์เชื่อมต่ออยู่ การล็อกโทรศัพท์เป็นเวลานานอาจหยุดพักแอป
- บน Windows หากการเชื่อมต่อล้มเหลว ให้เริ่มบริการ WebClient แล้วลองที่อยู่อีกครั้ง
- WebDAV และ SMB ต่างก็เมาต์เป็นไดรฟ์เครือข่าย ใช้ WebDAV เมื่อมี Windows เข้ามาเกี่ยวข้อง และ [SMB](/docs/howto/how-to-set-up-smb-server-on-iphone-ipad-for-file-sharing/) เมื่อคุณต้องการความเร็วของ Finder และการเข้ารหัส
- เพื่อการถ่ายโอนที่เร็วที่สุด ให้ตั้งคุณภาพรูปภาพและวิดีโอไว้ที่ Original ในการตั้งค่า
