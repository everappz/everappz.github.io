WebDAV הופך תיקייה לכונן רשת שמחשב יכול לפתוח במנהל הקבצים הרגיל שלו. הוא רץ על אותו פרוטוקול אינטרנט שהדפדפן שלכם משתמש בו, ולכן הוא נודד היטב בין Mac, Windows ו-Linux בלי מנהלי התקנים מיוחדים. עם [Everdisk](/products/everdisk) אפשר להריץ שרת WebDAV על ה-iPhone או ה-iPad שלכם, כך שהטלפון מופיע ככונן שאפשר לעיין בו, להעתיק ממנו ולהעתיק אליו כמעט מכל מחשב.

WebDAV הוא הבחירה הטובה ביותר כש-Windows בתמונה, כי File Explorer ב-Windows מתחבר אליו בצורה נקייה. המדריך הזה מכסה את ההקמה ואיך להתחבר מ-Mac, מ-Windows, מ-Linux, מ-Android ומ-iPhone שני.

## מה צריך

- iPhone או iPad עם [Everdisk](https://apps.apple.com/app/apple-store/id6751851132?pt=95781850&ct=everappzcom&mt=8) מותקן.
- מחשב או מכשיר אחר **באותה רשת Wi-Fi**.
- הקבצים שאתם רוצים לשתף, בתיקיית המסמכים של Everdisk או בתיקיות שאתם מוסיפים.

## הקמת שרת ה-WebDAV ב-Everdisk

### שלב 1: בחרו מה לשתף והגדירו גישה

פתחו את Everdisk, עברו ללשונית **שיתוף**, והקישו על **מה לשתף**. תיקיית המסמכים משותפת כברירת מחדל. הוסיפו עוד עם **הוסף תיקייה** ו-**הוסף קובץ**.

פתחו את **הגדרות**, ואז **שיתוף**, ואז **גישה**. הפעילו את **עריכת קבצים** אם אתם רוצים שמחשבים מחוברים יעתיקו קבצים אל הטלפון שלכם וישנו שם או ימחקו, או כבו אותה לכונן לקריאה בלבד. הגדירו כאן **התחברות** ו-**סיסמה** אם אתם רוצים כניסה, או השאירו אותן ריקות לגישת אורח.

### שלב 2: הפעילו את שרת ה-WebDAV

עברו אל **הגדרות**, ואז **שיתוף**, ואז **חיבורים**, והפעילו את **מחשב**. זה שרת ה-WebDAV (הוא נושא את התג WebDAV).

### שלב 3: התחילו לשתף ורשמו את הכתובת

חזרו ללשונית **שיתוף** והקישו על **התחלה**. סעיף **כיצד להתחבר** מציג את כתובת ה-WebDAV. היא נראית כך:

```
http://192.168.1.20:8080
```

המספר אחרי הנקודתיים הוא ה-**פורט**, שהוא **8080** כברירת מחדל. החלק הראשון הוא כתובת ה-iPhone שלכם ברשת ה-Wi-Fi, ולכן שלכם תהיה שונה. השאירו את Everdisk פתוחה על המסך בזמן שמכשיר מחובר.

## התחברות מ-Mac

1. פתחו את **Finder**, בחרו **Go**, ואז **Connect to Server** (או לחצו **Command ו-K**).
2. הקלידו את כתובת ה-WebDAV שמוצגת ב-Everdisk, למשל `http://192.168.1.20:8080`.
3. הקליקו על **Connect**, ואז בחרו **Guest** או הזינו את ה-**התחברות** וה-**סיסמה** שלכם.

ה-iPhone שלכם נפתח בחלון Finder ומתנהג כמו תיקייה רגילה. העתיקו קבצים לכל כיוון אם עריכת קבצים מופעלת.

## התחברות מ-Windows

ל-Windows יש לקוח WebDAV מובנה, ולכן זה עובד מ-File Explorer.

1. פתחו את **File Explorer**, הקליקו קליק ימני על **This PC** בסרגל הצד, ובחרו **Add a network location** (אפשר גם להשתמש ב-**Map network drive**).
2. כשתתבקשו לכתובת, הקלידו את אותה כתובת WebDAV מ-Everdisk, למשל `http://192.168.1.20:8080`, ואז הקליקו על **Next**.
3. הזינו את ה-**התחברות** וה-**סיסמה** שלכם אם הגדרתם.

המכשיר אז מופיע תחת This PC כמיקום רשת שאפשר לפתוח ולהעתיק ממנו קבצים. אם Windows מסרב להתחבר בפעם הראשונה, ודאו ששירות ה-**WebClient** פועל (חפשו Services בתפריט Start, מצאו את WebClient והגדירו אותו לפעול), ואז נסו שוב.

## התחברות מ-Linux

1. פתחו את מנהל הקבצים שלכם ובחרו **Connect to Server** או **Other Locations**.
2. הזינו את הכתובת עם קידומת WebDAV, למשל `dav://192.168.1.20:8080` (השתמשו ב-`davs://` רק אם הגדרתם TLS).
3. התחברו כאורח או הזינו את ההתחברות שלכם.

## התחברות מ-Android

ל-Android אין דפדפן WebDAV מערכתי, ולכן השתמשו במנהל קבצים שתומך בו:

1. התקינו אפליקציה כמו **Solid Explorer** או **CX File Explorer**.
2. הוסיפו חיבור **WebDAV** חדש.
3. הזינו את המארח ואת **פורט 8080**, בחרו את סכמת ה-`http`, והוסיפו את ההתחברות שלכם אם הגדרתם.

## התחברות מ-iPhone או iPad נוסף

אפליקציית Files של iOS אינה כוללת לקוח WebDAV, ולכן השתמשו באחד מאלה:

- **לשונית ה-מכשירים של Everdisk עצמה.** במכשיר השני, פתחו את Everdisk, עברו אל **מכשירים**, הקישו על **חיבור חדש**, בחרו **WebDAV**, והזינו את הכתובת, למשל `http://192.168.1.20:8080`. זו הדרך הפשוטה ביותר ואינה צריכה שום דבר נוסף.
- **אפליקציית WebDAV** כמו Documents by Readdle, שיכולה להוסיף חיבור WebDAV עם אותה כתובת והתחברות.

## מעדיפים קישור מהיר במקום כונן?

אם אתם רק צריכים לתפוס קובץ במהירות ולא רוצים לחבר כונן בכלל, הפעילו את חיבור ה-**דפדפן** בהגדרות, שיתוף, חיבורים. Everdisk אז נותנת לכם כתובת אינטרנט שאפשר לפתוח בכל דפדפן על כל מכשיר כדי לעיין ולהוריד את הקבצים שלכם. זו הדרך המהירה ביותר למסור קובץ ל-PC עם Windows, ל-Chromebook או לטלפון של חבר.

## לקריאה בלבד או לקריאה וכתיבה

מתג **עריכת קבצים** בהגדרות, שיתוף, גישה מחליט בזה. מופעל אומר שמחשבים מחוברים יכולים להעלות, לשנות שם ולמחוק. כבוי אומר שהכונן לקריאה בלבד, כך שאחרים יכולים לצפות ולהעתיק את הקבצים שלכם אך לא לשנות אותם.

## דרכים מהחיים שבהן אנשים משתמשים בזה

- **העתיקו קבצים אל ה-iPhone שלכם מ-PC עם Windows** על ידי מיפויו כמיקום רשת וגרירתם.
- **פרקו תמונות ומסמכים אל מחשב נייד** בעזרת מנהל הקבצים שאתם כבר מכירים, בלי כבל ובלי iTunes.
- **ערכו מסמך במקומו** מה-Mac שלכם, ופתחו אותו ישירות מהטלפון ושמרו בחזרה.
- **העבירו תיקייה בין iPhone ל-iPad** בעזרת לשונית ה-מכשירים של Everdisk במכשיר המקבל.

## כמה טיפים

- השאירו את Everdisk פתוחה בזמן שמכשיר מחובר. נעילת הטלפון לזמן רב עלולה להשהות את האפליקציה.
- ב-Windows, אם החיבור נכשל, הפעילו את שירות ה-WebClient ונסו את הכתובת שוב.
- WebDAV ו-SMB שניהם מתחברים ככונני רשת. השתמשו ב-WebDAV כש-Windows מעורב, וב-[SMB](/docs/howto/how-to-set-up-smb-server-on-iphone-ipad-for-file-sharing/) כשאתם רוצים מהירות של Finder והצפנה.
- להעברות המהירות ביותר, השאירו את איכות התמונות והווידאו על מקורי בהגדרות.
