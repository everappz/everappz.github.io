WebDAV は、フォルダーを、パソコンが通常のファイルマネージャーで開けるネットワークドライブに変えます。ブラウザが使うのと同じ Web プロトコルの上で動くため、特別なドライバーなしで Mac、Windows、Linux をまたいでうまく通ります。[Everdisk](/products/everdisk) を使えば、iPhone や iPad で WebDAV サーバーを動かせるので、スマホが、ほぼどんなパソコンからでも閲覧・コピー元・コピー先として使えるドライブとして表示されます。

WebDAV は、Windows がかかわるときに最適な選択肢です。Windows のエクスプローラーがきれいに接続できるからです。このガイドでは、設定方法と、Mac、Windows、Linux、Android、2 台目の iPhone からの接続方法を解説します。

## 必要なもの

- [Everdisk](https://apps.apple.com/app/apple-store/id6751851132?pt=95781850&ct=everappzcom&mt=8) をインストールした iPhone または iPad。
- **同じ Wi-Fi ネットワーク**上のパソコンまたは別のデバイス。
- 共有したいファイル。Everdisk の書類フォルダー内、または追加したフォルダー内にあること。

## Everdisk で WebDAV サーバーを設定する

### ステップ 1: 共有する内容を選んでアクセスを設定する

Everdisk を開き、**共有**タブに移動して、**共有する内容**をタップします。書類フォルダーは既定で共有されています。**フォルダを追加**や**ファイルを追加**でさらに加えられます。

**設定**、**共有**、**アクセス**の順に開きます。接続したパソコンにスマホへのファイルのコピーや名前の変更・削除を許可したい場合は**ファイルの編集**をオンに、読み取り専用のドライブにする場合はオフにします。サインインさせたい場合はここで**ログイン**と**パスワード**を設定し、ゲストアクセスにする場合は空のままにします。

### ステップ 2: WebDAV サーバーをオンにする

**設定**、**共有**、**接続**の順に進み、**コンピュータ**をオンにします。これが WebDAV サーバーです (WebDAV のタグが付いています)。

### ステップ 3: 共有を開始してアドレスを控える

**共有**タブに戻り、**スタート**をタップします。**接続方法**のセクションに WebDAV アドレスが表示されます。次のような形です:

```
http://192.168.1.20:8080
```

コロンの後ろの数字が**ポート**で、既定では **8080** です。最初の部分は Wi-Fi 上での iPhone のアドレスなので、あなたの場合は異なります。デバイスが接続している間は Everdisk を画面に開いたままにしてください。

## Mac から接続する

1. **Finder** を開き、**移動**を選び、次に**サーバへ接続**を選びます (または **Command と K** を押します)。
2. Everdisk に表示された WebDAV アドレス (例: `http://192.168.1.20:8080`) を入力します。
3. **接続**をクリックし、**ゲスト**を選ぶか、**ログイン**と**パスワード**を入力します。

iPhone が Finder のウィンドウで開き、普通のフォルダーのように動きます。ファイルの編集がオンなら、どちらの方向にもファイルをコピーできます。

## Windows から接続する

Windows には WebDAV クライアントが内蔵されているので、エクスプローラーから動きます。

1. **エクスプローラー**を開き、サイドバーの **PC** を右クリックして、**ネットワークの場所を追加する**を選びます (**ネットワークドライブの割り当て**も使えます)。
2. アドレスを求められたら、Everdisk の同じ WebDAV アドレス (例: `http://192.168.1.20:8080`) を入力し、**次へ**をクリックします。
3. 設定した場合は**ログイン**と**パスワード**を入力します。

すると、デバイスが PC の下に、開いてファイルをコピーできるネットワークの場所として表示されます。Windows が初回に接続を拒否する場合は、**WebClient** サービスが動いていることを確認してから (スタートメニューで「サービス」を検索し、WebClient を見つけて起動するように設定します)、もう一度試してください。

## Linux から接続する

1. ファイルマネージャーを開き、**Connect to Server** または **Other Locations** を選びます。
2. WebDAV のプレフィックスを付けたアドレス (例: `dav://192.168.1.20:8080`) を入力します (TLS を設定した場合のみ `davs://` を使います)。
3. ゲストとして接続するか、ログインを入力します。

## Android から接続する

Android にはシステムの WebDAV ブラウザがないので、対応したファイルマネージャーを使います:

1. **Solid Explorer** や **CX File Explorer** のようなアプリをインストールします。
2. 新しい **WebDAV** 接続を追加します。
3. ホストと**ポート 8080** を入力し、`http` スキームを選び、設定した場合はログインを加えます。

## 別の iPhone や iPad から接続する

iOS のファイルアプリには WebDAV クライアントが含まれていないので、次のいずれかを使います:

- **Everdisk 自身のデバイスタブ。** 2 台目のデバイスで Everdisk を開き、**デバイス**に移動して、**新しい接続**をタップし、**WebDAV** を選んでアドレス (例: `http://192.168.1.20:8080`) を入力します。これが一番簡単な方法で、追加のものは何も要りません。
- **WebDAV アプリ** (Documents by Readdle など)。同じアドレスとログインで WebDAV 接続を追加できます。

## ドライブより手早いリンクがよいですか?

ファイルを手早く 1 つ取りたいだけで、ドライブをマウントしたくない場合は、設定、共有、接続で**ブラウザ**接続をオンにします。すると Everdisk が、どのデバイスのどのブラウザでも開いてファイルを閲覧・ダウンロードできる Web アドレスを表示します。Windows PC、Chromebook、友人のスマホにファイルを渡す一番速い方法です。

## 読み取り専用か、読み書きか

設定、共有、アクセスの**ファイルの編集**スイッチがこれを決めます。オンにすると、接続したパソコンはアップロード・名前の変更・削除ができます。オフにすると、ドライブは読み取り専用になり、相手はファイルの表示とコピーはできますが変更はできません。

## 実際の活用シーン

- **Windows PC から iPhone にファイルをコピー。** ネットワークの場所として割り当て、ドラッグして移せます。
- **写真や書類をノート PC に取り出す。** すでに慣れたファイルマネージャーを使い、ケーブルも iTunes も不要です。
- **書類をその場で編集。** Mac からスマホの書類を直接開いて、保存し直せます。
- **iPhone と iPad の間でフォルダーを移動。** 受け取る側のデバイスで Everdisk のデバイスタブを使います。

## いくつかのヒント

- デバイスが接続している間は Everdisk を開いたままにしてください。スマホを長時間ロックすると、アプリが一時停止することがあります。
- Windows で接続に失敗する場合は、WebClient サービスを起動してからアドレスをもう一度試してください。
- WebDAV と SMB はどちらもネットワークドライブとしてマウントされます。Windows がかかわるときは WebDAV を、Finder の速度と暗号化がほしいときは [SMB](/docs/howto/how-to-set-up-smb-server-on-iphone-ipad-for-file-sharing/) を使ってください。
- 最速の転送のために、設定で写真と動画の画質をオリジナルのままにしてください。

{{% details title="WebDAV と SMB の違いは何ですか?" closed="true" %}}
どちらも iPhone をネットワークドライブとしてマウントします。WebDAV は Web プロトコルの上で動き、Windows のエクスプローラーからきれいに接続できるのが主な強みです。SMB は Mac、Linux、NAS デバイスでのネイティブなファイル共有で、Mac では通常より速く、転送を暗号化できる唯一の Everdisk 接続です。Everdisk は両方を同時に動かせます。
{{% /details %}}

{{% details title="WebDAV ドライブが切断されるのはなぜですか?" closed="true" %}}
iPhone がサーバーで、iOS はバックグラウンドに長く留まったアプリを一時停止します。デバイスが接続している間は Everdisk を画面に開いたままにし、長時間の転送中は電源につないでください。また、両方のデバイスが同じ Wi-Fi にとどまっていることも確認してください。
{{% /details %}}

{{% details title="Wi-Fi なしで WebDAV 経由で接続できますか?" closed="true" %}}

{{% /details %}}
