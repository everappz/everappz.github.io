**简短回答：** 在 Flacbox 中，你在**设置 > 音频播放器**里选择一个**播放引擎**：**标准**（Apple 的系统引擎）、**通用**（FFmpeg 引擎）或**音效**（**BASS™ 引擎**）。你选择的引擎决定了哪些文件格式可以播放，所以这个选择很重要。**音效**引擎能播放大多数 iPhone 应用跳过的额外格式（FLAC、DSD、WavPack、APE、Musepack、TrueAudio、Opus，以及像 MOD、XM、IT 和 S3M 这样的老式 **MOD 和 tracker 音乐**），而且它是唯一为这些声音工具提供支持的引擎：一个 **10 段均衡器**、**音量标准化**、**压缩器**、**Freeverb**、**自动哇音**、**移相器**、**镶边器**、**回声**、**合唱**、**失真**、**旋转**、**交叉馈送**，以及一个自建的 **DSP 链**。所以要使用本指南中的效果，请先将你的播放引擎设为**音效**。每个工具都有现成的**预设**。在**设置 > 音频播放器**中打开它们（音频效果、音频均衡器、信号处理），或点按播放器上的 **⋯（更多）**按钮并选择**音频效果**。你在这里所做的一切都不会改动你的文件。

> 下面的滑块和预设说明与 Flacbox 在应用内向你展示的简短描述相同，并融入了一点额外背景，让你在点按之前对全貌有所了解。

## 如何阅读本指南

每个工具的用法都相同：

1. **打开它。** 每个效果都有自己的开关。它们一开始全部关闭。你可以同时打开任意多个。
2. **选择一个预设。** 预设是现成的设置。点按一个，声音会立即变化。本指南列出了**每个**预设的作用。
3. **微调（可选）。** 打开滑块以手动调整。当你一移动滑块，效果就会显示**手动**，让你知道自己已离开了预设。每个滑块都有一个重置按钮。

任何东西都不会保存进你的文件。这些是实时效果。关闭一个效果，你的原始声音会立即恢复。

## 选择你的播放引擎（音效引擎才有这些效果）

Flacbox 不会把引擎混合在一起。你在**设置 > 音频播放器 > 播放引擎**里选择**一个**，你选择的引擎决定了你可以播放哪些文件格式以及效果是否可用。共有三种选择，在应用中以下面这些确切名称显示：

1. **标准。** Apple 内置的系统引擎。使用硬件解码以降低耗电。
2. **通用。** FFmpeg 引擎，能打开非常广泛的格式。
3. **音效。** **BASS™ 引擎**。它以完整精度播放无损和高解析度文件，增加了模块（tracker）音乐，并为本指南中的每个效果、10 段均衡器和 DSP 链提供支持。

由于每个引擎都支持自己的一套格式，你能播放的文件会随你选择的引擎而变化。更重要的是，效果、均衡器和 DSP 链**只**在**音效**引擎下工作，所以如果你想使用它们，请先选择它。

音效基于 **BASS™** 构建，这是来自 Un4seen Developments 的一个专业音频库。你可以在其主页 [un4seen.com](https://www.un4seen.com/) 上了解更多。

## 音乐格式：音效（BASS™）引擎增加了什么（包括 MOD 和 Tracker 音乐）

选择 **音效（BASS™）** 引擎后，Flacbox 会在日常格式之上播放下面这些专业格式。最特别的是**模块音乐**，也称为 **tracker 音乐**。模块文件不是普通录音。它包含一些小的乐器音色加上一份「乐谱」，说明如何演奏它们，Flacbox 会根据那份乐谱实时重建这首歌，就像这些文件本来应有的播放方式。普通播放器做不到这一点。

| 音乐类型 | 格式 | 值得了解 |
|---|---|---|
| **模块 / tracker 音乐** | MOD、XM、IT、S3M、MTM、UMX、MO3 | 由 BASS™ 模块播放器实时重建。非常适合芯片音乐以及老式 demoscene 或 Amiga 歌曲。 |
| **现代无损** | FLAC | 完整音质，比 WAV 更小。 |
| **其他无损** | WavPack (WV)、Monkey's Audio (APE)、TrueAudio (TTA)、Musepack (MPC) | 不太常见的无损类型，全部支持。 |
| **高解析度 DSD** | DSF、DFF | 使用 DSD over PCM 在普通硬件上播放。 |
| **现代有损** | Opus、Ogg Vorbis、MP3 | 常见的流媒体和下载类型。 |

音效引擎还能播放主流的 Apple 格式（AAC、ALAC、M4A、WAV、AIFF）和实时流，所以效果和均衡器在那些格式上也能工作。

**这为何对你有帮助：** 如果你有一批 FLAC 专辑、DSD 高解析度文件，以及一个装满老式 MOD 或 XM tracker 歌曲的文件夹，Flacbox 全都能播放，而且均衡器和效果对它们中的每一个都有效。

## 你将用到的三个菜单

Flacbox 把它的声音工具放在三个地方，全都在音频播放器设置里。首先确保你的**播放引擎**已设为**音效**（设置 > 音频播放器 > 播放引擎），因为效果、均衡器和 DSP 链只在该引擎下可用。

- **音频效果**（效果机架）：打开播放器，点按 **⋯（更多）**，点按**音频效果**。或前往**设置 > 音频播放器 > 音频效果**。
- **音频均衡器**（10 段和预设）：**设置 > 音频播放器 > 音频均衡器**。
- **信号处理**（你自己的 DSP 链）：**设置 > 音频播放器 > 信号处理**。

你还可以在**设置 > 音频播放器**下设置**输出采样率**、**声道**和**缓冲区大小**。

## 10 段均衡器

**它的作用：** 改变音乐的音色，从深沉的低音到明亮的高音。这是实现干净的**低音增强**或更明亮、更清晰高频的最佳工具。可以把它想象成十个音量旋钮，每个负责声音的不同片段。提升某一段可让那部分往前突出，降低它则将其往后拉。通常几 dB 的小幅调整听感最佳，而且它对你播放的所有内容都有效。

**它如何工作：** 十个滑块，位于 **32、64、125、250、500 Hz 以及 1、2、4、8、16 kHz**。每个从 **-12 dB（削减）**到 **+12 dB（提升）**。还有一个从 **-24 到 +24 dB** 的**前置放大器**用于整体电平。你可以保存自己的预设，并在设备之间**导出或导入**它们。

**每个内置预设的作用（22 个预设）：**

| 预设 | 它对你声音的作用 |
|---|---|
| **Flat** | 无变化。所有频段为零。一个干净的起点。 |
| **Acoustic** | 温暖的低音和清脆、突出的高音。让原声吉他和人声听起来自然而生动。 |
| **Bass Booster** | 低频强力提升，中频和高频保持不变。更有冲击力和分量。 |
| **Bass Reducer** | 削减低频。适用于轰鸣的房间、廉价耳塞或低音过重的曲目。 |
| **Treble Booster** | 只提升高音。增加光泽和空气感，更多细节。 |
| **Treble Reducer** | 柔化高音。驯服刺耳或尖锐的录音。 |
| **Classical** | 饱满的低音和柔和的高音，中频略有下凹。为管弦乐带来顺滑而宽阔的感觉。 |
| **Dance** | 大量低音和明亮高音，中频被挖空。为俱乐部曲目带来冲击力和活力。 |
| **Deep** | 温暖、厚实的低频和更柔和的高音。一种舒适、慵懒的声音。 |
| **Electronic** | 为合成器和节拍带来强劲低音和明亮高音。宽广而现代。 |
| **Hip-Hop** | 厚重的低音和清晰的高音，中频受控。有分量且有冲击力。 |
| **Jazz** | 温暖而顺滑，中频略有下凹。为原声爵士带来轻松自然的感觉。 |
| **Latin** | 提升的低音和高音，中频干净。明亮而生动。 |
| **Loudness** | 强力提升低音和高音（一条「微笑」曲线）。在低音量下听起来更饱满。 |
| **Lounge** | 突出的中频，边缘柔和。放松且适合人声。 |
| **Piano** | 清晰的中频和高频，让钢琴音符干净地鸣响。 |
| **Pop** | 为人声提升中频，低音和高音被往后拉。人声位于前排。 |
| **R&B** | 非常强的低中频温暖感和清晰的高音。顺滑而丰富。 |
| **Rock** | 为吉他和鼓提升低音和高音。充满活力且饱满。 |
| **Small Speakers** | 提升低音并削减高音，帮助小扬声器听起来更饱满。 |
| **Spoken Word** | 提升人声区并削减深低音。让说话清晰。 |
| **Vocal Booster** | 推高人声所在的中间部分，削减其周围。让人声突出。 |

**低音小贴士：** 从 **Bass Booster** 开始，然后如果听起来浑浊，就把前置放大器降低 1 到 2 dB，这样就不会失真。

## 音量标准化（均衡响度）

**它的作用：** 有些歌曲播放得比其他歌曲响，所以你老是要调音量。这会让每首歌自动以大约相同的音量播放，这样你就不必手动调整了。它非常适合混合了新旧录音、不同专辑或不同来源的随机播放列表，在那里一首曲目可能比下一首响得多。

**它如何工作：** 它使用 **EBU R128** 标准（以 **LUFS** 衡量，与流媒体服务使用的思路相同）听取每首曲目的真实响度，然后把每首曲目朝你的目标调整。它不需要你文件中有任何标签，也永远不会改动音频。EBU R128 衡量的是你耳朵在整首歌中实际感受到的响度，而不仅仅是最高峰值，这就是为什么它与曲目真正听起来的响度相符。Flacbox 在音乐播放时实时算出这一点（在可能时会提前检查响度），然后对曲目施加单一、稳定的音量变化。**最大提升**限制可防止非常安静的录音被推得太猛以致失真。由于它读取声音本身，它对任何来源都有效，包括云文件、实时流和模块音乐，即使这些文件完全没有响度标签也一样。

**滑块：**

| 控件 | 它的作用 | 范围（默认值） |
|---|---|---|
| **目标响度** | 设置每首曲目被拉平到的响度。数值越高，整体播放越响。 | -30 到 -6 LUFS（-16） |
| **最大提升** | 限制安静曲目最多能被放大多少。数值越高，柔和的录音越接近目标。 | 0 到 24 dB（12） |

**预设：**

| 预设 | 它的作用 |
|---|---|
| **Light** | 面向随意聆听的温和拉平。抹平明显的音量跳变，而不猛推安静曲目。 |
| **Standard** | 万用默认值。一个流媒体风格的响度目标，适合大多数音乐。从这里开始。 |
| **Strong** | 激进匹配，把安静曲目坚定地推高。最适合电平差异很大的混杂曲库。 |
| **Night** | 一个整体更安静的目标，但仍会提升柔和段落，让深夜聆听保持一致且低沉。 |

## 压缩器（均衡响与轻的段落）

**它的作用：** 在一首歌中，安静的部分可能太柔，响亮的部分可能太吵。这会把它们拉得更接近，让整首歌都容易听清，即使在车里或嘈杂的地方也是如此。它会轻轻地把最响的瞬间调低，并把较柔的部分提上来，这样你在同一首曲目内就不必再去够音量了。这与音量标准化不同：压缩器在一首歌**内部**均衡，而音量标准化在歌曲**之间**匹配响度。两者配合得很好。先从一个预设开始，只有在你想要更多控制时才打开滑块。

**滑块：**

| 控件 | 它的作用 | 范围（默认值） |
|---|---|---|
| **阈值** | 压缩开始的电平。数值越低，被压扁的声音越多，让安静和响亮的部分更接近。 | -60 到 0 dB（-20） |
| **比率** | 一旦响亮部分越过阈值，它们被压制的强度。数值越高，压缩越狠，声音越均匀。 | 1:1 到 30:1（4:1） |
| **起音** | 效果对突然的响亮峰值反应有多快。较短的值能抓住瞬态；较长的让它们通过。 | 0.1 到 1000 ms（10 ms） |
| **释音** | 响亮部分过去后效果放开的速度。较短的值可能造成抽吸感；较长的听起来更顺滑。 | 10 ms 到 5 s（100 ms） |
| **主增益** | 处理之后施加的最终输出提升。在动态被均衡后，提高它可以抬升整体响度。 | -30 到 +30 dB（0） |

**预设：**

| 预设 | 它的作用 |
|---|---|
| **Transparent** | 几乎察觉不到的安全网。几乎完全保留动态，只抓住最响的峰值。 |
| **Soft** | 面向家中 hi-fi 聆听的轻度拉平。细腻的平滑而不压扁音乐。 |
| **Standard** | 面向日常音乐播放的合理默认值。首个值得尝试的预设。 |
| **Heavy** | 面向嘈杂环境的激进均衡。汽车、拥挤房间、低音量聆听。 |
| **Voice / Podcast** | 为语音调校。较慢的起音让齿音通过，慷慨的补偿增益把人声提上来。 |
| **Old Recordings** | 面向平均电平低于现代发行的复古专辑和修复黑胶。 |
| **Late Night** | 大量压缩加上大幅提升，适合在意邻居或熟睡家人时的安静聆听。 |
| **Movie Dialog** | 在多变的配乐中，把口白衬托到音乐和音效之上。 |
| **Streaming Match** | 目标大约为现代流媒体服务在 -14 LUFS 左右的响度标准化。 |
| **Maximum Loudness** | 全力以赴。触及限制器；预期得到被压扁、非常平的信号。名副其实的最大音量预设。 |

## Freeverb（混响，一种空间感）

**它的作用：** 为音乐增添空间感，从一个小房间到一座大厅堂。选择一个预设，或自己微调干湿混合、房间大小、阻尼和宽度。混响是你在任何真实空间中听到的自然回音，Freeverb 用软件重现了它。少量能让平淡或近距离拾音的录音感觉更开阔、更有活力。大量则把音乐置于一个宽广、遥远的空间中。它是一种创意效果，所以保持湿混合适度以获得自然的效果。

**滑块：**

| 控件 | 它的作用 | 范围（默认值） |
|---|---|---|
| **干混合** | 保留多少原始的、未经处理的声音。数值越高，混合中保留的干信号越多。 | 0 到 1（0.0） |
| **湿混合** | 加入多少经过混响的声音。数值越高，混响越响、越明显。 | 0 到 3（1.0） |
| **房间大小** | 想象空间的大小。数值越高，混响尾音越长、越大，从小房间到大教堂。 | 0 到 1（0.5） |
| **阻尼** | 高频在尾音中消退的速度。数值越高，混响越暗、越温暖。 | 0 到 1（0.5） |
| **宽度** | 混响的立体声展开。数值越高，左右声道之间的空间感越宽。 | 0 到 1（1.0） |

**预设：**

| 预设 | 它的作用 |
|---|---|
| **Room** | 一个小而紧凑的空间。细腻的环境感，增添场所感而不冲淡声音。 |
| **Studio** | 一个干燥、受控的录音室。刚好足够的反射，听起来自然。 |
| **Hall** | 一座大型音乐厅。悠长、丰润的尾音，适合管弦乐和原声音乐。 |
| **Cathedral** | 一个巨大、回响的石砌空间。最长、最富戏剧性的混响尾音。 |
| **Plate** | 明亮、密集的录音室板式混响。人声和鼓的经典之选。 |
| **Ambience** | 短促、通透的环境感。增添一丝空间感，同时基本保持干燥。 |

## 自动哇音（时髦的滤波器扫频）

**它的作用：** 一个自行上下扫频的滤波器，产生时髦、类似人声的哇音。选择一个预设，或自己设置湿混合、反馈、速率、范围和频率。它就是吉他哇音踏板发出的那种「哇」扫频，但在这里它随音乐自行移动。它在放克、迪斯科和电子曲目上听起来很棒。它是一种大胆、明显的效果，所以在日常聆听中一点点就足够了。

**滑块：**

| 控件 | 它的作用 | 范围（默认值） |
|---|---|---|
| **湿混合** | 哇音效果在混合中有多强。数值越高，扫频滤波器越明显。 | -2 到 +2（1.5） |
| **反馈** | 多少输出被反馈回效果。数值越高，哇音越共振、越突出。 | -1 到 +1（0.5） |
| **速率** | 滤波器上下扫频的速度。数值越高，哇音越快、越有节奏感。 | 0.1 到 9 Hz（2.0） |

## 回声（重复）

## 交叉馈送（耳机上的自然声音）

在扬声器上，你的每只耳朵都能听到左右两个扬声器，只是时间和音量略有不同。在耳机上，那种自然的混合消失了：你的左耳只听到左声道，右耳只听到右声道。这种「超立体声」会让音乐感觉像是分裂在你的脑袋里，而硬声像的录音（某件乐器完全位于一侧）在长时间聆听时会感觉不自然或令人疲劳。

交叉馈送通过把每个声道的一小部分经过滤波后混入另一个声道来解决这个问题，带有微小的延迟和高频的温和滚降。这接近真实扬声器的声音到达你双耳的方式，包括你的头部对远侧耳朵略有遮挡的方式。结果是一个更自然、类扬声器的画面，它坐落在你稍前方而不是脑袋里，并减少长时间聆听的疲劳。Flacbox 使用著名的 **bs2b（Bauer stereophonic-to-binaural）**方法，这是一种受许多发烧级播放器采用的、受人尊重的开源交叉馈送。你可以在 [bs2b 项目页面](https://bs2b.sourceforge.net/)上了解该算法。

**截止**控制混合听起来有多温暖，**馈送电平**控制它有多强。这些预设涵盖了经典的 bs2b 级别，从几乎察觉不到的一点点，到坚定、类扬声器的混合。交叉馈送是一种耳机效果，所以在扬声器上聆听时请关闭它。

**滑块：**

| 控件 | 它的作用 | 范围（默认值） |
|---|---|---|
| **截止** | 设置声道间渗透开始滚降的位置。数值越低，效果越温暖、越明显。 | 300 到 2000 Hz（700） |
| **馈送电平** | 控制一个声道有多少渗入另一个。数值越高，声音越像扬声器。 | 1 到 15 dB（4.5） |

**预设：**

| 预设 | 它的作用 |
|---|---|
| **Subtle** | 面向随意聆听的几乎察觉不到的交叉馈送。柔化硬声像的立体声而不改变音色平衡。 |
| **Chu Moy** | 经典的万用默认值。均衡且略微温暖，几乎适用于任何素材。从这里开始。 |
| **Strong** | 面向声像更硬的混音的更强渗透。立体声收窄更明显。 |
| **Jan Meier** | 在耳机爱好者中很受欢迎。更宽的馈送，更像扬声器的呈现，略微提升低音。 |
| **Speaker-like** | 为在耳机上实现最自然的扬声器式重现而调校。 |
| **Vintage Stereo** | 为鼓和人声硬声像的 1960 和 1970 年代混音调校的激进交叉馈送。 |

## 这一切在底层如何工作（简单版）

- **引擎：** 你在设置 > 音频播放器 > 播放引擎里选择一个：**标准**（系统）、**通用**（FFmpeg）或**音效**（来自 [Un4seen Developments](https://www.un4seen.com/) 的 **BASS™ 引擎**）。你选择的引擎决定了哪些格式可以播放，而效果、均衡器和 DSP 链只在音效引擎中运行。
- **格式：** BASS™ 引擎在系统和 FFmpeg 格式之上增加了 FLAC、DSD、WavPack、APE、Musepack、TrueAudio、Opus 和模块（tracker）音乐。
- **效果：** 均衡器、压缩器和大多数效果使用 BASS™ 效果附加组件。Freeverb 就是 Freeverb 混响。合唱、镶边器和失真使用带有各自控件的经典 DirectX 风格效果。
- **音量标准化：** 一个实时的 **EBU R128** 响度拉平器（广播和流媒体使用的响度标准）。
- **交叉馈送：** **bs2b（Bauer）**交叉馈送，在 BASS™ 引擎内运行。
- **DSP 链：** 你的自定义模块，按你设置的确切顺序应用，作用于所有声道或仅一侧。
- **输出：** 你可以设置采样率、声道数和缓冲区大小以匹配你的设备。

由于这一切都在音乐播放时实时运行，这些效果：

- 对一切内容**实时**工作，包括云文件、流和模块音乐。
- **永不改动或重新保存**你的文件。关闭一个效果，原始声音便返回。
- 为每个效果**记住你的设置**。
- 可以自由地**混搭组合**，因为每一个都是独立的。

## 值得尝试的简单配方

**日常聆听**

- **更多低音，且干净：** 均衡器 > Bass Booster，然后把前置放大器降低 1 到 2 dB。或添加一个设为 Bass Boost 的 DSP 低架。
- **在混杂播放列表上均衡音量：** 音量标准化 > Standard，加上压缩器 > Soft。
- **温和的整体润色：** 压缩器 > Transparent，加上音量标准化 > Light。
- **更清晰的人声：** 均衡器 > Vocal Booster，或一个设为 Vocal Boost 的 DSP 峰值模块。
- **在小手机扬声器上获得更饱满的声音：** 均衡器 > Small Speakers。

**耳机**

- **在耳机上更好听、更不累：** 交叉馈送 > Chu Moy 或 Jan Meier。
- **在耳机上获得更宽的声音：** DSP 立体声宽度 > Wide，加上交叉馈送 > Chu Moy。
- **修复硬声像的 1960 和 1970 年代唱片：** 交叉馈送 > Vintage Stereo。
- **一点空气感和空间感：** Freeverb > Ambience，保持低量，加上交叉馈送 > Subtle。

**安静时段和口语音频**

- **深夜安静聆听：** 音量标准化 > Night，加上压缩器 > Late Night。
- **播客和有声书：** 压缩器 > Voice / Podcast，加上均衡器 > Spoken Word。
- **在嘈杂车内获得最响、最均匀的声音：** 音量标准化 > Strong，加上压缩器 > Heavy。

**解决问题**

- **驯服刺耳、明亮的录音：** 均衡器 > Treble Reducer，或一个设为 Tame Harsh 的 DSP 峰值模块。
- **去除电源嗡声：** DSP 链 > 陷波 > Mains Hum 60（或在欧洲用 Mains Hum 50）。
- **更紧凑、更干净的低音：** DSP 高通 > Tighten，以切除轰鸣的低频。
- **在低音过重的混音中减少轰鸣：** DSP 低架 > Trim Bass，或峰值 > De-Boom。

**创意与好玩**

- **温暖、有空间感的感觉：** Freeverb > Hall，保持低量。
- **梦幻、宽阔的吉他：** 合唱 > Wide，加上回声 > Long。
- **复古 lo-fi：** DSP 链 > 位压碎（LoFi）接入软削波（Warm）。
- **在电子曲目上的时髦运动：** 自动哇音 > Funky，或移相器 > Fast。
- **经典的喷气式飞机扫频：** 镶边器 > Jet。

## 常见问题

{{% details title="Flacbox 使用什么声音引擎？" closed="true" %}}
你在设置 > 音频播放器里选择一个播放引擎：标准（Apple 的系统引擎）、通用（FFmpeg 引擎）或音效（来自 Un4seen Developments 的 BASS™ 引擎，un4seen.com）。你选择的引擎决定了哪些文件格式可以播放。音效是那个能播放额外格式如 FLAC、DSD、WavPack、APE、Musepack、TrueAudio、Opus 以及 MOD 或 tracker 音乐的引擎，而且它是唯一提供实时效果、10 段均衡器和 DSP 链的引擎。要使用这些效果，请将播放引擎设为音效。
{{% /details %}}

{{% details title="Flacbox 能播放 MOD、XM、IT 以及其他 tracker 或模块音乐吗？" closed="true" %}}
可以。BASS™ 引擎有一个内置的模块播放器，能加载 MOD、XM、IT、S3M、MTM、UMX 和 MO3 文件，并根据其模式和乐器音色实时重建这首歌，正如 tracker 音乐本应有的播放方式。普通 iPhone 播放器做不到这一点。效果和均衡器对模块音乐也有效。
{{% /details %}}

{{% details title="Flacbox 支持 DSD 和高解析度文件吗？" closed="true" %}}
可以。Flacbox 通过 BASS™ 引擎使用 DSD over PCM 播放 DSD 文件（DSF 和 DFF），因此它们能在普通输出硬件上工作，此外还有用于无损播放的 FLAC、WavPack、Monkey's Audio (APE)、Musepack 和 TrueAudio。
{{% /details %}}

{{% details title="Flacbox 有哪些音效？" closed="true" %}}
一个 10 段均衡器、音量标准化、压缩器、Freeverb、自动哇音、移相器、镶边器、回声、合唱、失真、旋转和交叉馈送，还有一个自建的 DSP 链，带有滤波器、架式、增益、软削波、位压碎、环形调制器、颤音、延迟和立体声宽度。每一个都是独立的，可以与其他的组合。
{{% /details %}}

{{% details title="什么是预设？" closed="true" %}}
预设是一个效果的现成设置。你无需自己移动滑块，只需点按一个预设，声音就会随之变化。Flacbox 中的每个效果都有若干预设，本指南列出了每一个的作用。如果你在选择一个预设之后移动滑块，效果会显示「手动」，告诉你它现在使用的是你自己的数值。
{{% /details %}}

{{% details title="如何在 Flacbox 中打开音频效果？" closed="true" %}}
打开正在播放播放器，点按 ⋯（更多）按钮，然后选择音频效果。或前往设置 > 音频播放器 > 音频效果。点按一个效果，打开它的开关，选择一个预设，或打开滑块进行微调。
{{% /details %}}

{{% details title="均衡器在哪里，什么是最佳设置？" closed="true" %}}
前往设置 > 音频播放器 > 音频均衡器。它有从 32 Hz 到 16 kHz 的 10 个频段，每个从 -12 到 +12 dB，加上一个 -24 到 +24 dB 的前置放大器和 22 个预设。想要更多低音，使用 Bass Booster。想要更清晰的人声，使用 Vocal Booster 或 Pop。想要更明亮的声音，使用 Treble Booster。然后按喜好调整单个频段。
{{% /details %}}

{{% details title="如何在 Flacbox 中增强低音？" closed="true" %}}
两种简便方法。在音频均衡器中，选择 Bass Booster（或把 32 Hz 和 64 Hz 频段提升几 dB）。或者，在信号处理中，添加一个设为 Bass Boost 的低架模块。在这两种情况下，都把前置放大器降低或添加一个增益模块 1 到 2 dB，让低音保持干净且不失真。
{{% /details %}}

{{% details title="哪个均衡器预设最适合我的音乐？" closed="true" %}}
Rock 和 Electronic 以强劲的低音和高音增添能量。Acoustic、Jazz 和 Classical 保持温暖自然。Pop 和 Vocal Booster 把人声往前推。Bass Booster 和 Hip-Hop 增添分量。Deep 和 Loudness 在低音量下听起来更饱满。从与你的曲风相符的那个开始，然后微调。
{{% /details %}}

{{% details title="什么是音量标准化，它与 ReplayGain 有何不同？" closed="true" %}}
它让每首曲目以大约相同的响度播放。它使用 EBU R128 标准（以 LUFS，就像流媒体服务那样）衡量真实响度，并把每首曲目朝你的目标调整，带有一个最大提升限制。与 ReplayGain 不同，它不需要你文件中有任何标签，并对任何来源实时工作，且不改动音频。预设：Light、Standard、Strong 和 Night。
{{% /details %}}

{{% details title="什么是交叉馈送，我应该使用它吗？" closed="true" %}}
交叉馈送把左右声道的一点混合在一起，让耳机感觉更像真实的扬声器，而不像声音卡在你脑袋里。它只用于耳机，所以在扬声器上请关闭它。Flacbox 使用 bs2b（Bauer）方法，带有像 Chu Moy 和 Jan Meier 这样的预设。
{{% /details %}}

{{% details title="压缩器和音量标准化之间有什么区别？" closed="true" %}}
音量标准化匹配不同歌曲之间的响度。压缩器均衡单首歌内部的响与轻的部分。它们解决不同的问题，并配合得很好，尤其是在车里或嘈杂的地方。
{{% /details %}}

{{% details title="什么是信号处理（DSP）链？" closed="true" %}}
它是设置 > 音频播放器 > 信号处理中一个自建的机架。添加像滤波器、架式、增益、软削波、位压碎、环形调制器、颤音、延迟和立体声宽度这样的模块，以任意顺序排列它们，打开或关闭每一个，并把链指向所有声道、左或右。由于顺序很重要，你可以精确设计出你想要的声音。
{{% /details %}}

{{% details title="均衡器、效果和 DSP 链之间有什么区别？" closed="true" %}}
均衡器是一个简单的 10 段音色控制。音频效果是带有预设的现成工具（压缩器、混响、回声等等）。DSP 链是你从单个模块构建自己效果顺序的地方。你可以同时运行这三者。
{{% /details %}}

{{% details title="这些效果会改动或损坏我的音乐文件吗？" closed="true" %}}
不会。一切都在音乐播放时实时应用。你的文件永远不会被改动或重新保存。关闭一个效果，原始声音会立即返回。
{{% /details %}}

{{% details title="我可以同时使用多个效果吗？" closed="true" %}}
可以。每个效果都有自己的开关，而且没有总开关，所以任何组合都可行。例如，音量标准化加压缩器以获得均匀的聆听，或在耳机上使用 Freeverb 加交叉馈送，再叠加均衡器。
{{% /details %}}

{{% details title="为什么效果控件是灰色的？" closed="true" %}}
该效果已关闭。打开编辑器顶部的开关即可使用这些控件。每个效果默认都是关闭的。
{{% /details %}}

{{% details title="手动标签是什么意思？" closed="true" %}}
它意味着你把某个滑块从预设移开了，所以效果现在使用的是你自己的自定义数值而非某个具名预设。每个滑块都有一个重置按钮，再次选择一个预设会替换你的手动数值。
{{% /details %}}

{{% details title="我可以保存和分享我的均衡器预设吗？" closed="true" %}}
可以。除了 22 个内置预设之外，你还可以制作自己的、重新排序它们，并导出或导入它们，把你的设置转移到另一台设备。
{{% /details %}}

{{% details title="这些效果在 CarPlay、流媒体和后台播放中有效吗？" closed="true" %}}
有效。这些效果在 BASS™ 引擎内运行，所以它们适用于本地文件、云盘、媒体服务器、流和模块音乐，并且在 CarPlay 和后台播放期间持续工作。
{{% /details %}}

{{% details title="我可以更改音频输出质量吗？" closed="true" %}}
可以。在设置 > 音频播放器中，你可以设置输出采样率、声道数和缓冲区大小，以匹配你的耳机、扬声器或 DAC。
{{% /details %}}

{{% details title="耳机的一个好的起始设置是什么？" closed="true" %}}
打开音量标准化（Standard），添加一个轻度压缩器（Soft），选择一个你喜欢的均衡器预设，并打开交叉馈送（Chu Moy 或 Jan Meier）。让混响、回声和失真保持关闭，除非你想要一种创意声音。
{{% /details %}}
