**簡短回答：** 在 Flacbox 中，你要在 **設定 > 音訊播放器** 裡選擇一個 **播放引擎**：**Standard**（Apple 的系統引擎）、**Universal**（FFmpeg 引擎）或 **Sound FX**（**BASS™ 引擎**）。你選的引擎決定了哪些檔案格式能播放，所以這個選擇很重要。**Sound FX** 引擎能播放多數 iPhone 應用程式跳過的額外格式（FLAC、DSD、WavPack、APE、Musepack、TrueAudio、Opus，以及像 MOD、XM、IT、S3M 這類老式的 **MOD 與 tracker 音樂**），而且它是唯一能驅動這些聲音工具的引擎：**10 段等化器**、**音量正規化**、**壓縮器**、**Freeverb**、**Auto Wah**、**Phaser**、**Flanger**、**回音**、**Chorus**、**失真**、**Rotate**、**Crossfeed**，以及自訂的 **DSP 鏈**。所以要使用本指南中的效果，請先把你的播放引擎設成 **Sound FX**。每個工具都有現成的 **預設**。你可以在 **設定 > 音訊播放器**（音效、音訊等化器、訊號處理）中開啟它們，或在播放器上點按 **⋯（更多操作）** 按鈕並選擇 **音效**。你在這裡所做的任何操作都不會改變你的檔案。

> 下方對滑桿和預設的說明，與 Flacbox 在應用程式內顯示給你的簡短說明相同，並加入了一點額外背景資訊，讓你在點按之前先掌握全貌。

## 如何閱讀本指南

每個工具的運作方式都相同：

1. **開啟它。** 每個效果都有自己的開/關開關。它們一開始全都是關閉的。你可以同時開啟任意多個。
2. **選擇一個預設。** 預設是現成的設定。點按其中一個，聲音會立刻改變。本指南列出了 **每一個** 預設的作用。
3. **微調（選用）。** 打開滑桿以手動調整。你一移動滑桿，該效果就會顯示 **Manual**，讓你知道你已經離開了預設。每個滑桿都有一個重設按鈕。

任何設定都不會存進你的檔案裡。這些是即時效果。關掉一個效果，你原本的聲音會立刻回來。

## 選擇你的播放引擎（Sound FX 才有效果）

Flacbox 不會把引擎混在一起。你要在 **設定 > 音訊播放器 > 播放引擎** 裡選 **一個**，你選的引擎決定了你能播放哪些檔案格式，以及是否能使用這些效果。共有三種選擇，在應用程式中以下列這些確切名稱顯示：

1. **Standard。** Apple 內建的系統引擎。使用硬體解碼以降低耗電。
2. **Universal。** FFmpeg 引擎，能開啟非常廣泛的各種格式。
3. **Sound FX。** **BASS™ 引擎**。它能以完整的精確度播放無損與高解析度檔案、加入 module（tracker）音樂，並驅動本指南中的每個效果、10 段等化器與 DSP 鏈。

由於每個引擎都支援自己的一套格式，你能播放的檔案會隨你所選的引擎而改變。更重要的是，這些效果、等化器與 DSP 鏈 **只** 能在 **Sound FX** 引擎下運作，所以如果你想使用它們，請先選擇它。

Sound FX 建構於 **BASS™** 之上，這是來自 Un4seen Developments 的專業音訊庫。你可以在其首頁 [un4seen.com](https://www.un4seen.com/) 上閱讀更多資訊。

## 音樂格式：Sound FX（BASS™）引擎新增了哪些（包括 MOD 與 Tracker 音樂）

選取 **Sound FX（BASS™）** 引擎後，Flacbox 除了日常格式之外，還能播放下列這些專業格式。其中最特別的是 **module 音樂**，也稱為 **tracker 音樂**。module 檔案不是普通的錄音。它包含小段的樂器聲音，加上一份說明如何演奏它們的「樂譜」，Flacbox 會依照這份樂譜即時重建歌曲，也就是這些檔案原本應被播放的方式。一般播放器辦不到這一點。

| 音樂類型 | 格式 | 值得一提 |
|---|---|---|
| **Module / tracker 音樂** | MOD, XM, IT, S3M, MTM, UMX, MO3 | 由 BASS™ module 播放器即時重建。非常適合 chiptune 與老式 demoscene 或 Amiga 歌曲。 |
| **現代無損** | FLAC | 完整品質，比 WAV 更小。 |
| **其他無損** | WavPack (WV), Monkey's Audio (APE), TrueAudio (TTA), Musepack (MPC) | 較少見的無損類型，全部支援。 |
| **高解析度 DSD** | DSF, DFF | 使用 DSD over PCM 在一般硬體上播放。 |
| **現代有損** | Opus, Ogg Vorbis, MP3 | 常見的串流與下載類型。 |

Sound FX 引擎也能播放主流的 Apple 格式（AAC、ALAC、M4A、WAV、AIFF）與即時串流，所以這些效果與等化器對它們同樣有效。

**這對你有什麼幫助：** 如果你手上有一堆 FLAC 專輯、DSD 高解析度檔案，以及一個裝滿老式 MOD 或 XM tracker 歌曲的資料夾，Flacbox 全都能播放，而且等化器與效果對其中每一個都有效。

## 你會用到的三個選單

Flacbox 把它的聲音工具放在三個地方，全都在音訊播放器設定裡。首先請確認你的 **播放引擎** 已設為 **Sound FX**（設定 > 音訊播放器 > 播放引擎），因為這些效果、等化器與 DSP 鏈只能在該引擎下使用。

- **音效**（效果機架）：開啟播放器，點按 **⋯（更多操作）**，點按 **音效**。或前往 **設定 > 音訊播放器 > 音效**。
- **音訊等化器**（10 段與預設）：**設定 > 音訊播放器 > 音訊等化器**。
- **訊號處理**（你自己的 DSP 鏈）：**設定 > 音訊播放器 > 訊號處理**。

你也可以在 **設定 > 音訊播放器** 下設定 **輸出取樣率**、**聲道** 與 **緩衝區大小**。

## 10 段等化器

**它的作用：** 改變音樂的音色，從深沉的低音到明亮的高音。這是做出乾淨 **低音增強** 或更明亮、更清晰高頻的最佳工具。把它想成十個音量旋鈕，每個負責聲音的不同片段。抬升某一段可讓那部分更突出，降低則把它往後拉。通常幾 dB 的小幅調整聽起來最好，而且它對你播放的所有內容都有效。

**它的運作方式：** 十個滑桿位於 **32、64、125、250、500 Hz 與 1、2、4、8、16 kHz**。每個範圍從 **-12 dB（衰減）** 到 **+12 dB（增益）**。另外還有一個從 **-24 到 +24 dB** 的 **前級放大器（Preamplifier）** 用於調整整體音量。你可以儲存自己的預設，並在裝置之間 **匯出或匯入** 它們。

**每個內建預設的作用（22 個預設）：**

| 預設 | 它對你的聲音做什麼 |
|---|---|
| **Flat** | 沒有改變。所有頻段皆為零。乾淨的起點。 |
| **Acoustic** | 溫暖的低音與清脆、鮮明的高音。讓木吉他與人聲聽來自然而生動。 |
| **Bass Booster** | 大幅抬升低頻，中頻與高頻不變。更有衝擊力與份量。 |
| **Bass Reducer** | 削減低頻。適合低音轟隆的房間、廉價耳塞或低音沉重的曲目。 |
| **Treble Booster** | 只抬升高頻。增添光澤與空氣感、更多細節。 |
| **Treble Reducer** | 柔化高頻。馴服刺耳或尖銳的錄音。 |
| **Classical** | 飽滿的低音與柔和的高音，中頻略微下凹。對管弦樂而言平順而寬闊。 |
| **Dance** | 強勁的低音與明亮的高音，中頻挖凹。對舞曲而言有衝擊力且充滿活力。 |
| **Deep** | 溫暖厚實的低頻，搭配較柔的高音。慵懶放鬆的聲音。 |
| **Electronic** | 為合成器與節拍打造的強勁低音與明亮高音。寬闊而現代。 |
| **Hip-Hop** | 厚重的低音與清晰的高音，中頻受控。有份量又有衝擊力。 |
| **Jazz** | 溫暖平順，中頻略微下凹。對原音爵士而言輕鬆而自然。 |
| **Latin** | 抬升的低音與高音，中頻乾淨。明亮而生動。 |
| **Loudness** | 大幅抬升低音與高音（「微笑」曲線）。在低音量下聽來更飽滿。 |
| **Lounge** | 突出的中頻與柔和的邊緣。放鬆且對人聲友善。 |
| **Piano** | 清晰的中頻與高頻，讓鋼琴音符乾淨地鳴響。 |
| **Pop** | 抬升中頻以突顯人聲，低音與高音往後拉。人聲居於前方。 |
| **R&B** | 非常強勁的中低頻溫暖感與清晰高音。平順而豐富。 |
| **Rock** | 為吉他與鼓抬升低音與高音。充滿活力且飽滿。 |
| **Small Speakers** | 抬升低音並削減高音，幫助微小的喇叭聽來更飽滿。 |
| **Spoken Word** | 抬升人聲頻段並削減深沉低音。讓說話聲清晰。 |
| **Vocal Booster** | 推升人聲所在的中段，並削減其周圍。讓人聲突出。 |

**低音小提示：** 先從 **Bass Booster** 開始，接著若聽來混濁，把前級放大器往下拉 1 到 2 dB，讓聲音不失真。

## 音量正規化（一致的響度）

**它的作用：** 有些歌曲比其他歌曲播得更大聲，所以你一直得調整音量。這會讓每首歌自動以大致相同的音量播放，你就不必手動調整。對於混雜了新舊錄音、不同專輯或不同來源的隨機播放清單來說，這非常理想，因為其中一首曲目可能比下一首大聲許多。

**它的運作方式：** 它使用 **EBU R128** 標準（以 **LUFS** 測量，與串流服務所用的概念相同）聆聽每首曲目的實際響度，然後把每首曲目調整到你的目標。它不需要你檔案中的任何標籤，也絕不會改變音訊。EBU R128 測量的是你的耳朵在整首歌中實際感受到的響度，而非只是最高的峰值，這就是它為什麼能符合曲目在你聽來真正的音量大小。Flacbox 會在音樂播放時即時算出這一點（並在可行時預先檢查響度），然後對曲目套用單一、穩定的音量變化。**Max boost** 上限可防止非常安靜的錄音被推得太高而失真。由於它讀取的是聲音本身，因此對任何來源都有效，包括雲端檔案、即時串流與 module 音樂，即使檔案完全沒有響度標籤也一樣。

**滑桿：**

| 控制項 | 它的作用 | 範圍（預設） |
|---|---|---|
| **Target loudness** | 設定每首曲目被調整趨近的響度。數值越高，整體播放越大聲。 | -30 到 -6 LUFS (-16) |
| **Max boost** | 限制安靜曲目最多能被放大多少。數值越高，柔和的錄音越接近目標。 | 0 到 24 dB (12) |

**預設：**

| 預設 | 它的作用 |
|---|---|
| **Light** | 適合休閒聆聽的輕柔調整。撫平明顯的音量跳動，而不會用力推升安靜曲目。 |
| **Standard** | 萬用的預設值。串流風格的響度目標，適合大多數音樂。從這裡開始。 |
| **Strong** | 積極的匹配，堅定地把安靜曲目推上去。最適合音量差異很大的混合曲庫。 |
| **Night** | 整體較安靜的目標，但仍會抬升柔和的段落，讓深夜聆聽保持一致且低音量。 |

## 壓縮器（拉平大聲與小聲的部分）

**它的作用：** 在同一首歌裡，安靜的部分可能太小聲、大聲的部分可能太大聲。這會把它們拉得更接近，讓整首歌容易聽清，即使在車上或吵雜的地方。它會溫和地把最大聲的瞬間調低、把較柔的部分抬高，讓你不必在一首曲目中途一直去調音量。這與音量正規化不同：壓縮器拉平的是 **單一** 歌曲 **之內** 的音量，而音量正規化匹配的是 **不同歌曲之間** 的響度。兩者搭配得很好。先從一個預設開始，只有在你想要更多控制時才打開滑桿。

**滑桿：**

| 控制項 | 它的作用 | 範圍（預設） |
|---|---|---|
| **Threshold** | 壓縮開始的音量位準。數值越低，會壓扁越多聲音，讓安靜與大聲的部分更接近。 | -60 到 0 dB (-20) |
| **Ratio** | 大聲的部分一旦超過門檻後被壓抑的強度。數值越高壓縮越猛，讓聲音更平均。 | 1:1 到 30:1 (4:1) |
| **Attack** | 效果對突然的大聲峰值反應的速度。較短的值能抓住暫態；較長的值則讓它們通過。 | 0.1 到 1000 ms (10 ms) |
| **Release** | 大聲部分過去後效果放手的速度。較短的值可能會產生抽動感；較長的值聽來更平順。 | 10 ms 到 5 s (100 ms) |
| **Master gain** | 處理後套用的最終輸出增益。動態被拉平後，抬高這個以提升整體響度。 | -30 到 +30 dB (0) |

**預設：**

| 預設 | 它的作用 |
|---|---|
| **Transparent** | 幾乎察覺不到的安全網。幾乎完全保留動態，只抓住最大聲的峰值。 |
| **Soft** | 適合家中 hi-fi 聆聽的輕度調整。細膩地平順化，而不壓扁音樂。 |
| **Standard** | 適合日常音樂播放的合理預設值。第一個該試的預設。 |
| **Heavy** | 為吵雜環境而設的積極拉平。車內、擁擠的房間、低音量聆聽。 |
| **Voice / Podcast** | 為語音調校。較慢的 attack 讓齒音通過，充足的補償增益把人聲拉上來。 |
| **Old Recordings** | 適合老專輯與修復的黑膠，這些的平均音量低於現代發行。 |
| **Late Night** | 大量壓縮加上大幅增益，適合在意鄰居或家人熟睡時的安靜聆聽。 |
| **Movie Dialog** | 在變化多端的原聲帶中，把口白拉到相對於音樂與音效的前方。 |
| **Streaming Match** | 目標約略對準現代串流服務約 -14 LUFS 的響度正規化。 |
| **Maximum Loudness** | 全力以赴。碰到限幅器；預期會得到被壓扁、非常平均的訊號。名副其實的最大音量預設。 |

## Freeverb（殘響，空間感）

**它的作用：** 為音樂加入空間感，從小房間一直到大廳堂。選一個預設，或自行微調乾濕混合、房間大小、阻尼與寬度。殘響是你在任何真實空間中聽到的自然回音，而 Freeverb 以軟體重現它。少量能讓平板或近距離收音的錄音感覺更開闊、更有生命力。大量則把音樂置於廣大、遙遠的空間中。這是一種創意效果，所以把濕混合保持適度以得到自然的結果。

**滑桿：**

| 控制項 | 它的作用 | 範圍（預設） |
|---|---|---|
| **Dry mix** | 保留多少原始、未經處理的聲音。數值越高，混合中留下越多乾訊號。 | 0 到 1 (0.0) |
| **Wet mix** | 加入多少殘響過的聲音。數值越高，殘響越大聲、越明顯。 | 0 到 3 (1.0) |
| **Room size** | 想像空間的大小。數值越高給出越長、越大的殘響尾音，從小房間一直到大教堂。 | 0 到 1 (0.5) |
| **Damp** | 尾音中高頻消退的速度。數值越高，殘響越暗、越溫暖。 | 0 到 1 (0.5) |
| **Width** | 殘響的立體聲展開。數值越高，讓空間在左右聲道之間感覺越寬。 | 0 到 1 (1.0) |

**預設：**

| 預設 | 它的作用 |
|---|---|
| **Room** | 一個小而緊密的空間。細膩的環境感，增添臨場感而不沖淡聲音。 |
| **Studio** | 一間乾、受控的錄音室。恰到好處的反射讓聲音自然。 |
| **Hall** | 一座大型音樂廳。悠長飽滿的尾音，適合管弦樂與原音音樂。 |
| **Cathedral** | 一個巨大、迴響的石造空間。最長、最戲劇性的殘響尾音。 |
| **Plate** | 明亮、密實的錄音室板式殘響。人聲與鼓的經典之選。 |
| **Ambience** | 短促、通透的環境感。加入輕微的空間感，同時大致保持乾聲。 |

## Auto Wah（放克濾波器掃描）

**它的作用：** 一個會自行上下掃描的濾波器，帶來放克、類人聲的哇哇聲。選一個預設，或自行設定濕混合、回授、速率、範圍與頻率。這與吉他哇哇踏板做出的「哇哇」掃描相同，但在這裡它會自行隨音樂節奏移動。用在放克、迪斯可與電子曲目上聽起來很棒。這是一個大膽、明顯的效果，所以在日常聆聽中一點點就很夠。

**滑桿：**

| 控制項 | 它的作用 | 範圍（預設） |
|---|---|---|
| **Wet mix** | 哇哇效果在混合中的強度。數值越高，掃描的濾波器越明顯。 | -2 到 +2 (1.5) |
| **Feedback** | 有多少輸出被回授進效果中。數值越高，哇哇越有共鳴、越明顯。 | -1 到 +1 (0.5) |
| **Rate** | 濾波器上下掃描的速度。數值越高，哇哇越快、越有節奏感。 | 0.1 到 9 Hz (2.0) |
| **Range** | 濾波器掃描的幅度，以八度計。數值越高，掃描越寬、越戲劇性。 | 0.1 到 9 octaves (4.3) |
| **Frequency** | 濾波器掃描環繞的基礎頻率。數值越低聽來越深；越高聽來越明亮。 | 1 到 1000 Hz (50) |

**預設：**

| 預設 | 它的作用 |
|---|---|
| **Classic** | 均衡、經典的哇哇掃描。放克與搖滾的好起點。 |
| **Slow** | 緩慢、寬闊的掃描，溫和地上下漂移。非常適合 pad 與長音。 |
| **Funky** | 快速、有衝擊力的掃描，充滿律動。為吉他與合成器增添節奏咬勁。 |
| **Deep** | 從低頻起始的深沉、寬闊掃描。宏大而戲劇性。 |
| **Subtle** | 溫和、含蓄的移動。增添個性而不主宰聲音。 |
| **Resonant** | 高回授的尖銳、共鳴哇哇。類人聲且富表現力。 |

## Phaser（旋繞的呼嘯）

**它的作用：** 一個掃描濾波器，為聲音加入旋繞、呼嘯的動態。選一個預設，或自行設定回授、速率、範圍與頻率。它加入溫和的動態與微光，而不改變音符。用在人聲與 pad 上很細膩，用在合成器與吉他上則很戲劇性。試試 Slow 得到夢幻感，或 Jet 得到強烈的旋繞。

**滑桿：**

| 控制項 | 它的作用 | 範圍（預設） |

| **Feedback** | 有多少輸出被回授進效果中。數值越高，phaser 越有共鳴、越明顯。 | -1 到 +1 (0.0) |
| **Rate** | 濾波器上下掃描的速度。數值越高，phasing 越快、越有節奏感。 | 0.1 到 9 Hz (1.0) |
| **Range** | 濾波器掃描的幅度，以八度計。數值越高，掃描越寬、越戲劇性。 | 0.1 到 9 octaves (4.0) |
| **Frequency** | 濾波器掃描環繞的基礎頻率。數值越低聽來越深；越高聽來越明亮。 | 1 到 1000 Hz (100) |

**預設：**

| 預設 | 它的作用 |
|---|---|
| **Classic** | 均衡、經典的 phaser 掃描。吉他與鍵盤的好起點。 |
| **Slow** | 緩慢、寬闊的掃描，溫和地上下漂移。非常適合 pad 與長音。 |
| **Fast** | 快速、閃爍的掃描，充滿律動。增添動態與能量。 |
| **Deep** | 從低頻起始的深沉、寬闊掃描。宏大而戲劇性。 |
| **Subtle** | 溫和、含蓄的移動。增添個性而不主宰聲音。 |
| **Jet** | 高回授的強烈、共鳴掃描，經典的噴射機呼嘯。 |

## Flanger（噴射機掃描）

**它的作用：** 一段短促、移動的延遲，讓聲音帶有噴射機般的掃描呼嘯。選一個預設，或自行設定深度、回授、速率與延遲。它是 phaser 更強烈、更金屬味的表親，以經典搖滾與電子音樂中的呼嘯掃描而聞名。細膩的設定加入溫和的動態，而深沉的設定則戲劇性且明顯。最好節制地使用，作為點綴。

**滑桿：**

| 控制項 | 它的作用 | 範圍（預設） |
|---|---|---|
| **Depth** | 掃描效果的強度。數值越高，flanging 越明顯。 | 0 到 100% (25) |
| **Feedback** | 有多少輸出被回授進效果中。數值越高，flanger 越有共鳴、越金屬味。 | -99 到 +99% (-50) |
| **Rate** | 掃描上下移動的速度。數值越高，動態越快、越閃爍。 | 0 到 10 Hz (0.25) |
| **Delay** | 掃描所建立於其上的基礎延遲時間。數值越高，特性越深沉、越空洞。 | 0 到 4 ms (2.0) |

**預設：**

| 預設 | 它的作用 |
|---|---|
| **Classic** | 均衡、經典的 flanger。吉他與鍵盤的好起點。 |
| **Subtle** | 溫和、含蓄的掃描。增添動態而不主宰聲音。 |
| **Deep** | 帶強回授的深沉、厚重掃描。宏大而戲劇性。 |
| **Jet** | 帶正回授的強烈掃描，經典的噴射機呼嘯。 |
| **Fast** | 快速、閃爍的掃描，充滿律動與能量。 |
| **Wide** | 帶長延遲的緩慢、寬闊掃描。飽滿而寬敞。 |

## 回音（重複）

**它的作用：** 把聲音重複為漸弱的回音，帶來空間感與深度。選一個預設，或自行設定濕混合、回授與延遲。它就像在峽谷中呼喊：聲音在短暫間隔後回來一次或多次。單一短促的重複增添厚度與復古感，而帶更多回授的較長重複則營造寬廣、拖曳的尾音。Ping Pong 預設讓重複在你的左右耳之間彈跳，在耳機上很有趣。把濕混合保持適度，讓回音襯托音樂而非蓋過它。

**滑桿：**

| 控制項 | 它的作用 | 範圍（預設） |
|---|---|---|
| **Wet mix** | 回音相較於原始聲音有多大聲。數值越高，重複越突出。 | -2 到 +2 (0.6) |
| **Feedback** | 回音重複多少次。數值越高，重複越多且花更久才消退。 | -1 到 +1 (0.5) |
| **Delay** | 回音之間的時間。較短的值給出緊密的 slap-back；較長的值給出間隔開的重複。 | 0.01 到 2 s (0.4) |

**預設：**

| 預設 | 它的作用 |
|---|---|
| **Slapback** | 緊貼在聲音之後的單一、緊密重複。經典的 rockabilly slap-back。 |
| **Room** | 短促、自然的回音，像小房間。增添空間感而不糊掉聲音。 |
| **Tape** | 溫暖、中等的重複，逐漸消退，像老式磁帶延遲。 |
| **Dub** | 帶強回授的悠長、厚重重複。宏大、dub 味且寬敞。 |
| **Ping Pong** | 回音在左右喇叭之間彈跳，帶來寬闊的立體聲效果。 |
| **Long** | 緩慢、間隔寬的重複，在聲音後方遠處拖曳消散。 |

## Chorus（更厚、更寬的聲音）

**它的作用：** 藉由在原聲上疊加一個變動的副本，讓聲音變厚並變寬。選一個預設，或自行設定乾濕混合、深度、速率與回授。它藉由加入略微失諧、移動的副本，讓單一樂器或人聲聽來像好幾個一起演奏。這增添豐富感與溫和的微光。細膩的設定讓聲音溫暖起來，而強烈的設定則飽滿而夢幻。它在吉他、鍵盤與人聲上很受歡迎。

**滑桿：**

| 控制項 | 它的作用 | 範圍（預設） |
|---|---|---|
| **Wet/Dry** | 相較於原始聲音，你聽到多少 chorus。數值越高，效果越明顯。 | 0 到 100% (50) |
| **Depth** | 音高上下擺動的幅度。數值越高，聲音越厚、越閃爍。 | 0 到 100% (25) |
| **Rate** | 微光移動的速度。較慢的速率聽來溫和飽滿；較快的速率聽來更像顫音。 | 0 到 10 Hz (1.1) |
| **Feedback** | 有多少效果被回授進自身。數值越高，chorus 越有共鳴、越強烈。 | -99 到 +99% (25) |

**預設：**

| 預設 | 它的作用 |
|---|---|
| **Subtle** | 溫和的增厚，增添溫暖感而不引人注意。 |
| **Lush** | 豐富、經典的 chorus。吉他與鍵盤絕佳的萬用設定。 |
| **Ensemble** | 飽滿、層疊的微光，讓單一樂器聽來像好幾個。 |
| **Vibrato** | 全濕搭配快速速率，帶來擺動的顫音而非細膩的 chorus。 |
| **Wide** | 緩慢、寬闊的微光，打開立體聲影像。寬敞而夢幻。 |
| **Twelve-String** | 明亮、共鳴的微光，令人聯想到十二弦吉他。 |

## 失真（顆粒與稜角）

**它的作用：** 藉由過載聲音來增添顆粒與稜角。選一個預設，或自行設定 drive、輸出與音色。它刻意讓聲音變粗糙，從溫暖、帶顆粒的稜角到破碎、毛絨的音色。這是一種創意、好玩的效果，而非提升品質的方法，所以少量使用。用在電子、搖滾與實驗曲目上很有趣。如果一個厚重的預設變得太大聲，就把 Output 調低。

**滑桿：**

| 控制項 | 它的作用 | 範圍（預設） |
|---|---|---|
| **Drive** | 聲音被失真的猛烈程度。數值越高越有顆粒、越具攻擊性。 | 0 到 100% (15) |
| **Output** | 失真後的輸出位準。若厚重的設定變得太大聲就把它調低。 | -60 到 0 dB (-18) |
| **Tone** | 在失真前滾降高頻。數值越低聽來越暗、越溫暖。 | 100 到 8000 Hz (8000) |
| **Center** | 失真聚焦環繞的頻率。讓特性偏亮或偏暗。 | 100 到 8000 Hz (2400) |
| **Width** | 那個聚焦有多寬。窄聽來尖銳而鼻音；寬聽來飽滿而開闊。 | 100 到 8000 Hz (2400) |

**預設：**

| 預設 | 它的作用 |
|---|---|
| **Warm Drive** | 輕度、溫暖的顆粒，增添稜角而不太改變特性。 |
| **Crunch** | 經典的酥脆過載，有衝擊力且有節奏。 |
| **Overdrive** | 明亮、有 drive 的音色，充滿咬勁。非常適合主奏聲音。 |
| **Fuzz** | 厚實、飽和的 fuzz。厚重且充滿泛音。 |
| **Metal** | 緊實、聚焦中頻的高增益音色，適合具攻擊性、厚重的聲音。 |
| **Screamer** | 突出的中頻增益過載，能穿透而出，像 tube screamer。 |
| **LoFi** | 壓碎、窄頻的失真，帶來帶顆粒的 lo-fi 特性。 |

## Rotate（旋轉立體聲）

**它的作用：** 讓聲音在立體聲場中旋轉，帶來旋轉式、旋繞的效果。選一個預設，或自行設定速率。它緩慢地讓聲音在你的左右聲道之間移動，有點像旋轉的喇叭，增添旋繞、催眠般的感覺。緩慢的設定溫和而寬闊，而快速的設定則暈眩且明顯。這是一種立體聲效果，所以在耳機或擺位良好的喇叭上最明顯。

**滑桿：**

| 控制項 | 它的作用 | 範圍（預設） |
|---|---|---|
| **Rate** | 聲音在立體聲場中旋轉的速度。負值往反方向旋轉；零則保持靜止。 | -5 到 +5 Hz (1.0) |

**預設：**

| 預設 | 它的作用 |
|---|---|
| **Slow Pan** | 緩慢、溫和地從一側漂移到另一側。細膩而寬闊。 |
| **Sway** | 穩定的左右搖擺。為立體聲影像增添溫和的動態。 |
| **Rotary** | 令人聯想到旋轉喇叭的中速旋轉。 |
| **Fast Spin** | 在立體聲場中快速旋轉，帶來暈眩、旋繞的效果。 |
| **Reverse** | 反方向的中速旋轉。 |
| **Whirl** | 極快速的旋繞。強烈而令人迷失方向。 |

## Crossfeed（耳機上的自然聲音）

在喇叭上，你的每隻耳朵都會聽到左右兩個喇叭，只是時間與音量略有不同。在耳機上，那種自然的融合消失了：你的左耳只聽到左聲道，右耳只聽到右聲道。這種「超級立體聲」會讓音樂感覺像是分裂在你的腦中，而硬左右分離的錄音（某個樂器完全位於一側）在長時間聆聽時可能感覺不自然或令人疲勞。

Crossfeed 藉由把少量、經過濾波的每個聲道混入另一個聲道來修正這一點，並帶有微小的延遲與高頻的溫和滾降。這接近於來自真實喇叭的聲音抵達你雙耳的方式，包括你的頭部略微遮蔽遠側耳朵的方式。結果是更自然、類喇叭的影像，位於你的前方一點而非腦中，並在長時間聆聽時減少聽覺疲勞。Flacbox 使用著名的 **bs2b（Bauer stereophonic-to-binaural）** 方法，這是許多發燒級播放器採用、備受推崇的開源 crossfeed。你可以在 [bs2b 專案頁面](https://bs2b.sourceforge.net/) 上閱讀關於該演算法的資訊。

**Cutoff** 控制混合聽來有多溫暖，而 **Feed level** 控制它有多強。這些預設涵蓋經典的 bs2b 級別，從幾乎察覺不到的觸感，一直到堅定、類喇叭的混合。Crossfeed 是耳機效果，所以在你用喇叭聆聽時把它關掉。

**滑桿：**

| 控制項 | 它的作用 | 範圍（預設） |
|---|---|---|
| **Cutoff** | 設定聲道之間的滲入開始滾降的位置。數值越低，效果越溫暖、越明顯。 | 300 到 2000 Hz (700) |
| **Feed level** | 控制一個聲道有多少滲入另一個。數值越高，聲音越像喇叭。 | 1 到 15 dB (4.5) |

**預設：**

| 預設 | 它的作用 |
|---|---|
| **Subtle** | 適合休閒聆聽、幾乎察覺不到的 crossfeed。柔化硬左右分離的立體聲而不改變音色平衡。 |
| **Chu Moy** | 經典的萬用預設值。均衡且略帶溫暖，幾乎適用於任何素材。從這裡開始。 |
| **Strong** | 為更硬左右分離的混音提供更強的滲入。更明顯的立體聲收窄。 |
| **Jan Meier** | 在耳機愛好者中很受歡迎。更寬的 feed、更像喇叭的呈現、略微抬升低音。 |
| **Speaker-like** | 為在耳機上得到最自然的喇叭式重現而調校。 |
| **Vintage Stereo** | 為 1960 與 1970 年代帶硬左右分離鼓與人聲的混音而調校的積極 crossfeed。 |

## 訊號處理：打造你自己的 DSP 鏈

除了現成的效果之外，Flacbox 讓你在 **設定 > 音訊播放器 > 訊號處理** 中打造自己的鏈。正如應用程式在鏈為空時的說明：*「點按 + 以加入一個效果。以各自的開關開啟或關閉每一個、拖曳以重新排序、點按以編輯其參數，並長按以複製或刪除。」*

**順序很重要**：失真前的一個濾波器，聽來與失真後的同一個濾波器不同。你也可以把整條鏈指向 **All channels**、**Left channel** 或 **Right channel**。

以下是每個區塊，附上應用程式對每個滑桿與每個預設的原文說明。

### Gain（音量修整）

在鏈中的某一點抬升或降低音量。

| 控制項 | 它的作用 | 範圍（預設） |
|---|---|---|
| **Gain** | 在鏈中這一點抬升或削減音量。用它在其他效果之後補回音量，或驅動接在後面的效果。 | -24 到 +24 dB (0) |

| 預設 | 它的作用 |
|---|---|
| **Unity** | 音量沒有改變。中性的起點。 |
| **Cut** | 大幅削減。馴服大聲的來源，或在接在後面的效果之前騰出空間。 |
| **Trim** | 溫和的削減，把音量稍微往回拉。 |
| **Lift** | 適度的增益，把安靜的來源抬上來。 |
| **Boost** | 為安靜素材提供強力增益，或更猛地驅動後面的效果。 |
| **Max** | 最大增益。很大聲，留意鏈中稍後的削波。 |

### Low Pass（移除高頻）

| 控制項 | 它的作用 | 範圍（預設） |
|---|---|---|
| **Cutoff** | 設定濾波器開始滾降高頻的位置。調低以讓聲音變暗、變柔；朝頂端調高以完全開放。 | 20 Hz 到 20 kHz (20 kHz) |
| **Resonance** | 強調正好位於截止點的頻率。保持低以得到乾淨的滾降；調高以得到尖峰、呼嘯的邊緣。 | 0.1 到 10 (0.707) |

| 預設 | 它的作用 |
|---|---|
| **Air** | 只修整最頂端。稍微去掉稜角而不使聲音變鈍。 |
| **Warm** | 溫和地滾降高頻，得到更溫暖、更圓潤的音色。 |
| **Mellow** | 明顯柔化。把明亮感往回拉，得到慵懶的感覺。 |
| **Muffled** | 暗且悶，彷彿隔著一道牆聽到。 |
| **Telephone** | 頻段中偏低處的窄、共鳴尖峰。單薄、類電話的人聲。 |

### High Pass（移除低頻）

| 控制項 | 它的作用 | 範圍（預設） |
|---|---|---|
| **Cutoff** | 設定濾波器開始滾降低頻的位置。調高以削薄低頻並移除隆隆聲；朝底端調低以完全開放。 | 20 Hz 到 20 kHz (20 Hz) |
| **Resonance** | 強調正好位於截止點的頻率。保持低以得到乾淨的滾降；調高以得到尖峰、呼嘯的邊緣。 | 0.1 到 10 (0.707) |

| 預設 | 它的作用 |
|---|---|
| **Rumble Cut** | 移除次聲波隆隆聲與直流偏移，而不觸及可聞的低頻。 |
| **Tighten** | 修整轟隆的低頻，得到更緊實、更乾淨的低音。 |
| **Thin** | 削減溫暖感與厚度，留下更輕、更薄的聲音。 |
| **Radio** | 只留下中頻與高頻，像小型收音機喇叭。 |
| **Telephone** | 頻段中偏高處的窄、共鳴尖峰。單薄、類電話的人聲。 |

### Band Pass（保留中間一段）

| 控制項 | 它的作用 | 範圍（預設） |
|---|---|---|
| **Center** | 設定濾波器通過的頻率。其上下皆被滾降。掃描它以挑出低音、中頻或高頻。 | 20 Hz 到 20 kHz (1 kHz) |
| **Resonance** | 控制頻帶有多寬。低值讓寬廣的範圍通過；調高以窄化到中心，得到尖銳、共鳴的音色。 | 0.1 到 10 (0.707) |

| 預設 | 它的作用 |
|---|---|
| **Voice** | 環繞大多數人聲所在中頻的寬頻帶。中性的起點。 |
| **Bass** | 隔離低頻，只留下低音與大鼓。 |
| **Body** | 聚焦於中低頻，得到溫暖、箱式的厚度。 |
| **Presence** | 抬升中高頻以得到清晰度與臨場感。 |
| **Telephone** | 窄的中頻頻帶。單薄、類電話的聲音。 |
| **Wah** | 非常窄、共鳴的尖峰。掃描中心以得到 wah 效果。 |

### Notch（移除一個窄頻帶）

| 控制項 | 它的作用 | 範圍（預設） |
|---|---|---|
| **Frequency** | 設定濾波器移除的頻率。其上下皆通過。把它調到某個嗡嗡聲或共鳴上以削除它。 | 20 Hz 到 20 kHz (60 Hz) |
| **Resonance** | 控制切除有多寬。低值挖掉寬廣的範圍；調高以只移除一個針點頻帶，留下其餘不動。 | 0.1 到 10 (8.0) |

| 預設 | 它的作用 |
|---|---|
| **Mains Hum 60** | 移除 60 Hz 電源嗡嗡聲（北美電源）。中性的起點。 |
| **Mains Hum 50** | 移除 50 Hz 電源嗡嗡聲（歐洲與其他地區電源）。 |
| **Rumble** | 切除低頻隆隆聲或共鳴，而不削薄整個低頻底部。 |
| **Mud** | 挖掉中低頻的混濁，得到更乾淨、更清晰的聲音。 |
| **Boxy** | 移除箱式的中頻鼻音。 |
| **Harsh** | 馴服中高頻中刺耳、尖銳的尖峰。 |

### Peaking（參數等化頻段）

| 控制項 | 它的作用 | 範圍（預設） |
|---|---|---|
| **Frequency** | 要抬升或削減的頻帶中心。掃描它以找到你想塑形的頻率。 | 20 Hz 到 20 kHz (1 kHz) |
| **Gain** | 在中心處抬升或削減多少。正值抬升該頻帶；負值挖掉它。 | -15 到 +15 dB (0) |
| **Q factor** | 設定頻帶有多寬。低值塑形寬廣區域；高值窄化以進行手術式、針點的調整。 | 0.1 到 10 (1.0) |

| 預設 | 它的作用 |
|---|---|
| **Presence** | 寬廣的中高頻抬升以得到清晰度與臨場感。中性的起點。 |
| **Warmth** | 寬廣的中低頻增益，增添厚度與溫暖感。 |
| **Vocal Boost** | 抬升核心人聲頻段以把人聲帶到前方。 |
| **Cut Mud** | 挖掉箱式的中低頻混濁，得到更乾淨的聲音。 |
| **Tame Harsh** | 窄幅削減以馴服刺耳、尖銳的尖峰。 |
| **Punch** | 低頻增益，為低頻增添衝擊力與力度。 |
| **Sub Boost** | 在最底部深度增益，得到額外的超低音份量。 |
| **Air** | 在頂端寬幅抬升，得到開闊、通透的光澤。 |
| **Clarity** | 抬升高中頻以增添清晰度與稜角。 |
| **De-Ess** | 在齒音頻段窄幅削減以馴服刺耳的 S 音。 |
| **De-Boom** | 切除轟隆的低頻堆積，得到更緊實的低頻。 |
| **Scoop** | 寬廣的中頻下凹，得到挖凹、現代的音色。 |

| **Fullness** | 填滿中低頻，得到更飽滿、更圓潤的聲音。 |
| **Trim Bass** | 適度削減以減輕低音沉重的混音。 |

### Soft Clip（溫暖飽和）

| 控制項 | 它的作用 | 範圍（預設） |
|---|---|---|
| **Drive** | 把訊號更用力推進波形塑形器。少量增添溫和的溫暖感；大量把峰值圓化為厚實的飽和與顆粒。 | 0 到 40 dB (0) |

| 預設 | 它的作用 |
|---|---|
| **Warm** | 一點點 drive，得到溫和、類比風格的溫暖感。 |
| **Drive** | 明顯的飽和，讓聲音變厚並增添色彩。 |
| **Crunch** | 帶可聞酥脆邊緣的厚重 drive。 |
| **Fuzz** | 厚實、毛絨的失真。峰值被用力壓扁。 |
| **Destroy** | 最大 drive。具攻擊性、完全飽和的顆粒。 |

### Bit Crusher（復古 Lo-Fi）

| 控制項 | 它的作用 | 範圍（預設） |
|---|---|---|
| **Bit depth** | 設定用多少位元描述每個取樣。位元越少代表越粗的階梯與更多量化雜訊，得到酥脆、帶顆粒的數位聲音。 | 1 到 16 bits (16) |
| **Sample rate** | 對音訊降取樣。在百分之一百時取樣率不變；調低以讓每個取樣持續更久，使高頻變鈍並增添刺耳、混疊的邊緣。 | 1% 到 100% (100%) |

| 預設 | 它的作用 |
|---|---|
| **Vintage** | 品質細微的下降，像早期的數位取樣機。 |
| **LoFi** | 經典的 8 位元、半取樣率 lo-fi。粗粒且復古。 |
| **Crunch** | 更重的壓碎，帶可聞的酥脆邊緣。 |
| **Gritty** | 粗糙且帶顆粒。位準之間的階梯很明顯。 |
| **Destroy** | 極端縮減。刺耳、破碎、幾乎難以辨認。 |

### Ring Modulator（金屬與機器人音色）

| 控制項 | 它的作用 | 範圍（預設） |

| **Mix** | 把調變後的聲音與原聲混合。在百分之零時你只聽到乾訊號；在百分之一百時只聽到完全調變的音調。 | 0% 到 100% (0%) |

| 預設 | 它的作用 |
|---|---|
| **Tremolo** | 非常低的 carrier 把它變成振幅震音，擺動音量。 |
| **Robot** | 中等 carrier 增添鏗鏘的泛音，得到經典的機器人語音效果。 |
| **Metallic** | 密集、非諧的泛音，得到刺耳、金屬的音色。 |
| **Bell** | 較高的 carrier 給出明亮、鐘鈴般的鳴響。 |
| **Alien** | 全濕搭配高 carrier。極端、外星、幾乎難以辨認。 |

### Tremolo（音量擺動）

| 控制項 | 它的作用 | 範圍（預設） |
|---|---|---|
| **Rate** | 設定音量脈動的速度。較慢的速率給出平順的搖擺；較快的速率給出快速的抖動。 | 0.1 到 20 Hz (5) |
| **Depth** | 設定每次脈動時音量下降多少。在百分之零時音量穩定；在百分之一百時一路下沉到寂靜。 | 0% 到 100% (0%) |

| 預設 | 它的作用 |
|---|---|
| **Gentle** | 緩慢、淺淺的搖擺。細膩的動態而不引人注意。 |
| **Classic** | 經典的音箱震音：中等速率與適中深度。 |
| **Deep** | 強烈、深沉的脈動，每個週期幾乎下沉到寂靜。 |
| **Fast** | 快速的顫動，得到閃爍、緊張的感覺。 |
| **Chop** | 快速且全深度。強硬、抖動的切分。 |

### Delay（回音）

| 控制項 | 它的作用 | 範圍（預設） |
|---|---|---|
| **Time** | 設定每個回音前的間隔。短時間給出緊密的 slapback；較長時間把重複拉得更開。 | 0.01 到 2 s (0.25) |
| **Feedback** | 設定每個回音有多少被回授進去。低值給出單一重複；較高值建立一長串拖曳的回音。 | 0 到 0.95 (0.4) |
| **Mix** | 把回音與原聲混合。在百分之零時你只聽到乾訊號；在百分之一百時只聽到回音。 | 0% 到 100% (0%) |

| 預設 | 它的作用 |
|---|---|
| **Slapback** | 緊貼原聲的單一短回音。Rockabilly 與人聲加倍。 |
| **Echo** | 經典的回音：清晰的重複帶少許拖曳尾音。 |
| **Ping** | 快速、彈跳的重複，增添節奏動態。 |
| **Ambient** | 較長、較柔的重複，洗散成寬敞的尾音。 |
| **Dub** | 高回授，得到悠長、dub 味的回音串瀑。 |
| **Cavern** | 悠長、深沉的重複，像聲音在巨大空間中迴響。 |

| 控制項 | 它的作用 | 範圍（預設） |
|---|---|---|
| **Width** | 收窄或加寬立體聲影像。百分之零塌縮為單聲道，百分之一百保持不變，較高值把兩側往外推。只在 All-channels 目標上影響立體聲曲目。 | 0% 到 200% (100%) |

| 預設 | 它的作用 |
|---|---|
| **Wide** | 溫和的加寬，打開立體聲影像。中性的起點。 |
| **Wider** | 更強的展開，得到宏大、沉浸的立體聲場。 |
| **Max** | 最大寬度。非常寬，但留意單聲道相容性問題。 |
| **Narrow** | 把兩側往內拉，得到更緊實、更居中的影像。 |
| **Focused** | 幾乎居中，只帶一絲立體聲。 |
| **Mono** | 完全塌縮為單聲道。兩個喇叭播放相同的訊號。 |

## 這一切在幕後如何運作（簡易版）

- **引擎：** 你在 設定 > 音訊播放器 > 播放引擎 中選一個：**Standard**（系統）、**Universal**（FFmpeg）或 **Sound FX**（來自 [Un4seen Developments](https://www.un4seen.com/) 的 **BASS™ 引擎**）。你選的引擎決定了哪些格式能播放，而這些效果、等化器與 DSP 鏈只在 Sound FX 引擎中運作。
- **格式：** BASS™ 引擎在系統與 FFmpeg 格式之上，加入了 FLAC、DSD、WavPack、APE、Musepack、TrueAudio、Opus 與 module（tracker）音樂。
- **效果：** 等化器、壓縮器與大多數效果使用 BASS™ 效果附加元件。Freeverb 是 Freeverb 殘響。Chorus、Flanger 與失真使用帶各自控制項的經典 DirectX 風格效果。
- **音量正規化：** 一個即時的 **EBU R128** 響度調平器（廣播與串流所用的響度標準）。
- **Crossfeed：** 在 BASS™ 引擎內運行的 **bs2b（Bauer）** crossfeed。
- **DSP 鏈：** 你的自訂區塊，以你設定的確切順序，在所有聲道或僅一側套用。
- **輸出：** 你可以設定取樣率、聲道數與緩衝區大小，以配合你的器材。

由於這一切都在音樂播放時即時運行，這些效果：

- 在所有內容上 **即時** 運作，包括雲端檔案、串流與 module 音樂。
- **絕不改變或重新儲存** 你的檔案。關掉一個效果，原聲就會回來。
- 為每個效果 **記住你的設定**。
- 可以自由地 **混合搭配**，因為每一個都是獨立的。

## 值得一試的簡單配方

**日常聆聽**

- **更多低音，乾淨地：** 等化器 > Bass Booster，然後把前級放大器降低 1 到 2 dB。或加入一個設為 Bass Boost 的 DSP Low Shelf。
- **在混合播放清單中拉平音量：** 音量正規化 > Standard，加上壓縮器 > Soft。
- **溫和的整體潤飾：** 壓縮器 > Transparent，加上音量正規化 > Light。
- **更清晰的人聲：** 等化器 > Vocal Booster，或一個設為 Vocal Boost 的 DSP Peaking 區塊。
- **在小型手機喇叭上得到更飽滿的聲音：** 等化器 > Small Speakers。

**耳機**

- **在耳機上更悅耳、更不疲勞：** Crossfeed > Chu Moy 或 Jan Meier。
- **在耳機上得到更寬的聲音：** DSP Stereo Width > Wide，加上 Crossfeed > Chu Moy。
- **修正硬左右分離的 1960 與 1970 年代唱片：** Crossfeed > Vintage Stereo。
- **一點空氣感與空間：** Freeverb > Ambience，保持低量，加上 Crossfeed > Subtle。

**安靜時光與口語音訊**

- **深夜安靜聆聽：** 音量正規化 > Night，加上壓縮器 > Late Night。
- **Podcast 與有聲書：** 壓縮器 > Voice / Podcast，加上等化器 > Spoken Word。
- **在吵雜的車內得到最大、最平均的聲音：** 音量正規化 > Strong，加上壓縮器 > Heavy。

**修正問題**

- **馴服刺耳、明亮的錄音：** 等化器 > Treble Reducer，或一個設為 Tame Harsh 的 DSP Peaking 區塊。
- **移除電源嗡嗡聲：** DSP 鏈 > Notch > Mains Hum 60（或在歐洲用 Mains Hum 50）。
- **更緊實、更乾淨的低音：** DSP High Pass > Tighten，以切除轟隆的低頻。
- **在低音沉重的混音中減少轟隆：** DSP Low Shelf > Trim Bass，或 Peaking > De-Boom。

**創意與趣味**

- **溫暖、有空間感的感覺：** Freeverb > Hall，保持低量。
- **夢幻、寬敞的吉他：** Chorus > Wide，加上回音 > Long。
- **復古 lo-fi：** DSP 鏈 > Bit Crusher（LoFi）接入 Soft Clip（Warm）。
- **在電子曲目上的放克動態：** Auto Wah > Funky，或 Phaser > Fast。
- **經典的噴射機掃描：** Flanger > Jet。

## 常見問題

{{% details title="Flacbox 使用什麼音訊引擎？" closed="true" %}}
你在 設定 > 音訊播放器 中選一個播放引擎：Standard（Apple 的系統引擎）、Universal（FFmpeg 引擎）或 Sound FX（來自 Un4seen Developments 的 BASS™ 引擎，un4seen.com）。你選的引擎決定了哪些檔案格式能播放。Sound FX 是能播放 FLAC、DSD、WavPack、APE、Musepack、TrueAudio、Opus，以及 MOD 或 tracker 音樂等額外格式的那一個，而且它是唯一提供即時效果、10 段等化器與 DSP 鏈的引擎。要使用這些效果，請把播放引擎設為 Sound FX。
{{% /details %}}

{{% details title="Flacbox 能播放 MOD、XM、IT 與其他 tracker 或 module 音樂嗎？" closed="true" %}}
可以。BASS™ 引擎有內建的 module 播放器，能載入 MOD、XM、IT、S3M、MTM、UMX 與 MO3 檔案，並依其樣式與樂器聲音即時重建歌曲，也就是 tracker 音樂原本應被播放的方式。一般的 iPhone 播放器辦不到。效果與等化器對 module 音樂同樣有效。
{{% /details %}}

{{% details title="Flacbox 支援 DSD 與高解析度檔案嗎？" closed="true" %}}
可以。Flacbox 透過 BASS™ 引擎使用 DSD over PCM 播放 DSD 檔案（DSF 與 DFF），讓它們能在一般輸出硬體上運作，此外還有 FLAC、WavPack、Monkey's Audio（APE）、Musepack 與 TrueAudio 的無損播放。
{{% /details %}}

{{% details title="Flacbox 有哪些音效？" closed="true" %}}
一個 10 段等化器、音量正規化、壓縮器、Freeverb、Auto Wah、Phaser、Flanger、回音、Chorus、失真、Rotate 與 Crossfeed，另外還有一條自訂的 DSP 鏈，包含濾波器、shelf、gain、soft clip、bit crusher、ring modulator、tremolo、delay 與 stereo width。每一個都是獨立的，可以與其他效果組合。
{{% /details %}}

{{% details title="什麼是預設？" closed="true" %}}
預設是效果的現成設定。你不用自己移動滑桿，只要點按一個預設，聲音就會隨之改變。Flacbox 中的每個效果都有數個預設，本指南列出了每一個的作用。如果你在選了預設之後移動滑桿，該效果會顯示「Manual」，告訴你它現在使用的是你自己的數值。
{{% /details %}}

{{% details title="我要如何在 Flacbox 中開啟音效？" closed="true" %}}
開啟正在播放的播放器，點按 ⋯（更多操作）按鈕，並選擇 音效。或前往 設定 > 音訊播放器 > 音效。點按一個效果、開啟它的開關，並選一個預設，或打開滑桿來微調。
{{% /details %}}

{{% details title="等化器在哪裡，最佳設定是什麼？" closed="true" %}}
前往 設定 > 音訊播放器 > 音訊等化器。它有從 32 Hz 到 16 kHz 的 10 個頻段，每個從 -12 到 +12 dB，另外還有一個 -24 到 +24 dB 的前級放大器與 22 個預設。想要更多低音，用 Bass Booster。想要更清晰的人聲，用 Vocal Booster 或 Pop。想要更明亮的聲音，用 Treble Booster。然後依喜好調整個別頻段。
{{% /details %}}

{{% details title="我要如何在 Flacbox 中增強低音？" closed="true" %}}
有兩個簡單的方法。在音訊等化器中，選 Bass Booster（或把 32 Hz 與 64 Hz 頻段抬升幾 dB）。或者，在訊號處理中，加入一個設為 Bass Boost 的 Low Shelf 區塊。兩種情況下，都把前級放大器降低或加入一個 Gain 區塊 1 到 2 dB，讓低音保持乾淨而不失真。
{{% /details %}}

{{% details title="哪個等化器預設最適合我的音樂？" closed="true" %}}
Rock 與 Electronic 以強勁的低音與高音增添能量。Acoustic、Jazz 與 Classical 保持溫暖而自然。Pop 與 Vocal Booster 把人聲推到前方。Bass Booster 與 Hip-Hop 增添份量。Deep 與 Loudness 在低音量下聽來更飽滿。先從符合你曲風的那一個開始，然後微調。
{{% /details %}}

{{% details title="什麼是音量正規化，它與 ReplayGain 有何不同？" closed="true" %}}
它讓每首曲目以大致相同的響度播放。它使用 EBU R128 標準（以 LUFS，像串流服務一樣）測量真實響度，並把每首曲目調整到你的目標，帶有一個 max-boost 上限。與 ReplayGain 不同，它不需要你檔案中的任何標籤，且對任何來源都有效、即時、不改變音訊。預設：Light、Standard、Strong 與 Night。
{{% /details %}}

{{% details title="什麼是 Crossfeed，我該使用它嗎？" closed="true" %}}
Crossfeed 把左右聲道的一小部分混在一起，讓耳機感覺更像真實的喇叭，而不那麼像聲音卡在你的腦中。它只適用於耳機，所以用喇叭時把它關掉。Flacbox 使用 bs2b（Bauer）方法，帶有像 Chu Moy 與 Jan Meier 這樣的預設。
{{% /details %}}

{{% details title="壓縮器與音量正規化有什麼差別？" closed="true" %}}
音量正規化匹配不同歌曲之間的響度。壓縮器拉平單一歌曲之內大聲與安靜的部分。它們解決不同的問題，且搭配得很好，尤其是在車內或吵雜的地方。
{{% /details %}}

{{% details title="什麼是訊號處理（DSP）鏈？" closed="true" %}}
它是 設定 > 音訊播放器 > 訊號處理 中一個自訂的機架。加入像濾波器、shelf、gain、soft clip、bit crusher、ring modulator、tremolo、delay 與 stereo width 這樣的區塊，以任意順序排列它們、開啟或關閉每一個，並把鏈指向所有聲道、左或右。由於順序很重要，你可以設計出你想要的確切聲音。
{{% /details %}}

{{% details title="等化器、效果與 DSP 鏈有什麼差別？" closed="true" %}}
等化器是一個簡單的 10 段音色控制。音效是帶預設的現成工具（壓縮器、殘響、回音等等）。DSP 鏈是你從個別區塊建立自己效果順序的地方。你可以同時運行這三者。
{{% /details %}}

{{% details title="這些效果會改變或損壞我的音樂檔案嗎？" closed="true" %}}
不會。一切都在音樂播放時即時套用。你的檔案絕不會被改變或重新儲存。關掉一個效果，原聲會立刻回來。
{{% /details %}}

{{% details title="我可以同時使用一個以上的效果嗎？" closed="true" %}}
可以。每個效果都有自己的開關，且沒有主開關，所以任何組合都行得通。例如，音量正規化加壓縮器以得到平均的聆聽，或在耳機上用 Freeverb 加 Crossfeed，並在上面加等化器。
{{% /details %}}

{{% details title="為什麼效果的控制項是灰色的？" closed="true" %}}
該效果已關閉。開啟編輯器頂端的開關以使用控制項。每個效果預設都是關閉的。
{{% /details %}}

{{% details title="Manual 標籤是什麼意思？" closed="true" %}}
它表示你把某個滑桿從預設移開了，所以該效果現在使用的是你自己的自訂數值而非具名的預設。每個滑桿都有一個重設按鈕，再選一次預設會取代你的手動數值。
{{% /details %}}

{{% details title="我可以儲存並分享我的等化器預設嗎？" closed="true" %}}
可以。除了 22 個內建預設之外，你可以製作自己的、重新排序它們，並匯出或匯入它們，把你的設定搬到另一部裝置。
{{% /details %}}

{{% details title="這些效果能與 CarPlay、串流和背景播放搭配運作嗎？" closed="true" %}}
可以。這些效果在 BASS™ 引擎內運行，所以它們適用於本機檔案、雲端硬碟、媒體伺服器、串流與 module 音樂，並在 CarPlay 與背景播放期間持續運作。
{{% /details %}}

{{% details title="我可以更改音訊輸出品質嗎？" closed="true" %}}
可以。在 設定 > 音訊播放器 中，你可以設定輸出取樣率、聲道數與緩衝區大小，以配合你的耳機、喇叭或 DAC。
{{% /details %}}

{{% details title="耳機的良好初始設定是什麼？" closed="true" %}}
開啟音量正規化（Standard）、加入一個輕度的壓縮器（Soft）、選一個你喜歡的等化器預設，並開啟 Crossfeed（Chu Moy 或 Jan Meier）。除非你想要創意的聲音，否則把殘響、回音與失真保持關閉。
{{% /details %}}
