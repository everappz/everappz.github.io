Η καρτέλα **Κοινή χρήση** είναι η καρδιά του Everdisk. Εδώ μετατρέπετε το iPhone ή το iPad σας σε ασύρματο δίσκο, επιλέγετε ακριβώς τι θέλετε να μοιραστείτε και παίρνετε τις διευθύνσεις που χρησιμοποιούν οι άλλες συσκευές για να συνδεθούν. Είναι η πρώτη καρτέλα που βλέπετε όταν ανοίγετε την εφαρμογή.

## Έναρξη και διακοπή της κοινής χρήσης

Στη μέση της οθόνης Κοινής χρήσης υπάρχει ένα μεγάλο στρογγυλό κουμπί.

- Πατήστε **Start** για να ενεργοποιήσετε ταυτόχρονα όλους τους διακομιστές σας. Το κουμπί δείχνει **Starting...** και μετά **Stop** μόλις η κοινή χρήση είναι ενεργή.
- Πατήστε **Stop** για να απενεργοποιήσετε ξανά τα πάντα. Οι συνδεδεμένες συσκευές αποσυνδέονται.

Όσο τρέχει η κοινή χρήση, τα αρχεία, οι φωτογραφίες και η μουσική που επιλέξατε είναι διαθέσιμα σε κάθε συσκευή στο ίδιο δίκτυο που συνδέεται με έναν από τους τέσσερις τρόπους παρακάτω.

> Η κοινή χρήση τρέχει μόνο όσο η εφαρμογή είναι ανοιχτή. Δείτε το **Κρατήστε την εφαρμογή ανοιχτή** προς το τέλος αυτής της σελίδας για να μάθετε γιατί και πώς να διατηρήσετε ενεργές τις μεγάλες μεταφορές.

## Επιλέξτε τι θα μοιραστείτε

Πριν ξεκινήσετε, πατήστε την κεφαλίδα **What to Share** για να ανοίξετε τρεις ομάδες. Μπορείτε να μοιραστείτε οποιονδήποτε συνδυασμό τους, αλλά πρέπει να επιλέξετε τουλάχιστον ένα πράγμα για να μπορέσει να ξεκινήσει η κοινή χρήση.

**Αρχεία και Φάκελοι**

- Ο φάκελος **Documents** της ίδιας της εφαρμογής μοιράζεται από προεπιλογή. Μπορείτε να σταματήσετε την κοινή του χρήση αν το προτιμάτε.
- Πατήστε **Add Folder** για να μοιραστείτε έναν φάκελο από οπουδήποτε στη συσκευή σας ή **Add File** για να μοιραστείτε μεμονωμένα αρχεία.
- Κάθε κοινόχρηστο στοιχείο έχει ένα κουμπί **Info** και ένα κουμπί **Stop Sharing**.

**Φωτογραφίες και Βίντεο**

- Ενεργοποιήστε το **Allow access to all Photos Library** για να μοιραστείτε ολόκληρη τη βιβλιοθήκη φωτογραφιών και βίντεο σας ή
- Πατήστε **Add Photos** για να διαλέξετε μόνο τις φωτογραφίες και τα βίντεο που θέλετε να μοιραστείτε.

**Μουσική**

- Ενεργοποιήστε το **Allow access to all Music Library** για να μοιραστείτε ολόκληρη τη μουσική βιβλιοθήκη σας ή
- Πατήστε **Add Tracks** για να μοιραστείτε μόνο επιλεγμένα τραγούδια.
- Τα κομμάτια που προστατεύονται (DRM) ή αποθηκεύονται μόνο στο cloud δεν μπορούν να μοιραστούν.

Αν προσπαθήσετε να ξεκινήσετε χωρίς να έχετε επιλέξει τίποτα, το Everdisk εμφανίζει μια σημείωση **Nothing to Share**. Αν αλλάξετε το τι μοιράζεστε ενώ η κοινή χρήση είναι ενεργή, πατήστε **Stop και Start ξανά** για να εφαρμοστεί η αλλαγή.

## Οι τέσσερις διακομιστές

Το Everdisk μοιράζεται το ίδιο περιεχόμενο με τέσσερις τρόπους ταυτόχρονα. Ο καθένας είναι σχεδιασμένος για διαφορετικό είδος συσκευής και ο καθένας μπορεί να ενεργοποιηθεί ή να απενεργοποιηθεί στο **Settings → Sharing → Connections**. Από προεπιλογή και οι τέσσερις είναι ενεργοί.

- **TV & Media Center (DLNA)** - για smart TV και media players. Εντοπίζουν μόνες τους τη συσκευή σας και εμφανίζουν τις φωτογραφίες, τα βίντεο και τη μουσική σας, με μικρογραφίες προεπισκόπησης.
- **Browser (HTTP)** - για οποιοδήποτε κινητό, tablet ή υπολογιστή. Το άλλο άτομο ανοίγει έναν σύνδεσμο σε ένα πρόγραμμα περιήγησης για να περιηγηθεί και να κατεβάσει τα αρχεία σας. Χωρίς εγκατάσταση.
- **Computer (WebDAV)** - για ένα Mac, ένα PC με Windows ή ένα μηχάνημα Linux. Η συσκευή σας εμφανίζεται ως κανονικός δίσκος δικτύου, ώστε να μπορείτε να σέρνετε αρχεία και προς τις δύο κατευθύνσεις.
- **Other Apps & Devices (FTP)** - για εφαρμογές αρχείων και προχωρημένους χρήστες που μιλούν FTP.

Για αναλυτικές οδηγίες σύνδεσης βήμα προς βήμα για κάθε τύπο, δείτε το [Συνδέστε τις συσκευές σας](/docs/guide/everdisk/everdisk-guide-connect).

## Πώς να συνδεθείτε και διευθύνσεις σύνδεσης

Αφού πατήσετε Start, η ενότητα **How to Connect** εμφανίζει μια κάρτα για κάθε ενεργό διακομιστή με την ακριβή **διεύθυνση** που πρέπει να πληκτρολογήσετε στην άλλη συσκευή. Κάθε διεύθυνση αντιγράφεται εύκολα - πατήστε την για να την αντιγράψετε, χρησιμοποιήστε το κουμπί **Share** για να τη στείλετε ή πατήστε το κουμπί **info (ⓘ)** για αναλυτικές οδηγίες ανά πρωτόκολλο.

- Η κάρτα DLNA εμφανίζει μια διεύθυνση περιγραφής συσκευής που τελειώνει σε `/device-desc.xml` για players που τη ζητούν.
- Όταν η συσκευή σας είναι συνδεδεμένη σε ένα Mac με καλώδιο, εμφανίζεται μια επιπλέον διεύθυνση με ένα σήμα **Cable Connection** που χρησιμοποιεί το όνομα `.local` της συσκευής σας.

Μπορείτε επίσης να ανοίξετε τη διεύθυνση ως **κωδικό QR**, ώστε η κάμερα μιας άλλης συσκευής να μεταβεί κατευθείαν σε αυτήν.

## Ποιος είναι συνδεδεμένος

Η ενότητα **Who is Connected** εμφανίζει σε πραγματικό χρόνο τις συσκευές που είναι αυτή τη στιγμή συνδεδεμένες μαζί σας. Πατήστε το κουμπί περισσότερων ενεργειών δίπλα σε οποιαδήποτε συσκευή για να την **αποκλείσετε (Block this device)** αν δεν την αναγνωρίζετε. Οι αποκλεισμένες συσκευές διαχειρίζονται στο [Πρόσβαση & Απόρρητο](/docs/guide/everdisk/everdisk-guide-access).

## Το όνομα και το avatar της συσκευής σας

Κάθε συσκευή έχει ένα φιλικό όνομα (όπως "Speedy-Hare") και ένα έγχρωμο avatar. Αυτό είναι το όνομα που εμφανίζει μια TV, ένας υπολογιστής ή μια άλλη εφαρμογή για τη συσκευή σας στο δίκτυο, ώστε να ξεχωρίζει εύκολα. Μπορείτε να δημιουργήσετε ξανά το όνομα και το avatar δωρεάν ή να ορίσετε ένα προσαρμοσμένο όνομα, εικονίδιο ή avatar από φωτογραφία με το Premium. Δείτε τις [Ρυθμίσεις](/docs/guide/everdisk/everdisk-guide-settings).

## Κοινή χρήση μέσω Wi-Fi ή καλωδίου USB

Η κοινή χρήση μπορεί να τρέξει σε δύο περιπτώσεις:

- **Μέσω Wi-Fi** - η συσκευή σας και οι άλλες συσκευές βρίσκονται στο ίδιο δίκτυο Wi-Fi.
- **Μέσω καλωδίου USB** - η συσκευή σας είναι συνδεδεμένη σε ένα **Mac** με καλώδιο, ακόμη κι όταν δεν υπάρχει καθόλου Wi-Fi. Αυτό είναι πιο γρήγορο από το Wi-Fi και συνεχίζει να λειτουργεί σε ένα αεροπλάνο, σε ένα ξενοδοχείο ή σε ένα κλειδωμένο δίκτυο.

Αν δεν είναι διαθέσιμο ούτε Wi-Fi ούτε καλώδιο, το κουμπί **Start** είναι απενεργοποιημένο και εμφανίζεται μια σημείωση **No Wi-Fi Connection**. Αν η σύνδεση πέσει ενώ η κοινή χρήση είναι ενεργή, το Everdisk σταματά αυτόματα την κοινή χρήση και σας ενημερώνει. Πατήστε το κουμπί info σε οποιαδήποτε από αυτές τις σημειώσεις για μια πλήρη εξήγηση.

## Κρατήστε την εφαρμογή ανοιχτή

Επειδή το iPhone ή το iPad σας λειτουργεί ως διακομιστής, **η κοινή χρήση λειτουργεί μόνο όσο το Everdisk είναι ανοιχτό στην οθόνη**. Αν κλείσετε την εφαρμογή ή κλειδώσετε τη συσκευή για μεγάλο διάστημα, το σύστημα μπορεί να θέσει την εφαρμογή σε παύση και η κοινή χρήση σταματά.

Για μεγάλες μεταφορές:

- Κρατήστε το Everdisk ανοιχτό και σε πρώτο πλάνο.
- Συνδέστε τη συσκευή σας στο ρεύμα.
- Ορίστε το **Auto-Lock** σε **Never** στην εφαρμογή Ρυθμίσεων του iOS όσο μεταφέρετε.

Μπορείτε να ενεργοποιήσετε το **Notify before disconnecting** (στο Settings → Sharing), ώστε το Everdisk να σας υπενθυμίζει να ανοίξετε ξανά την εφαρμογή προτού το σύστημα την αναστείλει. Πατήστε το κουμπί info στο banner **Keep the app open** για περισσότερες λεπτομέρειες.
