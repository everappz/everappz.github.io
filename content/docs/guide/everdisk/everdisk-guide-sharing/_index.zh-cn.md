**分享**标签是 Everdisk 的核心。你在这里把 iPhone 或 iPad 变成无线磁盘、精确选择想要分享的内容，并拿到其他设备用来连接的地址。打开应用时，你看到的第一个标签就是它。

## 开始和停止分享

分享界面的正中央是一个大圆按钮。

- 点**开始**，让所有已启用的服务器一次性全部上线。按钮先显示**启动中…**，等分享正式运行后变成**停止**。
- 点**停止**，让一切重新下线。已连接的设备会被断开。

分享运行期间，你选定的文件、照片和音乐会向同一网络里、用下面四种方式之一连接的任意设备开放。

> 分享只在应用打开时运行。为什么会这样，以及如何让大文件传输持续进行，请看本页末尾的**让应用保持打开**。

## 选择要分享的内容

开始之前，点**要分享的内容**这一栏，会展开三个分组。你可以随意搭配分享它们，但在开始分享前至少要选择一项。

**文件和文件夹**

- 应用自己的 **文档** 文件夹默认会被分享。如果你不想分享它，可以停止。
- 点**添加文件夹**，分享设备上任意位置的一个文件夹；或点**添加文件**，分享单个文件。
- 每个已分享的项目都有一个**信息**按钮和一个**停止分享**按钮。

**照片和视频**

- 打开**允许访问整个照片图库**，分享你全部的照片和视频；或者
- 点**添加照片**，只挑选你想分享的照片和视频。

**音乐**

- 打开**允许访问整个音乐库**，分享你全部的音乐；或者
- 点**添加曲目**，只分享选定的歌曲。
- 受保护的（DRM）曲目，以及只存放在云端的曲目，无法分享。

如果你什么都没选就想开始，Everdisk 会显示一条**没有可分享的内容**提示。如果在分享运行期间改动了分享内容，请先**停止再重新开始**，让改动生效。

## 四个服务器

Everdisk 会同时用四种方式分享同样的内容。每一种都是为不同类型的设备设计的，都可以在 **设置 → 分享 → 连接** 里单独开关。默认四种全部开启。

- **电视和媒体中心 (DLNA)** - 面向智能电视和媒体播放器。它们会自己发现你的设备，并显示你的照片、视频和音乐，还带预览缩略图。
- **浏览器 (HTTP)** - 面向任何手机、平板或电脑。对方在网页浏览器里打开一个链接，就能浏览和下载你的文件。无需安装任何东西。
- **电脑 (WebDAV)** - 面向 Mac、Windows PC 或 Linux 机器。你的设备会像一个普通网络磁盘一样出现，让你双向拖放文件。
- **其他应用和设备 (FTP)** - 面向使用 FTP 的文件应用和高级用户。

每种类型的分步连接说明，请看[连接你的设备](/docs/guide/everdisk/everdisk-guide-connect)。

## 如何连接和连接地址

点开始之后，**如何连接**这一部分会为每个正在运行的服务器显示一张卡片，上面有要在对方设备上输入的确切**地址**。每个地址都很容易复制 - 点一下即可复制，用**分享**按钮把它发出去，或者点**信息 (ⓘ)** 按钮查看针对各协议的详细说明。

- DLNA 卡片会显示一个以 `/device-desc.xml` 结尾的设备描述地址，供需要它的播放器使用。
- 当你的设备用线缆插到 Mac 上时，会额外出现一个带**线缆连接**徽标的地址，它使用你设备的 `.local` 名称。

你也可以把地址以 **QR 码**的形式打开，让另一台设备用摄像头直接跳转过去。

## 谁已连接

**谁已连接**这一部分会实时列出当前连着你的设备。点任意设备旁边的更多操作按钮，如果你不认识它，可以**屏蔽此设备**。被屏蔽的设备在[访问与隐私](/docs/guide/everdisk/everdisk-guide-access)里管理。

## 你的设备名称和头像

每台设备都有一个好记的名字（比如「Speedy-Hare」）和一个彩色头像。电视、电脑或其他应用在网络上就是用这个名字来显示你的设备的，方便一眼认出。你可以免费重新生成名字和头像，也可以用 Premium 设置自定义的名字、图标或照片头像。见[设置](/docs/guide/everdisk/everdisk-guide-settings)。

## 通过 Wi-Fi 或 USB 线分享

分享可以在两种情况下运行：

- **通过 Wi-Fi** - 你的设备和其他设备处于同一个 Wi-Fi 网络。
- **通过 USB 线** - 你的设备用线缆插在 **Mac** 上，即便完全没有 Wi-Fi 也行。这比 Wi-Fi 更快，在飞机上、酒店里，或者受限的网络中都能照常工作。

如果 Wi-Fi 和线缆都不可用，**开始**按钮会变灰，并出现一条**没有 Wi-Fi 连接**提示。如果分享期间连接断开，Everdisk 会自动停止分享并通知你。点任意一条这类提示上的信息按钮，可以看到完整说明。

## 让应用保持打开

由于是你的 iPhone 或 iPad 在充当服务器，**分享只在 Everdisk 保持在屏幕上打开时才有效**。如果你关闭应用，或者长时间锁屏，系统可能会暂停应用，分享随之停止。

传输大文件时：

- 让 Everdisk 保持打开并在前台。
- 给设备接上电源。
- 传输期间，在 iOS 的设置应用里把**自动锁定**设为**永不**。

你可以打开**断开前提醒**（在 设置 → 分享 里），这样在系统即将挂起应用之前，Everdisk 会提醒你重新打开它。点**让应用保持打开**横幅上的信息按钮，可以了解更多细节。
