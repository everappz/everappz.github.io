Everdisk เก็บไฟล์ของคุณไว้บนเครือข่ายของคุณเอง และให้คุณควบคุมได้อย่างง่ายดายว่าใครเข้าถึงได้และทำอะไรได้บ้าง คุณพบตัวควบคุมเหล่านี้ได้ที่ **Settings → Sharing → Access** พร้อมกับการตั้งค่าที่เกี่ยวข้องอีกไม่กี่อย่างใน File Manager

## ปกป้องการเข้าถึงด้วยชื่อผู้ใช้และรหัสผ่าน

โดยค่าเริ่มต้น ใครก็ตามบนเครือข่ายเดียวกันที่มีที่อยู่ของคุณจะเปิดไฟล์ที่คุณแชร์ได้ หากต้องการบังคับให้ลงชื่อเข้าใช้

1. ไปที่ **Settings → Sharing → Access**
2. ใส่ **Login** และ **Password**
3. ตอนนี้การเชื่อมต่อ **Browser (HTTP)**, **Computer (WebDAV)** และ **Other Apps & Devices (FTP)** จะขอรายละเอียดเหล่านั้นทั้งหมดก่อนที่จะแสดงไฟล์ของคุณ

เว้นทั้งสองช่องให้ว่างสำหรับการเข้าถึงแบบเปิด รหัสผ่านของคุณจะถูกเก็บไว้อย่างปลอดภัยใน Keychain ของอุปกรณ์

> **DLNA เปิดอยู่เสมอ** การเชื่อมต่อ TV & Media Center (DLNA) ป้องกันด้วยรหัสผ่านไม่ได้ ดังนั้นเมื่อเปิดใช้งานแล้ว อุปกรณ์ใด ๆ บน Wi-Fi เดียวกันจะเรียกดูสื่อที่คุณแชร์ได้ ปิดมันหากคุณต้องการเฉพาะการเชื่อมต่อที่มีการป้องกัน และควรแชร์เฉพาะบนเครือข่ายที่คุณไว้ใจเท่านั้น

## อนุญาตหรือบล็อกการแก้ไข (Files Editing)

ปุ่มสลับ **Files Editing** ควบคุมว่าอุปกรณ์ที่เชื่อมต่ออยู่จะดูไฟล์ของคุณได้อย่างเดียว หรือเปลี่ยนแปลงได้ด้วย

- **เปิด** (ค่าเริ่มต้น): อุปกรณ์ที่เชื่อมต่ออยู่จะ **อัปโหลด เปลี่ยนชื่อ และลบ** ไฟล์ที่คุณแชร์ได้ ทำให้อุปกรณ์ของคุณทำงานเหมือนไดรฟ์เครือข่ายสองทิศทางจริง ๆ
- **ปิด**: ไฟล์ที่คุณแชร์จะเป็น**แบบอ่านอย่างเดียว** คนอื่นดูและดาวน์โหลดได้ แต่เพิ่มหรือเปลี่ยนแปลงอะไรไม่ได้

การเปิดใช้งานจะแสดงคำเตือนสั้น ๆ เพราะมันเปิดโอกาสให้คนอื่นแก้ไขไฟล์ของคุณได้ และจะมีป้าย **Important** กำกับไว้ในขณะที่เปิดอยู่

## บล็อกอุปกรณ์

หากคุณเห็นอุปกรณ์ที่จำไม่ได้

1. บนหน้าจอการแชร์ หาอุปกรณ์นั้นในส่วน **Who is Connected**
2. แตะปุ่มดำเนินการเพิ่มเติมของมันแล้วเลือก **Block this device**

อุปกรณ์ที่ถูกบล็อกจะแสดงอยู่ใน **Settings → Sharing → Access → Blocked Devices** ซึ่งคุณ **unblock** ทีละเครื่อง หรือ **Unblock All** ได้ การบล็อกจะติดตามอุปกรณ์นั้นไปแม้ที่อยู่เครือข่ายจะเปลี่ยน (สำหรับการเชื่อมต่อ Browser, Computer และ TV)

## ถังขยะเทียบกับการลบถาวร

เมื่อไฟล์ถูกลบ ไม่ว่าจะโดยคุณในตัวจัดการไฟล์ หรือโดยอุปกรณ์ที่เชื่อมต่ออยู่ ตามปกติมันจะไปอยู่ใน**ถังขยะ**ที่กู้คืนได้ เพื่อให้คุณเอากลับมาได้

หากคุณต้องการให้ไฟล์ถูกลบทันทีโดยกู้คืนไม่ได้ ให้เปิด **Permanently Delete Files** ใน **Settings → File Manager → Deleting Files** โดยค่าเริ่มต้นจะปิดอยู่ **มันส่งผลต่อตัวจัดการไฟล์บนอุปกรณ์** และ**การลบที่ทำผ่านเครือข่าย** แต่ไม่เปลี่ยนวิธีที่คลัง Photos หรือคลัง Music ของระบบจัดการการลบ

## ทุกอย่างอยู่ภายในเครือข่าย

Everdisk แชร์เฉพาะผ่าน**เครือข่ายภายใน**ของคุณเท่านั้น ไม่มีอะไรถูกอัปโหลดขึ้นอินเทอร์เน็ต และไม่มีบัญชีคลาวด์คั่นกลาง มีบางเรื่องที่ควรรู้ไว้

- Everdisk ต้องใช้สิทธิ์ **Local Network** ของ iOS เพื่อให้อุปกรณ์ใกล้เคียงค้นหามันเจอ หากสิทธิ์นี้ปิดอยู่ จะมีข้อความอธิบายวิธีเปิดกลับในแอป Settings ของ iOS
- เพื่อความเป็นส่วนตัวสูงสุด ควรแชร์เฉพาะขณะที่คุณอยู่บนเครือข่าย **Wi-Fi ที่บ้านหรือส่วนตัว**ที่คุณไว้ใจ และระมัดระวังบน Wi-Fi สาธารณะ ชื่อผู้ใช้และรหัสผ่านช่วยได้ แต่ก็ไม่ใช่สิ่งที่ใช้แทนเครือข่ายที่ไว้ใจได้
- **ตัวเลือกที่เป็นส่วนตัวที่สุดคือสาย USB ต่อกับ Mac** ข้อมูลจะไปตรงผ่านสายและไม่แตะต้องเราเตอร์หรืออินเทอร์เน็ตเลย ดู [เชื่อมต่ออุปกรณ์ของคุณ](/docs/guide/everdisk/everdisk-guide-connect)
