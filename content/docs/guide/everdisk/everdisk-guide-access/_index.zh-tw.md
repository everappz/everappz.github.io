Everdisk 把你的檔案留在你自己的網路上，並給你簡單的控制項，讓你決定誰能存取它們、以及他們能做什麼。你可以在 **設定 → 分享 → Access** 裡找到這些控制項，另外還有幾個相關設定在檔案管理員裡。

## 用帳號和密碼保護存取

預設情況下，同一網路上任何有你位址的人都能開啟你分享的檔案。若要要求登入：

1. 前往 **設定 → 分享 → Access**。
2. 輸入 **Login** 和 **Password**。
3. 現在 **Browser (HTTP)**、**Computer (WebDAV)** 和 **Other Apps & Devices (FTP)** 連線在顯示你的檔案之前，都會要求這些登入資料。

兩個欄位都留空即為開放存取。你的密碼會安全地儲存在裝置的鑰匙圈裡。

> **DLNA 一律開放。** TV & Media Center (DLNA) 連線無法設定密碼保護，所以只要它開啟，同一 Wi-Fi 上的任何裝置都能瀏覽你分享的媒體。如果你只想要受保護的連線，就把它關掉，並只在你信任的網路上分享。

## 允許或封鎖編輯（Files Editing）

**Files Editing** 開關控制連接的裝置只能檢視你的檔案，還是也能變更它們。

- **開啟**（預設）：連接的裝置可以 **上傳、重新命名和刪除** 你分享的檔案 - 讓你的裝置像一台真正的雙向網路硬碟。
- **關閉**：你分享的檔案為 **唯讀**。別人可以檢視和下載，但無法新增或變更任何東西。

開啟它時會顯示一則簡短警告，因為它讓別人得以修改你的檔案。開啟期間它會帶有 **Important** 標記。

## 封鎖一台裝置

如果你看到不認得的裝置：

1. 在分享畫面上，在 **Who is Connected** 底下找到它。
2. 點一下它的更多操作按鈕，選擇 **Block this device**。

被封鎖的裝置會列在 **設定 → 分享 → Access → Blocked Devices** 裡，你可以在那裡 **解除封鎖** 其中一個或 **Unblock All**。即使裝置的網路位址改變，封鎖仍會跟著它（適用於 Browser、Computer 和 TV 連線）。

## 垃圾桶與永久刪除

當一個檔案被刪除 - 無論是你在檔案管理員裡刪除，或由連接的裝置刪除 - 它通常會進入可復原的 **垃圾桶**，讓你可以把它救回來。

如果你希望檔案立即移除、無法復原，請在 **設定 → File Manager → Deleting Files** 裡開啟 **Permanently Delete Files**。這預設是關閉的。**它會影響裝置上的檔案管理員** 以及 **透過網路進行的刪除**；它不會改變系統的相片圖庫或音樂圖庫處理刪除的方式。

## 一切都留在本地

Everdisk 只透過你的 **本地網路** 分享 - 沒有任何東西上傳到網際網路，中間也沒有雲端帳號。有幾件事值得知道：

- Everdisk 需要 iOS 的 **本地網路** 權限，附近的裝置才能找到它。如果那個權限關閉了，會有一則提示說明如何在 iOS 設定 app 裡把它重新開啟。
- 為了最高的隱私，只在你信任的 **家用或私人 Wi-Fi** 網路上分享，並在公共 Wi-Fi 上小心。帳號和密碼有幫助，但無法取代一個受信任的網路。
- **所有選項中最私密的，是用 USB 傳輸線接到 Mac** - 資料直接透過傳輸線傳送，完全不會經過路由器或網際網路。請看 [連接你的裝置](/docs/guide/everdisk/everdisk-guide-connect)。
