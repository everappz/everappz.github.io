Το Everdisk κρατά τα αρχεία σας στο δικό σας δίκτυο και σας δίνει απλά χειριστήρια για το ποιος μπορεί να τα φτάσει και τι μπορεί να κάνει. Θα βρείτε αυτά τα χειριστήρια στο **Settings → Sharing → Access**, καθώς και μερικές σχετικές ρυθμίσεις στη διαχείριση αρχείων.

## Προστασία της πρόσβασης με σύνδεση και κωδικό

Από προεπιλογή, οποιοσδήποτε στο ίδιο δίκτυο έχει τη διεύθυνσή σας μπορεί να ανοίξει τα κοινόχρηστα αρχεία σας. Για να απαιτήσετε μια σύνδεση:

1. Μεταβείτε στο **Settings → Sharing → Access**.
2. Εισαγάγετε μια **Σύνδεση** και έναν **Κωδικό**.
3. Τώρα οι συνδέσεις **Browser (HTTP)**, **Computer (WebDAV)** και **Other Apps & Devices (FTP)** ζητούν όλες αυτά τα στοιχεία προτού εμφανίσουν τα αρχεία σας.

Αφήστε και τα δύο πεδία κενά για ανοιχτή πρόσβαση. Ο κωδικός σας αποθηκεύεται με ασφάλεια στο Keychain της συσκευής.

> **Το DLNA είναι πάντα ανοιχτό.** Η σύνδεση TV & Media Center (DLNA) δεν μπορεί να προστατευτεί με κωδικό, οπότε μόλις ενεργοποιηθεί, οποιαδήποτε συσκευή στο ίδιο Wi-Fi μπορεί να περιηγηθεί στα κοινόχρηστα πολυμέσα σας. Απενεργοποιήστε το αν θέλετε μόνο προστατευμένες συνδέσεις και μοιράζεστε μόνο σε δίκτυα που εμπιστεύεστε.

## Επιτρέψτε ή αποκλείστε την επεξεργασία (Files Editing)

Ο διακόπτης **Files Editing** ελέγχει αν οι συνδεδεμένες συσκευές μπορούν μόνο να βλέπουν τα αρχεία σας ή και να τα αλλάζουν.

- **Ενεργό** (η προεπιλογή): οι συνδεδεμένες συσκευές μπορούν να **ανεβάζουν, να μετονομάζουν και να διαγράφουν** τα κοινόχρηστα αρχεία σας - οπότε η συσκευή σας λειτουργεί σαν πραγματικός αμφίδρομος δίσκος δικτύου.
- **Ανενεργό**: τα κοινόχρηστα αρχεία σας είναι **μόνο για ανάγνωση**. Οι άλλοι μπορούν να βλέπουν και να κατεβάζουν, αλλά δεν μπορούν να προσθέσουν ή να αλλάξουν οτιδήποτε.

Η ενεργοποίησή του εμφανίζει μια σύντομη προειδοποίηση, επειδή επιτρέπει σε άλλα άτομα να τροποποιούν τα αρχεία σας. Φέρει ένα σήμα **Important** όσο είναι ενεργό.

## Αποκλεισμός μιας συσκευής

Αν δείτε μια συσκευή που δεν αναγνωρίζετε:

1. Στην οθόνη Κοινής χρήσης, βρείτε τη κάτω από το **Who is Connected**.
2. Πατήστε το κουμπί περισσότερων ενεργειών της και επιλέξτε **Block this device**.

Οι αποκλεισμένες συσκευές παρατίθενται στο **Settings → Sharing → Access → Blocked Devices**, όπου μπορείτε να **καταργήσετε τον αποκλεισμό** μιας ή να επιλέξετε **Unblock All**. Ο αποκλεισμός ακολουθεί τη συσκευή ακόμη κι αν αλλάξει η διεύθυνση δικτύου της (για τις συνδέσεις Browser, Computer και TV).

## Κάδος έναντι μόνιμης διαγραφής

Όταν ένα αρχείο διαγράφεται - από εσάς στη διαχείριση αρχείων ή από μια συνδεδεμένη συσκευή - κανονικά πηγαίνει σε έναν ανακτήσιμο **κάδο**, ώστε να μπορείτε να το επαναφέρετε.

Αν προτιμάτε τα αρχεία να αφαιρούνται αμέσως χωρίς δυνατότητα ανάκτησης, ενεργοποιήστε το **Permanently Delete Files** στο **Settings → File Manager → Deleting Files**. Αυτό είναι ανενεργό από προεπιλογή. **Επηρεάζει τη διαχείριση αρχείων στη συσκευή** και **τις διαγραφές που γίνονται μέσω δικτύου**. Δεν αλλάζει τον τρόπο με τον οποίο η βιβλιοθήκη Photos ή η βιβλιοθήκη Music του συστήματος χειρίζονται τη διαγραφή.

## Τα πάντα παραμένουν τοπικά

Το Everdisk μοιράζεται μόνο μέσω του **τοπικού σας δικτύου** - τίποτα δεν ανεβαίνει στο διαδίκτυο και δεν υπάρχει λογαριασμός cloud στη μέση. Μερικά πράγματα αξίζει να γνωρίζετε:

- Το Everdisk χρειάζεται την άδεια **Local Network** του iOS, ώστε οι κοντινές συσκευές να μπορούν να το βρουν. Αν αυτή η άδεια είναι ανενεργή, μια σημείωση εξηγεί πώς να την ενεργοποιήσετε ξανά στην εφαρμογή Ρυθμίσεων του iOS.
- Για τη μεγαλύτερη ιδιωτικότητα, μοιράζεστε μόνο όσο βρίσκεστε σε ένα **οικιακό ή ιδιωτικό δίκτυο Wi-Fi** που εμπιστεύεστε και να είστε προσεκτικοί σε δημόσιο Wi-Fi. Μια σύνδεση και ένας κωδικός βοηθούν, αλλά δεν αντικαθιστούν ένα έμπιστο δίκτυο.
- Η **πιο ιδιωτική επιλογή από όλες είναι ένα καλώδιο USB σε ένα Mac** - τα δεδομένα περνούν κατευθείαν μέσω του καλωδίου και δεν φτάνουν ποτέ στον router ή στο διαδίκτυο. Δείτε το [Συνδέστε τις συσκευές σας](/docs/guide/everdisk/everdisk-guide-connect).
