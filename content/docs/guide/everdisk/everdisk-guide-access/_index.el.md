Το Everdisk κρατά τα αρχεία σας στο δικό σας δίκτυο και σας δίνει απλά χειριστήρια για το ποιος μπορεί να τα φτάσει και τι μπορεί να κάνει. Θα βρείτε αυτά τα χειριστήρια στο **Ρυθμίσεις → Κοινή χρήση → Πρόσβαση**, καθώς και μερικές σχετικές ρυθμίσεις στη διαχείριση αρχείων.

## Προστασία της πρόσβασης με σύνδεση και κωδικό

Από προεπιλογή, οποιοσδήποτε στο ίδιο δίκτυο έχει τη διεύθυνσή σας μπορεί να ανοίξει τα κοινόχρηστα αρχεία σας. Για να απαιτήσετε μια σύνδεση:

1. Μεταβείτε στο **Ρυθμίσεις → Κοινή χρήση → Πρόσβαση**.
2. Εισαγάγετε ένα **Όνομα σύνδεσης** και έναν **Κωδικό**.
3. Τώρα οι συνδέσεις **Πρόγραμμα περιήγησης (HTTP)**, **Υπολογιστής (WebDAV)**, **Υπολογιστής (Σύνθετα) (SMB)** και **Άλλες εφαρμογές και συσκευές (FTP)** ζητούν όλες αυτά τα στοιχεία προτού εμφανίσουν τα αρχεία σας.

Αφήστε και τα δύο πεδία κενά για ανοιχτή πρόσβαση. Ο κωδικός σας αποθηκεύεται με ασφάλεια στο Keychain της συσκευής.

> **Το DLNA είναι πάντα ανοιχτό.** Η σύνδεση Τηλεόραση και κέντρο πολυμέσων (DLNA) δεν μπορεί να προστατευτεί με κωδικό, οπότε μόλις ενεργοποιηθεί, οποιαδήποτε συσκευή στο ίδιο Wi-Fi μπορεί να περιηγηθεί στα κοινόχρηστα πολυμέσα σας. Απενεργοποιήστε το αν θέλετε μόνο προστατευμένες συνδέσεις και μοιράζεστε μόνο σε δίκτυα που εμπιστεύεστε.

## Κρυπτογραφήστε τη σύνδεση SMB (SMB3 / AES)

Μια σύνδεση και ένας κωδικός ελέγχουν **ποιος** μπορεί να συνδεθεί, αλλά τα ίδια τα δεδομένα εξακολουθούν να ταξιδεύουν χωρίς κρυπτογράφηση στις περισσότερες συνδέσεις. **Το SMB είναι η μόνη σύνδεση που μπορεί να κρυπτογραφήσει το Everdisk**, κάτι που κρυπτογραφεί κάθε μεταφορά ώστε κανείς άλλος στο ίδιο δίκτυο να μην μπορεί να τη διαβάσει.

Για να το ενεργοποιήσετε:

1. Ορίστε ένα **Όνομα σύνδεσης** και έναν **Κωδικό** όπως παραπάνω - οι κρυπτογραφημένες συνδέσεις δεν μπορούν να είναι ανώνυμες.
2. Μεταβείτε στο **Ρυθμίσεις → Κοινή χρήση** και ενεργοποιήστε την **Απαίτηση κρυπτογράφησης SMB**.
3. **Σταματήστε και ξεκινήστε** ξανά την κοινή χρήση ώστε να τεθεί σε ισχύ η αλλαγή.

Κάθε μεταφορά SMB προστατεύεται τότε με **κρυπτογράφηση SMB3 (AES)**. Η συνδεόμενη συσκευή πρέπει να υποστηρίζει SMB3 - το Finder σε ένα σύγχρονο Mac, ή **Windows 10 και νεότερα**. Είναι μια εξαιρετική επιλογή σε Wi-Fi που δεν εμπιστεύεστε πλήρως. Η Κρυπτογράφηση SMB είναι λειτουργία Premium.

## Επιτρέψτε ή αποκλείστε την επεξεργασία (Επεξεργασία αρχείων)

Ο διακόπτης **Επεξεργασία αρχείων** ελέγχει αν οι συνδεδεμένες συσκευές μπορούν μόνο να βλέπουν τα αρχεία σας ή και να τα αλλάζουν.

- **Ενεργό** (η προεπιλογή): οι συνδεδεμένες συσκευές μπορούν να **ανεβάζουν, να μετονομάζουν και να διαγράφουν** τα κοινόχρηστα αρχεία σας - οπότε η συσκευή σας λειτουργεί σαν πραγματικός αμφίδρομος δίσκος δικτύου.
- **Ανενεργό**: τα κοινόχρηστα αρχεία σας είναι **μόνο για ανάγνωση**. Οι άλλοι μπορούν να βλέπουν και να κατεβάζουν, αλλά δεν μπορούν να προσθέσουν ή να αλλάξουν οτιδήποτε.

Η ενεργοποίησή του εμφανίζει μια σύντομη προειδοποίηση, επειδή επιτρέπει σε άλλα άτομα να τροποποιούν τα αρχεία σας. Φέρει ένα σήμα **Σημαντικό** όσο είναι ενεργό.

## Αποκλεισμός μιας συσκευής

Αν δείτε μια συσκευή που δεν αναγνωρίζετε:

1. Στην οθόνη Κοινής χρήσης, βρείτε τη κάτω από το **Ποιος είναι συνδεδεμένος**.
2. Πατήστε το κουμπί περισσότερων ενεργειών της και επιλέξτε **Αποκλεισμός αυτής της συσκευής**.

Οι αποκλεισμένες συσκευές παρατίθενται στο **Ρυθμίσεις → Κοινή χρήση → Πρόσβαση → Αποκλεισμένες συσκευές**, όπου μπορείτε να **καταργήσετε τον αποκλεισμό** μιας ή να επιλέξετε **Κατάργηση αποκλεισμού όλων**. Ο αποκλεισμός ακολουθεί τη συσκευή ακόμη κι αν αλλάξει η διεύθυνση δικτύου της (για τις συνδέσεις Πρόγραμμα περιήγησης, Υπολογιστής και Τηλεόραση).

## Κάδος έναντι μόνιμης διαγραφής

Όταν ένα αρχείο διαγράφεται - από εσάς στη διαχείριση αρχείων ή από μια συνδεδεμένη συσκευή - κανονικά πηγαίνει σε έναν ανακτήσιμο **κάδο**, ώστε να μπορείτε να το επαναφέρετε.

Αν προτιμάτε τα αρχεία να αφαιρούνται αμέσως χωρίς δυνατότητα ανάκτησης, ενεργοποιήστε το **Μόνιμη διαγραφή αρχείων** στο **Ρυθμίσεις → Διαχείριση αρχείων → Διαγραφή αρχείων**. Αυτό είναι ανενεργό από προεπιλογή. **Επηρεάζει τη διαχείριση αρχείων στη συσκευή** και **τις διαγραφές που γίνονται μέσω δικτύου**. Δεν αλλάζει τον τρόπο με τον οποίο η βιβλιοθήκη Photos ή η βιβλιοθήκη Music του συστήματος χειρίζονται τη διαγραφή.

## Τα πάντα παραμένουν τοπικά

Το Everdisk μοιράζεται μόνο μέσω του **τοπικού σας δικτύου** - τίποτα δεν ανεβαίνει στο διαδίκτυο και δεν υπάρχει λογαριασμός cloud στη μέση. Μερικά πράγματα αξίζει να γνωρίζετε:

- Το Everdisk χρειάζεται την άδεια **Τοπικό δίκτυο** του iOS, ώστε οι κοντινές συσκευές να μπορούν να το βρουν. Αν αυτή η άδεια είναι ανενεργή, μια σημείωση εξηγεί πώς να την ενεργοποιήσετε ξανά στην εφαρμογή Ρυθμίσεων του iOS.
- Για τη μεγαλύτερη ιδιωτικότητα, μοιράζεστε μόνο όσο βρίσκεστε σε ένα **οικιακό ή ιδιωτικό δίκτυο Wi-Fi** που εμπιστεύεστε και να είστε προσεκτικοί σε δημόσιο Wi-Fi. Μια σύνδεση και ένας κωδικός βοηθούν, αλλά δεν αντικαθιστούν ένα έμπιστο δίκτυο.
- Η **πιο ιδιωτική επιλογή από όλες είναι ένα καλώδιο USB σε ένα Mac** - τα δεδομένα περνούν κατευθείαν μέσω του καλωδίου και δεν φτάνουν ποτέ στον router ή στο διαδίκτυο. Δείτε το [Συνδέστε τις συσκευές σας](/docs/guide/everdisk/everdisk-guide-connect).
