Everdisk はデバイスでメディアを再生し、写真と音楽のライブラリをまるごとネットワーク経由で共有します。このページでは、ドキュメントタブの写真モードと音楽モード、メディアプレーヤー、そして写真と動画がどう共有されるかを制御する画質設定を扱います。

## 写真と音楽のライブラリをまるごと共有する

[共有](/docs/guide/everdisk/everdisk-guide-sharing)画面の **共有する内容** で、**すべての写真ライブラリへのアクセスを許可** と **すべての音楽ライブラリへのアクセスを許可** をオンにできます。共有が始まると、すべてのアルバムとトラックが 5 つのサーバーすべてで利用できるようになります - テレビ、ブラウザ、ネットワークドライブ (WebDAV または SMB)、ファイルアプリで。**写真を追加** や **曲を追加** を使って、特定の写真、動画、トラックだけを自分で選ぶこともできます。

保護されている (DRM) 曲や、クラウドにのみ保存されているトラックは共有できません。

## ミニプレーヤーで音声を再生する

音声ファイルをタップすると - ドキュメント、接続したフォルダー、音楽ライブラリ、デバイスタブのサーバーのいずれからでも - **ミニプレーヤー** で再生され、アプリ内を移動しても画面下部に表示され続けます。

- バーにはアートワーク、タイトルとサブタイトル、**再生・一時停止** と **次へ** のコントロールが表示されます。
- バーをタップまたは上にスワイプすると **フルプレーヤー** に展開します。下にスワイプすると再び縮小し、その間も音声は再生され続けます。
- バーを **タップして長押し** すると **キュー** が開き、すべてのトラックを確認したり、**シャッフル** をオンにしたり、**リピート** (オフ、すべて、1 曲) を設定したり、**停止** したりできます。
- 再生は **ロック画面** やメディアキーにも表示され、実際のタイトル、アーティスト、アルバムが示されます。

フォルダー内の 1 つの音声ファイルをタップすると、そのフォルダーの音声すべてがキューとして再生されます。

## 動画を全画面で視聴する

動画をタップすると **全画面** で再生されます。Everdisk は内蔵のシステム動画プレーヤーを使うので、**AirPlay**、**Picture in Picture**、**再生速度** を含む標準のコントロールが使えます。動画はローカルファイル、接続したフォルダー、再生元のサーバーから再生できます。動画を開始すると、2 つが重ならないようにミニプレーヤーの音声はすべて停止します。

## 写真を見る

- **ドキュメントタブ → 写真モード** では、共有した写真と動画を閲覧できます。
- 写真をタップするとシステムのプレビューが開き、ズーム、スワイプ、共有ができます。
- **Web ブラウザ** では、写真は全画面のギャラリーで開き、スワイプ、ピンチでのズーム、スライドショーボタンが使えます。
- **テレビ** では、写真は DLNA 経由でプレビューのサムネイル付きで表示されます。

位置情報を持つ写真や動画は、その 情報 画面に **ピン付きの地図** を表示します。

## テレビにメディアを送る

テレビにメディアを表示するには、**TV とメディアセンター (DLNA)** サーバーを使います。共有を開始し、テレビであなたのデバイスを選んで閲覧します。テレビがあなたのデバイスからメディアを取得します - [デバイスを接続する](/docs/guide/everdisk/everdisk-guide-connect)を参照してください。(Everdisk は Chromecast を使いません。AirPlay は全画面の動画プレーヤーから利用できます。)

## オリジナル画質と互換画質

写真や動画を共有するとき、Everdisk はそれらをそのまま送ることも、古いテレビやブラウザで開けるように変換することもできます。これは **設定 → 共有** で設定します。

- **写真 → 形式** (オリジナルまたは最も互換性が高い / JPEG) と **画質** (オリジナル、高、中、低)。
- **動画 → 形式** (オリジナルまたは最も互換性が高い / H.264 MP4) と **画質**。

覚えておきたいこと:

- **オリジナルが最速** です。ファイルは変換なしでそのまま送られます。
- それ以外の設定は **その場で変換** するため、特に WebDAV、SMB、FTP では遅くなり、バッテリーの消費も増えます。
- まずオリジナルを試してください。特定のテレビやブラウザがファイルを開けない場合にのみ、最も互換性が高い設定に切り替えましょう。
- **音楽** は常にオリジナルのまま共有されます。音楽の画質設定はありません。

写真と動画の変換は Premium 機能です。オリジナル画質は常に無料で利用できます。
