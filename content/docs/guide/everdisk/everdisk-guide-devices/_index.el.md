Το Everdisk δεν είναι μόνο ένας ασύρματος δίσκος - είναι επίσης ένας πελάτης για τις άλλες συσκευές στο δίκτυό σας. Η καρτέλα **Συσκευές** σας επιτρέπει να συνδέεστε σε διακομιστές **DLNA**, **WebDAV**, **FTP**, **SFTP** και **SMB**, συμπεριλαμβανομένων Mac, PC με Windows, μηχανημάτων Linux, δίσκων NAS και media servers, και στη συνέχεια να περιηγείστε, να μεταδίδετε και να κατεβάζετε τα αρχεία τους.

## Η οθόνη Συσκευές

Η καρτέλα Συσκευές έχει δύο μέρη:

- **Συνδέσεις** - οι διακομιστές που έχετε ήδη αποθηκεύσει.
- **Διαθέσιμες συσκευές** - διακομιστές που εντοπίζει αυτόματα το Everdisk στο τοπικό σας δίκτυο.

Για να συνδεθείτε σε κάτι που το Everdisk έχει ήδη εντοπίσει, απλώς πατήστε το στις **Διαθέσιμες συσκευές**. Για να προσθέσετε έναν διακομιστή χειροκίνητα, πατήστε το κουμπί **συν (+)** ή το **Νέα σύνδεση**.

## Προσθήκη νέας σύνδεσης

Πατήστε **Νέα σύνδεση** και επιλέξτε τον τύπο του διακομιστή που θέλετε να φτάσετε:

- **DLNA / UPnP** - ιδανικό για media servers. Μεταδώστε βίντεο, μουσική και φωτογραφίες από βιβλιοθήκες πολυμέσων, δίσκους αποθήκευσης δικτύου και TV και υπολογιστές με DLNA. Το DLNA είναι μόνο για ανάγνωση: μπορείτε να περιηγείστε, να μεταδίδετε και να κατεβάζετε, αλλά δεν μπορείτε να ανεβάζετε ή να αλλάζετε αρχεία.
- **WebDAV** - συνδεθείτε σε διακομιστές αρχείων, δίσκους αποθήκευσης δικτύου και cloud δίσκους που υποστηρίζουν WebDAV. Ανάγνωση και εγγραφή όταν το επιτρέπει ο διακομιστής.
- **FTP** - συνηθισμένο σε routers, δίσκους αποθήκευσης δικτύου και web hosting. Η προεπιλεγμένη θύρα είναι η 21 (990 για ασφαλές FTPS). Μπορείτε να ορίσετε μια προσαρμοσμένη θύρα στη διεύθυνση, για παράδειγμα `ftp://host:2121`. Αφήστε τη σύνδεση και τον κωδικό κενά για ανώνυμη πρόσβαση.
- **SFTP** - συνδεθείτε με ασφάλεια μέσω SSH. Η προεπιλεγμένη θύρα είναι η 22. Χρησιμοποιήστε μια προσαρμοσμένη θύρα στη διεύθυνση αν χρειάζεται, για παράδειγμα `sftp://host:2222`.
- **SMB** - συνδεθείτε σε Mac, PC με Windows, διακομιστές Linux και αποθηκευτικούς χώρους δικτύου (NAS) που μοιράζονται φακέλους μέσω **SMB / CIFS**. Εισαγάγετε μια διεύθυνση όπως `smb://server-address/share-name/` (παραδείγματα: `smb://local-server-name/share-name/folder-path`, `smb://192.168.1.105/share-name/folder-path`, `smb://remote-server.com`). Το SMB προσθέτει δύο προαιρετικά πεδία: ένα όνομα **Ομάδα εργασίας**, και μια **Έκδοση πρωτοκόλλου** που μπορείτε να αφήσετε στο **Αυτόματη** ή να επιβάλετε σε **SMB1** ή **SMB2**. Αν αρχεία ή φάκελοι με ειδικούς χαρακτήρες δεν ανοίγουν, δοκιμάστε να αλλάξετε την έκδοση σε **SMB1**.

> Το Everdisk συνδέεται μόνο σε αυτά τα πρωτόκολλα τοπικού δικτύου και άμεσης διευθυνσιοδότησης. Δεν συνδέεται σε λογαριασμούς cloud όπως το Google Drive ή το Dropbox. Ένας cloud δίσκος είναι προσβάσιμος μόνο αν αυτή η υπηρεσία προσφέρει μια διεύθυνση **WebDAV** που μπορείτε να πληκτρολογήσετε.

## Εισαγωγή της διεύθυνσης και σύνδεση

Στο πρόγραμμα επεξεργασίας σύνδεσης, συμπληρώστε:

- **Τίτλος** - ένα φιλικό όνομα για τη σύνδεση.
- **URL / διεύθυνση** - η διεύθυνση του διακομιστή (εμφανίζονται παραδείγματα για κάθε τύπο).
- **Όνομα σύνδεσης** και **Κωδικός** - αφήστε και τα δύο κενά αν ο διακομιστής επιτρέπει ανώνυμη πρόσβαση.

Για το WebDAV μπορείτε να επιτρέψετε μη έγκυρα πιστοποιητικά αν ο διακομιστής σας χρησιμοποιεί αυτο-υπογεγραμμένο. Αν η ταυτότητα ενός ασφαλούς διακομιστή δεν μπορεί να επαληθευτεί, το Everdisk σας ζητά να επιβεβαιώσετε προτού τον εμπιστευτείτε.

Οι δωρεάν χρήστες μπορούν να αποθηκεύσουν έως **10** συνδέσεις. Το Premium αφαιρεί το όριο.

## Περιήγηση, μετάδοση και λήψη

Μόλις συνδεθείτε, πατήστε τον διακομιστή για να τον ανοίξετε:

- **Περιηγηθείτε** στους φακέλους σε λίστα ή πλέγμα, ταξινομήστε τους και δείτε μικρογραφίες. Οι διακομιστές DLNA εμφανίζουν επίσης λεπτομέρειες μουσικής και εξώφυλλα.
- **Μεταδώστε** ήχο και βίντεο. Ο ήχος πηγαίνει στην ουρά του mini player. Το βίντεο αναπαράγεται σε πλήρη οθόνη. Η αναζήτηση λειτουργεί ενώ ένα αρχείο μεταδίδεται.
- **Κατεβάστε** αρχεία στη συσκευή σας. Επιλέξτε αρκετά ταυτόχρονα για μαζική λήψη. Οι λήψεις εμφανίζονται στο **Μεταφορές αρχείων** και καταλήγουν στον φάκελο **Έγγραφα**.
- Το **Πληροφορίες** σε οποιοδήποτε στοιχείο εμφανίζει το είδος, το μέγεθος, την ημερομηνία, τη διαδρομή και τις λεπτομέρειες πολυμέσων του.

## Αλλαγή αρχείων σε έναν διακομιστή

Σε διακομιστές που επιτρέπουν εγγραφή - **WebDAV, FTP, SFTP και SMB** - μπορείτε επίσης να διαχειρίζεστε αρχεία:

- **Νέος φάκελος**
- **Αποστολή αρχείων** από τη συσκευή σας
- **Μετονομασία**, **Μετακίνηση** και **Διαγραφή** (ένα στοιχείο ή αρκετά ταυτόχρονα)

Οι διακομιστές **DLNA** είναι μόνο για ανάγνωση, οπότε αυτές οι ενέργειες δεν είναι διαθέσιμες εκεί.

## Παρακολούθηση των μεταφορών σας

Οι λήψεις και οι μεταφορτώσεις τρέχουν στο παρασκήνιο και εμφανίζονται στο **Μεταφορές αρχείων**, το οποίο ανοίγετε από την επάνω αριστερή γωνία της καρτέλας **Έγγραφα**. Εκεί μπορείτε να παρακολουθείτε την πρόοδο και να θέτετε σε παύση, να συνεχίζετε, να επαναλαμβάνετε, να ακυρώνετε ή να καθαρίζετε εργασίες. Μπορείτε επίσης να ρυθμίσετε τις μεταφορές στο [Ρυθμίσεις → Δίκτυο](/docs/guide/everdisk/everdisk-guide-settings) (μόνο Wi-Fi έναντι Wi-Fi και δεδομένων κινητής, πόσες τρέχουν ταυτόχρονα και αν συνεχίζουν στο παρασκήνιο).
