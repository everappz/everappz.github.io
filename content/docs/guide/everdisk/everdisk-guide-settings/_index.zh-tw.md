**設定** 分頁把一切分成三大區域 - **共享**、**網路** 和 **檔案管理員** - 再加上 Premium、意見回饋和法律連結。本頁說明每個設定及其預設值。

## Premium

在設定的頂端，你會看到自己的 Premium 狀態，或一個 **解鎖所有功能** 按鈕。Everdisk 可免費使用，但有一些限制；一次性的 **Premium 終身版** 購買可解除它們。請看本頁結尾的 [Premium](#premium-lifetime)。

## 分享設定

### 一般

- **自動開始裝置分享** - 一打開 app 就開始分享。*（Premium。）*
- **共享文件檔案夾** - 分享 app 自己的文件資料夾。預設開啟。
- **中斷連線前通知** - 在系統於背景暫停 app 之前，提醒你重新開啟它。預設關閉；第一次會要求通知權限。

### 裝置檔案

- **裝置名稱** - 其他裝置在網路上看到你的名稱。點一下即可編輯。*（Premium。）*
- **裝置頭像** - 你裝置的圖示和背景顏色。你可以挑選圖示、背景漸層，或 **從相片選擇頭像**。*（Premium。）*
- **重新產生名稱和頭像** 和 **重新產生頭像** - 取得新的隨機名稱和／或頭像。*（免費。）*

### 存取權

- **登入名稱** 和 **密碼** - 為瀏覽器、電腦和其他應用程式連線要求登入。
- **檔案編輯** - 讓連接的裝置上傳、重新命名和刪除。預設開啟。
- **已封鎖的裝置** - 管理你封鎖過的裝置。

詳情請看 [存取與隱私](/docs/guide/everdisk/everdisk-guide-access)。

### 連接

開啟或關閉每種伺服器。五種預設全部開啟，每一種都有一個 info (ⓘ) 按鈕，附連線說明：

- **電視與媒體中心**（DLNA）
- **瀏覽器**（HTTP）
- **電腦**（WebDAV）
- **電腦（進階）**（SMB） - 給 Mac、Windows 和 Linux 的網路硬碟；在 Mac 上會自己出現在 Finder 側邊欄。唯一可以加密的連線。
- **其他應用程式和裝置**（FTP）

### 相片

- **格式** - 原始 或 相容性最高（JPEG）。
- **品質** - 原始、高、中 或 低。

原始 以外的任何選項都會在分享時轉換相片，這較慢。轉換是 Premium 功能。

### 影片

- **格式** - 原始 或 相容性最高（H.264 MP4）。
- **品質** - 原始、高、中 或 低。

和相片同樣的道理：原始 最快，而轉換是 Premium。如果較舊的電視無法播放某個影片，就降低品質。

### 進階

- **HTTP 連接埠**（預設 80）、**WebDAV 連接埠**（預設 8080）、**SMB 埠**（預設 4455）、**FTP 連接埠**（預設 2121）。DLNA 會自動選擇它的連接埠。*（變更連接埠是 Premium；免費使用者可以看到數值。）*

### SMB 加密

- **要求 SMB 加密** - 用 **SMB3 加密 (AES)** 加密每一次 SMB 傳輸，讓網路上的其他人都無法讀取你的檔案。預設關閉。它需要上方設定好的 **登入帳號和密碼**（加密的連接不能匿名）以及支援 SMB3 的用戶端，例如新型 Mac 上的 Finder 或 Windows 10 以上版本。變更會在你下次開始分享時生效。*（Premium。）*

### DLNA 縮圖

- **顯示縮圖** - 為電視發佈預覽影像。預設開啟（免費）。
- 選擇要發佈哪些尺寸：**Small (160px)**、**Medium (640px)**、**Large (1024px)**、**Extra Large (4096px)**。

## 網路設定

- **檔案傳輸** - 下載和上傳只用 **Wi-Fi**，或用 **Wi-Fi 和行動數據**。預設 Wi-Fi。
- **並行傳輸上限** - 同時執行幾個傳輸。預設 5。
- **背景傳輸** - 在你使用其他畫面時讓傳輸持續進行。預設開啟。
- **檔案縮圖** - 抓取其他裝置上檔案的縮圖時，只用 Wi-Fi 或也用行動網路。預設 Wi-Fi。

## 檔案管理員設定

- **永久刪除檔案** - 立即刪除，不進垃圾桶。預設關閉。請看 [存取與隱私](/docs/guide/everdisk/everdisk-guide-access)。
- **重置所有通知訊息** - 找回你已關閉的提示橫幅。
- **縮圖快取** - 查看快取縮圖佔用多少空間，以及 **清除縮圖快取**。

## 意見回饋與法律

在底部，你可以 **為此 App 評分**、**傳送意見反映**、**取得更多 App**，並開啟 **條款與條件** 和 **隱私權政策**。

## Premium Lifetime

Everdisk 可免費使用。單次的 **Premium 終身版** 購買 - 一次性付款，不是訂閱 - 可解鎖：

- **無限制檔案夾** - 分享超過 5 個資料夾。
- **無限連線** - 在裝置分頁上儲存超過 10 個伺服器。
- **照片與影片轉換** - 以 原始 以外的任何品質分享。
- **SMB 加密** - 用 SMB3 加密 (AES) 保護 SMB 傳輸。
- **自訂連接埠** - 設定你自己的 HTTP、WebDAV、SMB 和 FTP 連接埠。
- **自動開始分享** - 打開 app 時自動開始分享。
- **裝置自訂** - 自訂裝置名稱、頭像圖示、背景漸層或相片頭像。

Premium 綁定你的 Apple ID。用 **回復購買項目** 在你以同一組 Apple ID 登入的其他裝置上解鎖它。
