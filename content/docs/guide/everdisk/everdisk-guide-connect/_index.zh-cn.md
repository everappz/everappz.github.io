在[分享](/docs/guide/everdisk/everdisk-guide-sharing)界面点了**开始**之后，其他设备可以用五种不同的方式连接到你的文件。挑选与你要用的设备相匹配的那一种。无论哪种方式，你需要的确切**地址**都会显示在分享界面的**如何连接**部分。

> 两台设备必须在**同一个 Wi-Fi 网络**上 - 或者，对于 Mac，用 **USB 线**连接（见最后一节）。

## 在电视上观看 (DLNA)

用这种方式在智能电视或媒体播放器上展示照片、视频和音乐。

1. 在 **设置 → 分享 → 连接** 里，确认**电视和媒体中心**已开启（它默认就是开的）。
2. 在分享界面点**开始**。
3. 在电视上，打开它内置的媒体播放器或媒体服务器应用（可能叫 Media Player、SmartShare、AllShare 或类似名字）。
4. 你的设备会以它的名字（例如「Speedy-Hare」）出现在媒体服务器列表里。选中它。
5. 浏览你分享的照片、视频和音乐，开始播放。预览缩略图会自动出现。

注意事项：

- DLNA 无法设置密码保护，所以只要它开着，同一 Wi-Fi 上的任何人都能访问这个连接。
- 如果某个视频在老电视上无法播放，请在 **设置 → 分享 → 视频** 里降低视频质量，让 Everdisk 把它转换成兼容性更好的格式。

## 在网页浏览器里打开 (HTTP)

用这种方式把文件交给任何有网页浏览器的人 - 无需安装应用。

1. 在 **设置 → 分享 → 连接** 里，确认**浏览器**已开启。
2. 点**开始**。
3. 在分享界面复制**浏览器**地址（或显示它的 QR 码）。
4. 在对方的手机、平板或电脑上，打开任意网页浏览器（Safari、Chrome、Edge、Firefox），输入那个地址。
5. 页面打开后就是你分享的文件。

在浏览器里，对方可以：

- 在**列表**和**网格**视图之间切换，并按名称、日期或大小排序。
- 看到照片、视频、PDF 和音乐封面的真实**缩略图**。
- 打开某张照片进入全屏**图库**，支持滑动、双指缩放和幻灯片播放。
- 在内置**播放器**里播放音乐，带播放队列、随机播放和循环。
- **下载**任意文件，或者把整个文件夹（或选中的多个项目）打包成一个 **Archive.zip** 下载。
- 把文件**上传**回你的设备 - 仅当你打开了**文件编辑**时才可以（见[访问与隐私](/docs/guide/everdisk/everdisk-guide-access)）。

## 把它当作网络磁盘 (WebDAV)

用这种方式让你的设备像一块普通磁盘一样出现在 Mac、Windows PC 或 Linux 机器上，从而双向拖放文件。

**在 Mac 上 (Finder)**

1. 在 **设置 → 分享 → 连接** 里，确认**电脑**已开启。
2. 点**开始**，记下**电脑 (WebDAV)** 地址。
3. 在 Finder 里，选择**前往 → 连接服务器**（或按 **⌘K**）。
4. 完全照显示的样子输入 WebDAV 地址，然后点**连接**。
5. 如果你设了登录名和密码就输入它们，否则以访客身份连接。
6. 你的设备会像其他任何网络磁盘一样打开。把文件拖进拖出即可。

**在 Windows 上**

1. 打开**文件资源管理器**，右键点击**此电脑**，选择**添加网络位置**（或映射网络驱动器）。
2. 输入 Everdisk 里显示的 WebDAV 地址。
3. 如果你设了登录名和密码就输入它们。

**在 Linux 上**

1. 打开你的文件管理器，选择**连接服务器**（或使用 `davs://` / `dav://`）。
2. 输入 Everdisk 里显示的 WebDAV 地址。

连接是只读还是双向，取决于**文件编辑**设置。打开它，你可以把文件复制到设备上，并重命名或删除它们；关闭它，磁盘就是只读的。

## 通过 SMB 连接（加密网络磁盘）

SMB 是用作 Mac、Windows 和 Linux 的网络磁盘，基于这些系统已有的文件共享功能，所以你的设备会像一块普通网络磁盘一样出现 - 而且它是唯一可以加密的连接。

1. 在 **设置 → 分享 → 连接** 里，确认**电脑（高级）**（即 SMB 连接）已开启。
2. 点**开始**，记下 **SMB** 地址，它看起来像 `smb://192.168.1.20:4455/Share`。
3. 从你的电脑连接：
   - **Mac：**你的设备会在**位置**（网络）下自行出现在 **Finder 边栏**里 - 直接点它并登录即可。若想手动连接，请选择**前往 → 连接服务器**（**⌘K**）并输入该地址。
   - **Windows：**打开**文件资源管理器**，右键点击**此电脑**并选择**映射网络驱动器**，然后用分享界面上的主机名和共享名输入 `\\<address>\Share`（或在地址栏中输入 `smb://` 地址）。
   - **Linux：**在你的文件管理器里选择**连接服务器**并输入该地址。
4. 如果你设了登录名和密码就输入它们，否则以访客身份连接。
5. 共享名为 **Share**。打开**文件编辑**后，你可以双向复制文件；关闭它，就是只读的。

**开启加密（在不受信任的 Wi-Fi 上推荐）**

SMB 是 Everdisk 唯一可以加密的连接。要用 **SMB3 加密 (AES)** 保护每一次传输：

1. 在 **设置 → 分享 → 访问** 里，设置一个**登录名**和**密码** - 加密连接不能匿名。
2. 在 **设置 → 分享** 里，开启**要求 SMB 加密**。
3. **停止再重新开始**分享，让改动生效。

你的客户端必须支持 SMB3 - 现代 Mac 上的 Finder，或 **Windows 10 及更高版本**。SMB 加密是一项 Premium 功能。

## 连接一个文件应用 (FTP)

用这种方式连接使用 FTP 的文件管理和传输应用（例如电脑上的 FileZilla 或 Cyberduck）。

1. 在 **设置 → 分享 → 连接** 里，确认**其他应用和设备**已开启。
2. 点**开始**，记下 **FTP** 地址。
3. 在你的 FTP 应用里，用那个地址新建一个连接。
4. 如果你设了登录名和密码就输入它们，或者留空以进行匿名访问。

## 通过 USB 线传输（Mac，无需 Wi-Fi）

在没有 Wi-Fi 时，或者当你想要最快、最私密的传输时，用这种方式。它只支持 **Mac**。

1. 用普通的充电线把你的 iPhone 或 iPad 插到 Mac 上。
2. 如果设备上问到，点**信任此电脑**。
3. 在 Everdisk 里点**开始**。会出现一条**可用快速连接**提示，分享界面会显示一个额外的、带**线缆连接**徽标、以 `.local` 结尾的地址。
4. 在 Mac 上，打开 Finder → **前往 → 连接服务器**（**⌘K**），输入那个 `.local` 地址（它对浏览器连接和电脑连接都有效）。
5. 你的设备会通过线缆打开 - 比 Wi-Fi 更快，而且数据绝不经过路由器或互联网。

注意事项：

- 使用 **`.local` 名称**，而不是 IP 地址（IP 地址只在 Wi-Fi 下有效），也绝不要用 `localhost`。
- 线缆方式**仅限 Mac**。Windows PC 和 Android 设备必须使用 Wi-Fi。
- 你也可以通过标准的 iOS 文件共享，在 Mac 上用 Finder，或在 Windows 上用 Apple 设备应用（或 iTunes），把文件拖进 Everdisk 文件夹。
