[공유](/docs/guide/everdisk/everdisk-guide-sharing) 화면에서 **시작**을 누르면, 다른 기기가 다섯 가지 방식으로 여러분의 파일에 연결할 수 있습니다. 사용하려는 기기에 맞는 방법을 고르세요. 어느 경우든 필요한 정확한 **주소**는 공유 화면의 **연결 방법** 섹션에 표시됩니다.

> 두 기기는 반드시 **같은 Wi-Fi 네트워크**에 있어야 합니다 - Mac이라면 **USB 케이블**로 연결해도 됩니다(마지막 섹션 참고).

## TV에서 감상하기 (DLNA)

스마트 TV나 미디어 플레이어에서 사진, 동영상, 음악을 보여 줄 때 사용하세요.

1. **설정 → 공유 → 연결하기**에서 **TV 및 미디어 센터**가 켜져 있는지 확인하세요(기본으로 켜져 있습니다).
2. 공유 화면에서 **시작**을 누르세요.
3. TV에서 내장 미디어 플레이어나 미디어 서버 앱을 여세요(Media Player, SmartShare, AllShare 등으로 불릴 수 있습니다).
4. 미디어 서버 목록에 여러분의 기기가 이름(예: "Speedy-Hare")으로 나타납니다. 그것을 선택하세요.
5. 공유한 사진, 동영상, 음악을 탐색하고 재생을 시작하세요. 미리보기 썸네일이 자동으로 나타납니다.

참고:

- DLNA는 비밀번호로 보호할 수 없으므로, 켜져 있는 동안에는 같은 Wi-Fi에 있는 누구에게나 이 연결이 열려 있습니다.
- 오래된 TV에서 동영상이 재생되지 않으면 **설정 → 공유 → 동영상**에서 동영상 품질을 낮추세요. 그러면 Everdisk가 더 호환성 좋은 형식으로 변환해 줍니다.

## 웹 브라우저에서 열기 (HTTP)

웹 브라우저만 있으면 누구에게든 파일을 건네줄 수 있습니다 - 설치할 앱이 없습니다.

1. **설정 → 공유 → 연결하기**에서 **브라우저**가 켜져 있는지 확인하세요.
2. **시작**을 누르세요.
3. 공유 화면에서 **브라우저** 주소를 복사하세요(또는 QR 코드를 표시하세요).
4. 상대방의 휴대폰, 태블릿, 컴퓨터에서 아무 웹 브라우저(Safari, Chrome, Edge, Firefox)나 열고 그 주소를 입력하세요.
5. 여러분이 공유한 파일과 함께 페이지가 열립니다.

브라우저에서 상대방은 다음을 할 수 있습니다:

- **목록**과 **격자** 보기를 전환하고 이름, 날짜, 크기순으로 정렬합니다.
- 사진, 동영상, PDF, 음악 아트워크의 실제 **썸네일**을 봅니다.
- 사진을 열어 넘기기, 손가락으로 확대하기, 슬라이드쇼가 되는 전체 화면 **갤러리**로 봅니다.
- 대기열, 셔플, 반복이 있는 내장 **플레이어**로 음악을 재생합니다.
- 파일을 하나씩 **다운로드**하거나, 폴더 전체(또는 고른 여러 항목)를 하나의 **Archive.zip**으로 내려받습니다.
- 파일을 여러분의 기기로 다시 **업로드**합니다 - 단, **파일 편집**을 켠 경우에만 가능합니다([접근 및 개인정보 보호](/docs/guide/everdisk/everdisk-guide-access) 참고).

## 네트워크 드라이브로 사용하기 (WebDAV)

Mac, Windows PC, Linux 컴퓨터에서 여러분의 기기를 일반 디스크처럼 나타나게 해서 양방향으로 파일을 끌어다 옮길 때 사용하세요.

**Mac에서 (Finder)**

1. **설정 → 공유 → 연결하기**에서 **컴퓨터**가 켜져 있는지 확인하세요.
2. **시작**을 누르고 **컴퓨터 (WebDAV)** 주소를 확인하세요.
3. Finder에서 **이동 → 서버에 연결**을 선택하세요(또는 **⌘K**를 누르세요).
4. 표시된 WebDAV 주소를 그대로 입력하고 **연결**을 클릭하세요.
5. 로그인과 비밀번호를 설정했다면 입력하고, 아니면 게스트로 연결하세요.
6. 여러분의 기기가 다른 네트워크 드라이브처럼 열립니다. 파일을 안팎으로 끌어다 옮기세요.

**Windows에서**

1. **파일 탐색기**를 열고 **내 PC**를 마우스 오른쪽 버튼으로 클릭한 뒤 **네트워크 위치 추가**를 선택하세요(또는 네트워크 드라이브를 연결하세요).
2. Everdisk에 표시된 WebDAV 주소를 입력하세요.
3. 로그인과 비밀번호를 설정했다면 입력하세요.

**Linux에서**

1. 파일 관리자를 열고 **서버에 연결**을 선택하세요(또는 `davs://` / `dav://`를 사용하세요).
2. Everdisk에 표시된 WebDAV 주소를 입력하세요.

연결이 읽기 전용인지 양방향인지는 **파일 편집** 설정에 따라 달라집니다. 켜져 있으면 여러분의 기기로 파일을 복사하고 이름을 바꾸거나 삭제할 수 있으며, 꺼져 있으면 드라이브가 읽기 전용이 됩니다.

## SMB로 연결하기 (암호화된 네트워크 드라이브)

SMB는 Mac, Windows, Linux를 위한 네트워크 드라이브로, 그 시스템에 이미 있는 파일 공유 기능을 기반으로 하기 때문에 여러분의 기기가 일반 네트워크 드라이브처럼 나타납니다 - 그리고 암호화할 수 있는 유일한 연결입니다.

1. **설정 → 공유 → 연결하기**에서 **컴퓨터(고급)**(SMB 연결)이 켜져 있는지 확인하세요.
2. **시작**을 누르고 **SMB** 주소를 확인하세요. `smb://192.168.1.20:4455/Share`처럼 보입니다.
3. 컴퓨터에서 연결하세요:
   - **Mac:** 기기가 **Finder 사이드바**의 **위치**(네트워크)에 자동으로 나타납니다 - 클릭한 뒤 로그인하세요. 직접 연결하려면 **이동 → 서버에 연결**(**⌘K**)을 선택하고 주소를 입력하세요.
   - **Windows:** **파일 탐색기**를 열고 **내 PC**를 오른쪽 클릭한 뒤 **네트워크 드라이브 매핑**을 선택하고, 공유 화면의 호스트와 공유 이름을 사용해 `\\<address>\Share`를 입력하세요(또는 주소 표시줄에 `smb://` 주소를 입력하세요).
   - **Linux:** 파일 관리자에서 **서버에 연결**을 선택하고 주소를 입력하세요.
4. 로그인과 비밀번호를 설정했다면 입력하고, 아니면 게스트로 연결하세요.
5. 공유 이름은 **Share**입니다. **파일 편집**이 켜져 있으면 양방향으로 파일을 복사할 수 있고, 꺼져 있으면 읽기 전용입니다.

**암호화 켜기 (신뢰하기 어려운 Wi-Fi에서 권장)**

SMB는 암호화할 수 있는 유일한 Everdisk 연결입니다. 모든 전송을 **SMB3 암호화(AES)**로 보호하려면:

1. **설정 → 공유 → 접근**에서 **로그인**과 **비밀번호**를 설정하세요 - 암호화된 연결은 익명일 수 없습니다.
2. **설정 → 공유**에서 **SMB 암호화 요구**를 켜세요.
3. 변경 사항이 적용되도록 공유를 다시 **중지했다가 시작**하세요.

클라이언트가 SMB3를 지원해야 합니다 - 최신 Mac의 Finder, 또는 **Windows 10 이상**. SMB 암호화는 Premium 기능입니다.

## 파일 앱 연결하기 (FTP)

FTP를 사용하는 파일 관리자와 전송 앱(예: 컴퓨터의 FileZilla나 Cyberduck)에 사용하세요.

1. **설정 → 공유 → 연결하기**에서 **다른 앱 및 기기**가 켜져 있는지 확인하세요.
2. **시작**을 누르고 **FTP** 주소를 확인하세요.
3. FTP 앱에서 그 주소로 새 연결을 추가하세요.
4. 로그인과 비밀번호를 설정했다면 입력하고, 익명 접근을 하려면 비워 두세요.

## USB 케이블로 전송하기 (Mac, Wi-Fi 불필요)

Wi-Fi가 없거나, 가장 빠르고 사생활이 보호되는 전송을 원할 때 사용하세요. **Mac**에서만 작동합니다.

1. 일반 충전 케이블로 iPhone이나 iPad를 Mac에 연결하세요.
2. 기기에서 물어보면 **이 컴퓨터를 신뢰**를 누르세요.
3. Everdisk에서 **시작**을 누르세요. **빠른 연결 사용 가능** 안내가 나타나고, 공유 화면에 `.local`로 끝나는 추가 주소가 **케이블 연결** 배지와 함께 표시됩니다.
4. Mac에서 Finder → **이동 → 서버에 연결**(**⌘K**)을 열고 그 `.local` 주소를 입력하세요(브라우저 연결과 컴퓨터 연결 모두에 사용됩니다).
5. 여러분의 기기가 케이블을 통해 열립니다 - Wi-Fi보다 빠르며 데이터는 공유기나 인터넷을 거치지 않습니다.

참고:

- IP 주소가 아니라 **`.local` 이름**을 사용하세요(IP 주소는 Wi-Fi에서만 작동합니다). 그리고 `localhost`는 절대 사용하지 마세요.
- 케이블 방식은 **Mac 전용**입니다. Windows PC와 Android 기기는 Wi-Fi를 사용해야 합니다.
- 표준 iOS 파일 공유를 통해 Mac의 Finder나 Windows의 Apple Devices 앱(또는 iTunes)으로 Everdisk 폴더에 파일을 끌어다 놓을 수도 있습니다.
