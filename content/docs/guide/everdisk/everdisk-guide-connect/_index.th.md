เมื่อคุณแตะ **Start** บนหน้าจอ [การแชร์](/docs/guide/everdisk/everdisk-guide-sharing) แล้ว อุปกรณ์อื่นจะเชื่อมต่อกับไฟล์ของคุณได้ห้าวิธี เลือกวิธีที่ตรงกับอุปกรณ์ที่คุณต้องการใช้ ในทุกกรณี **ที่อยู่**ที่คุณต้องใช้จะแสดงอยู่ในส่วน **วิธีเชื่อมต่อ** ของหน้าจอการแชร์

> อุปกรณ์ทั้งสองต้องอยู่บน**เครือข่าย Wi-Fi เดียวกัน** หรือสำหรับ Mac ต้องเชื่อมต่อด้วย**สาย USB** (ดูหัวข้อสุดท้าย)

## ดูบนทีวี (DLNA)

ใช้วิธีนี้เพื่อแสดงรูปภาพ วิดีโอ และเพลงบนสมาร์ททีวีหรือเครื่องเล่นสื่อ

1. ใน **การตั้งค่า → การแชร์ → การเชื่อมต่อ** ตรวจสอบให้แน่ใจว่า **ทีวีและศูนย์มีเดีย** เปิดอยู่ (เปิดโดยค่าเริ่มต้น)
2. บนหน้าจอการแชร์ แตะ **Start**
3. บนทีวีของคุณ เปิดเครื่องเล่นสื่อในตัวหรือแอปเซิร์ฟเวอร์สื่อ (อาจเรียกว่า Media Player, SmartShare, AllShare หรือชื่อคล้ายกัน)
4. อุปกรณ์ของคุณจะปรากฏในรายการเซิร์ฟเวอร์สื่อตามชื่อของมัน (เช่น "Speedy-Hare") เลือกเครื่องนั้น
5. เรียกดูรูปภาพ วิดีโอ และเพลงที่คุณแชร์ แล้วเริ่มเล่นได้เลย ภาพตัวอย่างขนาดย่อจะปรากฏขึ้นโดยอัตโนมัติ

หมายเหตุ

- DLNA ป้องกันด้วยรหัสผ่านไม่ได้ ดังนั้นการเชื่อมต่อนี้จึงเปิดให้ทุกคนบน Wi-Fi เดียวกันเข้าถึงได้ในขณะที่เปิดใช้งานอยู่
- ถ้าวิดีโอเล่นไม่ได้บนทีวีรุ่นเก่า ให้ลดคุณภาพวิดีโอใน **การตั้งค่า → การแชร์ → วิดีโอ** เพื่อให้ Everdisk แปลงเป็นรูปแบบที่รองรับได้ง่ายกว่า

## เปิดในเว็บเบราว์เซอร์ (HTTP)

ใช้วิธีนี้เพื่อส่งไฟล์ให้กับใครก็ได้ที่มีเว็บเบราว์เซอร์ โดยไม่ต้องติดตั้งแอป

1. ใน **การตั้งค่า → การแชร์ → การเชื่อมต่อ** ตรวจสอบให้แน่ใจว่า **เบราว์เซอร์** เปิดอยู่
2. แตะ **Start**
3. บนหน้าจอการแชร์ คัดลอกที่อยู่ **เบราว์เซอร์** (หรือแสดง QR code ของมัน)
4. บนโทรศัพท์ แท็บเล็ต หรือคอมพิวเตอร์อีกเครื่อง เปิดเว็บเบราว์เซอร์ใดก็ได้ (Safari, Chrome, Edge, Firefox) แล้วพิมพ์ที่อยู่นั้น
5. หน้าเว็บจะเปิดขึ้นพร้อมไฟล์ที่คุณแชร์

ในเบราว์เซอร์ อีกฝ่ายจะทำสิ่งเหล่านี้ได้

- สลับระหว่างมุมมอง**แบบรายการ**และ**แบบตาราง** และเรียงตามชื่อ วันที่ หรือขนาด
- เห็น**ภาพตัวอย่างขนาดย่อ**จริงของรูปภาพ วิดีโอ ไฟล์ PDF และปกอัลบั้มเพลง
- เปิดรูปภาพเข้าสู่**แกลเลอรี**แบบเต็มจอ พร้อมปัด ซูมด้วยการหุบนิ้ว และสไลด์โชว์
- เล่นเพลงใน**เครื่องเล่น**ในตัว พร้อมคิว สุ่มเล่น และเล่นซ้ำ
- **ดาวน์โหลด**ไฟล์ใดก็ได้ หรือดาวน์โหลดทั้งโฟลเดอร์ (หรือหลายรายการที่เลือกไว้) เป็นไฟล์ **Archive.zip** เดียว
- **อัปโหลด**ไฟล์กลับมายังอุปกรณ์ของคุณ เฉพาะเมื่อคุณเปิด **การแก้ไขไฟล์** ไว้ (ดู [การเข้าถึงและความเป็นส่วนตัว](/docs/guide/everdisk/everdisk-guide-access))

## ใช้เป็นไดรฟ์เครือข่าย (WebDAV)

ใช้วิธีนี้เพื่อให้อุปกรณ์ของคุณปรากฏเป็นดิสก์ปกติบน Mac, Windows PC หรือเครื่อง Linux เพื่อให้คุณลากไฟล์ได้ทั้งสองทิศทาง

**บน Mac (Finder)**

1. ใน **การตั้งค่า → การแชร์ → การเชื่อมต่อ** ตรวจสอบให้แน่ใจว่า **คอมพิวเตอร์** เปิดอยู่
2. แตะ **Start** และจดที่อยู่ **คอมพิวเตอร์ (WebDAV)**
3. ใน Finder เลือก **Go → Connect to Server** (หรือกด **⌘K**)
4. พิมพ์ที่อยู่ WebDAV ให้ตรงตามที่แสดง แล้วคลิก **Connect**
5. ใส่ชื่อผู้ใช้และรหัสผ่านหากคุณตั้งไว้ มิฉะนั้นเชื่อมต่อในฐานะแขก
6. อุปกรณ์ของคุณจะเปิดขึ้นเหมือนไดรฟ์เครือข่ายอื่น ๆ ลากไฟล์เข้าหรือออกได้เลย

**บน Windows**

1. เปิด **File Explorer** คลิกขวาที่ **This PC** แล้วเลือก **Add a network location** (หรือแมปไดรฟ์เครือข่าย)
2. ใส่ที่อยู่ WebDAV ที่แสดงใน Everdisk
3. ใส่ชื่อผู้ใช้และรหัสผ่านหากคุณตั้งไว้

**บน Linux**

1. เปิดตัวจัดการไฟล์ของคุณแล้วเลือก **Connect to Server** (หรือใช้ `davs://` / `dav://`)
2. ใส่ที่อยู่ WebDAV ที่แสดงใน Everdisk

การเชื่อมต่อจะเป็นแบบอ่านอย่างเดียวหรือสองทิศทางนั้นขึ้นอยู่กับการตั้งค่า **การแก้ไขไฟล์** เมื่อเปิดไว้ คุณจะคัดลอกไฟล์ลงอุปกรณ์ และเปลี่ยนชื่อหรือลบได้ เมื่อปิดไว้ ไดรฟ์จะเป็นแบบอ่านอย่างเดียว

## เชื่อมต่อผ่าน SMB (ไดรฟ์เครือข่ายที่เข้ารหัสได้)

SMB คือไดรฟ์เครือข่ายสำหรับ Mac, Windows และ Linux ที่สร้างขึ้นบนการแชร์ไฟล์ที่มีอยู่แล้วในระบบเหล่านั้น อุปกรณ์ของคุณจึงปรากฏเป็นไดรฟ์เครือข่ายปกติ และเป็นการเชื่อมต่อเดียวที่คุณเข้ารหัสได้

1. ใน **การตั้งค่า → การแชร์ → การเชื่อมต่อ** ตรวจสอบให้แน่ใจว่า **คอมพิวเตอร์ (ขั้นสูง)** (การเชื่อมต่อ SMB) เปิดอยู่
2. แตะ **Start** และจดที่อยู่ **SMB** ซึ่งมีลักษณะเช่น `smb://192.168.1.20:4455/Share`
3. เชื่อมต่อจากคอมพิวเตอร์ของคุณ
   - **Mac:** อุปกรณ์ของคุณจะปรากฏขึ้นเองใน**แถบข้าง Finder** ใต้ **Locations** (Network) เพียงคลิกที่มันแล้วลงชื่อเข้าใช้ หากต้องการเชื่อมต่อด้วยตัวเองแทน ให้เลือก **Go → Connect to Server** (**⌘K**) แล้วใส่ที่อยู่
   - **Windows:** เปิด **File Explorer** คลิกขวาที่ **This PC** แล้วเลือก **Map network drive** จากนั้นใส่ `\\<address>\Share` โดยใช้โฮสต์และชื่อแชร์จากหน้าจอการแชร์ (หรือพิมพ์ที่อยู่ `smb://` ในแถบที่อยู่)
   - **Linux:** ในตัวจัดการไฟล์ของคุณ เลือก **Connect to Server** แล้วใส่ที่อยู่
4. ใส่ชื่อผู้ใช้และรหัสผ่านหากคุณตั้งไว้ มิฉะนั้นเชื่อมต่อในฐานะแขก
5. แชร์นี้มีชื่อว่า **Share** เมื่อเปิด **การแก้ไขไฟล์** ไว้ คุณจะคัดลอกไฟล์ได้ทั้งสองทิศทาง เมื่อปิดไว้ ไดรฟ์จะเป็นแบบอ่านอย่างเดียว

**เปิดการเข้ารหัส (แนะนำบน Wi-Fi ที่ไม่ไว้ใจ)**

SMB เป็นการเชื่อมต่อเดียวของ Everdisk ที่เข้ารหัสได้ วิธีปกป้องการถ่ายโอนทุกครั้งด้วย **การเข้ารหัส SMB3 (AES)**

1. ใน **การตั้งค่า → การแชร์ → การเข้าถึง** ตั้ง **ชื่อผู้ใช้** และ **รหัสผ่าน** การเชื่อมต่อที่เข้ารหัสไม่สามารถไม่ระบุตัวตนได้
2. ใน **การตั้งค่า → การแชร์** เปิด **ต้องใช้การเข้ารหัส SMB**
3. **หยุดแล้วเริ่ม** การแชร์อีกครั้งเพื่อให้การเปลี่ยนแปลงมีผล

ไคลเอนต์ของคุณต้องรองรับ SMB3 เช่น Finder บน Mac รุ่นใหม่ หรือ **Windows 10 ขึ้นไป** การเข้ารหัส SMB เป็นฟีเจอร์ Premium

## เชื่อมต่อแอปไฟล์ (FTP)

ใช้วิธีนี้สำหรับแอปจัดการไฟล์และแอปถ่ายโอนที่ใช้ FTP (เช่น FileZilla หรือ Cyberduck บนคอมพิวเตอร์)

1. ใน **การตั้งค่า → การแชร์ → การเชื่อมต่อ** ตรวจสอบให้แน่ใจว่า **แอปและอุปกรณ์อื่นๆ** เปิดอยู่
2. แตะ **Start** และจดที่อยู่ **FTP**
3. ในแอป FTP ของคุณ เพิ่มการเชื่อมต่อใหม่โดยใช้ที่อยู่นั้น
4. ใส่ชื่อผู้ใช้และรหัสผ่านหากคุณตั้งไว้ หรือเว้นว่างไว้สำหรับการเข้าถึงแบบไม่ระบุตัวตน

## ถ่ายโอนผ่านสาย USB (Mac ไม่ต้องใช้ Wi-Fi)

ใช้วิธีนี้เมื่อไม่มี Wi-Fi หรือเมื่อคุณต้องการการถ่ายโอนที่เร็วที่สุดและเป็นส่วนตัวที่สุด ใช้ได้กับ **Mac** เท่านั้น

1. เสียบ iPhone หรือ iPad ของคุณเข้ากับ Mac ด้วยสายชาร์จปกติ
2. หากอุปกรณ์ถาม ให้แตะ **Trust This Computer**
3. ใน Everdisk แตะ **Start** จะมีข้อความ **มีการเชื่อมต่อที่รวดเร็ว** ปรากฏขึ้น และหน้าจอการแชร์จะแสดงที่อยู่เพิ่มขึ้นมาพร้อมป้าย **การเชื่อมต่อผ่านสายเคเบิล** ที่ลงท้ายด้วย `.local`
4. บน Mac เปิด Finder → **Go → Connect to Server** (**⌘K**) แล้วใส่ที่อยู่ `.local` นั้น (ใช้ได้ทั้งการเชื่อมต่อเบราว์เซอร์และคอมพิวเตอร์)
5. อุปกรณ์ของคุณจะเปิดขึ้นผ่านสาย เร็วกว่า Wi-Fi และข้อมูลไม่แตะต้องเราเตอร์หรืออินเทอร์เน็ตเลย

หมายเหตุ

- ใช้**ชื่อ `.local`** ไม่ใช่ที่อยู่ IP (ที่อยู่ IP ใช้ได้เฉพาะผ่าน Wi-Fi) และห้ามใช้ `localhost` เด็ดขาด
- เส้นทางผ่านสายใช้ได้กับ **Mac เท่านั้น** เครื่อง Windows PC และอุปกรณ์ Android ต้องใช้ Wi-Fi
- คุณยังลากไฟล์เข้าไปในโฟลเดอร์ Everdisk ได้โดยใช้ Finder บน Mac หรือแอป Apple Devices (หรือ iTunes) บน Windows ผ่านการแชร์ไฟล์มาตรฐานของ iOS
