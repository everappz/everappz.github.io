在 [分享](/docs/guide/everdisk/everdisk-guide-sharing) 畫面上點一下 **開始** 之後，其他裝置就能用五種不同方式連上你的檔案。挑選符合你想使用裝置的方法。無論哪一種，你需要的確切 **位址** 都會顯示在分享畫面的 **如何連線** 區段裡。

> 兩台裝置必須在 **同一個 Wi-Fi 網路** 上 - 或者，若是 Mac，用 **USB 傳輸線** 連接（請看最後一節）。

## 在電視上觀看 (DLNA)

用這個方式在智慧型電視或媒體播放器上顯示相片、影片和音樂。

1. 在 **設定 → 共享 → 連線** 裡，確認 **電視與媒體中心** 已開啟（預設是開啟的）。
2. 在分享畫面上，點一下 **開始**。
3. 在你的電視上，開啟內建的媒體播放器或媒體伺服器 app（它可能叫 Media Player、SmartShare、AllShare 或類似的名稱）。
4. 你的裝置會以它的名稱（例如「Speedy-Hare」）出現在媒體伺服器清單裡。選取它。
5. 瀏覽你分享的相片、影片和音樂並開始播放。預覽縮圖會自動出現。

注意事項：

- DLNA 無法設定密碼保護，所以只要開啟，同一 Wi-Fi 上的任何人都能存取這個連線。
- 如果影片在較舊的電視上無法播放，請在 **設定 → 共享 → 影片** 裡降低影片品質，讓 Everdisk 把它轉換成相容性更高的格式。

## 在網頁瀏覽器裡開啟 (HTTP)

用這個方式把檔案交給任何有網頁瀏覽器的人 - 完全不用安裝 app。

1. 在 **設定 → 共享 → 連線** 裡，確認 **瀏覽器** 已開啟。
2. 點一下 **開始**。
3. 在分享畫面上，複製 **瀏覽器** 位址（或顯示它的 QR code）。
4. 在另一支手機、平板或電腦上，開啟任何網頁瀏覽器（Safari、Chrome、Edge、Firefox）並輸入那個位址。
5. 頁面就會開啟，顯示你分享的檔案。

在瀏覽器裡，對方可以：

- 在 **清單** 和 **格狀** 檢視間切換，並依名稱、日期或大小排序。
- 看到相片、影片、PDF 和音樂封面的真實 **縮圖**。
- 開啟相片進入全螢幕 **圖庫**，支援滑動、雙指縮放和幻燈片播放。
- 在內建 **播放器** 裡播放音樂，附有佇列、隨機播放和重複播放。
- **下載** 任何檔案，或把整個資料夾（或數個選取的項目）當成一個 **Archive.zip** 下載。
- 把檔案 **上傳** 回你的裝置 - 前提是你開啟了 **檔案編輯**（請看 [存取與隱私](/docs/guide/everdisk/everdisk-guide-access)）。

## 當成網路硬碟使用 (WebDAV)

用這個方式讓你的裝置在 Mac、Windows PC 或 Linux 電腦上像一般磁碟一樣出現，讓你雙向拖放檔案。

**在 Mac（Finder）上**

1. 在 **設定 → 共享 → 連線** 裡，確認 **電腦** 已開啟。
2. 點一下 **開始** 並記下 **電腦 (WebDAV)** 位址。
3. 在 Finder 裡，選擇 **前往 → 連接伺服器**（或按 **⌘K**）。
4. 完全依照顯示的內容輸入 WebDAV 位址，然後按 **連接**。
5. 如果你設了帳號和密碼就輸入，否則以訪客身分連接。
6. 你的裝置會像其他網路硬碟一樣開啟。把檔案拖進拖出即可。

**在 Windows 上**

1. 開啟 **檔案總管**，右鍵點 **本機**，然後選 **新增網路位置**（或對應網路磁碟機）。
2. 輸入 Everdisk 裡顯示的 WebDAV 位址。
3. 如果你設了帳號和密碼就輸入。

**在 Linux 上**

1. 開啟你的檔案管理員並選擇 **連接伺服器**（或使用 `davs://` / `dav://`）。
2. 輸入 Everdisk 裡顯示的 WebDAV 位址。

連線是唯讀還是雙向，取決於 **檔案編輯** 設定。開啟時，你可以把檔案複製到裝置上，並重新命名或刪除；關閉時，磁碟為唯讀。

## 透過 SMB 連接（加密的網路硬碟）

SMB 是給 Mac、Windows 和 Linux 的網路硬碟，建構在這些系統既有的檔案分享功能上，所以你的裝置會像一般網路硬碟一樣出現 - 而且它是唯一可以加密的連線。

1. 在 **設定 → 共享 → 連線** 裡，確認 **電腦（進階）**（SMB 連接）已開啟。
2. 點一下 **開始** 並記下 **SMB** 位址，它看起來像 `smb://192.168.1.20:4455/Share`。
3. 從你的電腦連接：
   - **Mac：** 你的裝置會在 **位置**（網路）底下自己出現在 **Finder 側邊欄** - 直接點一下它並登入即可。若想手動連接，就選擇 **前往 → 連接伺服器**（**⌘K**）並輸入位址。
   - **Windows：** 開啟 **檔案總管**，右鍵點 **本機** 並選 **對應網路磁碟機**，然後用分享畫面上的主機和共享名稱輸入 `\\<address>\Share`（或在位址列輸入 `smb://` 位址）。
   - **Linux：** 在你的檔案管理員選擇 **連接伺服器** 並輸入位址。
4. 如果你設了帳號和密碼就輸入，否則以訪客身分連接。
5. 共享名稱為 **Share**。開啟 **檔案編輯** 後可以雙向複製檔案；關閉它則為唯讀。

**開啟加密（在不受信任的 Wi-Fi 上建議使用）**

SMB 是 Everdisk 唯一可以加密的連線。想用 **SMB3 加密 (AES)** 保護每一次傳輸：

1. 在 **設定 → 共享 → 存取權** 裡，設定 **登入名稱** 和 **密碼** - 加密的連接不能匿名。
2. 在 **設定 → 共享** 裡，開啟 **要求 SMB 加密**。
3. **先停止再重新開始** 分享，讓變更生效。

你的用戶端必須支援 SMB3 - 新型 Mac 上的 Finder，或 **Windows 10 以上版本**。SMB 加密屬於 Premium 功能。

## 連接檔案 app (FTP)

用這個方式連接支援 FTP 的檔案管理員和傳輸 app（例如電腦上的 FileZilla 或 Cyberduck）。

1. 在 **設定 → 共享 → 連線** 裡，確認 **其他應用程式和裝置** 已開啟。
2. 點一下 **開始** 並記下 **FTP** 位址。
3. 在你的 FTP app 裡，用那個位址新增一個連線。
4. 如果你設了帳號和密碼就輸入，或留空以進行匿名存取。

## 透過 USB 傳輸線傳輸（Mac，不需 Wi-Fi）

當沒有 Wi-Fi，或你想要最快、最私密的傳輸時，就用這個方式。它只適用於 **Mac**。

1. 用一般的充電線把你的 iPhone 或 iPad 接到 Mac。
2. 若裝置上詢問，點一下 **信任這部電腦**。
3. 在 Everdisk 裡點一下 **開始**。會出現 **可用快速連線** 提示，分享畫面也會多出一個帶 **傳輸線連接** 標記、以 `.local` 結尾的位址。
4. 在 Mac 上，開啟 Finder → **前往 → 連接伺服器**（**⌘K**），輸入那個 `.local` 位址（它對瀏覽器和電腦兩種連線都有效）。
5. 你的裝置會透過傳輸線開啟 - 比 Wi-Fi 更快，而且資料完全不會經過路由器或網際網路。

注意事項：

- 使用 **`.local` 名稱**，而非 IP 位址（IP 位址只在 Wi-Fi 上有效），也絕不要用 `localhost`。
- 傳輸線路徑 **僅限 Mac**。Windows PC 和 Android 裝置必須使用 Wi-Fi。
- 你也可以透過標準的 iOS 檔案分享，在 Mac 上用 Finder，或在 Windows 上用 Apple Devices app（或 iTunes），把檔案拖進 Everdisk 資料夾。
