ברגע שתקישו על **Start** במסך ה[שיתוף](/docs/guide/everdisk/everdisk-guide-sharing), מכשירים אחרים יכולים להתחבר לקבצים שלכם בארבע דרכים שונות. בחרו את השיטה שמתאימה למכשיר שאתם רוצים להשתמש בו. בכל מקרה, ה**כתובת** המדויקת שאתם צריכים מוצגת בקטע **How to Connect** של מסך השיתוף.

> שני המכשירים חייבים להיות על **אותה רשת Wi-Fi** - או, במקרה של Mac, מחוברים ב**כבל USB** (ראו את הקטע האחרון).

## צפייה בטלוויזיה (DLNA)

השתמשו בזה כדי להציג תמונות, סרטונים ומוזיקה בטלוויזיה חכמה או בנגן מדיה.

1. ב-**Settings → Sharing → Connections**, ודאו ש-**TV & Media Center** מופעל (הוא מופעל כברירת מחדל).
2. במסך השיתוף, הקישו על **Start**.
3. בטלוויזיה שלכם, פתחו את נגן המדיה המובנה או את אפליקציית שרת המדיה שלה (היא עשויה להיקרא Media Player, SmartShare, AllShare או משהו דומה).
4. המכשיר שלכם מופיע ברשימת שרתי המדיה לפי שמו (למשל "Speedy-Hare"). בחרו בו.
5. עיינו בתמונות, בסרטונים ובמוזיקה המשותפים והתחילו לנגן. תמונות תצוגה מקדימה מופיעות אוטומטית.

הערות:

- אי אפשר להגן על DLNA בסיסמה, כך שהחיבור הזה פתוח לכל מי שנמצא על אותה רשת Wi-Fi כל עוד הוא מופעל.
- אם סרטון לא מתנגן בטלוויזיה ישנה, הורידו את איכות הווידאו ב-**Settings → Sharing → Videos** כדי ש-Everdisk ימיר אותו לפורמט תואם יותר.

## פתיחה בדפדפן אינטרנט (HTTP)

השתמשו בזה כדי למסור קבצים לכל מי שיש לו דפדפן - בלי אפליקציה להתקין.

1. ב-**Settings → Sharing → Connections**, ודאו ש-**Browser** מופעל.
2. הקישו על **Start**.
3. במסך השיתוף, העתיקו את כתובת ה-**Browser** (או הציגו את קוד ה-QR שלה).
4. בטלפון, בטאבלט או במחשב השני, פתחו כל דפדפן אינטרנט (Safari, Chrome, Edge, Firefox) והקלידו את הכתובת.
5. העמוד נפתח עם הקבצים המשותפים שלכם.

בדפדפן הצד השני יכול:

- לעבור בין תצוגת **list** לתצוגת **grid** ולמיין לפי שם, תאריך או גודל.
- לראות **תמונות תצוגה מקדימה** אמיתיות לתמונות, לסרטונים, לקובצי PDF ולעטיפות מוזיקה.
- לפתוח תמונה ל**גלריה** במסך מלא עם החלקה, זום בצביטה ומצגת.
- לנגן מוזיקה ב**נגן** מובנה עם תור, ערבוב וחזרה.
- **להוריד** כל קובץ, או להוריד תיקייה שלמה (או כמה פריטים נבחרים) כ**Archive.zip** יחיד.
- **להעלות** קבצים בחזרה למכשיר שלכם - רק אם הפעלתם את **Files Editing** (ראו [גישה ופרטיות](/docs/guide/everdisk/everdisk-guide-access)).

## שימוש בו ככונן רשת (WebDAV)

השתמשו בזה כדי לגרום למכשיר שלכם להופיע ככונן רגיל ב-Mac, במחשב Windows או במכונת Linux, כדי שתוכלו לגרור קבצים בשני הכיוונים.

**ב-Mac (Finder)**

1. ב-**Settings → Sharing → Connections**, ודאו ש-**Computer** מופעל.
2. הקישו על **Start** ורשמו את כתובת ה-**Computer (WebDAV)**.
3. ב-Finder, בחרו **Go → Connect to Server** (או הקישו **⌘K**).
4. הקלידו את כתובת ה-WebDAV בדיוק כפי שהיא מוצגת ולחצו על **Connect**.
5. הזינו את שם המשתמש והסיסמה אם הגדרתם כאלה, אחרת התחברו כאורח.
6. המכשיר שלכם נפתח כמו כל כונן רשת אחר. גררו קבצים פנימה או החוצה.

**ב-Windows**

1. פתחו את **File Explorer**, לחצו לחיצה ימנית על **This PC** ובחרו **Add a network location** (או מפו כונן רשת).
2. הזינו את כתובת ה-WebDAV המוצגת ב-Everdisk.
3. הזינו את שם המשתמש והסיסמה אם הגדרתם כאלה.

**ב-Linux**

1. פתחו את מנהל הקבצים שלכם ובחרו **Connect to Server** (או השתמשו ב-`davs://` / `dav://`).
2. הזינו את כתובת ה-WebDAV המוצגת ב-Everdisk.

האם החיבור יהיה לקריאה בלבד או דו-כיווני תלוי בהגדרת **Files Editing**. כשהיא מופעלת, אתם יכולים להעתיק קבצים אל המכשיר שלכם ולשנות את שמם או למחוק אותם; כשהיא כבויה, הכונן הוא לקריאה בלבד.

## חיבור אפליקציית קבצים (FTP)

השתמשו בזה עבור אפליקציות מנהל קבצים והעברה שמדברות FTP (למשל FileZilla או Cyberduck במחשב).

1. ב-**Settings → Sharing → Connections**, ודאו ש-**Other Apps & Devices** מופעל.
2. הקישו על **Start** ורשמו את כתובת ה-**FTP**.
3. באפליקציית ה-FTP שלכם, הוסיפו חיבור חדש באמצעות הכתובת הזו.
4. הזינו את שם המשתמש והסיסמה אם הגדרתם כאלה, או השאירו אותם ריקים לגישה אנונימית.

## העברה דרך כבל USB (Mac, ללא צורך ב-Wi-Fi)

השתמשו בזה כשאין Wi-Fi, או כשאתם רוצים את ההעברה המהירה והפרטית ביותר. זה עובד עם **Mac** בלבד.

1. חברו את ה-iPhone או ה-iPad שלכם ל-Mac בעזרת כבל הטעינה הרגיל.
2. אם מתבקשים במכשיר, הקישו על **Trust This Computer**.
3. ב-Everdisk, הקישו על **Start**. מופיעה הודעת **Fast Connection Available** ומסך השיתוף מציג כתובת נוספת עם תווית **Cable Connection** שמסתיימת ב-`.local`.
4. ב-Mac, פתחו את Finder → **Go → Connect to Server** (**⌘K**) והזינו את כתובת ה-`.local` הזו (היא עובדת גם לחיבור Browser וגם לחיבור Computer).
5. המכשיר שלכם נפתח דרך הכבל - מהיר יותר מ-Wi-Fi, והנתונים לעולם לא נוגעים בנתב או באינטרנט.

הערות:

- השתמשו ב**שם ה-`.local`**, לא בכתובת IP (כתובות IP עובדות רק דרך Wi-Fi), ולעולם לא ב-`localhost`.
- נתיב הכבל הוא ל-**Mac בלבד**. מחשבי Windows ומכשירי Android חייבים להשתמש ב-Wi-Fi.
- אתם יכולים גם לגרור קבצים לתיקיית Everdisk באמצעות Finder ב-Mac, או באמצעות אפליקציית Apple Devices (או iTunes) ב-Windows, דרך שיתוף הקבצים הסטנדרטי של iOS.
