แท็บ **Documents** คือตัวจัดการไฟล์ครบครันสำหรับทุกอย่างบนอุปกรณ์ของคุณ เป็นที่ที่ไฟล์ดาวน์โหลดมาอยู่ เป็นที่ที่คุณจัดระเบียบสิ่งที่จะแชร์ และเป็นที่ที่คุณบีบอัดไฟล์ สแกนเอกสาร และเชื่อมต่อโฟลเดอร์จากที่อื่นบนอุปกรณ์ของคุณ

ด้านบนของแท็บ Documents จะมีตัวสลับสามโหมด ได้แก่ **Documents**, **Photos** และ **Music** หน้านี้ครอบคลุมโหมด **Documents** (ไฟล์และโฟลเดอร์ของคุณ) ส่วน Photos และ Music อยู่ในหน้า [รูปภาพ เพลง และวิดีโอ](/docs/guide/everdisk/everdisk-guide-media)

## เรียกดูไฟล์ของคุณ

- สลับระหว่างมุมมอง**แบบรายการ**และ**แบบตาราง** (ไอคอน)
- **เรียงลำดับ**ตามชื่อ วันที่ หรือขนาด
- ทุกไฟล์จะแสดง**ภาพตัวอย่างขนาดย่อ**เท่าที่ทำได้ ทั้งรูปภาพ เฟรมวิดีโอ หน้าแรกของ PDF ปกอัลบั้มเพลง และตัวอย่างข้อความ

โฟลเดอร์ Documents จะถูกแชร์โดยค่าเริ่มต้นเมื่อคุณเปิดการแชร์ ดังนั้นอะไรก็ตามที่คุณเก็บไว้ที่นี่จึงส่งให้อุปกรณ์อื่นได้ง่าย

## การจัดการไฟล์ในชีวิตประจำวัน

เปิดเมนูดำเนินการเพิ่มเติม (•••) ด้านบนของโฟลเดอร์ หรือเมนูข้างไฟล์แต่ละไฟล์ เพื่อจัดการกับไฟล์ของคุณ

- **New Folder** - สร้างโฟลเดอร์เพื่อจัดระเบียบไฟล์ของคุณ
- **Rename** - เปลี่ยนชื่อไฟล์หรือโฟลเดอร์
- **Move** - ย้ายรายการไปยังอีกโฟลเดอร์
- **Copy** - ทำสำเนารายการไปยังอีกโฟลเดอร์
- **Upload** - ส่งรายการไปยังอุปกรณ์ที่คุณเชื่อมต่ออยู่บนแท็บ Devices
- **Open In** - ส่งไฟล์ไปยังแอปอื่นผ่านชีตการแชร์ของระบบ
- **Delete** - ลบรายการ โดยค่าเริ่มต้น รายการที่ลบจะไปอยู่ในถังขยะที่กู้คืนได้ คุณเปิดการลบทันทีได้ในการตั้งค่า (ดู [การเข้าถึงและความเป็นส่วนตัว](/docs/guide/everdisk/everdisk-guide-access))
- **Info** - เปิดหน้าข้อมูลไฟล์ (ดูด้านล่าง)

## บีบอัดและแตกไฟล์ (archive และ unarchive)

Everdisk มีการบีบอัดไฟล์ในตัว ไม่ต้องใช้แอปเพิ่ม

- **สร้างไฟล์ zip:** เลือกหนึ่งรายการหรือหลายรายการ แล้วเลือก **Archive** รายการเดียวจะถูกบีบอัดเดี่ยว ๆ ส่วนหลายรายการจะถูกรวมเป็น **Archive.zip** ไฟล์เดียว
- **แตกไฟล์:** แตะที่ไฟล์ **.zip** หรือ **.rar** แล้ว Everdisk จะแตกไฟล์ออกมาไว้ในโฟลเดอร์ปัจจุบัน

การบีบอัดและการแตกไฟล์จะแสดงแถบความคืบหน้าที่คุณยกเลิกได้ เมื่อโฟลเดอร์หรือไฟล์บีบอัดใหม่พร้อมแล้ว Everdisk จะเลื่อนไปยังไฟล์นั้นและไฮไลต์ให้เห็นสั้น ๆ

## เชื่อมต่อโฟลเดอร์ภายนอก

คุณทำงานกับโฟลเดอร์ที่อยู่ที่อื่นบนอุปกรณ์ของคุณได้ ไม่ใช่แค่โฟลเดอร์ Documents ของแอปเท่านั้น

1. ในโฟลเดอร์ Documents เปิดเมนู ••• แล้วเลือก **Connect Folder**
2. เลือกโฟลเดอร์ที่ใดก็ได้บนอุปกรณ์ของคุณ
3. โฟลเดอร์นั้นจะปรากฏด้านบนของแท็บ Documents พร้อมป้าย **Connected**

โฟลเดอร์ที่เชื่อมต่อจะอ่านและเขียนได้ และแชร์ผ่านเครือข่ายได้เหมือนโฟลเดอร์อื่น หากต้องการนำออก ให้เปิด **Info** ของโฟลเดอร์นั้นแล้วเลือก **Disconnect** ซึ่งเป็นเพียงการยกเลิกการเชื่อมโยงเท่านั้น ตัวโฟลเดอร์และไฟล์ในนั้นยังคงอยู่บนอุปกรณ์ของคุณ

## สแกนเอกสารเป็น PDF

Everdisk เปลี่ยนเอกสารกระดาษให้เป็นไฟล์ PDF ที่สะอาดตาได้โดยใช้กล้องของคุณ

1. ในแท็บ Documents เปิดเมนู ••• แล้วเลือก **Scan Documents**
2. เล็งกล้องไปที่หน้าเอกสาร Everdisk จะหาขอบให้อัตโนมัติ ปรับหน้าให้ตรง และให้คุณถ่ายหน้าถัดไปได้
3. เมื่อคุณถ่ายเสร็จ ทุกหน้าจะถูกบันทึกรวมกันเป็นไฟล์ **PDF หลายหน้า** ไฟล์เดียวในโฟลเดอร์ปัจจุบัน

การสแกนต้องใช้อุปกรณ์ที่มีกล้องจริง จากนั้นคุณแชร์ PDF ผ่านเครือข่ายได้ หรือส่งไปยังแอปอื่นด้วย **Open In**

## เครื่องมือ PDF

Everdisk มีชุด **PDF Tools** ในตัวสำหรับจัดการไฟล์ PDF เปิดเมนูดำเนินการเพิ่มเติม (•••) ของ PDF ใดก็ได้ หรือหน้า **Info** ของมัน ในแท็บ Documents แล้วแตะ **PDF Tools** หน้าจอจะแสดงภาพตัวอย่างขนาดย่อและจำนวนหน้าของ PDF และจัดกลุ่มเครื่องมือออกเป็นสามส่วน หาก PDF มีการป้องกันด้วยรหัสผ่าน Everdisk จะขอรหัสผ่านก่อน PDF Tools ใช้งานได้ฟรี

**Optimize**

- **Compress** - ทำให้ PDF เล็กลง Everdisk จะแสดงขนาดปัจจุบันและขนาดผลลัพธ์โดยประมาณสำหรับแต่ละตัวเลือก แบบ **Standard** จะยังเลือกข้อความได้และบีบอัดใหม่เฉพาะรูปภาพ ส่วนแบบ **High**, **Medium**, **Small** และ **Smallest** จะเรนเดอร์หน้าใหม่เป็นรูปภาพที่ความละเอียดต่ำลง (เหมาะที่สุดสำหรับงานสแกนและรูปถ่าย แต่จะเลือกข้อความไม่ได้อีกต่อไป)
- **Text Recognition (OCR)** - จดจำข้อความใน PDF เลือก **Searchable PDF** เพื่อเพิ่มชั้นข้อความที่ซ่อนอยู่ ให้ค้นหาเอกสารและเลือกข้อความได้ (หน้าจะดูเหมือนเดิมทุกอย่าง) หรือเลือก **Text File (.txt)** เพื่อบันทึกเฉพาะข้อความที่จดจำได้ไว้ข้าง ๆ PDF
- **Flatten** - ฝังคำอธิบายประกอบและข้อมูลในช่องฟอร์มลงในหน้าเอกสาร เพื่อไม่ให้แก้ไขได้อีก ขั้นตอนนี้ยังทำให้ลายเซ็น ไฮไลต์ และตราประทับเป็นขั้นสุดท้ายด้วย

**Security**

- **Password** - ตั้ง เปลี่ยน หรือลบรหัสผ่านที่ต้องใช้ในการเปิด PDF การลบหรือเปลี่ยนต้องใช้รหัสผ่านปัจจุบัน
- **Permissions** - ตรวจสอบว่า PDF อนุญาตอะไรบ้าง เช่น การคัดลอก การพิมพ์ การแสดงความคิดเห็น และการกรอกฟอร์ม นี่เป็นมุมมองแบบอ่านอย่างเดียว ใช้เครื่องมือ Password เพื่อปกป้องไฟล์

**Metadata**

- **Edit Metadata** - เปลี่ยนหรือล้างชื่อเรื่อง ผู้เขียน หัวเรื่อง ผู้สร้าง ผู้ผลิต และคำสำคัญของ PDF หรือลบข้อมูลเมตาทั้งหมดในครั้งเดียว วันที่สร้างและวันที่แก้ไขจะแสดงไว้เพื่อใช้อ้างอิง

## ทำเครื่องหมายและเซ็นชื่อบน PDF และรูปภาพ

หากต้องการเพิ่มคำอธิบายประกอบลงใน PDF (หรือรูปภาพ) เพียง **แตะที่ไฟล์** ในแท็บ Documents เพื่อเปิดในโปรแกรมดูในตัว แล้วเปิดเครื่องมือ **Markup** คุณ **วาด ไฮไลต์ เพิ่มข้อความและรูปทรง และเพิ่มลายเซ็น** ด้วยนิ้วได้ และการเปลี่ยนแปลงของคุณจะถูกบันทึกกลับลงในไฟล์ หากภายหลังคุณต้องการล็อกเครื่องหมายเหล่านั้นไม่ให้แก้ไขได้ ให้ใช้ **PDF Tools → Flatten** กับไฟล์นั้น

## เลือกหลายรายการพร้อมกัน

เปิด**โหมดเลือก** (Select) เพื่อจัดการหลายรายการพร้อมกัน ช่องทำเครื่องหมายจะปรากฏข้างแต่ละรายการ และแถบด้านล่างจะมี **Move**, **Copy**, **Upload**, **Archive**, **Open In** และ **Delete** สำหรับทุกอย่างที่คุณเลือกไว้ ใช้ **Select All** หรือ **Deselect All** เพื่อทำงานได้เร็วขึ้น

## ข้อมูลไฟล์

หน้า **Info** ของไฟล์ใดก็ได้จะแสดง

- ภาพตัวอย่าง
- **ตำแหน่ง** (เส้นทาง) แบบเต็มบนอุปกรณ์ของคุณ
- ขนาด วันที่สร้างและวันที่แก้ไข และคุณสมบัติสื่อโดยละเอียด
- สำหรับรูปภาพและวิดีโอที่มีข้อมูลตำแหน่ง จะมี**แผนที่พร้อมหมุด**และปุ่ม **Open in Maps**
- ปุ่ม **Share**
