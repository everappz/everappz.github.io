Tab **Dokumen** adalah pengelola file lengkap untuk segala yang ada di perangkat Anda. Di sinilah unduhan tersimpan, tempat Anda menata apa yang dibagikan, dan tempat Anda mengompresi file, memindai dokumen, serta menghubungkan folder dari tempat lain di perangkat Anda.

Di bagian atas tab Dokumen ada pengalih dengan tiga mode - **Dokumen**, **Foto**, dan **Musik**. Halaman ini membahas mode **Dokumen** (file dan folder Anda). Foto dan Musik dibahas di [Foto, Musik & Video](/docs/guide/everdisk/everdisk-guide-media).

## Menelusuri file Anda

- Beralih antara tampilan **daftar** dan **kisi** (ikon).
- **Urutkan** berdasarkan nama, tanggal, atau ukuran.
- Setiap file menampilkan **thumbnail** jika memungkinkan - foto, cuplikan video, halaman pertama PDF, sampul musik, dan pratinjau teks.

Folder Dokumen dibagikan secara default saat Anda mengaktifkan berbagi, jadi apa pun yang Anda simpan di sini mudah diberikan ke perangkat lain.

## Tindakan file sehari-hari

Buka menu tindakan lainnya (•••) di bagian atas folder, atau menu di sebelah satu file, untuk mengelola file Anda:

- **Folder Baru** - buat folder untuk menata file Anda.
- **Ganti Nama** - ubah nama file atau folder.
- **Pindahkan** - pindahkan item ke folder lain.
- **Salin** - gandakan item ke folder lain.
- **Unggah** - kirim item ke perangkat yang terhubung dengan Anda di tab Perangkat.
- **Buka Di** - berikan file ke aplikasi lain melalui lembar berbagi sistem.
- **Hapus** - buang item. Secara default item yang dihapus masuk ke tempat sampah yang bisa dipulihkan; Anda bisa mengaktifkan penghapusan langsung di Pengaturan (lihat [Akses & Privasi](/docs/guide/everdisk/everdisk-guide-access)).
- **Info** - buka layar info file (lihat di bawah).

## Kompresi dan ekstrak (arsip dan ekstrak)

Everdisk sudah dilengkapi fitur pengarsipan bawaan - tidak perlu aplikasi tambahan.

- **Membuat zip:** pilih satu item, atau beberapa item, lalu pilih **Arsipkan**. Satu item dikompresi sendiri; beberapa item digabung menjadi satu **Archive.zip**.
- **Mengekstrak:** ketuk file **.zip** atau **.rar** dan Everdisk mengekstraknya ke folder yang sedang dibuka.

Pengompresan dan pengekstrakan menampilkan bilah progres yang bisa Anda batalkan. Setelah folder atau arsip baru siap, Everdisk menggulir ke sana dan menyorotnya sesaat.

## Menghubungkan folder eksternal

Anda bisa mengelola folder yang berada di tempat lain pada perangkat Anda, tidak hanya folder Dokumen milik aplikasi.

1. Di folder Dokumen, buka menu ••• lalu pilih **Hubungkan Folder**.
2. Pilih folder di mana saja pada perangkat Anda.
3. Folder itu muncul di bagian atas tab Dokumen dengan label **Terhubung**.

Folder yang terhubung bersifat baca-tulis dan bisa dibagikan lewat jaringan seperti folder lainnya. Untuk menghapusnya, buka **Info** folder tersebut lalu pilih **Putuskan** - ini hanya memutuskan tautannya; folder dan file di dalamnya tetap ada di perangkat Anda.

## Memindai dokumen ke PDF

Everdisk bisa mengubah dokumen kertas menjadi PDF yang rapi menggunakan kamera Anda.

1. Di tab Dokumen, buka menu ••• lalu pilih **Pindai Dokumen**.
2. Arahkan kamera ke halaman. Everdisk menemukan tepinya secara otomatis, meluruskan halaman, dan membiarkan Anda mengambil lebih banyak halaman.
3. Setelah selesai, semua halaman disimpan bersama sebagai satu **PDF multi-halaman** di folder yang sedang dibuka.

Pemindaian memerlukan perangkat dengan kamera asli. Anda kemudian bisa membagikan PDF lewat jaringan, atau mengirimnya ke aplikasi lain dengan **Buka Di**.

## Alat PDF

Everdisk menyertakan rangkaian **Alat PDF** bawaan untuk mengelola file PDF. Buka menu tindakan lainnya (•••) pada PDF mana pun - atau layar **Info**-nya - di tab Dokumen lalu ketuk **Alat PDF**. Layar menampilkan thumbnail PDF dan jumlah halamannya, serta mengelompokkan alat ke dalam tiga area. Jika PDF dilindungi kata sandi, Everdisk meminta kata sandinya terlebih dahulu. Alat PDF gratis.

**Optimalkan**

- **Kompres** - perkecil ukuran PDF. Everdisk menampilkan ukuran saat ini dan perkiraan ukuran hasil untuk tiap opsi. **Standar** mempertahankan teks tetap bisa dipilih dan hanya mengompres ulang gambar; **Tinggi**, **Sedang**, **Kecil**, dan **Terkecil** merender ulang halaman menjadi gambar pada resolusi lebih rendah (paling cocok untuk hasil pindaian dan foto, tetapi teks tidak lagi bisa dipilih).
- **Pengenalan Teks (OCR)** - kenali teks di dalam PDF. Pilih **PDF yang Bisa Dicari** untuk menambahkan lapisan teks tersembunyi agar dokumen bisa dicari dan teksnya bisa dipilih (halaman tampak identik), atau **File Teks (.txt)** untuk menyimpan hanya teks yang dikenali di samping PDF.
- **Ratakan** - tanamkan anotasi dan isian kolom formulir ke dalam halaman agar tidak bisa lagi diedit. Ini juga memfinalkan tanda tangan, sorotan, dan stempel.

**Keamanan**

- **Kata Sandi** - atur, ubah, atau hapus kata sandi yang diperlukan untuk membuka PDF. Menghapus atau mengubahnya memerlukan kata sandi saat ini.
- **Izin** - tinjau apa yang diizinkan PDF, seperti menyalin, mencetak, mengomentari, dan mengisi formulir. Ini tampilan hanya-baca; gunakan alat Kata Sandi untuk melindungi file.

**Metadata**

- **Edit Metadata** - ubah atau kosongkan judul, penulis, subjek, pembuat, produsen, dan kata kunci PDF, atau hapus semua metadata sekaligus. Tanggal pembuatan dan modifikasi ditampilkan sebagai acuan.

## Memberi markah dan menandatangani PDF dan foto

Untuk menganotasi PDF (atau foto), cukup **ketuk** di tab Dokumen untuk membukanya di penampil bawaan, lalu buka alat **Markah**. Anda bisa **menggambar, menyorot, menambahkan teks dan bentuk, serta menambahkan tanda tangan** dengan jari, dan perubahan Anda tersimpan kembali ke file. Jika nanti Anda ingin mengunci markah itu agar tidak bisa diedit, jalankan **Alat PDF → Ratakan** pada file tersebut.

## Memilih beberapa item sekaligus

Aktifkan **mode pilihan** (Pilih) untuk mengelola banyak item bersamaan. Kotak centang muncul di sebelah tiap item, dan bilah di bagian bawah menawarkan **Pindahkan**, **Salin**, **Unggah**, **Arsipkan**, **Buka Di**, dan **Hapus** untuk semua yang Anda pilih. Gunakan **Pilih Semua** atau **Batalkan Semua Pilihan** untuk mempercepat prosesnya.

## Info file

Layar **Info** untuk file mana pun menampilkan:

- Sebuah pratinjau.
- **Lokasi** lengkap (jalur) pada perangkat Anda.
- Ukuran, tanggal dibuat dan dimodifikasi, serta atribut media terperinci.
- Untuk foto dan video yang memiliki data lokasi, sebuah **peta dengan pin** dan tombol **Buka di Maps**.
- Sebuah tombol **Bagikan**.
