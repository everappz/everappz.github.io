<div class="hx:mt-6"></div>

Everdisk は iPhone や iPad をワイヤレスドライブに変えて、ファイル・写真・動画・音楽をローカルネットワーク上のあらゆるデバイス (スマート TV、Mac や PC、Web ブラウザ、別のスマホ) と共有します。アカウントもクラウドも不要で、相手側にインストールするものもありません。この FAQ では、よく寄せられる質問にお答えし、実際のシーンでの使い方を紹介します。手順ごとの説明は [Everdisk ユーザーガイド](/docs/guide/everdisk/) をご覧ください。

<div class="hx:w-full">

{{% details title="Everdisk とは何ですか?" closed="true" %}}
Everdisk は iPhone・iPad 向けの **ワイヤレスドライブ** アプリです。お使いのデバイスをハブに変えて、選んだファイル・写真・動画・音楽をローカルネットワーク上のあらゆる機器と共有できます。さらに他のサーバーにも接続できるので、それらのファイルを閲覧・ストリーミングすることもできます。<br><br>

4 つのサーバーを同時に動かします。TV 向けの **DLNA**、Web ブラウザ向けの **HTTP**、Finder/Windows/Linux 向けの **WebDAV**、ファイルアプリ向けの **FTP** です。これにより、どのデバイスも自分に合った方法で接続できます。アカウントもクラウドも不要で、**スタート** をタップするだけで準備完了です。ファイルマネージャー、メディアプレーヤー、フォトギャラリー、書類の PDF へのスキャン、zip 圧縮と解凍も備えています。
{{% /details %}}

{{% details title="Everdisk はどのように動きますか?" closed="true" %}}
**スタート** をタップすると、Everdisk はデバイスをローカルネットワーク上のサーバーに変え、選択したコンテンツを共有します。4 つの接続方法が同時に動くので、さまざまなデバイスがそれぞれ好みの方法で接続できます。<br><br>

- **DLNA** - スマート TV やメディアプレーヤーがデバイスを自動的に見つけ、メディアをサムネイル付きで表示します。<br>
- **HTTP** - Web ブラウザでリンクを開いて、誰でもファイルを閲覧・ダウンロードできます。<br>
- **WebDAV** - Finder、Windows、Linux でデバイスが普通のネットワークドライブとして表示されます。<br>
- **FTP** - ファイルアプリやパワーツールが FTP で接続します。<br><br>

すべてがローカルの Wi-Fi (または Mac への USB ケーブル) 経由で行われ、インターネットには一切送信されません。
{{% /details %}}

{{% details title="アカウントやログイン、インターネットは必要ですか?" closed="true" %}}
いいえ。Everdisk にアカウントもインターネット接続も必要ありません。すべて **ローカルネットワーク** 上、または Mac への **USB ケーブル** で動作します。クラウドにアップロードされるものは何もありません。唯一の任意のログインは、**あなた自身** が自分の共有をパスワード保護するために設定できるものだけです。
{{% /details %}}

{{% details title="共有はどうやって始めますか?" closed="true" %}}
**共有** タブを開き、**共有するもの** をタップしてファイル・写真・音楽を選び、大きな **スタート** ボタンをタップします。すると **接続方法** のセクションに、他のデバイスが接続するための正確なアドレスが表示されます。**停止** をタップすれば、すべてを再びオフラインにできます。
{{% /details %}}

{{% details title="何を共有できますか?" closed="true" %}}
3 種類のコンテンツを、任意の組み合わせで共有できます。<br><br>

- **ファイルとフォルダー** - アプリのドキュメントフォルダー (初期状態で共有) に加え、**フォルダーを追加** や **ファイルを追加** で加えたフォルダーや個々のファイル。<br>
- **写真と動画** - **すべての写真ライブラリへのアクセスを許可** で写真ライブラリをまるごと、または **写真を追加** で選んだ項目だけ。<br>
- **音楽** - **すべての音楽ライブラリへのアクセスを許可** で音楽ライブラリをまるごと、または **曲を追加** で選んだ曲だけ。<br><br>

共有を始めるには、少なくとも 1 つを選択する必要があります。保護された (DRM) 曲やクラウド上のみの曲は共有できません。
{{% /details %}}

{{% details title="パソコンと写真を共有するにはどうしますか?" closed="true" %}}
1. **共有** 画面で **共有するもの → 写真と動画** を開き、**すべての写真ライブラリへのアクセスを許可** をオンにします (または特定の写真を追加します)。<br>
2. **スタート** をタップします。<br>
3. パソコン側で、どの Web ブラウザでも **ブラウザ** アドレスを開いてダウンロードするか、Finder (Mac) や File Explorer (Windows) から **コンピュータ (WebDAV)** アドレスに接続して写真をドラッグします。<br><br>

ヒント: 最速で転送するには、写真の **形式** を **オリジナル** のままにしてください。
{{% /details %}}

{{% details title="動画や写真をテレビで見るにはどうしますか?" closed="true" %}}
1. **設定 → 共有 → 接続** で、**TV とメディアセンター (DLNA)** がオンになっていることを確認します。<br>
2. **スタート** をタップします。<br>
3. テレビ側で、内蔵のメディアプレーヤーやメディアサーバーアプリを開き、メディアサーバー一覧からデバイスを名前で選びます。<br>
4. 閲覧して再生します。プレビューサムネイルは自動的に表示されます。<br><br>

古いテレビで動画が再生できない場合は、**設定 → 共有 → 動画** で画質を下げると、Everdisk がより互換性の高い形式に変換します。
{{% /details %}}

{{% details title="音楽を聴くにはどうしますか?" closed="true" %}}
**共有するもの** で **すべての音楽ライブラリへのアクセスを許可** をオンにし (または曲を追加し)、**スタート** をタップします。すると、別のデバイスの Web ブラウザ (キュー、シャッフル、リピート付きの内蔵プレーヤーがあります)、DLNA テレビ、または Everdisk 内の **ドキュメント → 音楽** モードから音楽を再生できます。音楽は常にオリジナル画質で共有されます。
{{% /details %}}

{{% details title="Everdisk 内で動画を見るにはどうしますか?" closed="true" %}}
動画をタップすると (ドキュメント内、接続したフォルダー、またはデバイスタブのサーバーのいずれでも)、システム内蔵のプレーヤーで **全画面** 再生されます。**AirPlay**、**Picture in Picture**、**再生速度** など標準の操作が使えます。音声はアプリ下部に表示される **ミニプレーヤー** で、キュー、シャッフル、リピート付きで再生されます。
{{% /details %}}

{{% details title="Web ブラウザでファイルを開くにはどうしますか?" closed="true" %}}
1. **設定 → 共有 → 接続** で、**ブラウザ (HTTP)** がオンになっていることを確認します。<br>
2. **スタート** をタップして **ブラウザ** アドレスをコピーします (または QR コードを表示します)。<br>
3. 相手のデバイスで、どの Web ブラウザでもそのアドレスを入力します。<br><br>

相手はグリッドやリストで閲覧し、写真を全画面ギャラリーで見て、音楽を再生し、ファイルをダウンロードできます。フォルダーまるごとを 1 つの **Archive.zip** としてダウンロードすることも可能です。**ファイルの編集** をオンにしていれば、相手からファイルをアップロードして送り返すこともできます。相手側にインストールするものは何もありません。
{{% /details %}}

{{% details title="Finder でデバイスをネットワークドライブとして使うにはどうしますか?" closed="true" %}}
1. **設定 → 共有 → 接続** で **コンピュータ (WebDAV)** がオンになっていることを確認し、**スタート** をタップします。<br>
2. Mac で Finder を開き、**移動 → サーバへ接続** を選びます (または **⌘K** を押します)。<br>
3. Everdisk に表示された **コンピュータ (WebDAV)** アドレスを入力し、**接続** をクリックします。<br>
4. ログインとパスワードを設定している場合はそれを入力します。設定していない場合はゲストとして接続します。<br><br>

デバイスは通常のネットワークドライブと同じようにマウントされます。**ファイルの編集** がオンなら双方向にファイルをドラッグでき、オフならドライブは読み取り専用になります。
{{% /details %}}

{{% details title="Windows や Linux からはどうやって接続しますか?" closed="true" %}}
**コンピュータ (WebDAV)** アドレスを使います。<br><br>

- **Windows:** File Explorer を開いて **PC** を右クリックし、**ネットワークの場所を追加** (またはネットワークドライブの割り当て) を選び、WebDAV アドレスを入力します。<br>
- **Linux:** ファイルマネージャーで **サーバーへ接続** を選び、WebDAV アドレスを入力します (例: `davs://` や `dav://` のプレフィックス付き)。<br><br>

ログインとパスワードを設定している場合はそれを入力します。
{{% /details %}}

{{% details title="Everdisk は Wi-Fi なしでも使えますか?" closed="true" %}}
はい、**Mac** とケーブルがあれば使えます。iPhone や iPad を Mac に接続し、求められたら **信頼** をタップして、**スタート** をタップします。すると **共有** 画面に `.local` で終わる **ケーブル接続** アドレスが表示されます。Finder から (**⌘K**) それに接続してください。これは Wi-Fi がまったくなくても動作し (飛行機の中、ホテル、ロックされたネットワークで便利です)、Wi-Fi より速くプライベートです。
{{% /details %}}

{{% details title="USB ケーブルは Windows PC や Android でも使えますか?" closed="true" %}}
いいえ。ケーブル接続は **Mac** のみで動作します。Windows PC や Android デバイスは **Wi-Fi** で接続します。(Windows では、Apple デバイスアプリや iTunes を使ってケーブル経由で Everdisk のフォルダーにファイルをドラッグすることはできますが、これはライブ共有とは別のものです。)
{{% /details %}}

{{% details title="共有中はなぜアプリを開いたままにする必要があるのですか?" closed="true" %}}
iPhone や iPad がサーバーになりますが、iOS はアプリがバックグラウンドでネットワークサーバーを動かし続けることを許可していません。そのため、共有は Everdisk が **画面に表示されている間** だけ機能します。長時間の転送では、アプリを前面に保ち、電源につなぎ、iOS の設定アプリで **自動ロック** を **なし** に設定してください。**切断前に通知** をオンにすれば、システムが一時停止する前に Everdisk が知らせてくれます。
{{% /details %}}

{{% details title="Wi-Fi とケーブル、どちらが速いですか?" closed="true" %}}
**Mac への USB ケーブル** の方が Wi-Fi より速く、信頼性も高いです。データがケーブルを通って直接届くためです。ルーターやインターネットを一切経由しないので、最もプライベートな方法でもあります。大量の写真や動画の転送に使ってください。
{{% /details %}}

{{% details title="4 つのサーバー (DLNA、HTTP、WebDAV、FTP) の違いは何ですか?" closed="true" %}}
どれも同じコンテンツを共有しますが、適したデバイスが異なります。<br><br>

- **TV とメディアセンター (DLNA)** - スマート TV やメディアプレーヤー向け。<br>
- **ブラウザ (HTTP)** - あらゆる Web ブラウザ向け。インストール不要。<br>
- **コンピュータ (WebDAV)** - Finder/Windows/Linux でデバイスをネットワークドライブにします。<br>
- **その他のアプリとデバイス (FTP)** - ファイルアプリやパワーツール向け。<br><br>

それぞれを **設定 → 共有 → 接続** でオン・オフできます。
{{% /details %}}

{{% details title="ファイルをパスワードで保護するにはどうしますか?" closed="true" %}}
**設定 → 共有 → アクセス** で **ログイン** と **パスワード** を設定します。すると、ブラウザ、コンピュータ、その他のアプリの接続でその情報が求められるようになります。オープンアクセスにする場合は両方を空のままにしてください。<br><br>

注意: **DLNA** (TV) 接続はパスワード保護できないため、オンの間は同じ Wi-Fi 上の誰にでも開かれています。保護された接続だけにしたい場合はオフにしてください。
{{% /details %}}

{{% details title="他の人がファイルを変更できないようにできますか?" closed="true" %}}
はい。**設定 → 共有 → アクセス** の **ファイルの編集** トグルで制御します。**オン** (初期設定) の場合、接続したデバイスはアップロード、名前の変更、削除ができます。**オフ** にすると共有ファイルが **読み取り専用** になり、相手は閲覧とダウンロードはできますが、何も変更できなくなります。
{{% /details %}}

{{% details title="見覚えのないデバイスをブロックするにはどうしますか?" closed="true" %}}
**共有** 画面の **接続中のデバイス** でそのデバイスを見つけ、その他のアクションボタンをタップして **このデバイスをブロック** を選びます。ブロックしたデバイスは **設定 → 共有 → アクセス → ブロックしたデバイス** で管理でき、個別にブロック解除したり **すべてブロック解除** したりできます。
{{% /details %}}

{{% details title="誰かが共有ファイルを削除したら、完全に消えてしまいますか?" closed="true" %}}
初期設定ではそうではありません。削除したファイルは復元可能なゴミ箱に入るので、取り戻せます。復元なしで即座に削除したい場合は、**設定 → ファイルマネージャー → ファイルの削除** で **ファイルを完全に削除** をオンにしてください。
{{% /details %}}

{{% details title="Everdisk はプライベートで安全ですか?" closed="true" %}}
はい。Everdisk は **ローカルネットワーク** 上でのみ共有します。インターネットには何も送信されず、クラウドアカウントもありません。プライバシーを最大限に保つには、信頼できる自宅やプライベートな Wi-Fi で共有し、ログインとパスワードを追加し、公共の Wi-Fi では注意してください。**Mac への USB ケーブル** が最もプライベートな方法です。Everdisk は近くのデバイスが見つけられるよう、iOS の **ローカルネットワーク** の許可が必要です。
{{% /details %}}

{{% details title="Everdisk は NAS や他のサーバーに接続できますか?" closed="true" %}}
はい。**デバイス** タブでネットワーク上の他のサーバー **へ** 接続できます。**新規接続** をタップして **DLNA / UPnP**、**WebDAV**、**FTP**、**SFTP** のいずれかを選び、アドレスと (必要なら) ログインを入力すれば、閲覧・ストリーミング・ダウンロードができます。WebDAV、FTP、SFTP サーバーでは、フォルダーの作成、アップロード、名前の変更、移動、削除もできます。DLNA サーバーは読み取り専用です。
{{% /details %}}

{{% details title="Google Drive や Dropbox のようなクラウドストレージに接続できますか?" closed="true" %}}
Everdisk は iCloud Drive、Google Drive、Dropbox、OneDrive などのクラウドアカウントにはサインインしません。**ローカルネットワークと直接アドレス指定できる** サーバー (DLNA、WebDAV、FTP、SFTP) にのみ接続します。クラウドサービスは、新しい WebDAV 接続に入力できる **WebDAV** アドレスを提供している場合にのみ利用できます。
{{% /details %}}

{{% details title="デバイスタブは何のためのものですか?" closed="true" %}}
Everdisk のクライアント側の機能です。**接続** には保存したサーバーが一覧表示され、**利用可能なデバイス** にはネットワーク上で自動的に見つかったサーバーが表示されます。どれかをタップすればそのファイルを閲覧・ストリーミング・ダウンロードでき、**新規接続** をタップすれば DLNA、WebDAV、FTP、SFTP サーバーを手動で追加できます。
{{% /details %}}

{{% details title="サーバーからデバイスへファイルをダウンロードするにはどうしますか?" closed="true" %}}
**デバイス** タブでサーバーを開き、目的のものまで移動して **ダウンロード** を選びます (複数の項目を選べばまとめてダウンロードできます)。ダウンロードはバックグラウンドで実行され、**ファイル転送** (ドキュメントタブの左上) に表示され、**ドキュメント** フォルダーに保存されます。
{{% /details %}}

{{% details title="Everdisk にはファイルマネージャーがありますか?" closed="true" %}}
はい。**ドキュメント** タブは本格的なファイルマネージャーです。リストやグリッドで閲覧し、フォルダーの作成、名前の変更、移動、コピー、アップロード、削除ができ、どのファイルでも **情報** 画面を開けます。ダウンロードはここに保存され、ドキュメントフォルダーは初期状態で共有されます。
{{% /details %}}

{{% details title="ファイルを zip (アーカイブ) にするにはどうしますか?" closed="true" %}}
**ドキュメント** タブで 1 つ以上の項目を選び、**アーカイブ** を選びます。1 つの項目はそれ単体で zip 化され、複数の項目は 1 つの **Archive.zip** にまとめられます。Web ブラウザでは、フォルダーまるごとや選んだ複数の項目を 1 つの zip としてダウンロードすることもできます。
{{% /details %}}

{{% details title="アーカイブを解凍するにはどうしますか?" closed="true" %}}
**ドキュメント** タブで **.zip** や **.rar** ファイルをタップすると、Everdisk が現在のフォルダーに展開します。キャンセルできるプログレスバーも表示されます。
{{% /details %}}

{{% details title="書類を PDF にスキャンするにはどうしますか?" closed="true" %}}
**ドキュメント** タブでその他のアクション (•••) メニューを開き、**書類をスキャン** を選びます。各ページにカメラを向けると (Everdisk が自動的に端を検出してページをまっすぐに補正します)、すべてのページがまとめて 1 つの **複数ページ PDF** として現在のフォルダーに保存されます。カメラのあるデバイスが必要です。
{{% /details %}}

{{% details title="Everdisk にはどんな PDF ツールがありますか?" closed="true" %}}
Everdisk には内蔵の **PDF ツール** スイートがあります。**ドキュメント** タブで PDF の **•••** メニュー (または情報画面) を開き、**PDF ツール** をタップします。3 つの分野に分かれています。<br><br>

**最適化**<br>
- **圧縮** - PDF を小さくします。保存前に、各オプションの現在のサイズと推定結果サイズが表示されます。<br>
- **テキスト認識 (OCR)** - スキャンした PDF を **検索可能な PDF** に変換したり、テキストだけを **.txt** ファイルに書き出したりします。<br>
- **フラット化** - 注釈やフォーム入力をページに焼き込んで編集できないようにします。<br><br>

**セキュリティ**<br>
- **パスワード** - PDF を開くのに必要なパスワードを設定・変更・削除します。<br>
- **権限** - PDF が何を許可しているか (コピー、印刷、コメントなど) を確認します。<br><br>

**メタデータ**<br>
- **メタデータの編集** - タイトル、作成者、件名、キーワードなどの書類情報を変更・消去します。<br><br>

PDF ツールは無料で使えます。PDF がパスワード保護されている場合、Everdisk はツールを使う前にそのパスワードを尋ねます。
{{% /details %}}

{{% details title="PDF を圧縮するにはどうしますか?" closed="true" %}}
PDF の **•••** メニュー → **PDF ツール** → **圧縮** を開きます。Everdisk が現在のファイルサイズと各オプションの推定サイズを表示します。<br><br>

- **標準** はテキストを選択可能なまま保ち、画像だけを再圧縮します。<br>
- **高**、**中**、**小**、**最小** はページをより低い解像度の画像として再レンダリングします。スキャンや写真に最適ですが、テキストは選択できなくなります。<br><br>

希望のオプションをタップすると、Everdisk が小さくした PDF を保存します。
{{% /details %}}

{{% details title="スキャンした PDF を検索可能 (OCR) にするにはどうしますか?" closed="true" %}}
PDF の **•••** メニュー → **PDF ツール** → **テキスト認識** を開きます。**検索可能な PDF** を選ぶと隠しテキストレイヤーが追加され、テキストを検索・選択できるようになります (ページの見た目はまったく同じです)。**テキストファイル (.txt)** を選ぶと、認識したテキストだけを PDF の隣に保存します。大きなファイルやスキャンしたファイルは少し時間がかかることがあります。
{{% /details %}}

{{% details title="PDF ファイルをパスワードで保護するにはどうしますか?" closed="true" %}}
PDF の **•••** メニュー → **PDF ツール** → **パスワード** を開きます。PDF がまだ保護されていない場合は、新しいパスワードを入力して確認すると設定できます。すでに保護されている場合は、現在のパスワードを入力して **削除** または **変更** します。パスワードは安全な場所に保管してください。保護された PDF はパスワードがないと開けません。<br><br>

これは PDF **ファイル** そのものを保護するもので、共有セッション全体を保護する **ログインとパスワード** (上のセキュリティの質問を参照) とは別のものです。
{{% /details %}}

{{% details title="Everdisk で PDF に書き込みや署名ができますか?" closed="true" %}}
はい。**ドキュメント** タブで PDF (または写真) をタップすると内蔵ビューアで開き、**マークアップ** ツールで指を使って **描画、ハイライト、テキストや図形の追加、署名** ができます。変更はファイルに直接保存されます。<br><br>

その書き込みを後から編集できないよう永続化したい場合は、PDF の **••• → PDF ツール → フラット化** を開きます。パスワードの追加、OCR の実行、圧縮、書類情報の編集には、他の **PDF ツール** を使ってください (上の質問を参照)。
{{% /details %}}

{{% details title="デバイス上の別の場所にあるフォルダーを接続できますか?" closed="true" %}}
はい。**ドキュメント** タブで ••• メニューを開いて **フォルダーを接続** を選び、デバイス上の任意のフォルダーを選びます。すると **接続済み** ラベル付きで上部に表示され、他のフォルダーと同じようにネットワークで共有できます。リンクを解除するには、その情報から **切断** を使ってください。フォルダーとファイルはデバイス上に残ります。
{{% /details %}}

{{% details title="他の人が私のデバイスにファイルをアップロードして送り返せますか?" closed="true" %}}
はい、**ファイルの編集** がオンのときにできます。Web ブラウザでは相手に **アップロード** パネルが表示され、WebDAV や FTP 接続ではあなたのデバイスにファイルをコピーできます。共有を読み取り専用にするには、**ファイルの編集** をオフにしてください (設定 → 共有 → アクセス)。
{{% /details %}}

{{% details title="写真や動画の転送が遅いのはなぜですか?" closed="true" %}}
写真や動画の **形式** が **最も互換性が高い** に設定されていたり、**画質** が **オリジナル** より下だったりすると、Everdisk は共有時に各ファイルを変換します。これは時間がかかり、バッテリーの消費も増えます。最速で転送するには、**設定 → 共有** で **形式** と **画質** を **オリジナル** に設定し、特定のテレビやブラウザでファイルが開けない場合にだけ最も互換性が高い設定に切り替えてください。
{{% /details %}}

{{% details title="デバイスが表示されない、または接続できません。何を確認できますか?" closed="true" %}}
- 両方のデバイスが **同じ Wi-Fi ネットワーク** 上にあることを確認します (または Mac のケーブルを使います)。<br>
- 共有が **開始** されていて、正しいサーバーが 設定 → 共有 → 接続 で **オン** になっていることを確認します。<br>
- アドレスは共有画面に表示されたとおりに正確に入力します。Wi-Fi では表示された IP を、ケーブルでは **`.local`** 名を使います (`localhost` は使いません)。<br>
- ログインとパスワードを設定している場合は、相手のデバイスで入力します。<br>
- iOS の設定アプリで Everdisk の **ローカルネットワーク** の許可が有効になっているか確認します。<br>
- 相手のデバイスが **ブロックしたデバイス** に入っていないか確認します。
{{% /details %}}

{{% details title="ネットワーク上に表示されるデバイス名を変更できますか?" closed="true" %}}
Everdisk はデバイスに親しみやすい名前とアバターを自動的に付けます。これらは無料で **再生成** できます。**カスタム** の名前、アイコン、グラデーション、写真アバターの設定は Premium の **デバイスのカスタマイズ** 機能の一部です。
{{% /details %}}

{{% details title="接続ポートを変更できますか?" closed="true" %}}
初期設定は **HTTP 80**、**WebDAV 8080**、**FTP 2121** です (DLNA はポートを自動的に選びます)。これらは無料で確認でき、**カスタムポート** の設定は Premium 機能です (設定 → 共有 の **詳細設定**)。
{{% /details %}}

{{% details title="Everdisk は無料ですか? Premium で何が追加されますか?" closed="true" %}}
Everdisk は **無料** でダウンロードできます。4 つのサーバーをすべて動かし、パスワードでアクセスを保護し、写真と音楽のライブラリをまるごと共有し、ファイルマネージャーを使い、PDF にスキャンし、他のサーバーに接続できます。無料版では最大 **5 つのフォルダー** を共有し、最大 **10 件のサーバー接続** を保存できます。<br><br>

買い切りの **Premium Lifetime** (サブスクリプションではありません) を購入すると、次の機能が追加されます。**フォルダー無制限**、**接続無制限**、**写真・動画の変換** (オリジナル以外の画質)、**カスタムポート**、**自動共有開始**、**デバイスのカスタマイズ** です。
{{% /details %}}

{{% details title="Premium はサブスクリプションですか? 他のデバイスでも使えますか?" closed="true" %}}
Premium はサブスクリプションではなく **買い切り** です。一度支払えば、更新されることはありません。Apple ID に紐づくため、同じ Apple ID でサインインしている他のデバイスで **購入の復元** を使って解除できます。
{{% /details %}}
