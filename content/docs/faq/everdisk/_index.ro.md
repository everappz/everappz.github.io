<div class="hx:mt-6"></div>

Everdisk îți transformă iPhone-ul sau iPad-ul într-un disc wireless care partajează fișiere, fotografii, videoclipuri și muzică cu orice dispozitiv din rețeaua ta locală - un televizor smart, un Mac sau PC, un browser web sau alt telefon - fără conturi, fără cloud și fără nimic de instalat pe cealaltă parte. Aceste întrebări frecvente răspund la cele mai des întâlnite întrebări și parcurg scenarii obișnuite din lumea reală. Pentru instrucțiuni pas cu pas, vezi [Ghidul de utilizare Everdisk](/docs/guide/everdisk/).

<div class="hx:w-full">

{{% details title="Ce este Everdisk?" closed="true" %}}
Everdisk este o aplicație de **disc wireless** pentru iPhone și iPad. Îți transformă dispozitivul într-un centru care partajează fișierele, fotografiile, videoclipurile și muzica pe care le alegi cu orice se află în rețeaua ta locală și se conectează totodată la alte servere, ca să le poți răsfoi și transmite fișierele.<br><br>

Rulează patru servere deodată - **DLNA** pentru televizoare, **HTTP** pentru browsere web, **WebDAV** pentru Finder/Windows/Linux și **FTP** pentru aplicații de fișiere - astfel încât fiecare dispozitiv se conectează cum îi place. Nu există conturi și nici cloud: apeși **Start** și ești gata. Include și un manager de fișiere, un player media, o galerie foto, scanarea documentelor în PDF și arhivare/dezarhivare.
{{% /details %}}

{{% details title="Cum funcționează Everdisk?" closed="true" %}}
Când apeși **Start**, Everdisk îți transformă dispozitivul într-un server din rețeaua ta locală și partajează conținutul selectat. Patru metode diferite de conectare rulează în același timp, ca diferite dispozitive să se poată conecta așa cum preferă:<br><br>

- **DLNA** - televizoarele smart și playerele media îți găsesc automat dispozitivul și îți afișează media cu miniaturi.<br>
- **HTTP** - oricine deschide un link într-un browser web pentru a-ți răsfoi și descărca fișierele.<br>
- **WebDAV** - dispozitivul tău apare ca un disc de rețea obișnuit în Finder, Windows sau Linux.<br>
- **FTP** - aplicațiile de fișiere și instrumentele avansate se conectează prin FTP.<br><br>

Totul se petrece prin rețeaua ta Wi-Fi locală (sau printr-un cablu USB către un Mac) și nu atinge niciodată internetul.
{{% /details %}}

{{% details title="Am nevoie de un cont, de autentificare sau de internet?" closed="true" %}}
Nu. Everdisk nu are nevoie de niciun cont și de nicio conexiune la internet. Funcționează în întregime în **rețeaua ta locală** sau printr-un **cablu USB** către un Mac. Nu se încarcă nimic în vreun cloud. Singura autentificare opțională este cea pe care o poți seta **tu** pentru a-ți proteja cu parolă propria partajare.
{{% /details %}}

{{% details title="Cum încep să partajez?" closed="true" %}}
Deschide fila **Partajare**, apasă **Ce partajez** și alege-ți fișierele, fotografiile și/sau muzica, apoi apasă butonul mare **Start**. Secțiunea **Cum te conectezi** îți arată apoi adresele exacte pe care le folosesc alte dispozitive pentru a se conecta. Apasă **Stop** pentru a scoate totul din nou offline.
{{% /details %}}

{{% details title="Ce pot partaja?" closed="true" %}}
Trei tipuri de conținut, în orice combinație:<br><br>

- **Fișiere și foldere** - folderul Documente al aplicației (partajat implicit), plus orice foldere sau fișiere individuale pe care le adaugi cu **Adaugă folder** și **Adaugă fișier**.<br>
- **Fotografii și videoclipuri** - întreaga ta bibliotecă Fotografii cu **Permite accesul la toată biblioteca Fotografii** sau doar elementele selectate cu **Adaugă fotografii**.<br>
- **Muzică** - întreaga ta bibliotecă Muzică cu **Permite accesul la toată biblioteca Muzică** sau doar melodiile selectate cu **Adaugă piese**.<br><br>

Trebuie să selectezi cel puțin un lucru înainte ca partajarea să poată începe. Piesele protejate (DRM) și cele disponibile doar în cloud nu pot fi partajate.
{{% /details %}}

{{% details title="Cum partajez fotografii cu computerul meu?" closed="true" %}}
1. Pe ecranul **Partajare**, deschide **Ce partajez → Fotografii și videoclipuri** și activează **Permite accesul la toată biblioteca Fotografii** (sau adaugă fotografii anume).<br>
2. Apasă **Start**.<br>
3. Pe computer, fie deschide adresa **Browser** în orice browser web și descarcă, fie conectează-te la adresa **Computer (WebDAV)** din Finder (Mac) sau File Explorer (Windows) și trage fotografiile.<br><br>

Sfat: păstrează **Formatul** fotografiilor pe **Original** pentru cel mai rapid transfer.
{{% /details %}}

{{% details title="Cum îmi vizionez videoclipurile sau fotografiile pe un televizor?" closed="true" %}}
1. În **Setări → Partajare → Conexiuni**, asigură-te că **TV și centru media (DLNA)** este activat.<br>
2. Apasă **Start**.<br>
3. Pe televizor, deschide playerul media integrat sau aplicația de server media și alege dispozitivul tău după nume din lista de servere media.<br>
4. Răsfoiește și redă. Miniaturile de previzualizare apar automat.<br><br>

Dacă un televizor mai vechi nu redă un videoclip, scade calitatea în **Setări → Partajare → Videoclipuri**, ca Everdisk să îl convertească într-un format mai compatibil.
{{% /details %}}

{{% details title="Cum îmi ascult muzica?" closed="true" %}}
Activează **Permite accesul la toată biblioteca Muzică** (sau adaugă piese) în **Ce partajez**, apoi apasă **Start**. Apoi îți poți reda muzica din browserul web al altui dispozitiv (există un player integrat cu coadă, redare aleatorie și repetare), de pe un televizor DLNA sau chiar în Everdisk, folosind modul **Documente → Muzică**. Muzica este mereu partajată în calitatea ei originală.
{{% /details %}}

{{% details title="Cum urmăresc filme în Everdisk?" closed="true" %}}
Apasă orice videoclip - din Documentele tale, dintr-un folder conectat sau de pe un server din fila Dispozitive - și se redă **pe tot ecranul** cu playerul integrat al sistemului, cu comenzi standard, inclusiv **AirPlay**, **Picture in Picture** și **viteza de redare**. Audio se redă într-un **mini player** care rămâne în partea de jos a aplicației, cu coadă, redare aleatorie și repetare.
{{% /details %}}

{{% details title="Cum îmi deschid fișierele într-un browser web?" closed="true" %}}
1. În **Setări → Partajare → Conexiuni**, asigură-te că **Browser (HTTP)** este activat.<br>
2. Apasă **Start** și copiază adresa **Browser** (sau afișează codul ei QR).<br>
3. Pe celălalt dispozitiv, deschide orice browser web și tastează acea adresă.<br><br>

Cealaltă persoană poate răsfoi într-o grilă sau listă, vedea fotografii într-o galerie pe tot ecranul, reda muzică și descărca fișiere - inclusiv descărcarea unui folder întreg ca un singur **Archive.zip**. Dacă ai activat **Editarea fișierelor**, poate și să îți încarce fișiere înapoi. Nu are nimic de instalat de partea ei.
{{% /details %}}

{{% details title="Cum îmi folosesc dispozitivul ca disc de rețea în Finder?" closed="true" %}}
1. În **Setări → Partajare → Conexiuni**, asigură-te că **Computer (WebDAV)** este activat, apoi apasă **Start**.<br>
2. Pe Mac, deschide Finder și alege **Go → Connect to Server** (sau apasă **⌘K**).<br>
3. Introdu adresa **Computer (WebDAV)** afișată în Everdisk și dă clic pe **Connect**.<br>
4. Introdu utilizatorul și parola, dacă ai setat una; altfel conectează-te ca invitat.<br><br>

Dispozitivul tău se montează ca orice disc de rețea. Cu **Editarea fișierelor** activată poți trage fișiere în ambele sensuri; cu ea dezactivată, discul este doar pentru citire.
{{% /details %}}

{{% details title="Cum mă conectez din Windows sau Linux?" closed="true" %}}
Folosește adresa **Computer (WebDAV)**.<br><br>

- **Windows:** deschide File Explorer → clic dreapta pe **This PC** → **Add a network location** (sau mapează un disc de rețea) și introdu adresa WebDAV.<br>
- **Linux:** în managerul tău de fișiere alege **Connect to Server** și introdu adresa WebDAV (de exemplu cu un prefix `davs://` sau `dav://`).<br><br>

Introdu utilizatorul și parola, dacă ai setat una.
{{% /details %}}

{{% details title="Everdisk funcționează fără Wi-Fi?" closed="true" %}}
Da, cu un **Mac** și un cablu. Conectează-ți iPhone-ul sau iPad-ul la Mac, apasă **Trust** dacă ți se cere și apasă **Start**. O adresă **Conexiune prin cablu** care se termină în `.local` apare pe ecranul Partajare; conectează-te la ea din Finder (**⌘K**). Aceasta funcționează complet fără Wi-Fi - excelent într-un avion, la hotel sau într-o rețea blocată - și este mai rapidă și mai privată decât Wi-Fi-ul.
{{% /details %}}

{{% details title="Pot folosi cablul USB cu un PC Windows sau cu Android?" closed="true" %}}
Nu. Conexiunea prin cablu funcționează doar cu un **Mac**. PC-urile Windows și dispozitivele Android se conectează prin **Wi-Fi**. (Pe Windows poți totuși trage fișiere în folderul Everdisk folosind aplicația Apple Devices sau iTunes prin cablu, ceea ce este separat de partajarea live.)
{{% /details %}}

{{% details title="De ce trebuie să țin aplicația deschisă în timp ce partajez?" closed="true" %}}
iPhone-ul sau iPad-ul tău este serverul, iar iOS nu permite aplicațiilor să țină un server de rețea rulând în fundal. Așadar, partajarea funcționează doar cât timp Everdisk este **deschis pe ecran**. Pentru transferuri lungi, ține aplicația în prim-plan, conectează la alimentare și setează **Blocare automată** pe **Niciodată** în aplicația Setări iOS. Poți activa și **Anunță înainte de deconectare**, ca Everdisk să te avertizeze înainte ca sistemul să o pună pe pauză.
{{% /details %}}

{{% details title="Care este mai rapid - Wi-Fi sau cablul?" closed="true" %}}
**Cablul USB către un Mac** este mai rapid și mai fiabil decât Wi-Fi-ul, pentru că datele trec direct prin cablu. Este totodată cea mai privată opțiune, fiindcă nimic nu trece prin routerul tău sau prin internet. Folosește-l pentru transferuri mari de fotografii și videoclipuri.
{{% /details %}}

{{% details title="Care este diferența dintre cele patru servere (DLNA, HTTP, WebDAV, FTP)?" closed="true" %}}
Toate partajează același conținut, dar se potrivesc unor dispozitive diferite:<br><br>

- **TV și centru media (DLNA)** - pentru televizoare smart și playere media.<br>
- **Browser (HTTP)** - pentru orice browser web, fără instalare.<br>
- **Computer (WebDAV)** - face din dispozitivul tău un disc de rețea în Finder/Windows/Linux.<br>
- **Alte aplicații și dispozitive (FTP)** - pentru aplicații de fișiere și instrumente avansate.<br><br>

Poți activa sau dezactiva oricare dintre ele în **Setări → Partajare → Conexiuni**.
{{% /details %}}

{{% details title="Cum îmi protejez fișierele cu parolă?" closed="true" %}}
Mergi la **Setări → Partajare → Acces** și setează un **Utilizator** și o **Parolă**. Conexiunile Browser, Computer și Alte aplicații vor cere apoi aceste date. Lasă ambele goale pentru acces liber.<br><br>

Notă: conexiunea **DLNA** (TV) nu poate fi protejată cu parolă, așa că este deschisă oricui se află pe aceeași rețea Wi-Fi cât timp este activă. Dezactiveaz-o dacă vrei doar conexiuni protejate.
{{% /details %}}

{{% details title="Pot împiedica oamenii să-mi modifice fișierele?" closed="true" %}}
Da. Comutatorul **Editarea fișierelor** din **Setări → Partajare → Acces** controlează acest lucru. Cu el **activat** (implicit), dispozitivele conectate pot încărca, redenumi și șterge. Dezactiveaz-l pentru a-ți face fișierele partajate **doar pentru citire** - ceilalți pot vedea și descărca, dar nu pot modifica nimic.
{{% /details %}}

{{% details title="Cum blochez un dispozitiv pe care nu îl recunosc?" closed="true" %}}
Pe ecranul **Partajare**, găsește dispozitivul la **Cine este conectat**, apasă butonul de mai multe acțiuni și alege **Blochează acest dispozitiv**. Gestionează dispozitivele blocate în **Setări → Partajare → Acces → Dispozitive blocate**, unde poți debloca unul sau apăsa **Deblochează tot**.
{{% /details %}}

{{% details title="Dacă cineva șterge un fișier partajat, este pierdut pentru totdeauna?" closed="true" %}}
Nu implicit. Fișierele șterse ajung într-un coș de gunoi recuperabil, ca să le poți aduce înapoi. Dacă preferi ștergerea imediată, fără recuperare, activează **Șterge definitiv fișierele** în **Setări → Manager de fișiere → Ștergerea fișierelor**.
{{% /details %}}

{{% details title="Everdisk este privat și sigur?" closed="true" %}}
Da. Everdisk partajează doar prin **rețeaua ta locală** - nimic nu ajunge pe internet și nu există niciun cont în cloud. Pentru cea mai bună confidențialitate, partajează pe o rețea Wi-Fi de acasă sau privată în care ai încredere, adaugă un utilizator și o parolă și fii atent pe Wi-Fi public. **Cablul USB către un Mac** este cea mai privată opțiune dintre toate. Everdisk are nevoie de permisiunea iOS **Rețea locală**, ca dispozitivele din apropiere să îl poată găsi.
{{% /details %}}

{{% details title="Poate Everdisk să se conecteze la NAS-ul meu sau la alte servere?" closed="true" %}}
Da. Fila **Dispozitive** se conectează **la** alte servere din rețeaua ta. Apasă **Conexiune nouă** și alege **DLNA / UPnP**, **WebDAV**, **FTP** sau **SFTP**, introdu adresa și eventualul utilizator și poți răsfoi, transmite și descărca. Pe serverele WebDAV, FTP și SFTP poți totodată crea foldere, încărca, redenumi, muta și șterge. Serverele DLNA sunt doar pentru citire.
{{% /details %}}

{{% details title="Mă pot conecta la stocare în cloud precum Google Drive sau Dropbox?" closed="true" %}}
Everdisk nu se autentifică în conturi cloud precum iCloud Drive, Google Drive, Dropbox sau OneDrive. Se conectează doar la servere **din rețeaua locală și adresate direct** (DLNA, WebDAV, FTP, SFTP). Un serviciu cloud este accesibil doar dacă oferă o adresă **WebDAV** pe care o poți tasta într-o conexiune WebDAV nouă.
{{% /details %}}

{{% details title="La ce folosește fila Dispozitive?" closed="true" %}}
Este partea de client a Everdisk: **Conexiuni** listează serverele pe care le-ai salvat, iar **Dispozitive disponibile** listează serverele găsite automat în rețeaua ta. Apasă pe unul pentru a-i răsfoi, transmite sau descărca fișierele sau apasă **Conexiune nouă** pentru a adăuga manual un server DLNA, WebDAV, FTP sau SFTP.
{{% /details %}}

{{% details title="Cum descarc fișiere de pe un server pe dispozitivul meu?" closed="true" %}}
Deschide serverul din fila **Dispozitive**, răsfoiește până la ce vrei și alege **Descărcați** (selectează mai multe elemente pentru un lot). Descărcările rulează în fundal, apar în **Transferuri de fișiere** (stânga-sus a filei Documente) și ajung în folderul tău **Documente**.
{{% /details %}}

{{% details title="Are Everdisk un manager de fișiere?" closed="true" %}}
Da. Fila **Documente** este un manager de fișiere complet. Poți răsfoi în listă sau grilă, crea foldere, redenumi, muta, copia, încărca și șterge și deschide ecranul **Informații** pentru orice fișier. Descărcările ajung aici, iar folderul Documente este partajat implicit.
{{% /details %}}

{{% details title="Cum arhivez (comprim) fișiere?" closed="true" %}}
În fila **Documente**, selectează unul sau mai multe elemente și alege **Arhivează**. Un singur element este arhivat de unul singur; mai multe elemente sunt grupate într-un singur **Archive.zip**. Într-un browser web poți totodată descărca un folder întreg sau mai multe elemente selectate ca o singură arhivă zip.
{{% /details %}}

{{% details title="Cum dezarhivez o arhivă?" closed="true" %}}
Apasă un fișier **.zip** sau **.rar** în fila **Documente**, iar Everdisk îl extrage în folderul curent, cu o bară de progres pe care o poți anula.
{{% /details %}}

{{% details title="Cum scanez un document în PDF?" closed="true" %}}
În fila **Documente**, deschide meniul de mai multe acțiuni (•••) și alege **Scanează documente**. Îndreaptă camera spre fiecare pagină - Everdisk găsește marginile și îndreaptă automat pagina - iar toate paginile sunt salvate împreună ca un singur **PDF cu mai multe pagini** în folderul curent. Ai nevoie de un dispozitiv cu cameră.
{{% /details %}}

{{% details title="Ce instrumente PDF include Everdisk?" closed="true" %}}
Everdisk are o suită integrată de **Instrumente PDF**. Deschide meniul **•••** al oricărui PDF (sau ecranul lui Informații) în fila **Documente** și apasă **Instrumente PDF**. Este grupată în trei zone:<br><br>

**Optimizare**<br>
- **Comprimare** - fă un PDF mai mic. Vezi dimensiunea actuală și o dimensiune estimată pentru fiecare opțiune înainte de a salva.<br>
- **Recunoaștere text (OCR)** - transformă un PDF scanat într-un **PDF care poate fi căutat** sau exportă doar textul într-un fișier **.txt**.<br>
- **Aplatizare** - fixează adnotările și completările din formular în pagină, ca să nu mai poată fi editate.<br><br>

**Securitate**<br>
- **Parolă** - setează, schimbă sau elimină parola necesară pentru deschiderea PDF-ului.<br>
- **Permisiuni** - verifică ce permite PDF-ul (copiere, imprimare, comentarii și altele).<br><br>

**Metadate**<br>
- **Editare metadate** - schimbă sau golește titlul, autorul, subiectul, cuvintele cheie și alte informații ale documentului.<br><br>

Instrumentele PDF sunt incluse gratuit. Dacă un PDF este protejat cu parolă, Everdisk cere parola lui înainte să poți folosi instrumentele.
{{% /details %}}

{{% details title="Cum comprim un PDF?" closed="true" %}}
Deschide meniul **•••** al PDF-ului → **Instrumente PDF** → **Comprimare**. Everdisk afișează dimensiunea actuală a fișierului și o dimensiune estimată pentru fiecare opțiune:<br><br>

- **Standard** păstrează textul selectabil și recomprimă doar imaginile.<br>
- **Mare**, **Medie**, **Mică** și **Cea mai mică** redau paginile din nou ca imagini la o rezoluție mai joasă - cel mai bine pentru scanuri și fotografii, dar textul nu mai este selectabil.<br><br>

Apasă opțiunea dorită și Everdisk salvează PDF-ul mai mic.
{{% /details %}}

{{% details title="Cum fac un PDF scanat să poată fi căutat (OCR)?" closed="true" %}}
Deschide meniul **•••** al PDF-ului → **Instrumente PDF** → **Recunoaștere text**. Alege **PDF care poate fi căutat** pentru a adăuga un strat de text ascuns, ca să poți căuta și selecta textul (paginile arată exact la fel), sau **Fișier text (.txt)** pentru a salva doar textul recunoscut lângă PDF. Fișierele mari sau scanate pot dura un pic.
{{% /details %}}

{{% details title="Cum protejez cu parolă un fișier PDF?" closed="true" %}}
Deschide meniul **•••** al PDF-ului → **Instrumente PDF** → **Parolă**. Dacă PDF-ul nu este încă protejat, introdu o parolă nouă și confirm-o pentru a o seta. Dacă este deja protejat, introdu parola curentă pentru a o **elimina** sau a o **schimba**. Păstrează parola la loc sigur - un PDF protejat nu poate fi deschis fără ea.<br><br>

Aceasta protejează **fișierul** PDF în sine, ceea ce este diferit de **utilizatorul și parola** care îți protejează întreaga sesiune de partajare (vezi întrebările despre securitate de mai sus).
{{% /details %}}

{{% details title="Pot să desenez pe un PDF sau să îl semnez în Everdisk?" closed="true" %}}
Da. Apasă un PDF (sau o fotografie) în fila **Documente** pentru a-l deschide în vizualizatorul integrat, apoi folosește instrumentele **Adnotare** pentru a **desena, evidenția, adăuga text și forme și semna** cu degetul. Modificările se salvează direct înapoi în fișier.<br><br>

Dacă vrei să faci acele marcaje permanente, ca să nu mai poată fi editate ulterior, deschide **••• → Instrumente PDF → Aplatizare** al PDF-ului. Pentru a adăuga o parolă, a rula OCR, a comprima sau a edita informațiile documentului, folosește celelalte **Instrumente PDF** (vezi întrebarea de mai sus).
{{% /details %}}

{{% details title="Pot conecta un folder aflat în altă parte pe dispozitivul meu?" closed="true" %}}
Da. În fila **Documente**, deschide meniul ••• și alege **Conectează folder**, apoi alege orice folder de pe dispozitivul tău. Apare în partea de sus cu eticheta **Conectat** și poate fi partajat în rețea ca orice alt folder. Folosește **Deconectează** din Informațiile lui pentru a-l scoate din legătură - folderul și fișierele rămân pe dispozitivul tău.
{{% /details %}}

{{% details title="Pot oamenii să încarce fișiere înapoi pe dispozitivul meu?" closed="true" %}}
Da, când **Editarea fișierelor** este activată. Într-un browser web primesc un panou **Încărcare**; pe o conexiune WebDAV sau FTP pot copia fișiere pe dispozitivul tău. Dezactivează **Editarea fișierelor** (în Setări → Partajare → Acces) pentru a face partajarea doar pentru citire.
{{% /details %}}

{{% details title="De ce se transferă lent o fotografie sau un videoclip?" closed="true" %}}
Dacă **Formatul** fotografiilor sau videoclipurilor este setat pe **Cel mai compatibil** sau **Calitatea** este sub **Original**, Everdisk convertește fiecare fișier pe măsură ce este partajat, ceea ce este mai lent și consumă mai multă baterie. Setează **Format** și **Calitate** pe **Original** în **Setări → Partajare** pentru cele mai rapide transferuri și treci pe Cel mai compatibil doar dacă un anumit televizor sau browser nu poate deschide un fișier.
{{% /details %}}

{{% details title="Un dispozitiv nu apare sau nu se conectează. Ce pot verifica?" closed="true" %}}
- Asigură-te că ambele dispozitive sunt pe **aceeași rețea Wi-Fi** (sau folosește cablul de Mac).<br>
- Confirmă că partajarea este **pornită** și că serverul potrivit este **activat** în Setări → Partajare → Conexiuni.<br>
- Tastează adresa exact cum apare pe ecranul Partajare; prin Wi-Fi folosește IP-ul afișat, iar prin cablu folosește numele **`.local`** (niciodată `localhost`).<br>
- Dacă ai setat un utilizator și o parolă, introdu-le pe celălalt dispozitiv.<br>
- Verifică dacă permisiunea **Rețea locală** este permisă pentru Everdisk în aplicația Setări iOS.<br>
- Asigură-te că celălalt dispozitiv nu se află în **Dispozitive blocate**.
{{% /details %}}

{{% details title="Pot schimba numele cu care apare dispozitivul meu în rețea?" closed="true" %}}
Everdisk îi dă dispozitivului tău un nume și un avatar prietenoase în mod automat, iar tu le poți **Regenera** gratuit. Setarea unui nume, a unei pictograme, a unui gradient sau a unei fotografii de avatar **personalizate** face parte din funcția Premium **Personalizarea dispozitivului**.
{{% /details %}}

{{% details title="Pot schimba porturile de conexiune?" closed="true" %}}
Valorile implicite sunt **HTTP 80**, **WebDAV 8080** și **FTP 2121** (DLNA își alege portul automat). Le poți vedea gratuit, iar setarea de **porturi personalizate** este o funcție Premium (**Avansat** în Setări → Partajare).
{{% /details %}}

{{% details title="Everdisk este gratuit și ce adaugă Premium?" closed="true" %}}
Everdisk se descarcă **gratuit**. Poți rula toate cele patru servere, proteja accesul cu o parolă, partaja întreaga ta bibliotecă Fotografii și Muzică, folosi managerul de fișiere, scana în PDF și te poți conecta la alte servere. Versiunea gratuită partajează până la **5 foldere** și salvează până la **10 conexiuni** la servere.<br><br>

O achiziție unică **Premium Lifetime** (nu un abonament) adaugă: **Foldere nelimitate**, **Conexiuni nelimitate**, **Conversia fotografiilor și videoclipurilor** (o calitate alta decât Original), **Porturi personalizate**, **Pornire automată a partajării** și **Personalizarea dispozitivului**.
{{% /details %}}

{{% details title="Premium este un abonament? Funcționează pe celelalte dispozitive ale mele?" closed="true" %}}
Premium este o **achiziție unică**, nu un abonament - plătești o dată și nu se reînnoiește niciodată. Este legat de Apple ID-ul tău, așa că poți folosi **Restaurare achiziții** pentru a-l debloca pe celelalte dispozitive conectate cu același Apple ID.
{{% /details %}}
