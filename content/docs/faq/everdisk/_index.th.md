<div class="hx:mt-6"></div>

Everdisk เปลี่ยน iPhone หรือ iPad ของคุณให้เป็นไดรฟ์ไร้สายที่แชร์ไฟล์ รูปภาพ วิดีโอ และเพลงกับอุปกรณ์ใดก็ได้บนเครือข่ายท้องถิ่นของคุณ - สมาร์ททีวี Mac หรือ PC เว็บเบราว์เซอร์ หรือโทรศัพท์อีกเครื่อง - โดยไม่ต้องมีบัญชี ไม่ต้องใช้คลาวด์ และไม่ต้องติดตั้งอะไรบนอีกฝั่ง คำถามที่พบบ่อยนี้ตอบคำถามที่คนถามมากที่สุดและพาคุณผ่านสถานการณ์ในชีวิตจริงที่พบได้ทั่วไป สำหรับคำแนะนำทีละขั้นตอน โปรดดู [คู่มือการใช้งาน Everdisk](/docs/guide/everdisk/)

<div class="hx:w-full">

{{% details title="Everdisk คืออะไร?" closed="true" %}}
Everdisk คือแอป **ไดรฟ์ไร้สาย** สำหรับ iPhone และ iPad มันเปลี่ยนอุปกรณ์ของคุณให้เป็นศูนย์กลางที่แชร์ไฟล์ รูปภาพ วิดีโอ และเพลงที่คุณเลือกกับทุกอย่างบนเครือข่ายท้องถิ่นของคุณ และยังเชื่อมต่อกับเซิร์ฟเวอร์อื่นเพื่อให้คุณเรียกดูและสตรีมไฟล์ของเซิร์ฟเวอร์เหล่านั้นได้ด้วย<br><br>

มันรันสี่เซิร์ฟเวอร์พร้อมกัน - **DLNA** สำหรับทีวี, **HTTP** สำหรับเว็บเบราว์เซอร์, **WebDAV** สำหรับ Finder/Windows/Linux และ **FTP** สำหรับแอปจัดการไฟล์ - ทุกอุปกรณ์จึงเชื่อมต่อได้ในแบบที่ถนัด ไม่มีบัญชีและไม่มีคลาวด์: คุณแตะ **Start** ก็พร้อมใช้งาน มันยังมีตัวจัดการไฟล์ เครื่องเล่นมีเดีย แกลเลอรีรูปภาพ การสแกนเอกสารเป็น PDF และการบีบอัด/แตกไฟล์ zip
{{% /details %}}

{{% details title="Everdisk ทำงานอย่างไร?" closed="true" %}}
เมื่อคุณแตะ **Start** Everdisk จะเปลี่ยนอุปกรณ์ของคุณให้เป็นเซิร์ฟเวอร์บนเครือข่ายท้องถิ่นและแชร์เนื้อหาที่คุณเลือก มีวิธีเชื่อมต่อสี่แบบทำงานพร้อมกัน เพื่อให้อุปกรณ์ต่าง ๆ เชื่อมต่อได้ในแบบที่ถนัด:<br><br>

- **DLNA** - สมาร์ททีวีและเครื่องเล่นมีเดียค้นหาอุปกรณ์ของคุณอัตโนมัติและแสดงมีเดียของคุณพร้อมภาพตัวอย่าง<br>
- **HTTP** - ใครก็ได้เปิดลิงก์ในเว็บเบราว์เซอร์เพื่อเรียกดูและดาวน์โหลดไฟล์ของคุณ<br>
- **WebDAV** - อุปกรณ์ของคุณปรากฏเป็นไดรฟ์เครือข่ายทั่วไปใน Finder, Windows หรือ Linux<br>
- **FTP** - แอปจัดการไฟล์และเครื่องมือระดับสูงเชื่อมต่อผ่าน FTP<br><br>

ทุกอย่างเกิดขึ้นบน Wi-Fi ท้องถิ่นของคุณ (หรือสาย USB ต่อกับ Mac) และไม่เคยแตะต้องอินเทอร์เน็ต
{{% /details %}}

{{% details title="ฉันต้องมีบัญชี ล็อกอิน หรืออินเทอร์เน็ตไหม?" closed="true" %}}
ไม่ต้อง Everdisk ไม่ต้องใช้บัญชีและไม่ต้องเชื่อมต่ออินเทอร์เน็ต มันทำงานทั้งหมดบน **เครือข่ายท้องถิ่น** ของคุณ หรือผ่าน **สาย USB** ต่อกับ Mac ไม่มีอะไรถูกอัปโหลดขึ้นคลาวด์ใด ๆ ล็อกอินเดียวที่เป็นตัวเลือกคือล็อกอินที่ **คุณ** ตั้งได้เองเพื่อป้องกันการแชร์ของคุณด้วยรหัสผ่าน
{{% /details %}}

{{% details title="ฉันจะเริ่มแชร์ได้อย่างไร?" closed="true" %}}
เปิดแท็บ **Sharing** แตะ **What to Share** เลือกไฟล์ รูปภาพ และ/หรือเพลงของคุณ แล้วแตะปุ่ม **Start** ตัวใหญ่ ส่วน **How to Connect** จะแสดงที่อยู่ที่แม่นยำที่อุปกรณ์อื่นใช้เชื่อมต่อ แตะ **Stop** เพื่อนำทุกอย่างออฟไลน์อีกครั้ง
{{% /details %}}

{{% details title="ฉันแชร์อะไรได้บ้าง?" closed="true" %}}
เนื้อหาสามประเภท ในทุกการผสมผสาน:<br><br>

- **ไฟล์และโฟลเดอร์** - โฟลเดอร์ Documents ของแอป (แชร์ไว้เป็นค่าเริ่มต้น) รวมถึงโฟลเดอร์หรือไฟล์แต่ละไฟล์ที่คุณเพิ่มด้วย **Add Folder** และ **Add File**<br>
- **รูปภาพและวิดีโอ** - คลัง Photos ทั้งหมดของคุณด้วย **Allow access to all Photos Library** หรือเฉพาะรายการที่เลือกด้วย **Add Photos**<br>
- **เพลง** - คลัง Music ทั้งหมดของคุณด้วย **Allow access to all Music Library** หรือเพลงที่เลือกด้วย **Add Tracks**<br><br>

คุณต้องเลือกอย่างน้อยหนึ่งอย่างก่อนจึงจะเริ่มแชร์ได้ เพลงที่มีการป้องกัน (DRM) และเพลงที่อยู่บนคลาวด์อย่างเดียวไม่สามารถแชร์ได้
{{% /details %}}

{{% details title="ฉันจะแชร์รูปภาพกับคอมพิวเตอร์ได้อย่างไร?" closed="true" %}}
1. บนหน้าจอ **Sharing** เปิด **What to Share → Photos and Videos** แล้วเปิด **Allow access to all Photos Library** (หรือเพิ่มรูปภาพที่ต้องการ)<br>
2. แตะ **Start**<br>
3. บนคอมพิวเตอร์ ให้เปิดที่อยู่ **Browser** ในเว็บเบราว์เซอร์ใดก็ได้แล้วดาวน์โหลด หรือเชื่อมต่อกับที่อยู่ **Computer (WebDAV)** จาก Finder (Mac) หรือ File Explorer (Windows) แล้วลากรูปภาพข้ามมา<br><br>

เคล็ดลับ: ตั้ง **Format** ของ Photos ไว้ที่ **Original** เพื่อการโอนที่เร็วที่สุด
{{% /details %}}

{{% details title="ฉันจะดูวิดีโอหรือรูปภาพบนทีวีได้อย่างไร?" closed="true" %}}
1. ใน **Settings → Sharing → Connections** ตรวจสอบให้แน่ใจว่า **TV & Media Center (DLNA)** เปิดอยู่<br>
2. แตะ **Start**<br>
3. บนทีวี เปิดเครื่องเล่นมีเดียในตัวหรือแอปมีเดียเซิร์ฟเวอร์ แล้วเลือกอุปกรณ์ของคุณตามชื่อจากรายการมีเดียเซิร์ฟเวอร์<br>
4. เรียกดูและเล่น ภาพตัวอย่างจะปรากฏอัตโนมัติ<br><br>

หากทีวีรุ่นเก่าเล่นวิดีโอไม่ได้ ให้ลดคุณภาพใน **Settings → Sharing → Videos** เพื่อให้ Everdisk แปลงเป็นรูปแบบที่เข้ากันได้มากกว่า
{{% /details %}}

{{% details title="ฉันจะฟังเพลงของฉันได้อย่างไร?" closed="true" %}}
เปิด **Allow access to all Music Library** (หรือเพิ่มเพลง) ใต้ **What to Share** แล้วแตะ **Start** จากนั้นคุณสามารถเล่นเพลงของคุณจากเว็บเบราว์เซอร์ของอุปกรณ์อื่น (มีเครื่องเล่นในตัวพร้อมคิว สลับเพลง และเล่นซ้ำ) จากทีวี DLNA หรือใน Everdisk เองด้วยโหมด **Documents → Music** เพลงจะแชร์ในคุณภาพต้นฉบับเสมอ
{{% /details %}}

{{% details title="ฉันจะดูหนังใน Everdisk ได้อย่างไร?" closed="true" %}}
แตะวิดีโอใดก็ได้ - ใน Documents ของคุณ โฟลเดอร์ที่เชื่อมต่อ หรือเซิร์ฟเวอร์ในแท็บ Devices - แล้วมันจะเล่น **แบบเต็มจอ** ด้วยเครื่องเล่นในตัวของระบบ พร้อมปุ่มควบคุมมาตรฐานรวมถึง **AirPlay**, **Picture in Picture** และ **ความเร็วในการเล่น** เสียงเล่นในเครื่องเล่น **ขนาดเล็ก** ที่ค้างอยู่ด้านล่างของแอปพร้อมคิว สลับเพลง และเล่นซ้ำ
{{% /details %}}

{{% details title="ฉันจะเปิดไฟล์ในเว็บเบราว์เซอร์ได้อย่างไร?" closed="true" %}}
1. ใน **Settings → Sharing → Connections** ตรวจสอบให้แน่ใจว่า **Browser (HTTP)** เปิดอยู่<br>
2. แตะ **Start** แล้วคัดลอกที่อยู่ **Browser** (หรือแสดงโค้ด QR)<br>
3. บนอุปกรณ์อีกเครื่อง เปิดเว็บเบราว์เซอร์ใดก็ได้แล้วพิมพ์ที่อยู่นั้น<br><br>

อีกฝ่ายสามารถเรียกดูแบบกริดหรือรายการ ดูรูปในแกลเลอรีเต็มจอ เล่นเพลง และดาวน์โหลดไฟล์ได้ - รวมถึงดาวน์โหลดทั้งโฟลเดอร์เป็นไฟล์เดียว **Archive.zip** หากคุณเปิด **Files Editing** ไว้ เขายังอัปโหลดไฟล์กลับมาให้คุณได้ด้วย ไม่ต้องติดตั้งอะไรบนฝั่งของเขา
{{% /details %}}

{{% details title="ฉันจะใช้อุปกรณ์เป็นไดรฟ์เครือข่ายใน Finder ได้อย่างไร?" closed="true" %}}
1. ใน **Settings → Sharing → Connections** ตรวจสอบให้แน่ใจว่า **Computer (WebDAV)** เปิดอยู่ แล้วแตะ **Start**<br>
2. บน Mac เปิด Finder เลือก **Go → Connect to Server** (หรือกด **⌘K**)<br>
3. ป้อนที่อยู่ **Computer (WebDAV)** ที่แสดงใน Everdisk แล้วคลิก **Connect**<br>
4. ป้อนล็อกอินและรหัสผ่านหากคุณตั้งไว้ มิฉะนั้นเชื่อมต่อในฐานะผู้เยี่ยมชม<br><br>

อุปกรณ์ของคุณจะเชื่อมต่อเหมือนไดรฟ์เครือข่ายทั่วไป เมื่อ **Files Editing** เปิดอยู่ คุณสามารถลากไฟล์ได้ทั้งสองทาง เมื่อปิดอยู่ ไดรฟ์จะเป็นแบบอ่านอย่างเดียว
{{% /details %}}

{{% details title="ฉันจะเชื่อมต่อจาก Windows หรือ Linux ได้อย่างไร?" closed="true" %}}
ใช้ที่อยู่ **Computer (WebDAV)**<br><br>

- **Windows:** เปิด File Explorer → คลิกขวาที่ **This PC** → **Add a network location** (หรือแมปไดรฟ์เครือข่าย) แล้วป้อนที่อยู่ WebDAV<br>
- **Linux:** ในตัวจัดการไฟล์ของคุณเลือก **Connect to Server** แล้วป้อนที่อยู่ WebDAV (เช่นด้วยคำนำหน้า `davs://` หรือ `dav://`)<br><br>

ป้อนล็อกอินและรหัสผ่านหากคุณตั้งไว้
{{% /details %}}

{{% details title="Everdisk ใช้งานได้โดยไม่มี Wi-Fi หรือไม่?" closed="true" %}}
ได้ ด้วย **Mac** และสาย เสียบ iPhone หรือ iPad เข้ากับ Mac แตะ **Trust** หากถูกถาม แล้วแตะ **Start** ที่อยู่ **Cable Connection** ที่ลงท้ายด้วย `.local` จะปรากฏบนหน้าจอ Sharing เชื่อมต่อกับมันจาก Finder (**⌘K**) วิธีนี้ใช้ได้โดยไม่มี Wi-Fi เลย - เหมาะบนเครื่องบิน ในโรงแรม หรือบนเครือข่ายที่ถูกล็อก - และเร็วกว่าและเป็นส่วนตัวกว่า Wi-Fi
{{% /details %}}

{{% details title="ฉันใช้สาย USB กับ Windows PC หรือ Android ได้ไหม?" closed="true" %}}
ไม่ได้ การเชื่อมต่อผ่านสายใช้ได้กับ **Mac** เท่านั้น Windows PC และอุปกรณ์ Android เชื่อมต่อผ่าน **Wi-Fi** (บน Windows คุณยังลากไฟล์เข้าโฟลเดอร์ Everdisk ได้โดยใช้แอป Apple Devices หรือ iTunes ผ่านสาย ซึ่งแยกจากการแชร์แบบสด)
{{% /details %}}

{{% details title="ทำไมฉันต้องเปิดแอปค้างไว้ขณะแชร์?" closed="true" %}}
iPhone หรือ iPad ของคุณคือเซิร์ฟเวอร์ และ iOS ไม่อนุญาตให้แอปรันเซิร์ฟเวอร์เครือข่ายค้างไว้เบื้องหลัง การแชร์จึงทำงานได้เฉพาะขณะที่ Everdisk **เปิดอยู่บนหน้าจอ** สำหรับการโอนที่ใช้เวลานาน ให้เปิดแอปไว้เบื้องหน้า เสียบชาร์จ และตั้ง **Auto-Lock** เป็น **Never** ในแอป Settings ของ iOS คุณยังเปิด **Notify before disconnecting** เพื่อให้ Everdisk เตือนคุณก่อนที่ระบบจะหยุดชั่วคราวได้ด้วย
{{% /details %}}

{{% details title="อะไรเร็วกว่ากัน - Wi-Fi หรือสาย?" closed="true" %}}
**สาย USB ต่อกับ Mac** เร็วกว่าและเสถียรกว่า Wi-Fi เพราะข้อมูลวิ่งตรงผ่านสาย มันยังเป็นตัวเลือกที่เป็นส่วนตัวที่สุด เพราะไม่มีอะไรผ่านเราเตอร์หรืออินเทอร์เน็ต ใช้มันสำหรับการโอนรูปภาพและวิดีโอขนาดใหญ่
{{% /details %}}

{{% details title="สี่เซิร์ฟเวอร์ (DLNA, HTTP, WebDAV, FTP) ต่างกันอย่างไร?" closed="true" %}}
ทั้งหมดแชร์เนื้อหาเดียวกันแต่เหมาะกับอุปกรณ์ต่างกัน:<br><br>

- **TV & Media Center (DLNA)** - สำหรับสมาร์ททีวีและเครื่องเล่นมีเดีย<br>
- **Browser (HTTP)** - สำหรับเว็บเบราว์เซอร์ใดก็ได้ ไม่ต้องติดตั้งอะไร<br>
- **Computer (WebDAV)** - ทำให้อุปกรณ์ของคุณเป็นไดรฟ์เครือข่ายใน Finder/Windows/Linux<br>
- **Other Apps & Devices (FTP)** - สำหรับแอปจัดการไฟล์และเครื่องมือระดับสูง<br><br>

คุณสามารถเปิดหรือปิดแต่ละอันได้ใน **Settings → Sharing → Connections**
{{% /details %}}

{{% details title="ฉันจะป้องกันไฟล์ด้วยรหัสผ่านได้อย่างไร?" closed="true" %}}
ไปที่ **Settings → Sharing → Access** แล้วตั้ง **Login** และ **Password** การเชื่อมต่อ Browser, Computer และ Other Apps จะถามรายละเอียดเหล่านั้น ปล่อยว่างทั้งคู่เพื่อให้เข้าถึงได้แบบเปิด<br><br>

หมายเหตุ: การเชื่อมต่อ **DLNA** (ทีวี) ไม่สามารถป้องกันด้วยรหัสผ่านได้ จึงเปิดให้ใครก็ได้บน Wi-Fi เดียวกันขณะที่มันเปิดอยู่ ปิดมันหากคุณต้องการเฉพาะการเชื่อมต่อที่มีการป้องกัน
{{% /details %}}

{{% details title="ฉันจะป้องกันไม่ให้คนอื่นเปลี่ยนแปลงไฟล์ของฉันได้ไหม?" closed="true" %}}
ได้ สวิตช์ **Files Editing** ใน **Settings → Sharing → Access** ควบคุมสิ่งนี้ เมื่อ **เปิด** อยู่ (ค่าเริ่มต้น) อุปกรณ์ที่เชื่อมต่อสามารถอัปโหลด เปลี่ยนชื่อ และลบได้ ปิดมันเพื่อทำให้ไฟล์ที่แชร์เป็นแบบ **อ่านอย่างเดียว** - คนอื่นดูและดาวน์โหลดได้แต่เปลี่ยนแปลงอะไรไม่ได้
{{% /details %}}

{{% details title="ฉันจะบล็อกอุปกรณ์ที่ไม่รู้จักได้อย่างไร?" closed="true" %}}
บนหน้าจอ **Sharing** หาอุปกรณ์ใต้ **Who is Connected** แตะปุ่มดำเนินการเพิ่มเติมของมัน แล้วเลือก **Block this device** จัดการอุปกรณ์ที่ถูกบล็อกได้ใน **Settings → Sharing → Access → Blocked Devices** ที่ซึ่งคุณสามารถปลดบล็อกทีละอันหรือ **Unblock All** ได้
{{% /details %}}

{{% details title="ถ้ามีคนลบไฟล์ที่แชร์ มันจะหายไปตลอดกาลไหม?" closed="true" %}}
ไม่ตามค่าเริ่มต้น ไฟล์ที่ถูกลบจะไปอยู่ในถังขยะที่กู้คืนได้ คุณจึงเรียกกลับมาได้ หากคุณต้องการลบทันทีโดยไม่กู้คืน ให้เปิด **Permanently Delete Files** ใน **Settings → File Manager → Deleting Files**
{{% /details %}}

{{% details title="Everdisk เป็นส่วนตัวและปลอดภัยหรือไม่?" closed="true" %}}
ใช่ Everdisk แชร์เฉพาะบน **เครือข่ายท้องถิ่น** ของคุณ - ไม่มีอะไรออกไปสู่อินเทอร์เน็ตและไม่มีบัญชีคลาวด์ เพื่อความเป็นส่วนตัวที่ดีที่สุด ให้แชร์บน Wi-Fi ที่บ้านหรือส่วนตัวที่คุณไว้ใจ เพิ่มล็อกอินและรหัสผ่าน และระมัดระวังบน Wi-Fi สาธารณะ **สาย USB ต่อกับ Mac** เป็นตัวเลือกที่เป็นส่วนตัวที่สุด Everdisk ต้องใช้สิทธิ์ **Local Network** ของ iOS เพื่อให้อุปกรณ์ใกล้เคียงค้นหามันเจอ
{{% /details %}}

{{% details title="Everdisk เชื่อมต่อกับ NAS หรือเซิร์ฟเวอร์อื่นได้ไหม?" closed="true" %}}
ได้ แท็บ **Devices** เชื่อมต่อ **ไปยัง** เซิร์ฟเวอร์อื่นบนเครือข่ายของคุณ แตะ **New Connection** แล้วเลือก **DLNA / UPnP**, **WebDAV**, **FTP** หรือ **SFTP** ป้อนที่อยู่และล็อกอินใด ๆ แล้วคุณก็เรียกดู สตรีม และดาวน์โหลดได้ บนเซิร์ฟเวอร์ WebDAV, FTP และ SFTP คุณยังสร้างโฟลเดอร์ อัปโหลด เปลี่ยนชื่อ ย้าย และลบได้ด้วย เซิร์ฟเวอร์ DLNA เป็นแบบอ่านอย่างเดียว
{{% /details %}}

{{% details title="ฉันเชื่อมต่อกับที่เก็บข้อมูลบนคลาวด์อย่าง Google Drive หรือ Dropbox ได้ไหม?" closed="true" %}}
Everdisk ไม่ได้ลงชื่อเข้าใช้บัญชีคลาวด์อย่าง iCloud Drive, Google Drive, Dropbox หรือ OneDrive มันเชื่อมต่อเฉพาะกับเซิร์ฟเวอร์ **บนเครือข่ายท้องถิ่นและที่ระบุที่อยู่โดยตรง** (DLNA, WebDAV, FTP, SFTP) บริการคลาวด์จะเข้าถึงได้ก็ต่อเมื่อมันมีที่อยู่ **WebDAV** ที่คุณสามารถพิมพ์ลงในการเชื่อมต่อ WebDAV ใหม่ได้เท่านั้น
{{% /details %}}

{{% details title="แท็บ Devices มีไว้ทำอะไร?" closed="true" %}}
มันคือฝั่งไคลเอนต์ของ Everdisk: **Connections** แสดงรายการเซิร์ฟเวอร์ที่คุณบันทึกไว้ และ **Available Devices** แสดงรายการเซิร์ฟเวอร์ที่พบอัตโนมัติบนเครือข่ายของคุณ แตะอันหนึ่งเพื่อเรียกดู สตรีม หรือดาวน์โหลดไฟล์ของมัน หรือแตะ **New Connection** เพื่อเพิ่มเซิร์ฟเวอร์ DLNA, WebDAV, FTP หรือ SFTP ด้วยตนเอง
{{% /details %}}

{{% details title="ฉันจะดาวน์โหลดไฟล์จากเซิร์ฟเวอร์มายังอุปกรณ์ของฉันได้อย่างไร?" closed="true" %}}
เปิดเซิร์ฟเวอร์ในแท็บ **Devices** เรียกดูไปยังสิ่งที่คุณต้องการ แล้วเลือก **Download** (เลือกหลายรายการเพื่อดาวน์โหลดเป็นชุด) การดาวน์โหลดทำงานเบื้องหลัง ปรากฏใน **File Transfers** (มุมบนซ้ายของแท็บ Documents) และไปอยู่ในโฟลเดอร์ **Documents** ของคุณ
{{% /details %}}

{{% details title="Everdisk มีตัวจัดการไฟล์ไหม?" closed="true" %}}
มี แท็บ **Documents** เป็นตัวจัดการไฟล์ครบครัน คุณสามารถเรียกดูแบบรายการหรือกริด สร้างโฟลเดอร์ เปลี่ยนชื่อ ย้าย คัดลอก อัปโหลด และลบ และเปิดหน้าจอ **Info** สำหรับไฟล์ใดก็ได้ การดาวน์โหลดจะมาอยู่ที่นี่ และโฟลเดอร์ Documents ถูกแชร์ไว้เป็นค่าเริ่มต้น
{{% /details %}}

{{% details title="ฉันจะบีบอัด (สร้างไฟล์เก็บถาวร) ไฟล์ได้อย่างไร?" closed="true" %}}
ในแท็บ **Documents** เลือกหนึ่งรายการหรือมากกว่า แล้วเลือก **Archive** รายการเดียวจะถูกบีบอัดเดี่ยว ๆ หลายรายการจะถูกรวมเป็นไฟล์เดียว **Archive.zip** ในเว็บเบราว์เซอร์ คุณยังดาวน์โหลดทั้งโฟลเดอร์หรือหลายรายการที่เลือกเป็น zip ไฟล์เดียวได้ด้วย
{{% /details %}}

{{% details title="ฉันจะแตกไฟล์เก็บถาวรได้อย่างไร?" closed="true" %}}
แตะไฟล์ **.zip** หรือ **.rar** ในแท็บ **Documents** แล้ว Everdisk จะแตกมันลงในโฟลเดอร์ปัจจุบัน พร้อมแถบความคืบหน้าที่คุณยกเลิกได้
{{% /details %}}

{{% details title="ฉันจะสแกนเอกสารเป็น PDF ได้อย่างไร?" closed="true" %}}
ในแท็บ **Documents** เปิดเมนูดำเนินการเพิ่มเติม (•••) แล้วเลือก **Scan Documents** เล็งกล้องไปที่แต่ละหน้า - Everdisk หาขอบและปรับหน้าให้ตรงอัตโนมัติ - และทุกหน้าจะถูกบันทึกรวมกันเป็น **PDF หลายหน้า** ไฟล์เดียวในโฟลเดอร์ปัจจุบัน คุณต้องมีอุปกรณ์ที่มีกล้อง
{{% /details %}}

{{% details title="Everdisk มีเครื่องมือ PDF อะไรบ้าง?" closed="true" %}}
Everdisk มีชุด **เครื่องมือ PDF** ในตัว เปิดเมนู **•••** ของ PDF ใด ๆ (หรือหน้าจอ Info ของมัน) ในแท็บ **Documents** แล้วแตะ **PDF Tools** มันแบ่งเป็นสามกลุ่ม:<br><br>

**Optimize**<br>
- **Compress** - ทำให้ PDF เล็กลง คุณจะเห็นขนาดปัจจุบันและขนาดผลลัพธ์โดยประมาณสำหรับแต่ละตัวเลือกก่อนบันทึก<br>
- **Text Recognition (OCR)** - เปลี่ยน PDF ที่สแกนให้เป็น **PDF ที่ค้นหาได้** หรือส่งออกเฉพาะข้อความเป็นไฟล์ **.txt**<br>
- **Flatten** - ฝังคำอธิบายประกอบและรายการในฟอร์มลงในหน้าเพื่อไม่ให้แก้ไขได้อีก<br><br>

**Security**<br>
- **Password** - ตั้ง เปลี่ยน หรือลบรหัสผ่านที่ต้องใช้เปิด PDF<br>
- **Permissions** - ตรวจสอบว่า PDF อนุญาตอะไรบ้าง (คัดลอก พิมพ์ แสดงความคิดเห็น และอื่น ๆ)<br><br>

**Metadata**<br>
- **Edit Metadata** - เปลี่ยนหรือล้างชื่อเรื่อง ผู้เขียน หัวเรื่อง คำสำคัญ และข้อมูลเอกสารอื่น ๆ<br><br>

เครื่องมือ PDF มีให้ใช้ฟรี หาก PDF มีการป้องกันด้วยรหัสผ่าน Everdisk จะถามรหัสผ่านของมันก่อนที่คุณจะใช้เครื่องมือได้
{{% /details %}}

{{% details title="ฉันจะบีบอัด PDF ได้อย่างไร?" closed="true" %}}
เปิดเมนู **•••** ของ PDF → **PDF Tools** → **Compress** Everdisk แสดงขนาดไฟล์ปัจจุบันและขนาดโดยประมาณสำหรับแต่ละตัวเลือก:<br><br>

- **Standard** ยังคงให้เลือกข้อความได้และบีบอัดเฉพาะรูปภาพใหม่เท่านั้น<br>
- **High**, **Medium**, **Small** และ **Smallest** จะเรนเดอร์หน้าใหม่เป็นรูปภาพที่ความละเอียดต่ำลง - เหมาะที่สุดสำหรับไฟล์สแกนและรูปภาพ แต่ข้อความจะไม่สามารถเลือกได้อีก<br><br>

แตะตัวเลือกที่คุณต้องการ แล้ว Everdisk จะบันทึก PDF ที่เล็กลง
{{% /details %}}

{{% details title="ฉันจะทำให้ PDF ที่สแกนค้นหาได้ (OCR) ได้อย่างไร?" closed="true" %}}
เปิดเมนู **•••** ของ PDF → **PDF Tools** → **Text Recognition** เลือก **Searchable PDF** เพื่อเพิ่มเลเยอร์ข้อความที่ซ่อนไว้ เพื่อให้คุณค้นหาและเลือกข้อความได้ (หน้าตายังเหมือนเดิมทุกประการ) หรือ **Text File (.txt)** เพื่อบันทึกเฉพาะข้อความที่จดจำได้ไว้ข้าง PDF ไฟล์ที่ใหญ่หรือสแกนมาอาจใช้เวลาสักครู่
{{% /details %}}

{{% details title="ฉันจะป้องกันไฟล์ PDF ด้วยรหัสผ่านได้อย่างไร?" closed="true" %}}
เปิดเมนู **•••** ของ PDF → **PDF Tools** → **Password** หาก PDF ยังไม่มีการป้องกัน ให้ป้อนรหัสผ่านใหม่และยืนยันเพื่อตั้งค่า หากมีการป้องกันอยู่แล้ว ให้ป้อนรหัสผ่านปัจจุบันเพื่อ **ลบ** หรือ **เปลี่ยน** มัน เก็บรหัสผ่านไว้ในที่ปลอดภัย - PDF ที่มีการป้องกันจะเปิดไม่ได้หากไม่มีมัน<br><br>

สิ่งนี้ป้องกัน **ไฟล์** PDF เอง ซึ่งต่างจาก **ล็อกอินและรหัสผ่าน** ที่ป้องกันเซสชันการแชร์ทั้งหมดของคุณ (ดูคำถามด้านความปลอดภัยด้านบน)
{{% /details %}}

{{% details title="ฉันวาดหรือเซ็นชื่อบน PDF ใน Everdisk ได้ไหม?" closed="true" %}}
ได้ แตะ PDF (หรือรูปภาพ) ในแท็บ **Documents** เพื่อเปิดในตัวดูในตัว จากนั้นใช้เครื่องมือ **Markup** เพื่อ **วาด ไฮไลต์ เพิ่มข้อความและรูปทรง และเซ็นชื่อ** ด้วยนิ้ว การเปลี่ยนแปลงของคุณจะบันทึกกลับลงไฟล์ทันที<br><br>

หากคุณต้องการทำให้เครื่องหมายเหล่านั้นถาวรจนแก้ไขไม่ได้ในภายหลัง ให้เปิด **••• → PDF Tools → Flatten** ของ PDF ในการเพิ่มรหัสผ่าน รัน OCR บีบอัด หรือแก้ไขข้อมูลเอกสาร ให้ใช้ **PDF Tools** ตัวอื่น (ดูคำถามด้านบน)
{{% /details %}}

{{% details title="ฉันเชื่อมต่อโฟลเดอร์ที่อยู่ที่อื่นบนอุปกรณ์ของฉันได้ไหม?" closed="true" %}}
ได้ ในแท็บ **Documents** เปิดเมนู ••• แล้วเลือก **Connect Folder** จากนั้นเลือกโฟลเดอร์ใดก็ได้บนอุปกรณ์ของคุณ มันจะปรากฏด้านบนพร้อมป้าย **Connected** และแชร์ผ่านเครือข่ายได้เหมือนโฟลเดอร์อื่น ๆ ใช้ **Disconnect** จาก Info ของมันเพื่อยกเลิกการเชื่อมโยง - โฟลเดอร์และไฟล์ยังคงอยู่บนอุปกรณ์ของคุณ
{{% /details %}}

{{% details title="คนอื่นอัปโหลดไฟล์กลับมายังอุปกรณ์ของฉันได้ไหม?" closed="true" %}}
ได้ เมื่อ **Files Editing** เปิดอยู่ ในเว็บเบราว์เซอร์เขาจะได้แผง **Upload** บนการเชื่อมต่อ WebDAV หรือ FTP เขาสามารถคัดลอกไฟล์ลงบนอุปกรณ์ของคุณได้ ปิด **Files Editing** (ใน Settings → Sharing → Access) เพื่อทำให้การแชร์เป็นแบบอ่านอย่างเดียว
{{% /details %}}

{{% details title="ทำไมรูปภาพหรือวิดีโอถึงโอนช้า?" closed="true" %}}
หาก **Format** ของ Photos หรือ Videos ถูกตั้งเป็น **Most Compatible** หรือ **Quality** ต่ำกว่า **Original** Everdisk จะแปลงแต่ละไฟล์ขณะแชร์ ซึ่งช้ากว่าและใช้แบตเตอรี่มากขึ้น ตั้ง **Format** และ **Quality** เป็น **Original** ใน **Settings → Sharing** เพื่อการโอนที่เร็วที่สุด และเปลี่ยนเป็น Most Compatible เฉพาะเมื่อทีวีหรือเบราว์เซอร์บางตัวเปิดไฟล์ไม่ได้เท่านั้น
{{% /details %}}

{{% details title="อุปกรณ์ไม่ปรากฏหรือเชื่อมต่อไม่ได้ ฉันควรตรวจสอบอะไร?" closed="true" %}}
- ตรวจสอบให้แน่ใจว่าอุปกรณ์ทั้งสองอยู่บน **เครือข่าย Wi-Fi เดียวกัน** (หรือใช้สายต่อกับ Mac)<br>
- ยืนยันว่าการแชร์ **เริ่มแล้ว** และเซิร์ฟเวอร์ที่ถูกต้อง **เปิดอยู่** ใน Settings → Sharing → Connections<br>
- พิมพ์ที่อยู่ให้ตรงกับที่แสดงบนหน้าจอ Sharing ทุกประการ ผ่าน Wi-Fi ให้ใช้ IP ที่แสดง และผ่านสายให้ใช้ชื่อ **`.local`** (ห้ามใช้ `localhost`)<br>
- หากคุณตั้งล็อกอินและรหัสผ่าน ให้ป้อนบนอุปกรณ์อีกเครื่อง<br>
- ตรวจสอบว่าสิทธิ์ **Local Network** ได้รับอนุญาตสำหรับ Everdisk ในแอป Settings ของ iOS<br>
- ตรวจสอบให้แน่ใจว่าอุปกรณ์อีกเครื่องไม่ได้อยู่ใน **Blocked Devices**
{{% /details %}}

{{% details title="ฉันเปลี่ยนชื่อที่อุปกรณ์แสดงบนเครือข่ายได้ไหม?" closed="true" %}}
Everdisk ตั้งชื่อและอวาตาร์ที่เป็นมิตรให้อุปกรณ์ของคุณอัตโนมัติ และคุณสามารถ **Regenerate** ได้ฟรี การตั้งชื่อ ไอคอน ไล่เฉดสี หรืออวาตาร์รูปภาพ **แบบกำหนดเอง** เป็นส่วนหนึ่งของฟีเจอร์ **Device Customization** ของ Premium
{{% /details %}}

{{% details title="ฉันเปลี่ยนพอร์ตการเชื่อมต่อได้ไหม?" closed="true" %}}
ค่าเริ่มต้นคือ **HTTP 80**, **WebDAV 8080** และ **FTP 2121** (DLNA เลือกพอร์ตของมันเองอัตโนมัติ) คุณดูมันได้ฟรี และการตั้ง **พอร์ตแบบกำหนดเอง** เป็นฟีเจอร์ของ Premium (**Advanced** ใน Settings → Sharing)
{{% /details %}}

{{% details title="Everdisk ฟรีไหม และ Premium เพิ่มอะไรบ้าง?" closed="true" %}}
Everdisk ดาวน์โหลด **ฟรี** คุณสามารถรันทั้งสี่เซิร์ฟเวอร์ ป้องกันการเข้าถึงด้วยรหัสผ่าน แชร์คลัง Photos และ Music ทั้งหมดของคุณ ใช้ตัวจัดการไฟล์ สแกนเป็น PDF และเชื่อมต่อกับเซิร์ฟเวอร์อื่นได้ เวอร์ชันฟรีแชร์ได้สูงสุด **5 โฟลเดอร์** และบันทึกการเชื่อมต่อเซิร์ฟเวอร์ได้สูงสุด **10 รายการ**<br><br>

การซื้อ **Premium Lifetime** แบบจ่ายครั้งเดียว (ไม่ใช่การสมัครสมาชิก) เพิ่ม: **Unlimited Folders**, **Unlimited Connections**, **Photo & Video Conversion** (คุณภาพอื่นนอกจาก Original), **Custom Ports**, **Auto-Start Sharing** และ **Device Customization**
{{% /details %}}

{{% details title="Premium เป็นการสมัครสมาชิกไหม? ใช้บนอุปกรณ์อื่นของฉันได้ไหม?" closed="true" %}}
Premium เป็น **การซื้อครั้งเดียว** ไม่ใช่การสมัครสมาชิก - คุณจ่ายครั้งเดียวและไม่มีการต่ออายุ มันผูกกับ Apple ID ของคุณ คุณจึงใช้ **Restore Purchases** เพื่อปลดล็อกบนอุปกรณ์อื่นของคุณที่ลงชื่อเข้าใช้ด้วย Apple ID เดียวกันได้
{{% /details %}}
