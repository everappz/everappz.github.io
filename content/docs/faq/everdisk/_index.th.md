<div class="hx:mt-6"></div>

Everdisk เปลี่ยน iPhone หรือ iPad ของคุณให้เป็นไดรฟ์ไร้สายที่แชร์ไฟล์ รูปภาพ วิดีโอ และเพลงกับอุปกรณ์ใดก็ได้บนเครือข่ายท้องถิ่นของคุณ - สมาร์ททีวี Mac หรือ PC เว็บเบราว์เซอร์ หรือโทรศัพท์อีกเครื่อง - โดยไม่ต้องมีบัญชี ไม่ต้องใช้คลาวด์ และไม่ต้องติดตั้งอะไรบนอีกฝั่ง คำถามที่พบบ่อยนี้ตอบคำถามที่คนถามมากที่สุดและพาคุณผ่านสถานการณ์ในชีวิตจริงที่พบได้ทั่วไป สำหรับคำแนะนำทีละขั้นตอน โปรดดู [คู่มือการใช้งาน Everdisk](/docs/guide/everdisk/)

<div class="hx:w-full">

{{% details title="Everdisk คืออะไร?" closed="true" %}}
Everdisk คือแอป **ไดรฟ์ไร้สาย** สำหรับ iPhone และ iPad มันเปลี่ยนอุปกรณ์ของคุณให้เป็นศูนย์กลางที่แชร์ไฟล์ รูปภาพ วิดีโอ และเพลงที่คุณเลือกกับทุกอย่างบนเครือข่ายท้องถิ่นของคุณ และยังเชื่อมต่อกับเซิร์ฟเวอร์อื่นเพื่อให้คุณเรียกดูและสตรีมไฟล์ของเซิร์ฟเวอร์เหล่านั้นได้ด้วย<br><br>

มันรันห้าเซิร์ฟเวอร์พร้อมกัน - **DLNA** สำหรับทีวี, **HTTP** สำหรับเว็บเบราว์เซอร์, **WebDAV** สำหรับ Finder/Windows/Linux, **SMB** สำหรับไดรฟ์เครือข่ายบน Mac, Windows และ Linux พร้อมการเข้ารหัสที่เลือกได้ และ **FTP** สำหรับแอปจัดการไฟล์ - ทุกอุปกรณ์จึงเชื่อมต่อได้ในแบบที่ถนัด ไม่มีบัญชีและไม่มีคลาวด์: คุณแตะ **Start** ก็พร้อมใช้งาน มันยังมีตัวจัดการไฟล์ เครื่องเล่นมีเดีย แกลเลอรีรูปภาพ การสแกนเอกสารเป็น PDF และการบีบอัด/แตกไฟล์ zip
{{% /details %}}

{{% details title="Everdisk ทำงานอย่างไร?" closed="true" %}}
เมื่อคุณแตะ **Start** Everdisk จะเปลี่ยนอุปกรณ์ของคุณให้เป็นเซิร์ฟเวอร์บนเครือข่ายท้องถิ่นและแชร์เนื้อหาที่คุณเลือก มีวิธีเชื่อมต่อห้าแบบทำงานพร้อมกัน เพื่อให้อุปกรณ์ต่าง ๆ เชื่อมต่อได้ในแบบที่ถนัด:<br><br>

- **DLNA** - สมาร์ททีวีและเครื่องเล่นมีเดียค้นหาอุปกรณ์ของคุณอัตโนมัติและแสดงมีเดียของคุณพร้อมภาพตัวอย่าง<br>
- **HTTP** - ใครก็ได้เปิดลิงก์ในเว็บเบราว์เซอร์เพื่อเรียกดูและดาวน์โหลดไฟล์ของคุณ<br>
- **WebDAV** - อุปกรณ์ของคุณปรากฏเป็นไดรฟ์เครือข่ายทั่วไปใน Finder, Windows หรือ Linux<br>
- **SMB** - ไดรฟ์เครือข่ายสำหรับ Mac, Windows และ Linux ที่สร้างขึ้นบนการแชร์ไฟล์ที่มีอยู่แล้วในระบบเหล่านั้น บน Mac จะปรากฏขึ้นเองในแถบข้าง Finder เป็นการเชื่อมต่อเดียวที่คุณเข้ารหัสได้ (การเข้ารหัส SMB3, AES)<br>
- **FTP** - แอปจัดการไฟล์และเครื่องมือระดับสูงเชื่อมต่อผ่าน FTP<br><br>

ทุกอย่างเกิดขึ้นบน Wi-Fi ท้องถิ่นของคุณ (หรือสาย USB ต่อกับ Mac) และไม่เคยแตะต้องอินเทอร์เน็ต
{{% /details %}}

{{% details title="ฉันต้องมีบัญชี ล็อกอิน หรืออินเทอร์เน็ตไหม?" closed="true" %}}
ไม่ต้อง Everdisk ไม่ต้องใช้บัญชีและไม่ต้องเชื่อมต่ออินเทอร์เน็ต มันทำงานทั้งหมดบน **เครือข่ายท้องถิ่น** ของคุณ หรือผ่าน **สาย USB** ต่อกับ Mac ไม่มีอะไรถูกอัปโหลดขึ้นคลาวด์ใด ๆ ล็อกอินเดียวที่เป็นตัวเลือกคือล็อกอินที่ **คุณ** ตั้งได้เองเพื่อป้องกันการแชร์ของคุณด้วยรหัสผ่าน
{{% /details %}}

{{% details title="ฉันจะเริ่มแชร์ได้อย่างไร?" closed="true" %}}
เปิดแท็บ **การแชร์** แตะ **สิ่งที่จะแชร์** เลือกไฟล์ รูปภาพ และ/หรือเพลงของคุณ แล้วแตะปุ่ม **Start** ตัวใหญ่ ส่วน **วิธีเชื่อมต่อ** จะแสดงที่อยู่ที่แม่นยำที่อุปกรณ์อื่นใช้เชื่อมต่อ แตะ **Stop** เพื่อนำทุกอย่างออฟไลน์อีกครั้ง
{{% /details %}}

{{% details title="ฉันแชร์อะไรได้บ้าง?" closed="true" %}}
เนื้อหาสามประเภท ในทุกการผสมผสาน:<br><br>

- **ไฟล์และโฟลเดอร์** - โฟลเดอร์เอกสารของแอป (แชร์ไว้เป็นค่าเริ่มต้น) รวมถึงโฟลเดอร์หรือไฟล์แต่ละไฟล์ที่คุณเพิ่มด้วย **เพิ่มโฟลเดอร์** และ **เพิ่มไฟล์**<br>
- **รูปภาพและวิดีโอ** - คลังรูปภาพทั้งหมดของคุณด้วย **อนุญาตให้เข้าถึงคลังรูปภาพทั้งหมด** หรือเฉพาะรายการที่เลือกด้วย **เพิ่มรูปภาพ**<br>
- **เพลง** - คลังเพลงทั้งหมดของคุณด้วย **อนุญาตให้เข้าถึงคลังเพลงทั้งหมด** หรือเพลงที่เลือกด้วย **เพิ่มเพลง**<br><br>

คุณต้องเลือกอย่างน้อยหนึ่งอย่างก่อนจึงจะเริ่มแชร์ได้ เพลงที่มีการป้องกัน (DRM) และเพลงที่อยู่บนคลาวด์อย่างเดียวไม่สามารถแชร์ได้
{{% /details %}}

{{% details title="ฉันจะแชร์รูปภาพกับคอมพิวเตอร์ได้อย่างไร?" closed="true" %}}
1. บนหน้าจอ **การแชร์** เปิด **สิ่งที่จะแชร์ → รูปภาพและวิดีโอ** แล้วเปิด **อนุญาตให้เข้าถึงคลังรูปภาพทั้งหมด** (หรือเพิ่มรูปภาพที่ต้องการ)<br>
2. แตะ **Start**<br>
3. บนคอมพิวเตอร์ ให้เปิดที่อยู่ **เบราว์เซอร์** ในเว็บเบราว์เซอร์ใดก็ได้แล้วดาวน์โหลด หรือเชื่อมต่อกับที่อยู่ **คอมพิวเตอร์ (WebDAV)** จาก Finder (Mac) หรือ File Explorer (Windows) แล้วลากรูปภาพข้ามมา<br><br>

เคล็ดลับ: ตั้ง **รูปแบบ** ของรูปภาพไว้ที่ **ต้นฉบับ** เพื่อการโอนที่เร็วที่สุด
{{% /details %}}

{{% details title="ฉันจะดูวิดีโอหรือรูปภาพบนทีวีได้อย่างไร?" closed="true" %}}
1. ใน **การตั้งค่า → การแชร์ → การเชื่อมต่อ** ตรวจสอบให้แน่ใจว่า **ทีวีและศูนย์มีเดีย (DLNA)** เปิดอยู่<br>
2. แตะ **Start**<br>
3. บนทีวี เปิดเครื่องเล่นมีเดียในตัวหรือแอปมีเดียเซิร์ฟเวอร์ แล้วเลือกอุปกรณ์ของคุณตามชื่อจากรายการมีเดียเซิร์ฟเวอร์<br>
4. เรียกดูและเล่น ภาพตัวอย่างจะปรากฏอัตโนมัติ<br><br>

หากทีวีรุ่นเก่าเล่นวิดีโอไม่ได้ ให้ลดคุณภาพใน **การตั้งค่า → การแชร์ → วิดีโอ** เพื่อให้ Everdisk แปลงเป็นรูปแบบที่เข้ากันได้มากกว่า
{{% /details %}}

{{% details title="ฉันจะฟังเพลงของฉันได้อย่างไร?" closed="true" %}}
เปิด **อนุญาตให้เข้าถึงคลังเพลงทั้งหมด** (หรือเพิ่มเพลง) ใต้ **สิ่งที่จะแชร์** แล้วแตะ **Start** จากนั้นคุณสามารถเล่นเพลงของคุณจากเว็บเบราว์เซอร์ของอุปกรณ์อื่น (มีเครื่องเล่นในตัวพร้อมคิว สลับเพลง และเล่นซ้ำ) จากทีวี DLNA หรือใน Everdisk เองด้วยโหมด **เอกสาร → เพลง** เพลงจะแชร์ในคุณภาพต้นฉบับเสมอ
{{% /details %}}

{{% details title="ฉันจะดูหนังใน Everdisk ได้อย่างไร?" closed="true" %}}
แตะวิดีโอใดก็ได้ - ในเอกสารของคุณ โฟลเดอร์ที่เชื่อมต่อ หรือเซิร์ฟเวอร์ในแท็บอุปกรณ์ - แล้วมันจะเล่น **แบบเต็มจอ** ด้วยเครื่องเล่นในตัวของระบบ พร้อมปุ่มควบคุมมาตรฐานรวมถึง **AirPlay**, **Picture in Picture** และ **ความเร็วในการเล่น** เสียงเล่นในเครื่องเล่น **ขนาดเล็ก** ที่ค้างอยู่ด้านล่างของแอปพร้อมคิว สลับเพลง และเล่นซ้ำ
{{% /details %}}

{{% details title="ฉันจะเปิดไฟล์ในเว็บเบราว์เซอร์ได้อย่างไร?" closed="true" %}}
1. ใน **การตั้งค่า → การแชร์ → การเชื่อมต่อ** ตรวจสอบให้แน่ใจว่า **เบราว์เซอร์ (HTTP)** เปิดอยู่<br>
2. แตะ **Start** แล้วคัดลอกที่อยู่ **เบราว์เซอร์** (หรือแสดงโค้ด QR)<br>
3. บนอุปกรณ์อีกเครื่อง เปิดเว็บเบราว์เซอร์ใดก็ได้แล้วพิมพ์ที่อยู่นั้น<br><br>

อีกฝ่ายสามารถเรียกดูแบบกริดหรือรายการ ดูรูปในแกลเลอรีเต็มจอ เล่นเพลง และดาวน์โหลดไฟล์ได้ - รวมถึงดาวน์โหลดทั้งโฟลเดอร์เป็นไฟล์เดียว **Archive.zip** หากคุณเปิด **การแก้ไขไฟล์** ไว้ เขายังอัปโหลดไฟล์กลับมาให้คุณได้ด้วย ไม่ต้องติดตั้งอะไรบนฝั่งของเขา
{{% /details %}}

{{% details title="ฉันจะใช้อุปกรณ์เป็นไดรฟ์เครือข่ายใน Finder ได้อย่างไร?" closed="true" %}}
1. ใน **การตั้งค่า → การแชร์ → การเชื่อมต่อ** ตรวจสอบให้แน่ใจว่า **คอมพิวเตอร์ (WebDAV)** เปิดอยู่ แล้วแตะ **Start**<br>
2. บน Mac เปิด Finder เลือก **Go → Connect to Server** (หรือกด **⌘K**)<br>
3. ป้อนที่อยู่ **คอมพิวเตอร์ (WebDAV)** ที่แสดงใน Everdisk แล้วคลิก **Connect**<br>
4. ป้อนล็อกอินและรหัสผ่านหากคุณตั้งไว้ มิฉะนั้นเชื่อมต่อในฐานะผู้เยี่ยมชม<br><br>

อุปกรณ์ของคุณจะเชื่อมต่อเหมือนไดรฟ์เครือข่ายทั่วไป เมื่อ **การแก้ไขไฟล์** เปิดอยู่ คุณสามารถลากไฟล์ได้ทั้งสองทาง เมื่อปิดอยู่ ไดรฟ์จะเป็นแบบอ่านอย่างเดียว
{{% /details %}}

{{% details title="ฉันจะเชื่อมต่อจาก Windows หรือ Linux ได้อย่างไร?" closed="true" %}}
ใช้ที่อยู่ **คอมพิวเตอร์ (WebDAV)**<br><br>

- **Windows:** เปิด File Explorer → คลิกขวาที่ **This PC** → **Add a network location** (หรือแมปไดรฟ์เครือข่าย) แล้วป้อนที่อยู่ WebDAV<br>
- **Linux:** ในตัวจัดการไฟล์ของคุณเลือก **Connect to Server** แล้วป้อนที่อยู่ WebDAV (เช่นด้วยคำนำหน้า `davs://` หรือ `dav://`)<br><br>

ป้อนล็อกอินและรหัสผ่านหากคุณตั้งไว้
{{% /details %}}

{{% details title="ฉันจะเชื่อมต่อผ่าน SMB ได้อย่างไร?" closed="true" %}}
1. ใน **การตั้งค่า → การแชร์ → การเชื่อมต่อ** ตรวจสอบให้แน่ใจว่า **คอมพิวเตอร์ (ขั้นสูง)** (การเชื่อมต่อ SMB) เปิดอยู่ แล้วแตะ **Start**<br>
2. คัดลอกที่อยู่ **SMB** ที่แสดงบนหน้าจอการแชร์ ซึ่งมีลักษณะเช่น `smb://192.168.1.20:4455/Share`<br>
3. เชื่อมต่อจากคอมพิวเตอร์ของคุณ:<br>
&nbsp;&nbsp;- **Mac:** อุปกรณ์ของคุณจะปรากฏขึ้นเองใน **แถบข้าง Finder** ใต้ **Locations** (Network) เพียงคลิกที่มัน หากต้องการเชื่อมต่อด้วยตัวเองแทน ให้เลือก **Go → Connect to Server** (**⌘K**) แล้วป้อนที่อยู่<br>
&nbsp;&nbsp;- **Windows:** ใน File Explorer คลิกขวาที่ **This PC** แล้วเลือก **Map network drive** จากนั้นป้อน `\\<address>\Share` หรือพิมพ์ที่อยู่ `smb://` ในแถบที่อยู่<br>
&nbsp;&nbsp;- **Linux:** ในตัวจัดการไฟล์ของคุณเลือก **Connect to Server** แล้วป้อนที่อยู่<br>
4. ป้อนล็อกอินและรหัสผ่านหากคุณตั้งไว้ มิฉะนั้นเชื่อมต่อในฐานะผู้เยี่ยมชม<br><br>

แชร์นี้มีชื่อว่า **Share** เมื่อ **การแก้ไขไฟล์** เปิดอยู่ คุณจะคัดลอกไฟล์ได้ทั้งสองทาง เมื่อปิดอยู่ ไดรฟ์จะเป็นแบบอ่านอย่างเดียว
{{% /details %}}

{{% details title="ฉันเข้ารหัสการเชื่อมต่อ SMB ได้ไหม?" closed="true" %}}
ได้ - และ SMB เป็นการเชื่อมต่อ **เดียว** ที่ Everdisk เข้ารหัสได้ ใน **การตั้งค่า → การแชร์** เปิด **ต้องใช้การเข้ารหัส SMB** เพื่อปกป้องการถ่ายโอน SMB ทุกครั้งด้วย **การเข้ารหัส SMB3 (AES)** เพื่อไม่ให้ใครก็ตามบนเครือข่ายเดียวกันอ่านไฟล์ของคุณได้ นี่เป็นตัวเลือกที่ดีบน Wi-Fi ที่คุณไม่ไว้ใจเต็มร้อย<br><br>

ข้อกำหนดบางประการ:<br>
- คุณต้องตั้ง **ล็อกอินและรหัสผ่าน** ก่อน - การเชื่อมต่อที่เข้ารหัสไม่สามารถไม่ระบุตัวตนได้<br>
- ไคลเอนต์ต้องรองรับ **SMB3** - Finder บน Mac รุ่นใหม่ หรือ **Windows 10 ขึ้นไป**<br>
- การเปลี่ยนแปลงจะมีผลในครั้งถัดไปที่คุณเริ่มการแชร์<br><br>

การเข้ารหัส SMB เป็นส่วนหนึ่งของการซื้อ **Premium Lifetime** แบบจ่ายครั้งเดียว
{{% /details %}}

{{% details title="Everdisk ใช้งานได้โดยไม่มี Wi-Fi หรือไม่?" closed="true" %}}
ได้ ด้วย **Mac** และสาย เสียบ iPhone หรือ iPad เข้ากับ Mac แตะ **Trust** หากถูกถาม แล้วแตะ **Start** ที่อยู่ **การเชื่อมต่อผ่านสายเคเบิล** ที่ลงท้ายด้วย `.local` จะปรากฏบนหน้าจอการแชร์ เชื่อมต่อกับมันจาก Finder (**⌘K**) วิธีนี้ใช้ได้โดยไม่มี Wi-Fi เลย - เหมาะบนเครื่องบิน ในโรงแรม หรือบนเครือข่ายที่ถูกล็อก - และเร็วกว่าและเป็นส่วนตัวกว่า Wi-Fi
{{% /details %}}

{{% details title="ฉันใช้สาย USB กับ Windows PC หรือ Android ได้ไหม?" closed="true" %}}
ไม่ได้ การเชื่อมต่อผ่านสายใช้ได้กับ **Mac** เท่านั้น Windows PC และอุปกรณ์ Android เชื่อมต่อผ่าน **Wi-Fi** (บน Windows คุณยังลากไฟล์เข้าโฟลเดอร์ Everdisk ได้โดยใช้แอป Apple Devices หรือ iTunes ผ่านสาย ซึ่งแยกจากการแชร์แบบสด)
{{% /details %}}

{{% details title="ทำไมฉันต้องเปิดแอปค้างไว้ขณะแชร์?" closed="true" %}}
iPhone หรือ iPad ของคุณคือเซิร์ฟเวอร์ และ iOS ไม่อนุญาตให้แอปรันเซิร์ฟเวอร์เครือข่ายค้างไว้เบื้องหลัง การแชร์จึงทำงานได้เฉพาะขณะที่ Everdisk **เปิดอยู่บนหน้าจอ** สำหรับการโอนที่ใช้เวลานาน ให้เปิดแอปไว้เบื้องหน้า เสียบชาร์จ และตั้ง **Auto-Lock** เป็น **Never** ในแอป Settings ของ iOS คุณยังเปิด **แจ้งเตือนก่อนตัดการเชื่อมต่อ** เพื่อให้ Everdisk เตือนคุณก่อนที่ระบบจะหยุดชั่วคราวได้ด้วย

{{% details title="อะไรเร็วกว่ากัน - Wi-Fi หรือสาย?" closed="true" %}}
**สาย USB ต่อกับ Mac** เร็วกว่าและเสถียรกว่า Wi-Fi เพราะข้อมูลวิ่งตรงผ่านสาย มันยังเป็นตัวเลือกที่เป็นส่วนตัวที่สุด เพราะไม่มีอะไรผ่านเราเตอร์หรืออินเทอร์เน็ต ใช้มันสำหรับการโอนรูปภาพและวิดีโอขนาดใหญ่
{{% /details %}}

{{% details title="ห้าเซิร์ฟเวอร์ (DLNA, HTTP, WebDAV, SMB, FTP) ต่างกันอย่างไร?" closed="true" %}}
ทั้งหมดแชร์เนื้อหาเดียวกันแต่เหมาะกับอุปกรณ์ต่างกัน:<br><br>

- **ทีวีและศูนย์มีเดีย (DLNA)** - สำหรับสมาร์ททีวีและเครื่องเล่นมีเดีย<br>
- **เบราว์เซอร์ (HTTP)** - สำหรับเว็บเบราว์เซอร์ใดก็ได้ ไม่ต้องติดตั้งอะไร<br>
- **คอมพิวเตอร์ (WebDAV)** - ทำให้อุปกรณ์ของคุณเป็นไดรฟ์เครือข่ายใน Finder/Windows/Linux<br>
- **คอมพิวเตอร์ (ขั้นสูง)** (SMB) - ไดรฟ์เครือข่ายสำหรับ Mac, Windows และ Linux บน Mac จะปรากฏขึ้นเองในแถบข้าง Finder หรือเชื่อมต่อด้วยตัวเองด้วยที่อยู่ `smb://` เป็นการเชื่อมต่อเดียวที่คุณเข้ารหัสได้ (SMB3, AES)<br>
- **แอปและอุปกรณ์อื่นๆ (FTP)** - สำหรับแอปจัดการไฟล์และเครื่องมือระดับสูง<br><br>

คุณสามารถเปิดหรือปิดแต่ละอันได้ใน **การตั้งค่า → การแชร์ → การเชื่อมต่อ**
{{% /details %}}

{{% details title="ฉันจะป้องกันไฟล์ด้วยรหัสผ่านได้อย่างไร?" closed="true" %}}
ไปที่ **การตั้งค่า → การแชร์ → การเข้าถึง** แล้วตั้ง **ชื่อผู้ใช้** และ **รหัสผ่าน** การเชื่อมต่อเบราว์เซอร์ คอมพิวเตอร์ คอมพิวเตอร์ (ขั้นสูง) และแอปอื่นๆ จะถามรายละเอียดเหล่านั้น ปล่อยว่างทั้งคู่เพื่อให้เข้าถึงได้แบบเปิด<br><br>

หมายเหตุ: การเชื่อมต่อ **DLNA** (ทีวี) ไม่สามารถป้องกันด้วยรหัสผ่านได้ จึงเปิดให้ใครก็ได้บน Wi-Fi เดียวกันขณะที่มันเปิดอยู่ ปิดมันหากคุณต้องการเฉพาะการเชื่อมต่อที่มีการป้องกัน
{{% /details %}}

{{% details title="ฉันจะป้องกันไม่ให้คนอื่นเปลี่ยนแปลงไฟล์ของฉันได้ไหม?" closed="true" %}}
ได้ สวิตช์ **การแก้ไขไฟล์** ใน **การตั้งค่า → การแชร์ → การเข้าถึง** ควบคุมสิ่งนี้ เมื่อ **เปิด** อยู่ (ค่าเริ่มต้น) อุปกรณ์ที่เชื่อมต่อสามารถอัปโหลด เปลี่ยนชื่อ และลบได้ ปิดมันเพื่อทำให้ไฟล์ที่แชร์เป็นแบบ **อ่านอย่างเดียว** - คนอื่นดูและดาวน์โหลดได้แต่เปลี่ยนแปลงอะไรไม่ได้
{{% /details %}}

{{% details title="ฉันจะบล็อกอุปกรณ์ที่ไม่รู้จักได้อย่างไร?" closed="true" %}}
บนหน้าจอ **การแชร์** หาอุปกรณ์ใต้ **ใครเชื่อมต่ออยู่** แตะปุ่มดำเนินการเพิ่มเติมของมัน แล้วเลือก **บล็อกอุปกรณ์นี้** จัดการอุปกรณ์ที่ถูกบล็อกได้ใน **การตั้งค่า → การแชร์ → การเข้าถึง → อุปกรณ์ที่บล็อก** ที่ซึ่งคุณสามารถปลดบล็อกทีละอันหรือ **Unblock All** ได้
{{% /details %}}

{{% details title="ถ้ามีคนลบไฟล์ที่แชร์ มันจะหายไปตลอดกาลไหม?" closed="true" %}}
ไม่ตามค่าเริ่มต้น ไฟล์ที่ถูกลบจะไปอยู่ในถังขยะที่กู้คืนได้ คุณจึงเรียกกลับมาได้ หากคุณต้องการลบทันทีโดยไม่กู้คืน ให้เปิด **ลบไฟล์อย่างถาวร** ใน **การตั้งค่า → ตัวจัดการไฟล์ → กำลังลบไฟล์**
{{% /details %}}

{{% details title="Everdisk เป็นส่วนตัวและปลอดภัยหรือไม่?" closed="true" %}}
ใช่ Everdisk แชร์เฉพาะบน **เครือข่ายท้องถิ่น** ของคุณ - ไม่มีอะไรออกไปสู่อินเทอร์เน็ตและไม่มีบัญชีคลาวด์ เพื่อความเป็นส่วนตัวที่ดีที่สุด ให้แชร์บน Wi-Fi ที่บ้านหรือส่วนตัวที่คุณไว้ใจ เพิ่มล็อกอินและรหัสผ่าน และระมัดระวังบน Wi-Fi สาธารณะ **สาย USB ต่อกับ Mac** เป็นตัวเลือกที่เป็นส่วนตัวที่สุด Everdisk ต้องใช้สิทธิ์ **เครือข่ายภายใน** ของ iOS เพื่อให้อุปกรณ์ใกล้เคียงค้นหามันเจอ
{{% /details %}}

{{% details title="Everdisk เชื่อมต่อกับ NAS หรือเซิร์ฟเวอร์อื่นได้ไหม?" closed="true" %}}
ได้ แท็บ **อุปกรณ์** เชื่อมต่อ **ไปยัง** เซิร์ฟเวอร์อื่นบนเครือข่ายของคุณ แตะ **การเชื่อมต่อใหม่** แล้วเลือก **DLNA / UPnP**, **WebDAV**, **FTP**, **SFTP** หรือ **SMB** (สำหรับ Mac, พีซี Windows, เครื่อง Linux และไดรฟ์ NAS ที่แชร์โฟลเดอร์ผ่าน SMB / CIFS) ป้อนที่อยู่และล็อกอินใด ๆ แล้วคุณก็เรียกดู สตรีม และดาวน์โหลดได้ บนเซิร์ฟเวอร์ WebDAV, FTP, SFTP และ SMB คุณยังสร้างโฟลเดอร์ อัปโหลด เปลี่ยนชื่อ ย้าย และลบได้ด้วย เซิร์ฟเวอร์ DLNA เป็นแบบอ่านอย่างเดียว
{{% /details %}}

{{% details title="ฉันเชื่อมต่อกับที่เก็บข้อมูลบนคลาวด์อย่าง Google Drive หรือ Dropbox ได้ไหม?" closed="true" %}}
Everdisk ไม่ได้ลงชื่อเข้าใช้บัญชีคลาวด์อย่าง iCloud Drive, Google Drive, Dropbox หรือ OneDrive มันเชื่อมต่อเฉพาะกับเซิร์ฟเวอร์ **บนเครือข่ายท้องถิ่นและที่ระบุที่อยู่โดยตรง** (DLNA, WebDAV, FTP, SFTP, SMB) บริการคลาวด์จะเข้าถึงได้ก็ต่อเมื่อมันมีที่อยู่ **WebDAV** ที่คุณสามารถพิมพ์ลงในการเชื่อมต่อ WebDAV ใหม่ได้เท่านั้น

{{% details title="แท็บอุปกรณ์ มีไว้ทำอะไร?" closed="true" %}}
มันคือฝั่งไคลเอนต์ของ Everdisk: **การเชื่อมต่อ** แสดงรายการเซิร์ฟเวอร์ที่คุณบันทึกไว้ และ **อุปกรณ์ที่พร้อมใช้งาน** แสดงรายการเซิร์ฟเวอร์ที่พบอัตโนมัติบนเครือข่ายของคุณ แตะอันหนึ่งเพื่อเรียกดู สตรีม หรือดาวน์โหลดไฟล์ของมัน หรือแตะ **การเชื่อมต่อใหม่** เพื่อเพิ่มเซิร์ฟเวอร์ DLNA, WebDAV, FTP, SFTP หรือ SMB ด้วยตนเอง
{{% /details %}}

{{% details title="ฉันจะดาวน์โหลดไฟล์จากเซิร์ฟเวอร์มายังอุปกรณ์ของฉันได้อย่างไร?" closed="true" %}}
เปิดเซิร์ฟเวอร์ในแท็บ **อุปกรณ์** เรียกดูไปยังสิ่งที่คุณต้องการ แล้วเลือก **ดาวน์โหลด** (เลือกหลายรายการเพื่อดาวน์โหลดเป็นชุด) การดาวน์โหลดทำงานเบื้องหลัง ปรากฏใน **การถ่ายโอนไฟล์** (มุมบนซ้ายของแท็บเอกสาร) และไปอยู่ในโฟลเดอร์ **เอกสาร** ของคุณ
{{% /details %}}

{{% details title="Everdisk มีตัวจัดการไฟล์ไหม?" closed="true" %}}
มี แท็บ **เอกสาร** เป็นตัวจัดการไฟล์ครบครัน คุณสามารถเรียกดูแบบรายการหรือกริด สร้างโฟลเดอร์ เปลี่ยนชื่อ ย้าย คัดลอก อัปโหลด และลบ และเปิดหน้าจอ **ข้อมูล** สำหรับไฟล์ใดก็ได้ การดาวน์โหลดจะมาอยู่ที่นี่ และโฟลเดอร์เอกสารถูกแชร์ไว้เป็นค่าเริ่มต้น

{{% details title="ฉันจะบีบอัด (สร้างไฟล์เก็บถาวร) ไฟล์ได้อย่างไร?" closed="true" %}}
ในแท็บ **เอกสาร** เลือกหนึ่งรายการหรือมากกว่า แล้วเลือก **บีบอัด** รายการเดียวจะถูกบีบอัดเดี่ยว ๆ หลายรายการจะถูกรวมเป็นไฟล์เดียว **Archive.zip** ในเว็บเบราว์เซอร์ คุณยังดาวน์โหลดทั้งโฟลเดอร์หรือหลายรายการที่เลือกเป็น zip ไฟล์เดียวได้ด้วย

{{% /details %}}

{{% details title="Everdisk มีเครื่องมือ PDF อะไรบ้าง?" closed="true" %}}
Everdisk มีชุด **เครื่องมือ PDF** ในตัว เปิดเมนู **•••** ของ PDF ใด ๆ (หรือหน้าจอข้อมูลของมัน) ในแท็บ **เอกสาร** แล้วแตะ **เครื่องมือ PDF** มันแบ่งเป็นสามกลุ่ม:<br><br>

**เพิ่มประสิทธิภาพ**<br>
- **บีบอัด** - ทำให้ PDF เล็กลง คุณจะเห็นขนาดปัจจุบันและขนาดผลลัพธ์โดยประมาณสำหรับแต่ละตัวเลือกก่อนบันทึก<br>
- **การรู้จำข้อความ (OCR)** - เปลี่ยน PDF ที่สแกนให้เป็น **PDF ที่ค้นหาได้** หรือส่งออกเฉพาะข้อความเป็นไฟล์ **.txt**<br>
- **ทำให้แบนราบ** - ฝังคำอธิบายประกอบและรายการในฟอร์มลงในหน้าเพื่อไม่ให้แก้ไขได้อีก<br><br>

**ความปลอดภัย**<br>
- **รหัสผ่าน** - ตั้ง เปลี่ยน หรือลบรหัสผ่านที่ต้องใช้เปิด PDF<br>
- **สิทธิ์** - ตรวจสอบว่า PDF อนุญาตอะไรบ้าง (คัดลอก พิมพ์ แสดงความคิดเห็น และอื่น ๆ)<br><br>

**ข้อมูลเมตา**<br>
- **แก้ไขข้อมูลเมตา** - เปลี่ยนหรือล้างชื่อเรื่อง ผู้เขียน หัวเรื่อง คำสำคัญ และข้อมูลเอกสารอื่น ๆ<br><br>

เครื่องมือ PDF มีให้ใช้ฟรี หาก PDF มีการป้องกันด้วยรหัสผ่าน Everdisk จะถามรหัสผ่านของมันก่อนที่คุณจะใช้เครื่องมือได้
{{% /details %}}

{{% details title="ฉันจะบีบอัด PDF ได้อย่างไร?" closed="true" %}}
เปิดเมนู **•••** ของ PDF → **เครื่องมือ PDF** → **บีบอัด** Everdisk แสดงขนาดไฟล์ปัจจุบันและขนาดโดยประมาณสำหรับแต่ละตัวเลือก:<br><br>

- **มาตรฐาน** ยังคงให้เลือกข้อความได้และบีบอัดเฉพาะรูปภาพใหม่เท่านั้น<br>
- **สูง**, **ปานกลาง**, **Small** และ **Smallest** จะเรนเดอร์หน้าใหม่เป็นรูปภาพที่ความละเอียดต่ำลง - เหมาะที่สุดสำหรับไฟล์สแกนและรูปภาพ แต่ข้อความจะไม่สามารถเลือกได้อีก<br><br>

แตะตัวเลือกที่คุณต้องการ แล้ว Everdisk จะบันทึก PDF ที่เล็กลง
{{% /details %}}

{{% details title="ฉันจะทำให้ PDF ที่สแกนค้นหาได้ (OCR) ได้อย่างไร?" closed="true" %}}
เปิดเมนู **•••** ของ PDF → **เครื่องมือ PDF** → **การรู้จำข้อความ** เลือก **PDF ที่ค้นหาได้** เพื่อเพิ่มเลเยอร์ข้อความที่ซ่อนไว้ เพื่อให้คุณค้นหาและเลือกข้อความได้ (หน้าตายังเหมือนเดิมทุกประการ) หรือ **ไฟล์ข้อความ (.txt)** เพื่อบันทึกเฉพาะข้อความที่จดจำได้ไว้ข้าง PDF ไฟล์ที่ใหญ่หรือสแกนมาอาจใช้เวลาสักครู่
{{% /details %}}

{{% details title="ฉันจะป้องกันไฟล์ PDF ด้วยรหัสผ่านได้อย่างไร?" closed="true" %}}
เปิดเมนู **•••** ของ PDF → **เครื่องมือ PDF** → **รหัสผ่าน** หาก PDF ยังไม่มีการป้องกัน ให้ป้อนรหัสผ่านใหม่และยืนยันเพื่อตั้งค่า หากมีการป้องกันอยู่แล้ว ให้ป้อนรหัสผ่านปัจจุบันเพื่อ **ลบ** หรือ **เปลี่ยน** มัน เก็บรหัสผ่านไว้ในที่ปลอดภัย - PDF ที่มีการป้องกันจะเปิดไม่ได้หากไม่มีมัน<br><br>

สิ่งนี้ป้องกัน **ไฟล์** PDF เอง ซึ่งต่างจาก **ล็อกอินและรหัสผ่าน** ที่ป้องกันเซสชันการแชร์ทั้งหมดของคุณ (ดูคำถามด้านความปลอดภัยด้านบน)
{{% /details %}}

{{% details title="ฉันวาดหรือเซ็นชื่อบน PDF ใน Everdisk ได้ไหม?" closed="true" %}}
ได้ แตะ PDF (หรือรูปภาพ) ในแท็บ **เอกสาร** เพื่อเปิดในตัวดูในตัว จากนั้นใช้เครื่องมือ **Markup** เพื่อ **วาด ไฮไลต์ เพิ่มข้อความและรูปทรง และเซ็นชื่อ** ด้วยนิ้ว การเปลี่ยนแปลงของคุณจะบันทึกกลับลงไฟล์ทันที<br><br>

หากคุณต้องการทำให้เครื่องหมายเหล่านั้นถาวรจนแก้ไขไม่ได้ในภายหลัง ให้เปิด **••• → เครื่องมือ PDF → ทำให้แบนราบ** ของ PDF ในการเพิ่มรหัสผ่าน รัน OCR บีบอัด หรือแก้ไขข้อมูลเอกสาร ให้ใช้ **เครื่องมือ PDF** ตัวอื่น (ดูคำถามด้านบน)
{{% /details %}}

{{% details title="ฉันเชื่อมต่อโฟลเดอร์ที่อยู่ที่อื่นบนอุปกรณ์ของฉันได้ไหม?" closed="true" %}}
ได้ ในแท็บ **เอกสาร** เปิดเมนู ••• แล้วเลือก **เชื่อมต่อโฟลเดอร์** จากนั้นเลือกโฟลเดอร์ใดก็ได้บนอุปกรณ์ของคุณ มันจะปรากฏด้านบนพร้อมป้าย **เชื่อมต่อแล้ว** และแชร์ผ่านเครือข่ายได้เหมือนโฟลเดอร์อื่น ๆ ใช้ **ตัดการเชื่อมต่อ** จากข้อมูลของมันเพื่อยกเลิกการเชื่อมโยง - โฟลเดอร์และไฟล์ยังคงอยู่บนอุปกรณ์ของคุณ
{{% /details %}}

{{% details title="คนอื่นอัปโหลดไฟล์กลับมายังอุปกรณ์ของฉันได้ไหม?" closed="true" %}}
ได้ เมื่อ **การแก้ไขไฟล์** เปิดอยู่ ในเว็บเบราว์เซอร์เขาจะได้แผง **อัปโหลด** บนการเชื่อมต่อ WebDAV หรือ FTP เขาสามารถคัดลอกไฟล์ลงบนอุปกรณ์ของคุณได้ ปิด **การแก้ไขไฟล์** (ใน การตั้งค่า → การแชร์ → การเข้าถึง) เพื่อทำให้การแชร์เป็นแบบอ่านอย่างเดียว
{{% /details %}}

{{% details title="ทำไมรูปภาพหรือวิดีโอถึงโอนช้า?" closed="true" %}}
หาก **รูปแบบ** ของรูปภาพหรือวิดีโอ ถูกตั้งเป็น **เข้ากันได้มากที่สุด** หรือ **คุณภาพ** ต่ำกว่า **ต้นฉบับ** Everdisk จะแปลงแต่ละไฟล์ขณะแชร์ ซึ่งช้ากว่าและใช้แบตเตอรี่มากขึ้น ตั้ง **รูปแบบ** และ **คุณภาพ** เป็น **ต้นฉบับ** ใน **การตั้งค่า → การแชร์** เพื่อการโอนที่เร็วที่สุด และเปลี่ยนเป็นเข้ากันได้มากที่สุดเฉพาะเมื่อทีวีหรือเบราว์เซอร์บางตัวเปิดไฟล์ไม่ได้เท่านั้น
{{% /details %}}

{{% details title="อุปกรณ์ไม่ปรากฏหรือเชื่อมต่อไม่ได้ ฉันควรตรวจสอบอะไร?" closed="true" %}}
- ตรวจสอบให้แน่ใจว่าอุปกรณ์ทั้งสองอยู่บน **เครือข่าย Wi-Fi เดียวกัน** (หรือใช้สายต่อกับ Mac)<br>
- ยืนยันว่าการแชร์ **เริ่มแล้ว** และเซิร์ฟเวอร์ที่ถูกต้อง **เปิดอยู่** ใน การตั้งค่า → การแชร์ → การเชื่อมต่อ<br>
- พิมพ์ที่อยู่ให้ตรงกับที่แสดงบนหน้าจอการแชร์ ทุกประการ ผ่าน Wi-Fi ให้ใช้ IP ที่แสดง และผ่านสายให้ใช้ชื่อ **`.local`** (ห้ามใช้ `localhost`)<br>
- หากคุณตั้งล็อกอินและรหัสผ่าน ให้ป้อนบนอุปกรณ์อีกเครื่อง<br>
- ตรวจสอบว่าสิทธิ์ **เครือข่ายภายใน** ได้รับอนุญาตสำหรับ Everdisk ในแอป Settings ของ iOS<br>
- ตรวจสอบให้แน่ใจว่าอุปกรณ์อีกเครื่องไม่ได้อยู่ใน **อุปกรณ์ที่บล็อก**
{{% /details %}}

{{% details title="ฉันเปลี่ยนชื่อที่อุปกรณ์แสดงบนเครือข่ายได้ไหม?" closed="true" %}}
Everdisk ตั้งชื่อและอวาตาร์ที่เป็นมิตรให้อุปกรณ์ของคุณอัตโนมัติ และคุณสามารถ **Regenerate** ได้ฟรี การตั้งชื่อ ไอคอน ไล่เฉดสี หรืออวาตาร์รูปภาพ **แบบกำหนดเอง** เป็นส่วนหนึ่งของฟีเจอร์ **การปรับแต่งอุปกรณ์** ของ Premium
{{% /details %}}

{{% details title="ฉันเปลี่ยนพอร์ตการเชื่อมต่อได้ไหม?" closed="true" %}}
ค่าเริ่มต้นคือ **HTTP 80**, **WebDAV 8080**, **SMB 4455** และ **FTP 2121** (DLNA เลือกพอร์ตของมันเองอัตโนมัติ) คุณดูมันได้ฟรี และการตั้ง **พอร์ตแบบกำหนดเอง** เป็นฟีเจอร์ของ Premium (**ขั้นสูง** ใน การตั้งค่า → การแชร์)
{{% /details %}}

{{% details title="Everdisk ฟรีไหม และ Premium เพิ่มอะไรบ้าง?" closed="true" %}}
Everdisk ดาวน์โหลด **ฟรี** คุณสามารถรันทั้งห้าเซิร์ฟเวอร์ ป้องกันการเข้าถึงด้วยรหัสผ่าน แชร์คลังรูปภาพและเพลงทั้งหมดของคุณ ใช้ตัวจัดการไฟล์ สแกนเป็น PDF และเชื่อมต่อกับเซิร์ฟเวอร์อื่นได้ เวอร์ชันฟรีแชร์ได้สูงสุด **5 โฟลเดอร์** และบันทึกการเชื่อมต่อเซิร์ฟเวอร์ได้สูงสุด **10 รายการ**<br><br>

การซื้อ **Premium Lifetime** แบบจ่ายครั้งเดียว (ไม่ใช่การสมัครสมาชิก) เพิ่ม: **โฟลเดอร์ไม่จำกัด**, **การเชื่อมต่อไม่จำกัด**, **การแปลงรูปภาพและวิดีโอ** (คุณภาพอื่นนอกจากต้นฉบับ), **การเข้ารหัส SMB** (SMB3/AES), **พอร์ตแบบกำหนดเอง**, **เริ่มการแชร์อัตโนมัติ** และ **การปรับแต่งอุปกรณ์**
{{% /details %}}

{{% details title="Premium เป็นการสมัครสมาชิกไหม? ใช้บนอุปกรณ์อื่นของฉันได้ไหม?" closed="true" %}}
Premium เป็น **การซื้อครั้งเดียว** ไม่ใช่การสมัครสมาชิก - คุณจ่ายครั้งเดียวและไม่มีการต่ออายุ มันผูกกับ Apple ID ของคุณ คุณจึงใช้ **กู้คืนการซื้อ** เพื่อปลดล็อกบนอุปกรณ์อื่นของคุณที่ลงชื่อเข้าใช้ด้วย Apple ID เดียวกันได้
{{% /details %}}
