<div class="hx:mt-6"></div>

Everdisk 把你的 iPhone 或 iPad 變成無線隨身碟，和區域網路上的任何裝置分享檔案、相片、影片和音樂 - 智慧電視、Mac 或 PC、瀏覽器，或另一支手機 - 不需要帳號、不需要雲端，對方也不必安裝任何東西。這份常見問題解答了大家最常問的問題，並帶你走過常見的實際情境。想看逐步操作說明，請參考 [Everdisk 使用指南](/docs/guide/everdisk/)。

<div class="hx:w-full">

{{% details title="什麼是 Everdisk？" closed="true" %}}
Everdisk 是 iPhone 和 iPad 的**無線隨身碟** App。它把你的裝置變成一個中樞，和區域網路上的任何裝置分享你選擇的檔案、相片、影片和音樂，同時也能連接其他伺服器，讓你瀏覽並串流它們的檔案。<br><br>

它同時執行五種伺服器 - 給電視的 **DLNA**、給瀏覽器的 **HTTP**、給 Finder/Windows/Linux 的 **WebDAV**、給 Mac、Windows 和 Linux 上網路磁碟並可選用加密的 **SMB**，以及給檔案 App 的 **FTP** - 讓每台裝置都能用習慣的方式連上。不需要帳號、不需要雲端：只要點一下 **開始** 就準備好了。它還內建檔案管理、媒體播放器、相片圖庫、掃描文件成 PDF，以及壓縮/解壓縮。
{{% /details %}}

{{% details title="Everdisk 如何運作？" closed="true" %}}
當你點一下 **開始**，Everdisk 就會把你的裝置變成區域網路上的伺服器，並分享你選取的內容。五種不同的連接方式同時運作，讓不同裝置用各自偏好的方式連上：<br><br>

- **DLNA** - 智慧電視和媒體播放器會自動找到你的裝置，並以縮圖顯示你的媒體。<br>
- **HTTP** - 任何人都能在瀏覽器打開一個連結，瀏覽和下載你的檔案。<br>
- **WebDAV** - 你的裝置在 Finder、Windows 或 Linux 裡像一般網路磁碟一樣出現。<br>
- **SMB** - 給 Mac、Windows 和 Linux 的網路磁碟，建構在這些系統既有的檔案分享功能上；在 Mac 上會自己出現在 Finder 側邊欄。它是唯一可以加密的連線 (SMB3 加密，AES)。<br>
- **FTP** - 檔案 App 和進階工具透過 FTP 連上。<br><br>

一切都在你的區域 Wi-Fi (或連到 Mac 的 USB 傳輸線) 上進行，永遠不會接觸網際網路。
{{% /details %}}

{{% details title="我需要帳號、登入或網路嗎？" closed="true" %}}
不用。Everdisk 不需要帳號，也不需要網路連線。它完全在你的**區域網路**上運作，或是透過連到 Mac 的 **USB 傳輸線**。沒有任何東西會上傳到雲端。唯一可選的登入，是**你**自己可以設定來為自己的分享加上密碼保護的那一個。
{{% /details %}}

{{% details title="我要怎麼開始分享？" closed="true" %}}
打開 **共享** 分頁，點一下 **分享什麼** 並選擇你的檔案、相片和/或音樂，然後點一下大大的 **開始** 按鈕。接著 **如何連線** 區塊就會顯示其他裝置連上所需的確切位址。點一下 **停止** 就能把一切重新下線。
{{% /details %}}

{{% details title="我可以分享什麼？" closed="true" %}}
三種內容，可任意組合：<br><br>

- **檔案與檔案夾** - App 的文件資料夾 (預設就會分享)，加上你用 **加入檔案夾** 和 **加入檔案** 新增的任何資料夾或個別檔案。<br>
- **相片和影片** - 用 **允許存取整個照片圖庫** 分享你的整個相片庫，或用 **加入照片** 只分享選取的項目。<br>
- **音樂** - 用 **允許存取整個音樂資料庫** 分享你的整個音樂庫，或用 **加入歌曲** 分享選取的歌曲。<br><br>

開始分享前，你必須至少選取一項內容。受保護 (DRM) 和僅存於雲端的曲目無法分享。
{{% /details %}}

{{% details title="我要怎麼把相片分享給電腦？" closed="true" %}}
1. 在 **共享** 畫面，打開 **分享什麼 → 照片與影片** 並開啟 **允許存取整個照片圖庫** (或加入特定相片)。<br>
2. 點一下 **開始**。<br>
3. 在電腦上，可以在任何瀏覽器打開 **瀏覽器** 位址並下載，或從 Finder (Mac) 或檔案總管 (Windows) 連接 **電腦 (WebDAV)** 位址，把相片拖過去。<br><br>

小訣竅：把相片的 **格式** 維持在 **原始**，傳輸最快。
{{% /details %}}

{{% details title="我要怎麼在電視上看我的影片或相片？" closed="true" %}}
1. 在 **設定 → 共享 → 連線**，確認 **電視與媒體中心 (DLNA)** 是開啟的。<br>
2. 點一下 **開始**。<br>
3. 在電視上，打開它內建的媒體播放器或媒體伺服器 App，從媒體伺服器清單裡用名稱挑選你的裝置。<br>
4. 瀏覽並播放。預覽縮圖會自動出現。<br><br>

如果較舊的電視無法播放某部影片，就在 **設定 → 共享 → 影片** 裡調低品質，讓 Everdisk 把它轉換成更相容的格式。
{{% /details %}}

{{% details title="我要怎麼聽我的音樂？" closed="true" %}}
在 **分享什麼** 下開啟 **允許存取整個音樂資料庫** (或加入曲目)，然後 **開始**。接著你就能從另一台裝置的瀏覽器 (內建播放器附佇列、隨機和重複)、從 DLNA 電視，或在 Everdisk 裡用 **文件 → 音樂** 模式播放你的音樂。音樂一律以原始品質分享。
{{% /details %}}

{{% details title="我要怎麼在 Everdisk 裡看影片？" closed="true" %}}
點一下任何影片 - 在你的文件裡、連接的資料夾裡，或「可用裝置」分頁的伺服器裡 - 它就會用內建的系統播放器 **全螢幕** 播放，並有標準控制項，包括 **AirPlay**、**Picture in Picture** 和 **播放速度**。音訊會在 **迷你播放器** 裡播放，它會停在 App 底部，附佇列、隨機和重複。
{{% /details %}}

{{% details title="我要怎麼在瀏覽器開啟我的檔案？" closed="true" %}}
1. 在 **設定 → 共享 → 連線**，確認 **瀏覽器 (HTTP)** 是開啟的。<br>
2. 點一下 **開始** 並複製 **瀏覽器** 位址 (或顯示它的 QR 碼)。<br>
3. 在另一台裝置上，打開任何瀏覽器並輸入那個位址。<br><br>

對方可以用格狀或清單瀏覽、在全螢幕圖庫裡看相片、聽音樂，並下載檔案 - 包括把整個資料夾當成一個 **Archive.zip** 下載。如果你開啟了 **檔案編輯**，他們還能把檔案上傳回來給你。對方完全不必安裝任何東西。
{{% /details %}}

{{% details title="我要怎麼在 Finder 裡把裝置當成網路磁碟？" closed="true" %}}
1. 在 **設定 → 共享 → 連線**，確認 **電腦 (WebDAV)** 是開啟的，然後 **開始**。<br>
2. 在 Mac 上，打開 Finder，選擇 **前往 → 連接伺服器** (或按 **⌘K**)。<br>
3. 輸入 Everdisk 裡顯示的 **電腦 (WebDAV)** 位址並點一下 **連接**。<br>
4. 如果你設了帳號和密碼就輸入；否則以訪客身分連接。<br><br>

你的裝置會像任何網路磁碟一樣掛載。開啟 **檔案編輯** 後可以雙向拖放檔案；關閉它則磁碟為唯讀。
{{% /details %}}

{{% details title="我要怎麼從 Windows 或 Linux 連上？" closed="true" %}}
使用 **電腦 (WebDAV)** 位址。<br><br>

- **Windows：** 打開檔案總管 → 在 **本機** 上按右鍵 → **新增網路位置** (或對應網路磁碟)，然後輸入 WebDAV 位址。<br>
- **Linux：** 在你的檔案管理程式選擇 **連接伺服器**，輸入 WebDAV 位址 (例如加上 `davs://` 或 `dav://` 前綴)。<br><br>

如果你設了帳號和密碼就輸入。
{{% /details %}}

{{% details title="我要怎麼透過 SMB 連接？" closed="true" %}}
1. 在 **設定 → 共享 → 連線**，確認 **電腦（進階）** (SMB 連接) 是開啟的，然後 **開始**。<br>
2. 複製分享畫面上顯示的 **SMB** 位址 - 它看起來像 `smb://192.168.1.20:4455/Share`。<br>
3. 從你的電腦連接：<br>
&nbsp;&nbsp;- **Mac：** 你的裝置會在 **位置** (網路) 底下自己出現在 **Finder 側邊欄** - 直接點一下它就好。若想手動連接，就選擇 **前往 → 連接伺服器** (**⌘K**) 並輸入位址。<br>
&nbsp;&nbsp;- **Windows：** 在檔案總管裡，在 **本機** 上按右鍵並選擇 **對應網路磁碟機**，然後輸入 `\\<address>\Share`，或在位址列輸入 `smb://` 位址。<br>
&nbsp;&nbsp;- **Linux：** 在你的檔案管理程式選擇 **連接伺服器** 並輸入位址。<br>
4. 如果你設了帳號和密碼就輸入，否則以訪客身分連接。<br><br>

共享名稱為 **Share**。開啟 **檔案編輯** 後可以雙向複製檔案；關閉它則磁碟為唯讀。
{{% /details %}}

{{% details title="我可以加密我的 SMB 連接嗎？" closed="true" %}}
可以 - 而且 SMB 是 Everdisk **唯一** 可以加密的連接。在 **設定 → 共享**，開啟 **要求 SMB 加密**，用 **SMB3 加密 (AES)** 保護每一次 SMB 傳輸，讓同一個網路上的其他人都無法讀取你的檔案。這在你不完全信任的 Wi-Fi 上是很好的選擇。<br><br>

幾項要求：<br>
- 你必須先設定 **登入帳號和密碼** - 加密的連接不能匿名。<br>
- 用戶端必須支援 **SMB3** - 新型 Mac 上的 Finder，或 **Windows 10 以上版本**。<br>
- 變更會在你下次開始分享時生效。<br><br>

SMB 加密屬於一次性 **Premium 終身版** 購買的一部分。
{{% /details %}}

{{% details title="Everdisk 沒有 Wi-Fi 也能用嗎？" closed="true" %}}
可以，用 **Mac** 加一條傳輸線就行。把你的 iPhone 或 iPad 接上 Mac，若被詢問就點一下 **信任**，然後點一下 **開始**。分享畫面上會出現一個以 `.local` 結尾的 **傳輸線連接** 位址；從 Finder 連上它 (**⌘K**)。這完全不需要 Wi-Fi - 在飛機上、飯店裡，或受限的網路裡都很好用 - 而且比 Wi-Fi 更快也更私密。
{{% /details %}}

{{% details title="我可以用 USB 傳輸線連接 Windows PC 或 Android 嗎？" closed="true" %}}
不行。傳輸線連接只適用於 **Mac**。Windows PC 和 Android 裝置要透過 **Wi-Fi** 連接。(在 Windows 上，你還是可以用 Apple 裝置 App 或 iTunes 透過傳輸線把檔案拖進 Everdisk 資料夾，那和即時分享是分開的。)
{{% /details %}}

{{% details title="分享時為什麼需要讓 App 保持開啟？" closed="true" %}}
你的 iPhone 或 iPad 就是伺服器，而 iOS 不允許 App 在背景維持網路伺服器運作。所以分享只在 Everdisk **在螢幕上開啟** 時才有效。傳輸較久時，請讓 App 保持在前景、接上電源，並在 iOS 設定 App 裡把 **自動鎖定** 設為 **永不**。你也可以開啟 **中斷連線前通知**，讓 Everdisk 在系統暫停它之前先提醒你。
{{% /details %}}

{{% details title="哪個比較快 - Wi-Fi 還是傳輸線？" closed="true" %}}
連到 Mac 的 **USB 傳輸線** 比 Wi-Fi 更快也更可靠，因為資料直接走傳輸線。它也是最私密的選項，因為沒有任何東西經過你的路由器或網際網路。傳輸大量相片和影片時就用它。
{{% /details %}}

{{% details title="五種伺服器 (DLNA、HTTP、WebDAV、SMB、FTP) 有什麼差別？" closed="true" %}}
它們分享的內容都一樣，但適合不同的裝置：<br><br>

- **電視與媒體中心 (DLNA)** - 給智慧電視和媒體播放器。<br>
- **瀏覽器 (HTTP)** - 給任何瀏覽器，不必安裝。<br>
- **電腦 (WebDAV)** - 讓你的裝置在 Finder/Windows/Linux 裡變成網路磁碟。<br>
- **電腦（進階） (SMB)** - 給 Mac、Windows 和 Linux 的網路磁碟；在 Mac 上會自己出現在 Finder 側邊欄，或用 `smb://` 位址手動連接。它是唯一可以加密的連線 (SMB3，AES)。<br>
- **其他應用程式和裝置 (FTP)** - 給檔案 App 和進階工具。<br><br>

你可以在 **設定 → 共享 → 連線** 裡把它們任意開啟或關閉。
{{% /details %}}

{{% details title="我要怎麼為我的檔案加上密碼保護？" closed="true" %}}
前往 **設定 → 共享 → 存取權**，設定一個 **登入名稱** 和 **密碼**。接著瀏覽器、電腦、電腦（進階）和其他 App 連接都會要求輸入這些資訊。兩者都留空則為開放存取。<br><br>

注意：**DLNA** (電視) 連接無法加上密碼保護，所以只要它開著，同一個 Wi-Fi 上的任何人都能存取。如果你只想要受保護的連接，就把它關掉。
{{% /details %}}

{{% details title="我可以阻止別人更改我的檔案嗎？" closed="true" %}}
可以。**設定 → 共享 → 存取權** 裡的 **檔案編輯** 開關就是控制這個的。開啟時 (預設)，連接的裝置可以上傳、重新命名和刪除。把它 **關閉** 就能讓你分享的檔案變成 **唯讀** - 其他人可以檢視和下載，但不能更改任何東西。
{{% /details %}}

{{% details title="我要怎麼封鎖一個我不認識的裝置？" closed="true" %}}
在 **共享** 畫面，在 **連線的裝置** 下找到那台裝置，點一下它的更多操作按鈕，然後選擇 **封鎖這台裝置**。在 **設定 → 共享 → 存取權 → 已封鎖的裝置** 裡管理被封鎖的裝置，你可以解除封鎖某一台或 **全部解除封鎖**。
{{% /details %}}

{{% details title="如果有人刪除了共享檔案，它就永遠不見了嗎？" closed="true" %}}
預設不會。被刪除的檔案會進入可復原的垃圾桶，讓你能救回來。如果你偏好立即刪除、不留復原機會，就在 **設定 → 檔案管理員 → 正在刪除檔案** 裡開啟 **永久刪除檔案**。
{{% /details %}}

{{% details title="Everdisk 私密又安全嗎？" closed="true" %}}
是的。Everdisk 只在你的 **區域網路** 上分享 - 沒有任何東西會傳到網際網路，也沒有雲端帳號。為了獲得最佳隱私，請在你信任的家用或私人 Wi-Fi 上分享、加上登入帳號和密碼，並在公共 Wi-Fi 上小心留意。連到 Mac 的 **USB 傳輸線** 是所有選項中最私密的。Everdisk 需要 iOS 的 **區域網路** 權限，好讓附近的裝置能找到它。
{{% /details %}}

{{% details title="Everdisk 可以連接我的 NAS 或其他伺服器嗎？" closed="true" %}}
可以。**可用裝置** 分頁能連接 **到** 你網路上的其他伺服器。點一下 **新增連線**，選擇 **DLNA / UPnP**、**WebDAV**、**FTP**、**SFTP** 或 **SMB** (適用於透過 SMB / CIFS 分享資料夾的 Mac、Windows PC、Linux 電腦和 NAS 磁碟)，輸入位址和任何登入資訊，你就能瀏覽、串流和下載。在 WebDAV、FTP、SFTP 和 SMB 伺服器上，你還能建立資料夾、上傳、重新命名、移動和刪除。DLNA 伺服器則為唯讀。
{{% /details %}}

{{% details title="我可以連接像 Google Drive 或 Dropbox 這樣的雲端儲存嗎？" closed="true" %}}
Everdisk 不會登入 iCloud Drive、Google Drive、Dropbox 或 OneDrive 這類雲端帳號。它只連接 **區域網路和直接定址** 的伺服器 (DLNA、WebDAV、FTP、SFTP、SMB)。雲端服務只有在提供一個你可以輸入到新 WebDAV 連線的 **WebDAV** 位址時才連得上。
{{% /details %}}

{{% details title="「可用裝置」分頁是做什麼的？" closed="true" %}}
它是 Everdisk 的用戶端那一面：**連線** 列出你儲存的伺服器，**可用裝置** 列出在你網路上自動找到的伺服器。點一下其中一個就能瀏覽、串流或下載它的檔案，或點一下 **新增連線** 手動加入 DLNA、WebDAV、FTP、SFTP 或 SMB 伺服器。
{{% /details %}}

{{% details title="我要怎麼把檔案從伺服器下載到我的裝置？" closed="true" %}}
在 **可用裝置** 分頁打開伺服器，瀏覽到你要的東西，然後選擇 **下載** (選取多個項目可批次下載)。下載會在背景進行，出現在 **檔案傳輸** 裡 (文件分頁左上角)，並存到你的 **文件** 資料夾。
{{% /details %}}

{{% details title="Everdisk 有檔案管理嗎？" closed="true" %}}
有。**文件** 分頁就是完整的檔案管理員。你可以用清單或格狀瀏覽，建立資料夾、重新命名、移動、複製、上傳和刪除，並為任何檔案打開 **資訊** 畫面。下載會存到這裡，而文件資料夾預設就會分享。
{{% /details %}}

{{% details title="我要怎麼壓縮 (封存) 檔案？" closed="true" %}}
在 **文件** 分頁，選取一個或多個項目，然後選擇 **壓縮**。單一項目會自行壓縮；多個項目會打包成一個 **Archive.zip**。在瀏覽器裡，你也可以把整個資料夾或多個選取的項目下載成單一 zip。
{{% /details %}}

{{% details title="我要怎麼解壓縮封存檔？" closed="true" %}}
在 **文件** 分頁點一下 **.zip** 或 **.rar** 檔，Everdisk 就會把它解壓縮到目前的資料夾，並有一個可取消的進度條。
{{% /details %}}

{{% details title="我要怎麼把文件掃描成 PDF？" closed="true" %}}
在 **文件** 分頁，打開更多操作 (•••) 選單並選擇 **掃描文件**。把相機對準每一頁 - Everdisk 會自動找到邊緣並把頁面拉正 - 所有頁面就會一起存成目前資料夾裡的一個 **多頁 PDF**。你需要一台有相機的裝置。
{{% /details %}}

{{% details title="Everdisk 包含哪些 PDF 工具？" closed="true" %}}
Everdisk 內建一套 **PDF 工具**。在 **文件** 分頁打開任何 PDF 的 **•••** 選單 (或它的資訊畫面)，點一下 **PDF 工具**。它分成三個區塊：<br><br>

**最佳化**<br>
- **壓縮** - 縮小 PDF。儲存前，每個選項都會顯示目前大小和預估結果大小。<br>
- **文字辨識 (OCR)** - 把掃描的 PDF 變成 **可搜尋 PDF**，或只把文字匯出成 **.txt** 檔。<br>
- **平面化** - 把註解和表單內容烙印到頁面上，讓它們無法再被編輯。<br><br>

**安全性**<br>
- **密碼** - 設定、變更或移除開啟 PDF 所需的密碼。<br>
- **權限** - 檢視 PDF 允許哪些操作 (複製、列印、註解等)。<br><br>

**中繼資料**<br>
- **編輯中繼資料** - 變更或清除標題、作者、主旨、關鍵字和其他文件資訊。<br><br>

PDF 工具免費提供。如果 PDF 有密碼保護，Everdisk 會在你使用工具前先要求輸入它的密碼。
{{% /details %}}

{{% details title="我要怎麼壓縮 PDF？" closed="true" %}}
打開 PDF 的 **•••** 選單 → **PDF 工具** → **壓縮**。Everdisk 會顯示目前檔案大小和每個選項的預估大小：<br><br>

- **標準** 會保留文字可選取，只重新壓縮圖片。<br>
- **高**、**中**、**小** 和 **最小** 會把頁面以較低解析度重新算繪成圖片 - 最適合掃描檔和相片，但文字就不再能選取了。<br><br>

點一下你要的選項，Everdisk 就會存下較小的 PDF。
{{% /details %}}

{{% details title="我要怎麼讓掃描的 PDF 變成可搜尋 (OCR)？" closed="true" %}}
打開 PDF 的 **•••** 選單 → **PDF 工具** → **文字辨識**。選擇 **可搜尋 PDF** 來加上一層隱藏的文字層，讓你可以搜尋和選取文字 (頁面看起來完全一樣)，或選擇 **文字檔案 (.txt)** 把辨識出的文字存在 PDF 旁邊。較大或掃描的檔案可能需要一點時間。
{{% /details %}}

{{% details title="我要怎麼為 PDF 檔案加上密碼保護？" closed="true" %}}
打開 PDF 的 **•••** 選單 → **PDF 工具** → **密碼**。如果 PDF 還沒有保護，就輸入新密碼並確認來設定它。如果它已經有保護，就輸入目前的密碼來 **移除** 或 **變更** 它。請把密碼保管在安全的地方 - 沒有它就無法打開受保護的 PDF。<br><br>

這保護的是 PDF **檔案** 本身，和保護你整個分享工作階段的 **登入帳號和密碼** 不同 (見上方的安全性問題)。
{{% /details %}}

{{% details title="我可以在 Everdisk 裡繪圖或簽署 PDF 嗎？" closed="true" %}}
可以。在 **文件** 分頁點一下 PDF (或相片) 用內建檢視器打開，然後用 **加註** 工具來 **繪圖、螢光標記、加文字和圖形，並用手指簽名**。你的變更會直接存回原檔。<br><br>

如果你想讓那些標記變成永久、之後無法再編輯，就打開 PDF 的 **••• → PDF 工具 → 平面化**。想加密碼、跑 OCR、壓縮或編輯文件資訊，就用其他 **PDF 工具** (見上一題)。
{{% /details %}}

{{% details title="我可以連接一個在裝置上其他位置的資料夾嗎？" closed="true" %}}
可以。在 **文件** 分頁，打開 ••• 選單並選擇 **連線檔案夾**，然後挑選裝置上的任何資料夾。它會出現在最上方，帶有 **已連線** 標籤，並能像其他資料夾一樣透過網路分享。從它的資訊裡選 **中斷連線** 就能解除連結 - 資料夾和檔案仍會留在你的裝置上。
{{% /details %}}

{{% details title="別人可以把檔案上傳回我的裝置嗎？" closed="true" %}}
可以，當 **檔案編輯** 開啟時。在瀏覽器裡他們會看到一個 **上傳** 面板；在 WebDAV 或 FTP 連接上，他們可以把檔案複製到你的裝置。把 **檔案編輯** 關閉 (在設定 → 共享 → 存取權) 就能讓分享變成唯讀。
{{% /details %}}

{{% details title="為什麼相片或影片傳輸得很慢？" closed="true" %}}
如果相片或影片的 **格式** 設為 **相容性最高**，或 **品質** 低於 **原始**，Everdisk 會在分享時逐一轉換每個檔案，這會比較慢也更耗電。想要最快的傳輸，就在 **設定 → 共享** 裡把 **格式** 和 **品質** 設為 **原始**，只有在某台特定電視或瀏覽器打不開檔案時才切換到相容性最高。
{{% /details %}}

{{% details title="某台裝置沒出現或連不上，我可以檢查什麼？" closed="true" %}}
- 確認兩台裝置都在 **同一個 Wi-Fi 網路** (或使用 Mac 傳輸線)。<br>
- 確認分享已 **開始**，而且正確的伺服器在 設定 → 共享 → 連線 裡是 **開啟** 的。<br>
- 完全照分享畫面上顯示的輸入位址；透過 Wi-Fi 用顯示的 IP，透過傳輸線用 **`.local`** 名稱 (絕不要用 `localhost`)。<br>
- 如果你設了登入帳號和密碼，就在另一台裝置上輸入。<br>
- 檢查 iOS 設定 App 裡有允許 Everdisk 的 **區域網路** 權限。<br>
- 確認另一台裝置不在 **已封鎖的裝置** 裡。
{{% /details %}}

{{% details title="我可以更改裝置在網路上顯示的名稱嗎？" closed="true" %}}
Everdisk 會自動給你的裝置一個友善的名稱和頭像，你可以免費 **重新產生** 它們。設定 **自訂** 的名稱、圖示、漸層或相片頭像則屬於 Premium 的 **裝置自訂** 功能。
{{% /details %}}

{{% details title="我可以更改連接埠嗎？" closed="true" %}}
預設值是 **HTTP 80**、**WebDAV 8080**、**SMB 4455** 和 **FTP 2121** (DLNA 會自動選它的連接埠)。你可以免費檢視它們，而設定 **自訂連接埠** 屬於 Premium 功能 (設定 → 共享 裡的 **進階**)。
{{% /details %}}

{{% details title="Everdisk 是免費的嗎？Premium 又多了什麼？" closed="true" %}}
Everdisk 是 **免費** 下載。你可以執行全部五種伺服器、用密碼保護存取、分享你的整個相片和音樂庫、使用檔案管理、掃描成 PDF，並連接其他伺服器。免費版最多分享 **5 個資料夾**，並儲存最多 **10 個伺服器連線**。<br><br>

一次性的 **Premium 終身版** 購買 (不是訂閱) 增加了：**無限制檔案夾**、**無限連線**、**照片與影片轉換** (原始以外的品質)、**SMB 加密** (SMB3/AES)、**自訂連接埠**、**自動開始分享**，以及 **裝置自訂**。
{{% /details %}}

{{% details title="Premium 是訂閱嗎？它能在我其他的裝置上使用嗎？" closed="true" %}}
Premium 是 **一次性購買**，不是訂閱 - 你只付一次，永不續訂。它綁定你的 Apple ID，所以你可以用 **回復購買項目** 在你其他以同一個 Apple ID 登入的裝置上解鎖。
{{% /details %}}
