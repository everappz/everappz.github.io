<div class="hx:mt-6"></div>

Everdisk 把你的 iPhone 或 iPad 变成一块无线硬盘，与本地网络上的任何设备共享文件、照片、视频和音乐 - 智能电视、Mac 或 PC、浏览器，或另一部手机 - 无需账户、无需云端，另一端也不用安装任何东西。本常见问题解答了大家问得最多的问题，并演示了常见的实际场景。如需分步说明，请参阅 [Everdisk 用户指南](/docs/guide/everdisk/)。

<div class="hx:w-full">

{{% details title="Everdisk 是什么？" closed="true" %}}
Everdisk 是一款面向 iPhone 和 iPad 的**无线硬盘**应用。它把你的设备变成一个中枢，与本地网络上的任何设备共享你所选的文件、照片、视频和音乐，还能连接到其他服务器，让你浏览和播放它们的文件。<br><br>

它同时运行五种服务器 - **DLNA** 适用于电视，**HTTP** 适用于浏览器，**WebDAV** 适用于 Finder/Windows/Linux，**SMB** 用作 Mac、Windows 和 Linux 上的网络硬盘，可选加密，**FTP** 适用于文件类应用 - 让每台设备都用自己喜欢的方式连接。无需账户、无需云端：只需点击**开始**，即刻就绪。它还包含文件管理器、媒体播放器、照片库、扫描文档转 PDF，以及压缩解压。
{{% /details %}}

{{% details title="Everdisk 如何工作？" closed="true" %}}
当你点击**开始**，Everdisk 会把你的设备变成本地网络上的一台服务器，并共享你所选的内容。五种不同的连接方式同时运行，让不同设备用各自偏好的方式连接：<br><br>

- **DLNA** - 智能电视和媒体播放器会自动找到你的设备，并带缩略图显示你的媒体。<br>
- **HTTP** - 任何人在浏览器中打开链接就能浏览和下载你的文件。<br>
- **WebDAV** - 你的设备在 Finder、Windows 或 Linux 中显示为普通网络硬盘。<br>
- **SMB** - 用作 Mac、Windows 和 Linux 的网络硬盘，基于这些系统已有的文件共享功能；在 Mac 上它会自行出现在 Finder 边栏中。它是唯一可以加密的连接 (SMB3 加密，AES)。<br>
- **FTP** - 文件类应用和高级工具通过 FTP 连接。<br><br>

一切都通过你的本地 Wi-Fi (或连接 Mac 的 USB 线) 进行，绝不接触互联网。
{{% /details %}}

{{% details title="我需要账户、登录或联网吗？" closed="true" %}}
不需要。Everdisk 无需账户，也无需联网。它完全在你的**本地网络**上工作，或通过连接 Mac 的 **USB 线**工作。没有任何内容上传到云端。唯一可选的登录是**你**可以自行设置的，用来给自己的共享加上密码保护。
{{% /details %}}

{{% details title="如何开始共享？" closed="true" %}}
打开**共享**标签页，点击**共享内容**并选择你的文件、照片和/或音乐，然后点击大大的**开始**按钮。随后**如何连接**部分会显示其他设备用来连接的确切地址。点击**停止**即可让一切重新下线。
{{% /details %}}

{{% details title="我能共享哪些内容？" closed="true" %}}
三种内容，可任意组合：<br><br>

- **文件和文件夹** - 应用的文档文件夹 (默认共享)，以及你用**添加文件夹**和**添加文件**加入的任何文件夹或单个文件。<br>
- **照片和视频** - 用**允许访问整个照片图库**共享你的整个照片图库，或用**添加照片**只共享选定的项目。<br>
- **音乐** - 用**允许访问整个音乐库**共享你的整个音乐库，或用**添加曲目**共享选定的歌曲。<br><br>

开始共享前，你必须至少选择一项。受保护 (DRM) 和仅存于云端的曲目无法共享。
{{% /details %}}

{{% details title="如何把照片共享给我的电脑？" closed="true" %}}
1. 在**共享**界面，打开**共享内容 → 照片和视频**，然后开启**允许访问整个照片图库** (或添加特定照片)。<br>
2. 点击**开始**。<br>
3. 在电脑上，可以在任意浏览器中打开**浏览器**地址并下载，或者从 Finder (Mac) 或文件资源管理器 (Windows) 连接到**电脑 (WebDAV)** 地址并把照片拖过去。<br><br>

小提示：把照片**格式**保持为**原始**，传输最快。
{{% /details %}}

{{% details title="如何在电视上观看我的视频或照片？" closed="true" %}}
1. 在**设置 → 共享 → 连接**中，确保**电视和媒体中心 (DLNA)** 已开启。<br>
2. 点击**开始**。<br>
3. 在电视上，打开它内置的媒体播放器或媒体服务器应用，从媒体服务器列表中按名称选择你的设备。<br>
4. 浏览并播放。预览缩略图会自动出现。<br><br>

如果较旧的电视无法播放某个视频，请在**设置 → 共享 → 视频**中降低画质，让 Everdisk 把它转换为更兼容的格式。
{{% /details %}}

{{% details title="如何收听我的音乐？" closed="true" %}}
在**共享内容**下开启**允许访问整个音乐库** (或添加曲目)，然后点击**开始**。之后你就能从另一台设备的浏览器播放你的音乐 (内置播放器支持队列、随机和循环)、从 DLNA 电视播放，或在 Everdisk 自身中通过**文档 → 音乐**模式播放。音乐始终以原始画质共享。
{{% /details %}}

{{% details title="如何在 Everdisk 内观看影片？" closed="true" %}}
点击任意视频 - 无论是你的文档、连接的文件夹，还是设备标签页上的服务器 - 它就会用内置的系统播放器**全屏**播放，并带标准控制，包括 **AirPlay**、**Picture in Picture** 和**播放速度**。音频会在停靠于应用底部的**迷你播放器**中播放，支持队列、随机和循环。
{{% /details %}}

{{% details title="如何在浏览器中打开我的文件？" closed="true" %}}
1. 在**设置 → 共享 → 连接**中，确保**浏览器 (HTTP)** 已开启。<br>
2. 点击**开始**并复制**浏览器**地址 (或显示它的 QR 码)。<br>
3. 在另一台设备上，打开任意浏览器并输入该地址。<br><br>

对方可以以网格或列表浏览、在全屏图库中查看照片、播放音乐并下载文件 - 包括把整个文件夹作为一个 **Archive.zip** 下载。如果你开启了**文件编辑**，他们还能把文件上传回给你。他们那端无需安装任何东西。
{{% /details %}}

{{% details title="如何在 Finder 中把我的设备当作网络硬盘？" closed="true" %}}
1. 在**设置 → 共享 → 连接**中，确保**电脑 (WebDAV)** 已开启，然后点击**开始**。<br>
2. 在 Mac 上，打开 Finder，选择**前往 → 连接服务器** (或按 **⌘K**)。<br>
3. 输入 Everdisk 中显示的**电脑 (WebDAV)** 地址，然后点击**连接**。<br>
4. 如果你设置了登录名和密码，请输入；否则以访客身份连接。<br><br>

你的设备会像任何网络硬盘一样挂载。开启**文件编辑**后，你可以双向拖放文件；关闭后，该硬盘为只读。
{{% /details %}}

{{% details title="如何从 Windows 或 Linux 连接？" closed="true" %}}
使用**电脑 (WebDAV)** 地址。<br><br>

- **Windows：**打开文件资源管理器 → 右键点击**此电脑** → **添加网络位置** (或映射网络硬盘)，然后输入 WebDAV 地址。<br>
- **Linux：**在你的文件管理器中选择**连接服务器**，然后输入 WebDAV 地址 (例如带 `davs://` 或 `dav://` 前缀)。<br><br>

如果你设置了登录名和密码，请一并输入。
{{% /details %}}

{{% details title="如何通过 SMB 连接？" closed="true" %}}
1. 在**设置 → 共享 → 连接**中，确保**电脑（高级）** (即 SMB 连接) 已开启，然后点击**开始**。<br>
2. 复制共享界面上显示的 **SMB** 地址 - 它看起来像 `smb://192.168.1.20:4455/Share`。<br>
3. 从你的电脑连接：<br>
&nbsp;&nbsp;- **Mac：**你的设备会在**位置** (网络) 下自行出现在 **Finder 边栏**中 - 直接点击它即可。若想手动连接，请选择**前往 → 连接服务器** (**⌘K**) 并输入该地址。<br>
&nbsp;&nbsp;- **Windows：**在文件资源管理器中，右键点击**此电脑**并选择**映射网络驱动器**，然后输入 `\\<address>\Share`，或在地址栏中输入 `smb://` 地址。<br>
&nbsp;&nbsp;- **Linux：**在你的文件管理器中选择**连接服务器**并输入该地址。<br>
4. 如果你设置了登录名和密码，请输入；否则以访客身份连接。<br><br>

共享名为 **Share**。开启**文件编辑**后，你可以双向复制文件；关闭后，该硬盘为只读。
{{% /details %}}

{{% details title="我能加密我的 SMB 连接吗？" closed="true" %}}
能 - 而且 SMB 是 Everdisk **唯一**可以加密的连接。在**设置 → 共享**中，开启**要求 SMB 加密**，用 **SMB3 加密 (AES)** 保护每一次 SMB 传输，这样同一网络上的其他人就无法读取你的文件。在你不完全信任的 Wi-Fi 上，这是个很好的选择。<br><br>

有几项要求：<br>
- 你必须先设置**登录名和密码** - 加密连接不能匿名。<br>
- 客户端必须支持 **SMB3** - 现代 Mac 上的 Finder，或 **Windows 10 及更高版本**。<br>
- 更改会在下次开始共享时生效。<br><br>

SMB 加密属于一次性的 **Premium Lifetime** 购买。
{{% /details %}}

{{% details title="Everdisk 没有 Wi-Fi 也能用吗？" closed="true" %}}
能，需要一台 **Mac** 和一根数据线。把你的 iPhone 或 iPad 插到 Mac 上，如有提示请点击**信任**，然后点击**开始**。共享界面上会出现一个以 `.local` 结尾的**数据线连接**地址；从 Finder 连接它 (**⌘K**)。这在完全没有 Wi-Fi 的情况下也能用 - 在飞机上、酒店里或受限网络中都很棒 - 而且比 Wi-Fi 更快、更私密。
{{% /details %}}

{{% details title="我能用 Windows PC 或 Android 通过 USB 线连接吗？" closed="true" %}}
不能。数据线连接仅适用于 **Mac**。Windows PC 和 Android 设备通过 **Wi-Fi** 连接。(在 Windows 上，你仍可以用 Apple 设备应用或 iTunes 通过数据线把文件拖进 Everdisk 文件夹，这与实时共享是两回事。)
{{% /details %}}

{{% details title="为什么共享时需要一直开着应用？" closed="true" %}}
你的 iPhone 或 iPad 就是服务器，而 iOS 不允许应用在后台保持网络服务器运行。所以共享只在 Everdisk **在屏幕上打开**时才有效。对于长时间传输，请让应用保持在前台、插上电源，并在 iOS 设置应用中把**自动锁定**设为**永不**。你还可以开启**断开前提醒**，让 Everdisk 在系统暂停它之前提醒你。
{{% /details %}}

{{% details title="哪个更快 - Wi-Fi 还是数据线？" closed="true" %}}
连接 Mac 的 **USB 数据线**比 Wi-Fi 更快也更可靠，因为数据直接走数据线。它也是最私密的选择，因为没有任何内容经过你的路由器或互联网。大量照片和视频传输时请用它。
{{% /details %}}

{{% details title="五种服务器 (DLNA、HTTP、WebDAV、SMB、FTP) 有什么区别？" closed="true" %}}
它们共享的都是相同内容，但适合不同设备：<br><br>

- **电视和媒体中心 (DLNA)** - 适用于智能电视和媒体播放器。<br>
- **浏览器 (HTTP)** - 适用于任意浏览器，无需安装。<br>
- **电脑 (WebDAV)** - 让你的设备在 Finder/Windows/Linux 中成为网络硬盘。<br>
- **电脑（高级）** (SMB) - 用作 Mac、Windows 和 Linux 的网络硬盘；在 Mac 上它会自行出现在 Finder 边栏中，也可用 `smb://` 地址手动连接。它是唯一可以加密的连接 (SMB3，AES)。<br>
- **其他应用和设备 (FTP)** - 适用于文件类应用和高级工具。<br><br>

你可以在**设置 → 共享 → 连接**中打开或关闭其中任意一项。
{{% /details %}}

{{% details title="如何给我的文件设置密码保护？" closed="true" %}}
进入**设置 → 共享 → 访问**，设置**登录名**和**密码**。之后浏览器、电脑、电脑（高级）和其他应用连接都会要求输入这些信息。两项都留空则为开放访问。<br><br>

注意：**DLNA** (电视) 连接无法设置密码保护，所以只要它开着，同一 Wi-Fi 上的任何人都能访问。如果你只想要受保护的连接，请把它关闭。
{{% /details %}}

{{% details title="我能阻止别人更改我的文件吗？" closed="true" %}}
可以。**设置 → 共享 → 访问**中的**文件编辑**开关负责这一点。开启时 (默认)，连接的设备可以上传、重命名和删除。关闭它可让你的共享文件变为**只读** - 别人可以查看和下载，但不能更改任何内容。
{{% /details %}}

{{% details title="如何拦截一台我不认识的设备？" closed="true" %}}
在**共享**界面，在**已连接的设备**下找到该设备，点击它的更多操作按钮，然后选择**拦截此设备**。在**设置 → 共享 → 访问 → 已拦截的设备**中管理已拦截的设备，你可以逐个解除拦截或**全部解除拦截**。
{{% /details %}}

{{% details title="如果有人删除了共享文件，它就永远没了吗？" closed="true" %}}
默认情况下不会。删除的文件会进入可恢复的回收站，方便你找回。如果你希望立即删除且不可恢复，请在**设置 → 文件管理器 → 删除文件**中开启**永久删除文件**。
{{% /details %}}

{{% details title="Everdisk 私密安全吗？" closed="true" %}}
安全。Everdisk 只在你的**本地网络**上共享 - 没有任何内容发往互联网，也没有云端账户。为获得最佳隐私保护，请在你信任的家庭或私人 Wi-Fi 上共享，加上登录名和密码，并在公共 Wi-Fi 上格外小心。连接 Mac 的 **USB 数据线**是最私密的选择。Everdisk 需要 iOS 的**本地网络**权限，附近的设备才能找到它。
{{% /details %}}

{{% details title="Everdisk 能连接到我的 NAS 或其他服务器吗？" closed="true" %}}
能。**设备**标签页用于连接**到**你网络上的其他服务器。点击**新建连接**并选择 **DLNA / UPnP**、**WebDAV**、**FTP**、**SFTP** 或 **SMB** (适用于通过 SMB / CIFS 共享文件夹的 Mac、Windows PC、Linux 机器和 NAS 硬盘)，输入地址和登录信息，就能浏览、播放和下载。在 WebDAV、FTP、SFTP 和 SMB 服务器上，你还能新建文件夹、上传、重命名、移动和删除。DLNA 服务器为只读。
{{% /details %}}

{{% details title="我能连接到 Google Drive 或 Dropbox 这类云存储吗？" closed="true" %}}
Everdisk 不会登录 iCloud Drive、Google Drive、Dropbox 或 OneDrive 等云账户。它只连接到**本地网络及可直接寻址**的服务器 (DLNA、WebDAV、FTP、SFTP、SMB)。只有当某个云服务提供了可填入新 WebDAV 连接的 **WebDAV** 地址时，才能访问它。
{{% /details %}}

{{% details title="设备标签页是做什么的？" closed="true" %}}
它是 Everdisk 的客户端一侧：**连接**列出你保存的服务器，**可用设备**列出在你网络上自动发现的服务器。点击其中一个即可浏览、播放或下载它的文件，或点击**新建连接**手动添加一个 DLNA、WebDAV、FTP、SFTP 或 SMB 服务器。
{{% /details %}}

{{% details title="如何把服务器上的文件下载到我的设备？" closed="true" %}}
在**设备**标签页上打开该服务器，浏览到你想要的内容，然后选择**下载** (选择多个项目可批量下载)。下载会在后台进行，出现在**文件传输**中 (文档标签页左上角)，并保存到你的**文档**文件夹。
{{% /details %}}

{{% details title="Everdisk 有文件管理器吗？" closed="true" %}}
有。**文档**标签页就是一个完整的文件管理器。你可以列表或网格浏览、新建文件夹、重命名、移动、复制、上传和删除，并打开任意文件的**信息**页。下载会保存到这里，而文档文件夹默认共享。
{{% /details %}}

{{% details title="如何压缩 (归档) 文件？" closed="true" %}}
在**文档**标签页，选择一个或多个项目，然后选择**归档**。单个项目会单独压缩；多个项目会打包成一个 **Archive.zip**。在浏览器中，你也可以把整个文件夹或多个选定项目下载为单个 zip。
{{% /details %}}

{{% details title="如何解压归档？" closed="true" %}}
在**文档**标签页点击 **.zip** 或 **.rar** 文件，Everdisk 就会把它解压到当前文件夹，并带有可取消的进度条。
{{% /details %}}

{{% details title="如何把文档扫描成 PDF？" closed="true" %}}
在**文档**标签页，打开更多操作 (•••) 菜单并选择**扫描文档**。把相机对准每一页 - Everdisk 会自动识别边缘并拉直页面 - 所有页面会一起保存为当前文件夹中的一个**多页 PDF**。你需要一台带相机的设备。
{{% /details %}}

{{% details title="Everdisk 包含哪些 PDF 工具？" closed="true" %}}
Everdisk 内置了一套 **PDF 工具**。在**文档**标签页打开任意 PDF 的 **•••** 菜单 (或它的信息页)，点击 **PDF 工具**。它分为三个部分：<br><br>

**优化**<br>
- **压缩** - 缩小 PDF。每个选项在保存前都会显示当前大小和预估结果大小。<br>
- **文字识别 (OCR)** - 把扫描的 PDF 变成**可搜索的 PDF**，或只把文字导出为 **.txt** 文件。<br>
- **扁平化** - 把批注和表单内容固化到页面上，使其无法再被编辑。<br><br>

**安全**<br>
- **密码** - 设置、更改或移除打开 PDF 所需的密码。<br>
- **权限** - 查看 PDF 允许哪些操作 (复制、打印、批注等)。<br><br>

**元数据**<br>
- **编辑元数据** - 更改或清除标题、作者、主题、关键词和其他文档信息。<br><br>

PDF 工具免费提供。如果某个 PDF 受密码保护，Everdisk 会在你使用工具前要求输入它的密码。
{{% /details %}}

{{% details title="如何压缩 PDF？" closed="true" %}}
打开 PDF 的 **•••** 菜单 → **PDF 工具** → **压缩**。Everdisk 会显示当前文件大小和每个选项的预估大小：<br><br>

- **标准**保留文字可选，只重新压缩图像。<br>
- **高**、**中**、**小**和**最小**会以较低分辨率把页面重新渲染为图像 - 最适合扫描件和照片，但文字将不再可选。<br><br>

点击你想要的选项，Everdisk 就会保存更小的 PDF。
{{% /details %}}

{{% details title="如何让扫描的 PDF 可搜索 (OCR)？" closed="true" %}}
打开 PDF 的 **•••** 菜单 → **PDF 工具** → **文字识别**。选择**可搜索的 PDF** 以添加隐藏的文字层，让你能搜索和选择文字 (页面外观完全不变)，或选择**文本文件 (.txt)** 把识别出的文字单独保存在 PDF 旁边。较大或扫描的文件可能需要一点时间。
{{% /details %}}

{{% details title="如何给 PDF 文件设置密码保护？" closed="true" %}}
打开 PDF 的 **•••** 菜单 → **PDF 工具** → **密码**。如果 PDF 还未受保护，输入新密码并确认即可设置。如果它已受保护，输入当前密码即可**移除**或**更改**它。请把密码妥善保管好 - 受保护的 PDF 没有密码就无法打开。<br><br>

这保护的是 PDF **文件**本身，与保护你整个共享会话的**登录名和密码**不同 (参见上面的安全问题)。
{{% /details %}}

{{% details title="我能在 Everdisk 中给 PDF 绘图或签名吗？" closed="true" %}}
可以。在**文档**标签页点击 PDF (或照片)，在内置查看器中打开，然后用**标注**工具**绘图、高亮、添加文字和形状，并用手指签名**。你的修改会直接保存回原文件。<br><br>

如果你想让这些标记永久化，使其之后无法再被编辑，请打开 PDF 的 **••• → PDF 工具 → 扁平化**。要添加密码、运行 OCR、压缩或编辑文档信息，请使用其他 **PDF 工具** (参见上面的问题)。
{{% /details %}}

{{% details title="我能连接设备上位于其他位置的文件夹吗？" closed="true" %}}
可以。在**文档**标签页，打开 ••• 菜单并选择**连接文件夹**，然后选取设备上的任意文件夹。它会显示在顶部，带有**已连接**标签，并能像其他文件夹一样通过网络共享。从它的信息页使用**断开连接**即可取消链接 - 文件夹和文件仍留在你的设备上。
{{% /details %}}

{{% details title="别人能把文件上传回我的设备吗？" closed="true" %}}
可以，前提是**文件编辑**已开启。在浏览器中他们会看到一个**上传**面板；在 WebDAV 或 FTP 连接上他们可以把文件复制到你的设备。关闭**文件编辑** (在设置 → 共享 → 访问中) 即可让共享变为只读。
{{% /details %}}

{{% details title="为什么某张照片或视频传输很慢？" closed="true" %}}
如果照片或视频的**格式**设为**最兼容**，或**画质**低于**原始**，Everdisk 会在共享每个文件时逐个转换，这会更慢也更耗电。在**设置 → 共享**中把**格式**和**画质**设为**原始**，传输最快；只有当某台特定电视或浏览器无法打开文件时，才切换到最兼容。
{{% /details %}}

{{% details title="某台设备不出现或无法连接。我该检查什么？" closed="true" %}}
- 确保两台设备在**同一个 Wi-Fi 网络**中 (或使用 Mac 数据线)。<br>
- 确认共享已**开始**，且相应服务器已在设置 → 共享 → 连接中**开启**。<br>
- 完全按照共享界面上显示的地址输入；通过 Wi-Fi 时使用显示的 IP，通过数据线时使用 **`.local`** 名称 (绝不要用 `localhost`)。<br>
- 如果你设置了登录名和密码，请在另一台设备上输入。<br>
- 检查 iOS 设置应用中已允许 Everdisk 使用**本地网络**权限。<br>
- 确保另一台设备不在**已拦截的设备**中。
{{% /details %}}

{{% details title="我能更改设备在网络上显示的名称吗？" closed="true" %}}
Everdisk 会自动给你的设备一个友好的名称和头像，你可以免费**重新生成**它们。设置**自定义**名称、图标、渐变或照片头像属于 Premium **设备自定义**功能。
{{% /details %}}

{{% details title="我能更改连接端口吗？" closed="true" %}}
默认端口为 **HTTP 80**、**WebDAV 8080**、**SMB 4455** 和 **FTP 2121** (DLNA 会自动选择端口)。你可以免费查看它们，而设置**自定义端口**是 Premium 功能 (设置 → 共享中的**高级**)。
{{% /details %}}

{{% details title="Everdisk 免费吗，Premium 增加了什么？" closed="true" %}}
Everdisk 可**免费**下载。你可以运行全部五种服务器、用密码保护访问、共享你的整个照片和音乐库、使用文件管理器、扫描转 PDF，并连接到其他服务器。免费版最多共享 **5 个文件夹**，最多保存 **10 个服务器连接**。<br><br>

一次性的 **Premium Lifetime** 购买 (非订阅) 增加了：**无限文件夹**、**无限连接**、**照片和视频转换** (原始以外的画质)、**SMB 加密** (SMB3/AES)、**自定义端口**、**自动开始共享**和**设备自定义**。
{{% /details %}}

{{% details title="Premium 是订阅吗？它能在我的其他设备上使用吗？" closed="true" %}}
Premium 是**一次性购买**，不是订阅 - 你只需付一次，它永不续订。它与你的 Apple ID 绑定，因此你可以用**恢复购买**在其他用同一 Apple ID 登录的设备上解锁。
{{% /details %}}
