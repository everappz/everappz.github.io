<div class="hx:mt-6"></div>

Everdisk는 iPhone이나 iPad를 무선 드라이브로 바꿔 파일, 사진, 동영상, 음악을 로컬 네트워크의 어떤 기기와도 공유해 줍니다 - 스마트 TV, Mac이나 PC, 웹 브라우저, 다른 휴대폰까지 - 계정도, 클라우드도, 상대 기기에 설치할 것도 없습니다. 이 FAQ는 사람들이 가장 많이 묻는 질문에 답하고 흔한 실제 상황을 하나씩 짚어 봅니다. 단계별 안내는 [Everdisk 사용 설명서](/docs/guide/everdisk/)를 참고하세요.

<div class="hx:w-full">

{{% details title="Everdisk란 무엇인가요?" closed="true" %}}
Everdisk는 iPhone과 iPad용 **무선 드라이브** 앱입니다. 기기를 허브로 바꿔 선택한 파일, 사진, 동영상, 음악을 로컬 네트워크의 어떤 기기와도 공유하며, 다른 서버에도 연결해 그 파일을 둘러보고 스트리밍할 수 있습니다.<br><br>

서버 다섯 개를 동시에 실행합니다 - TV를 위한 **DLNA**, 웹 브라우저를 위한 **HTTP**, Finder/Windows/Linux를 위한 **WebDAV**, Mac, Windows, Linux에서 선택적 암호화가 가능한 네트워크 드라이브를 위한 **SMB**, 파일 앱을 위한 **FTP** - 그래서 모든 기기가 각자 편한 방식으로 연결됩니다. 계정도 클라우드도 없습니다. **시작**을 탭하면 바로 준비됩니다. 파일 관리자, 미디어 플레이어, 사진 갤러리, 문서를 PDF로 스캔하기, 압축/압축 해제도 포함되어 있습니다.
{{% /details %}}

{{% details title="Everdisk는 어떻게 작동하나요?" closed="true" %}}
**시작**을 탭하면 Everdisk가 기기를 로컬 네트워크의 서버로 바꿔 선택한 콘텐츠를 공유합니다. 서로 다른 기기가 각자 선호하는 방식으로 연결될 수 있도록 다섯 가지 연결 방식이 동시에 실행됩니다.<br><br>

- **DLNA** - 스마트 TV와 미디어 플레이어가 기기를 자동으로 찾아 미디어를 썸네일과 함께 보여 줍니다.<br>
- **HTTP** - 누구든 웹 브라우저에서 링크를 열어 파일을 둘러보고 내려받습니다.<br>
- **WebDAV** - 기기가 Finder나 Windows, Linux에서 일반 네트워크 드라이브처럼 나타납니다.<br>
- **SMB** - Mac, Windows, Linux를 위한 네트워크 드라이브로, 그 시스템에 이미 있는 파일 공유 기능을 기반으로 합니다. Mac에서는 Finder 사이드바에 자동으로 나타납니다. 암호화할 수 있는 유일한 연결입니다(SMB3 암호화, AES).<br>
- **FTP** - 파일 앱과 전문 도구가 FTP로 연결됩니다.<br><br>

모든 것이 로컬 Wi-Fi(또는 Mac에 연결한 USB 케이블)를 통해 이루어지며 인터넷에는 절대 닿지 않습니다.
{{% /details %}}

{{% details title="계정이나 로그인, 인터넷이 필요한가요?" closed="true" %}}
아니요. Everdisk는 계정도 인터넷 연결도 필요 없습니다. 전적으로 **로컬 네트워크**에서, 또는 Mac에 연결한 **USB 케이블**로 작동합니다. 어떤 클라우드에도 아무것도 업로드되지 않습니다. 유일하게 선택 가능한 로그인은 **본인**이 자신의 공유를 비밀번호로 보호하기 위해 설정하는 것뿐입니다.
{{% /details %}}

{{% details title="공유는 어떻게 시작하나요?" closed="true" %}}
**공유** 탭을 열고 **공유할 항목**을 탭해 파일, 사진, 음악을 고른 뒤, 큰 **시작** 버튼을 탭하세요. 그러면 **연결 방법** 섹션에 다른 기기가 연결할 때 사용하는 정확한 주소가 표시됩니다. 다시 모두 오프라인으로 돌리려면 **중지**를 탭하세요.
{{% /details %}}

{{% details title="무엇을 공유할 수 있나요?" closed="true" %}}
세 가지 종류의 콘텐츠를, 어떤 조합으로든 공유할 수 있습니다.<br><br>

- **파일과 폴더** - 앱의 문서 폴더(기본으로 공유됨)와 **폴더 추가**, **파일 추가**로 더한 폴더나 개별 파일.<br>
- **사진과 동영상** - **모든 사진 라이브러리 접근 허용**으로 사진 라이브러리 전체, 또는 **사진 추가**로 선택한 항목만.<br>
- **음악** - **모든 음악 라이브러리 접근 허용**으로 음악 라이브러리 전체, 또는 **트랙 추가**로 선택한 곡만.<br><br>

공유를 시작하려면 적어도 하나는 선택해야 합니다. 보호된(DRM) 곡과 클라우드에만 있는 곡은 공유할 수 없습니다.
{{% /details %}}

{{% details title="컴퓨터와 사진을 어떻게 공유하나요?" closed="true" %}}
1. **공유** 화면에서 **공유할 항목 → 사진과 동영상**을 열고 **모든 사진 라이브러리 접근 허용**을 켜세요(또는 특정 사진을 추가).<br>
2. **시작**을 탭하세요.<br>
3. 컴퓨터에서 어떤 웹 브라우저로든 **브라우저** 주소를 열어 내려받거나, Finder(Mac)나 파일 탐색기(Windows)에서 **컴퓨터(WebDAV)** 주소에 연결해 사진을 끌어다 놓으세요.<br><br>

팁: 가장 빠른 전송을 위해 사진 **형식**을 **원본**으로 두세요.
{{% /details %}}

{{% details title="TV에서 동영상이나 사진을 어떻게 보나요?" closed="true" %}}
1. **설정 → 공유 → 연결**에서 **TV & 미디어 센터(DLNA)**가 켜져 있는지 확인하세요.<br>
2. **시작**을 탭하세요.<br>
3. TV에서 내장 미디어 플레이어나 미디어 서버 앱을 열고 미디어 서버 목록에서 이름으로 기기를 고르세요.<br>
4. 둘러보고 재생하세요. 미리 보기 썸네일이 자동으로 나타납니다.<br><br>

오래된 TV가 동영상을 재생하지 못하면 **설정 → 공유 → 동영상**에서 화질을 낮추세요. 그러면 Everdisk가 더 호환되는 형식으로 변환합니다.
{{% /details %}}

{{% details title="음악은 어떻게 듣나요?" closed="true" %}}
**공유할 항목**에서 **모든 음악 라이브러리 접근 허용**을 켜고(또는 트랙을 추가) **시작**을 누르세요. 그러면 다른 기기의 웹 브라우저(대기열, 셔플, 반복이 있는 내장 플레이어가 있습니다), DLNA TV, 또는 **문서 → 음악** 모드를 사용해 Everdisk 자체에서 음악을 재생할 수 있습니다. 음악은 항상 원본 화질로 공유됩니다.
{{% /details %}}

{{% details title="Everdisk 안에서 영화를 어떻게 보나요?" closed="true" %}}
어떤 동영상이든 탭하면 - 문서, 연결된 폴더, 장치 탭의 서버 어디에 있든 - 내장 시스템 플레이어로 **전체 화면** 재생되며 **AirPlay**, **Picture in Picture**, **재생 속도**를 포함한 표준 컨트롤을 사용할 수 있습니다. 오디오는 대기열, 셔플, 반복이 있는 **미니 플레이어**에서 앱 하단에 계속 머물며 재생됩니다.
{{% /details %}}

{{% details title="웹 브라우저에서 파일을 어떻게 여나요?" closed="true" %}}
1. **설정 → 공유 → 연결**에서 **브라우저(HTTP)**가 켜져 있는지 확인하세요.<br>
2. **시작**을 탭하고 **브라우저** 주소를 복사하세요(또는 QR 코드를 표시).<br>
3. 다른 기기에서 아무 웹 브라우저나 열어 그 주소를 입력하세요.<br><br>

상대는 격자나 목록으로 둘러보고, 전체 화면 갤러리로 사진을 보고, 음악을 재생하고, 파일을 내려받을 수 있으며 - 폴더 전체를 하나의 **Archive.zip**으로 내려받는 것도 포함됩니다. **파일 편집**을 켜 두었다면 상대가 파일을 다시 업로드할 수도 있습니다. 상대 쪽에 설치할 것은 없습니다.
{{% /details %}}

{{% details title="Finder에서 기기를 네트워크 드라이브로 어떻게 쓰나요?" closed="true" %}}
1. **설정 → 공유 → 연결**에서 **컴퓨터(WebDAV)**가 켜져 있는지 확인한 뒤 **시작**하세요.<br>
2. Mac에서 Finder를 열고 **이동 → 서버에 연결**을 선택하세요(또는 **⌘K**를 누르세요).<br>
3. Everdisk에 표시된 **컴퓨터(WebDAV)** 주소를 입력하고 **연결**을 클릭하세요.<br>
4. 로그인과 비밀번호를 설정했다면 입력하고, 아니면 게스트로 연결하세요.<br><br>

기기가 일반 네트워크 드라이브처럼 마운트됩니다. **파일 편집**이 켜져 있으면 양방향으로 파일을 끌어다 놓을 수 있고, 꺼져 있으면 드라이브가 읽기 전용입니다.
{{% /details %}}

{{% details title="Windows나 Linux에서는 어떻게 연결하나요?" closed="true" %}}
**컴퓨터(WebDAV)** 주소를 사용하세요.<br><br>

- **Windows:** 파일 탐색기를 열고 → **내 PC**를 오른쪽 클릭 → **네트워크 위치 추가**(또는 네트워크 드라이브 매핑)를 선택한 뒤 WebDAV 주소를 입력하세요.<br>
- **Linux:** 파일 관리자에서 **서버에 연결**을 선택하고 WebDAV 주소를 입력하세요(예: `davs://`나 `dav://` 접두어와 함께).<br><br>

로그인과 비밀번호를 설정했다면 입력하세요.
{{% /details %}}

{{% details title="SMB로 어떻게 연결하나요?" closed="true" %}}
1. **설정 → 공유 → 연결**에서 **컴퓨터(고급)**(SMB 연결)이 켜져 있는지 확인한 뒤 **시작**하세요.<br>
2. 공유 화면에 표시된 **SMB** 주소를 복사하세요 - `smb://192.168.1.20:4455/Share`처럼 보입니다.<br>
3. 컴퓨터에서 연결하세요:<br>
&nbsp;&nbsp;- **Mac:** 기기가 **Finder 사이드바**의 **위치**(네트워크)에 자동으로 나타납니다 - 클릭만 하면 됩니다. 직접 연결하려면 **이동 → 서버에 연결**(**⌘K**)을 선택하고 주소를 입력하세요.<br>
&nbsp;&nbsp;- **Windows:** 파일 탐색기에서 **내 PC**를 오른쪽 클릭하고 **네트워크 드라이브 매핑**을 선택한 뒤 `\\<address>\Share`를 입력하거나, 주소 표시줄에 `smb://` 주소를 입력하세요.<br>
&nbsp;&nbsp;- **Linux:** 파일 관리자에서 **서버에 연결**을 선택하고 주소를 입력하세요.<br>
4. 로그인과 비밀번호를 설정했다면 입력하고, 아니면 게스트로 연결하세요.<br><br>

공유 이름은 **Share**입니다. **파일 편집**이 켜져 있으면 양방향으로 파일을 복사할 수 있고, 꺼져 있으면 드라이브가 읽기 전용입니다.
{{% /details %}}

{{% details title="SMB 연결을 암호화할 수 있나요?" closed="true" %}}
네 - 그리고 SMB는 Everdisk가 암호화할 수 있는 **유일한** 연결입니다. **설정 → 공유**에서 **SMB 암호화 요구**를 켜면 모든 SMB 전송이 **SMB3 암호화(AES)**로 보호되어 같은 네트워크의 다른 누구도 파일을 읽을 수 없습니다. 완전히 신뢰하기 어려운 Wi-Fi에서 훌륭한 선택입니다.<br><br>

몇 가지 요구 사항:<br>
- 먼저 **로그인과 비밀번호**를 설정해야 합니다 - 암호화된 연결은 익명일 수 없습니다.<br>
- 클라이언트가 **SMB3**를 지원해야 합니다 - 최신 Mac의 Finder, 또는 **Windows 10 이상**.<br>
- 변경 사항은 다음번에 공유를 시작할 때 적용됩니다.<br><br>

SMB 암호화는 일회성 **Premium Lifetime** 구매에 포함됩니다.
{{% /details %}}

{{% details title="Everdisk는 Wi-Fi 없이도 되나요?" closed="true" %}}
네, **Mac**과 케이블만 있으면 됩니다. iPhone이나 iPad를 Mac에 꽂고, 물어보면 **신뢰**를 탭한 뒤 **시작**을 탭하세요. 공유 화면에 `.local`로 끝나는 **케이블 연결** 주소가 나타납니다. Finder(**⌘K**)에서 그 주소로 연결하세요. Wi-Fi가 전혀 없어도 됩니다 - 비행기 안이나 호텔, 잠긴 네트워크에서 유용하며 - Wi-Fi보다 빠르고 더 비공개입니다.
{{% /details %}}

{{% details title="USB 케이블을 Windows PC나 Android와 쓸 수 있나요?" closed="true" %}}
아니요. 케이블 연결은 **Mac**에서만 됩니다. Windows PC와 Android 기기는 **Wi-Fi**로 연결합니다. (Windows에서는 여전히 Apple Devices 앱이나 iTunes로 케이블을 통해 Everdisk 폴더에 파일을 끌어다 넣을 수 있는데, 이는 실시간 공유와는 별개입니다.)
{{% /details %}}

{{% details title="공유하는 동안 왜 앱을 계속 열어 두어야 하나요?" closed="true" %}}
iPhone이나 iPad가 서버이기 때문인데, iOS는 앱이 백그라운드에서 네트워크 서버를 계속 실행하도록 허용하지 않습니다. 그래서 공유는 Everdisk가 **화면에 열려 있는** 동안에만 됩니다. 긴 전송을 할 때는 앱을 앞에 두고, 전원에 연결하고, iOS 설정 앱에서 **자동 잠금**을 **안 함**으로 설정하세요. **연결 끊기 전 알림**을 켜 두면 시스템이 앱을 일시 중지하기 전에 Everdisk가 알려 줍니다.
{{% /details %}}

{{% details title="Wi-Fi와 케이블 중 어느 쪽이 더 빠른가요?" closed="true" %}}
데이터가 케이블을 통해 바로 가기 때문에 **Mac에 연결한 USB 케이블**이 Wi-Fi보다 빠르고 안정적입니다. 라우터나 인터넷을 아무것도 거치지 않으므로 가장 비공개인 방법이기도 합니다. 큰 사진과 동영상을 전송할 때 사용하세요.
{{% /details %}}

{{% details title="서버 다섯 개(DLNA, HTTP, WebDAV, SMB, FTP)의 차이는 무엇인가요?" closed="true" %}}
모두 같은 콘텐츠를 공유하지만 각기 다른 기기에 맞습니다.<br><br>

- **TV & 미디어 센터(DLNA)** - 스마트 TV와 미디어 플레이어용.<br>
- **브라우저(HTTP)** - 모든 웹 브라우저용, 설치 필요 없음.<br>
- **컴퓨터(WebDAV)** - 기기를 Finder/Windows/Linux에서 네트워크 드라이브로 만듦.<br>
- **컴퓨터(고급)**(SMB) - Mac, Windows, Linux를 위한 네트워크 드라이브. Mac에서는 Finder 사이드바에 자동으로 나타나고, 직접 `smb://` 주소로 연결할 수도 있습니다. 암호화할 수 있는 유일한 연결입니다(SMB3, AES).<br>
- **기타 앱과 기기(FTP)** - 파일 앱과 전문 도구용.<br><br>

**설정 → 공유 → 연결**에서 각각을 켜거나 끌 수 있습니다.
{{% /details %}}

{{% details title="파일을 비밀번호로 어떻게 보호하나요?" closed="true" %}}
**설정 → 공유 → 접근**으로 가서 **로그인**과 **비밀번호**를 설정하세요. 그러면 브라우저, 컴퓨터, 컴퓨터(고급), 기타 앱 연결이 그 정보를 요청합니다. 열린 접근을 원하면 둘 다 비워 두세요.<br><br>

참고: **DLNA**(TV) 연결은 비밀번호로 보호할 수 없어, 켜져 있는 동안 같은 Wi-Fi에 있는 누구에게나 열려 있습니다. 보호된 연결만 원하면 이를 끄세요.
{{% /details %}}

{{% details title="다른 사람이 내 파일을 바꾸지 못하게 할 수 있나요?" closed="true" %}}
네. **설정 → 공유 → 접근**의 **파일 편집** 토글로 이를 제어합니다. **켜져** 있으면(기본값) 연결된 기기가 업로드, 이름 바꾸기, 삭제를 할 수 있습니다. **꺼서** 공유 파일을 **읽기 전용**으로 만들면 - 다른 사람은 보고 내려받을 수는 있지만 아무것도 바꿀 수 없습니다.
{{% /details %}}

{{% details title="모르는 기기를 어떻게 차단하나요?" closed="true" %}}
**공유** 화면에서 **연결된 사용자** 아래에서 그 기기를 찾아 추가 작업 버튼을 탭하고 **이 기기 차단**을 선택하세요. 차단된 기기는 **설정 → 공유 → 접근 → 차단된 기기**에서 관리할 수 있으며, 개별 차단 해제나 **모두 차단 해제**가 가능합니다.
{{% /details %}}

{{% details title="누군가 공유 파일을 삭제하면 영영 사라지나요?" closed="true" %}}
기본적으로는 아닙니다. 삭제된 파일은 복구 가능한 휴지통으로 가므로 되찾을 수 있습니다. 복구 없이 즉시 삭제되기를 원하면 **설정 → 파일 관리자 → 파일 삭제**에서 **파일 영구 삭제**를 켜세요.
{{% /details %}}

{{% details title="Everdisk는 비공개이고 안전한가요?" closed="true" %}}
네. Everdisk는 **로컬 네트워크**로만 공유합니다 - 인터넷으로 나가는 것은 아무것도 없고 클라우드 계정도 없습니다. 최고의 프라이버시를 위해서는 신뢰하는 집이나 개인 Wi-Fi에서 공유하고, 로그인과 비밀번호를 추가하고, 공용 Wi-Fi에서는 주의하세요. **Mac에 연결한 USB 케이블**이 가장 비공개인 방법입니다. Everdisk는 주변 기기가 앱을 찾을 수 있도록 iOS **로컬 네트워크** 권한이 필요합니다.
{{% /details %}}

{{% details title="Everdisk가 내 NAS나 다른 서버에 연결할 수 있나요?" closed="true" %}}
네. **장치** 탭이 네트워크에 있는 다른 서버**에** 연결합니다. **새 연결**을 탭하고 **DLNA / UPnP**, **WebDAV**, **FTP**, **SFTP** 또는 **SMB**(SMB / CIFS로 폴더를 공유하는 Mac, Windows PC, Linux 컴퓨터, NAS 드라이브용) 중에서 고른 뒤 주소와 로그인을 입력하면 둘러보고, 스트리밍하고, 내려받을 수 있습니다. WebDAV, FTP, SFTP, SMB 서버에서는 폴더 만들기, 업로드, 이름 바꾸기, 옮기기, 삭제도 할 수 있습니다. DLNA 서버는 읽기 전용입니다.
{{% /details %}}

{{% details title="Google Drive나 Dropbox 같은 클라우드 저장소에 연결할 수 있나요?" closed="true" %}}
Everdisk는 iCloud Drive, Google Drive, Dropbox, OneDrive 같은 클라우드 계정에는 로그인하지 않습니다. **로컬 네트워크와 직접 주소로 지정된** 서버(DLNA, WebDAV, FTP, SFTP, SMB)에만 연결합니다. 클라우드 서비스는 새 WebDAV 연결에 입력할 수 있는 **WebDAV** 주소를 제공할 때만 접근할 수 있습니다.
{{% /details %}}

{{% details title="장치 탭은 무엇을 하는 곳인가요?" closed="true" %}}
Everdisk의 클라이언트 쪽입니다. **연결**은 저장한 서버를 보여 주고, **사용 가능한 장치**는 네트워크에서 자동으로 찾은 서버를 보여 줍니다. 하나를 탭해 파일을 둘러보고, 스트리밍하고, 내려받거나, **새 연결**을 탭해 DLNA, WebDAV, FTP, SFTP, SMB 서버를 직접 추가하세요.
{{% /details %}}

{{% details title="서버에서 기기로 파일을 어떻게 내려받나요?" closed="true" %}}
**장치** 탭에서 서버를 열고 원하는 것을 찾아 **다운로드**를 선택하세요(여러 항목을 골라 일괄 처리 가능). 다운로드는 백그라운드에서 실행되고, **파일 전송**(문서 탭 왼쪽 위)에 나타나며, **문서** 폴더에 저장됩니다.
{{% /details %}}

{{% details title="Everdisk에 파일 관리자가 있나요?" closed="true" %}}
네. **문서** 탭이 완전한 파일 관리자입니다. 목록이나 격자로 둘러보고, 폴더를 만들고, 이름을 바꾸고, 옮기고, 복사하고, 업로드하고, 삭제할 수 있으며, 어떤 파일이든 **정보** 화면을 열 수 있습니다. 다운로드는 여기에 저장되고, 문서 폴더는 기본으로 공유됩니다.
{{% /details %}}

{{% details title="파일을 어떻게 압축(아카이브)하나요?" closed="true" %}}
**문서** 탭에서 하나 이상의 항목을 선택하고 **아카이브**를 고르세요. 항목이 하나면 그것만 압축되고, 여러 개면 하나의 **Archive.zip**으로 묶입니다. 웹 브라우저에서는 폴더 전체나 선택한 여러 항목을 하나의 zip으로 내려받을 수도 있습니다.
{{% /details %}}

{{% details title="압축 파일을 어떻게 푸나요?" closed="true" %}}
**문서** 탭에서 **.zip**이나 **.rar** 파일을 탭하면 Everdisk가 현재 폴더에 압축을 풀며, 취소할 수 있는 진행 표시줄이 나타납니다.
{{% /details %}}

{{% details title="문서를 PDF로 어떻게 스캔하나요?" closed="true" %}}
**문서** 탭에서 추가 작업(•••) 메뉴를 열고 **문서 스캔**을 선택하세요. 카메라를 각 페이지에 향하면 - Everdisk가 가장자리를 찾아 페이지를 자동으로 반듯하게 펴고 - 모든 페이지가 현재 폴더에 하나의 **여러 페이지 PDF**로 함께 저장됩니다. 카메라가 있는 기기가 필요합니다.
{{% /details %}}

{{% details title="Everdisk에는 어떤 PDF 도구가 있나요?" closed="true" %}}
Everdisk에는 내장 **PDF 도구** 모음이 있습니다. **문서** 탭에서 어떤 PDF의 **•••** 메뉴(또는 정보 화면)를 열고 **PDF 도구**를 탭하세요. 세 영역으로 나뉩니다.<br><br>

**최적화**<br>
- **압축** - PDF를 더 작게 만듭니다. 저장하기 전에 각 옵션의 현재 크기와 예상 결과 크기를 볼 수 있습니다.<br>
- **텍스트 인식(OCR)** - 스캔한 PDF를 **검색 가능한 PDF**로 만들거나, 텍스트만 **.txt** 파일로 내보냅니다.<br>
- **병합** - 주석과 양식 입력을 페이지에 새겨 넣어 더 이상 편집할 수 없게 합니다.<br><br>

**보안**<br>
- **비밀번호** - PDF를 열 때 필요한 비밀번호를 설정하거나 변경하거나 제거합니다.<br>
- **권한** - PDF가 허용하는 것(복사, 인쇄, 주석 달기 등)을 확인합니다.<br><br>

**메타데이터**<br>
- **메타데이터 편집** - 제목, 작성자, 주제, 키워드 및 기타 문서 정보를 변경하거나 지웁니다.<br><br>

PDF 도구는 무료로 포함되어 있습니다. PDF가 비밀번호로 보호되어 있으면 Everdisk가 도구를 사용하기 전에 그 비밀번호를 요청합니다.
{{% /details %}}

{{% details title="PDF를 어떻게 압축하나요?" closed="true" %}}
PDF의 **•••** 메뉴 → **PDF 도구** → **압축**을 여세요. Everdisk가 현재 파일 크기와 각 옵션의 예상 크기를 보여 줍니다.<br><br>

- **표준**은 텍스트를 선택 가능한 상태로 유지하고 이미지만 다시 압축합니다.<br>
- **높음**, **중간**, **작게**, **가장 작게**는 페이지를 더 낮은 해상도의 이미지로 다시 렌더링합니다 - 스캔본과 사진에 가장 좋지만, 텍스트는 더 이상 선택할 수 없습니다.<br><br>

원하는 옵션을 탭하면 Everdisk가 더 작은 PDF를 저장합니다.
{{% /details %}}

{{% details title="스캔한 PDF를 어떻게 검색 가능하게(OCR) 만드나요?" closed="true" %}}
PDF의 **•••** 메뉴 → **PDF 도구** → **텍스트 인식**을 여세요. **검색 가능한 PDF**를 선택하면 숨겨진 텍스트 레이어가 추가되어 텍스트를 검색하고 선택할 수 있고(페이지 모습은 그대로입니다), **텍스트 파일(.txt)**을 선택하면 인식된 텍스트만 PDF 옆에 저장됩니다. 크거나 스캔한 파일은 시간이 조금 걸릴 수 있습니다.
{{% /details %}}

{{% details title="PDF 파일을 어떻게 비밀번호로 보호하나요?" closed="true" %}}
PDF의 **•••** 메뉴 → **PDF 도구** → **비밀번호**를 여세요. PDF가 아직 보호되지 않았다면 새 비밀번호를 입력하고 확인해 설정하세요. 이미 보호되어 있다면 현재 비밀번호를 입력해 **제거**하거나 **변경**하세요. 비밀번호는 안전한 곳에 보관하세요 - 보호된 PDF는 비밀번호 없이 열 수 없습니다.<br><br>

이것은 PDF **파일** 자체를 보호하는 것으로, 공유 세션 전체를 보호하는 **로그인과 비밀번호**(위 보안 질문 참고)와는 다릅니다.
{{% /details %}}

{{% details title="Everdisk에서 PDF에 그리거나 서명할 수 있나요?" closed="true" %}}
네. **문서** 탭에서 PDF(또는 사진)를 탭해 내장 뷰어에서 연 뒤, **마크업** 도구로 손가락으로 **그리고, 강조하고, 텍스트와 도형을 추가하고, 서명**하세요. 변경 사항은 파일에 바로 저장됩니다.<br><br>

그 표시를 나중에 편집할 수 없게 영구적으로 만들려면 PDF의 **••• → PDF 도구 → 병합**을 여세요. 비밀번호 추가, OCR 실행, 압축, 문서 정보 편집은 다른 **PDF 도구**를 사용하세요(위 질문 참고).
{{% /details %}}

{{% details title="기기의 다른 곳에 있는 폴더를 연결할 수 있나요?" closed="true" %}}
네. **문서** 탭에서 ••• 메뉴를 열고 **폴더 연결**을 선택한 뒤 기기의 아무 폴더나 고르세요. 그 폴더가 **연결됨** 라벨과 함께 맨 위에 나타나며 다른 폴더처럼 네트워크로 공유할 수 있습니다. 정보에서 **연결 끊기**를 사용해 연결을 해제하세요 - 폴더와 파일은 기기에 그대로 남습니다.
{{% /details %}}

{{% details title="다른 사람이 내 기기로 파일을 업로드할 수 있나요?" closed="true" %}}
네, **파일 편집**이 켜져 있을 때 가능합니다. 웹 브라우저에서는 상대에게 **업로드** 패널이 나타나고, WebDAV나 FTP 연결에서는 파일을 기기로 복사할 수 있습니다. 공유를 읽기 전용으로 만들려면 (설정 → 공유 → 접근에서) **파일 편집**을 끄세요.
{{% /details %}}

{{% details title="사진이나 동영상 전송이 왜 느린가요?" closed="true" %}}
사진이나 동영상 **형식**이 **가장 호환성 높음**으로 설정되어 있거나 **화질**이 **원본**보다 낮으면 Everdisk가 공유하면서 각 파일을 변환하는데, 이는 더 느리고 배터리를 더 씁니다. 가장 빠른 전송을 위해 **설정 → 공유**에서 **형식**과 **화질**을 **원본**으로 설정하고, 특정 TV나 브라우저가 파일을 열지 못할 때만 가장 호환성 높음으로 바꾸세요.
{{% /details %}}

{{% details title="기기가 나타나지 않거나 연결되지 않아요. 무엇을 확인할까요?" closed="true" %}}
- 두 기기가 **같은 Wi-Fi 네트워크**에 있는지 확인하세요(또는 Mac 케이블을 사용).<br>
- 공유가 **시작**되었고 설정 → 공유 → 연결에서 맞는 서버가 **켜져** 있는지 확인하세요.<br>
- 공유 화면에 표시된 대로 주소를 정확히 입력하세요. Wi-Fi에서는 표시된 IP를, 케이블에서는 **`.local`** 이름을 사용하세요(`localhost`는 절대 아닙니다).<br>
- 로그인과 비밀번호를 설정했다면 다른 기기에서 입력하세요.<br>
- iOS 설정 앱에서 Everdisk의 **로컬 네트워크** 권한이 허용되어 있는지 확인하세요.<br>
- 다른 기기가 **차단된 기기**에 있지 않은지 확인하세요.
{{% /details %}}

{{% details title="네트워크에 표시되는 기기 이름을 바꿀 수 있나요?" closed="true" %}}
Everdisk가 기기에 친근한 이름과 아바타를 자동으로 부여하며, 무료로 **다시 생성**할 수 있습니다. **사용자 지정** 이름, 아이콘, 그라디언트, 사진 아바타를 설정하는 것은 Premium **기기 맞춤 설정** 기능의 일부입니다.
{{% /details %}}

{{% details title="연결 포트를 바꿀 수 있나요?" closed="true" %}}
기본값은 **HTTP 80**, **WebDAV 8080**, **SMB 4455**, **FTP 2121**입니다(DLNA는 포트를 자동으로 선택합니다). 무료로 볼 수 있으며, **사용자 지정 포트**를 설정하는 것은 Premium 기능입니다(설정 → 공유의 **고급**).
{{% /details %}}

{{% details title="Everdisk는 무료인가요, Premium은 무엇을 추가하나요?" closed="true" %}}
Everdisk는 **무료**로 내려받습니다. 서버 다섯 개를 모두 실행하고, 비밀번호로 접근을 보호하고, 사진과 음악 라이브러리 전체를 공유하고, 파일 관리자를 쓰고, PDF로 스캔하고, 다른 서버에 연결할 수 있습니다. 무료 버전은 최대 **폴더 5개**를 공유하고 최대 **서버 연결 10개**를 저장합니다.<br><br>

일회성 **Premium Lifetime** 구매(구독이 아닙니다)는 다음을 추가합니다. **무제한 폴더**, **무제한 연결**, **사진 & 동영상 변환**(원본 외의 화질), **SMB 암호화**(SMB3/AES), **사용자 지정 포트**, **공유 자동 시작**, **기기 맞춤 설정**.
{{% /details %}}

{{% details title="Premium은 구독인가요? 다른 기기에서도 되나요?" closed="true" %}}
Premium은 구독이 아니라 **일회성 구매**입니다 - 한 번 결제하면 갱신되지 않습니다. Apple ID에 연결되므로 같은 Apple ID로 로그인한 다른 기기에서 **구입 항목 복원**을 사용해 잠금 해제할 수 있습니다.
{{% /details %}}
