<div class="hx:mt-6"></div>

Το Everdisk μετατρέπει το iPhone ή το iPad σας σε ασύρματο δίσκο που μοιράζεται αρχεία, φωτογραφίες, βίντεο και μουσική με οποιαδήποτε συσκευή στο τοπικό σας δίκτυο - μια smart TV, ένα Mac ή PC, έναν browser ή ένα άλλο τηλέφωνο - χωρίς λογαριασμούς, χωρίς cloud και χωρίς τίποτα προς εγκατάσταση στην άλλη πλευρά. Αυτό το FAQ απαντά στις ερωτήσεις που κάνουν συχνότερα οι χρήστες και σας καθοδηγεί σε συνηθισμένα πραγματικά σενάρια. Για οδηγίες βήμα προς βήμα, δείτε τον [Οδηγό χρήσης του Everdisk](/docs/guide/everdisk/).

<div class="hx:w-full">

{{% details title="Τι είναι το Everdisk;" closed="true" %}}
Το Everdisk είναι μια εφαρμογή **ασύρματου δίσκου** για iPhone και iPad. Μετατρέπει τη συσκευή σας σε έναν κόμβο που μοιράζεται τα αρχεία, τις φωτογραφίες, τα βίντεο και τη μουσική που επιλέγετε με οτιδήποτε στο τοπικό σας δίκτυο, ενώ συνδέεται και σε άλλους διακομιστές ώστε να περιηγείστε και να κάνετε μετάδοση από τα αρχεία τους.<br><br>

Τρέχει τέσσερις διακομιστές ταυτόχρονα - **DLNA** για τηλεοράσεις, **HTTP** για browsers, **WebDAV** για Finder/Windows/Linux, και **FTP** για εφαρμογές αρχείων - ώστε κάθε συσκευή να συνδέεται όπως της ταιριάζει. Δεν υπάρχουν λογαριασμοί ούτε cloud: πατάτε **Έναρξη** και είστε έτοιμοι. Περιλαμβάνει επίσης διαχειριστή αρχείων, media player, συλλογή φωτογραφιών, σάρωση εγγράφων σε PDF και zip/unzip.
{{% /details %}}

{{% details title="Πώς λειτουργεί το Everdisk;" closed="true" %}}
Όταν πατάτε **Έναρξη**, το Everdisk μετατρέπει τη συσκευή σας σε διακομιστή στο τοπικό σας δίκτυο και μοιράζεται το περιεχόμενο που επιλέξατε. Τέσσερις διαφορετικές μέθοδοι σύνδεσης τρέχουν ταυτόχρονα ώστε διαφορετικές συσκευές να μπορούν να συνδεθούν με τον τρόπο που προτιμούν:<br><br>

- **DLNA** - smart TV και media players βρίσκουν αυτόματα τη συσκευή σας και εμφανίζουν τα πολυμέσα σας με μικρογραφίες.<br>
- **HTTP** - ο καθένας ανοίγει έναν σύνδεσμο σε έναν browser για να περιηγηθεί και να κατεβάσει τα αρχεία σας.<br>
- **WebDAV** - η συσκευή σας εμφανίζεται ως κανονικός δικτυακός δίσκος σε Finder, Windows ή Linux.<br>
- **FTP** - εφαρμογές αρχείων και εργαλεία για έμπειρους χρήστες συνδέονται μέσω FTP.<br><br>

Όλα συμβαίνουν μέσω του τοπικού σας Wi-Fi (ή μέσω καλωδίου USB σε ένα Mac) και δεν αγγίζουν ποτέ το διαδίκτυο.
{{% /details %}}

{{% details title="Χρειάζομαι λογαριασμό, σύνδεση ή το διαδίκτυο;" closed="true" %}}
Όχι. Το Everdisk δεν χρειάζεται λογαριασμό ούτε σύνδεση στο διαδίκτυο. Λειτουργεί εξ ολοκλήρου στο **τοπικό σας δίκτυο**, ή μέσω **καλωδίου USB** σε ένα Mac. Τίποτα δεν μεταφορτώνεται σε κανένα cloud. Η μόνη προαιρετική σύνδεση είναι μία που μπορείτε να ορίσετε **εσείς** για να προστατέψετε με κωδικό τη δική σας κοινή χρήση.
{{% /details %}}

{{% details title="Πώς ξεκινώ την κοινή χρήση;" closed="true" %}}
Ανοίξτε την καρτέλα **Κοινή χρήση**, πατήστε **Τι θα μοιραστείτε** και επιλέξτε τα αρχεία, τις φωτογραφίες ή/και τη μουσική σας, και έπειτα πατήστε το μεγάλο κουμπί **Έναρξη**. Η ενότητα **Πώς να συνδεθείτε** εμφανίζει τότε τις ακριβείς διευθύνσεις που χρησιμοποιούν οι άλλες συσκευές για να συνδεθούν. Πατήστε **Διακοπή** για να τα βγάλετε ξανά όλα εκτός σύνδεσης.
{{% /details %}}

{{% details title="Τι μπορώ να μοιραστώ;" closed="true" %}}
Τρία είδη περιεχομένου, σε οποιονδήποτε συνδυασμό:<br><br>

- **Αρχεία και φάκελοι** - ο φάκελος Έγγραφα της εφαρμογής (κοινόχρηστος από προεπιλογή), μαζί με όποιους φακέλους ή μεμονωμένα αρχεία προσθέσετε με **Προσθήκη φακέλου** και **Προσθήκη αρχείου**.<br>
- **Φωτογραφίες και βίντεο** - ολόκληρη τη συλλογή Photos σας με **Να επιτρέπεται η πρόσβαση σε όλη τη συλλογή Photos**, ή μόνο επιλεγμένα στοιχεία με **Προσθήκη φωτογραφιών**.<br>
- **Μουσική** - ολόκληρη τη συλλογή Music σας με **Να επιτρέπεται η πρόσβαση σε όλη τη συλλογή Music**, ή επιλεγμένα τραγούδια με **Προσθήκη κομματιών**.<br><br>

Πρέπει να επιλέξετε τουλάχιστον ένα πράγμα πριν μπορέσει να ξεκινήσει η κοινή χρήση. Προστατευμένα (DRM) και μόνο-cloud κομμάτια δεν μπορούν να μοιραστούν.
{{% /details %}}

{{% details title="Πώς μοιράζομαι φωτογραφίες με τον υπολογιστή μου;" closed="true" %}}
1. Στην οθόνη **Κοινή χρήση**, ανοίξτε **Τι θα μοιραστείτε → Φωτογραφίες και βίντεο** και ενεργοποιήστε **Να επιτρέπεται η πρόσβαση σε όλη τη συλλογή Photos** (ή προσθέστε συγκεκριμένες φωτογραφίες).<br>
2. Πατήστε **Έναρξη**.<br>
3. Στον υπολογιστή, είτε ανοίξτε τη διεύθυνση **Browser** σε οποιονδήποτε browser και κατεβάστε, είτε συνδεθείτε στη διεύθυνση **Υπολογιστής (WebDAV)** από το Finder (Mac) ή την Εξερεύνηση αρχείων (Windows) και σύρετε τις φωτογραφίες.<br><br>

Συμβουλή: κρατήστε τη **Μορφή** των φωτογραφιών στο **Αρχική** για την πιο γρήγορη μεταφορά.
{{% /details %}}

{{% details title="Πώς βλέπω τα βίντεο ή τις φωτογραφίες μου σε μια τηλεόραση;" closed="true" %}}
1. Στις **Ρυθμίσεις → Κοινή χρήση → Συνδέσεις**, βεβαιωθείτε ότι το **Τηλεόραση & κέντρο πολυμέσων (DLNA)** είναι ενεργό.<br>
2. Πατήστε **Έναρξη**.<br>
3. Στην τηλεόραση, ανοίξτε τον ενσωματωμένο media player της ή την εφαρμογή διακομιστή πολυμέσων και επιλέξτε τη συσκευή σας από τη λίστα διακομιστών πολυμέσων με το όνομά της.<br>
4. Περιηγηθείτε και αναπαράγετε. Οι μικρογραφίες προεπισκόπησης εμφανίζονται αυτόματα.<br><br>

Αν μια παλαιότερη τηλεόραση δεν αναπαράγει ένα βίντεο, χαμηλώστε την ποιότητα στις **Ρυθμίσεις → Κοινή χρήση → Βίντεο** ώστε το Everdisk να το μετατρέψει σε πιο συμβατή μορφή.
{{% /details %}}

{{% details title="Πώς ακούω τη μουσική μου;" closed="true" %}}
Ενεργοποιήστε **Να επιτρέπεται η πρόσβαση σε όλη τη συλλογή Music** (ή προσθέστε κομμάτια) στο **Τι θα μοιραστείτε**, και έπειτα **Έναρξη**. Μπορείτε τότε να ακούσετε τη μουσική σας από τον browser μιας άλλης συσκευής (υπάρχει ενσωματωμένο player με ουρά, τυχαία σειρά και επανάληψη), από μια τηλεόραση DLNA, ή μέσα στο ίδιο το Everdisk με τη λειτουργία **Έγγραφα → Μουσική**. Η μουσική μοιράζεται πάντα στην αρχική της ποιότητα.
{{% /details %}}

{{% details title="Πώς βλέπω ταινίες μέσα στο Everdisk;" closed="true" %}}
Πατήστε οποιοδήποτε βίντεο - στα Έγγραφά σας, σε έναν συνδεδεμένο φάκελο ή σε έναν διακομιστή στην καρτέλα Συσκευές - και παίζει σε **πλήρη οθόνη** με τον ενσωματωμένο player του συστήματος, με τυπικά χειριστήρια όπως **AirPlay**, **Picture in Picture** και **ταχύτητα αναπαραγωγής**. Ο ήχος παίζει σε ένα **mini player** που παραμένει στο κάτω μέρος της εφαρμογής, με ουρά, τυχαία σειρά και επανάληψη.
{{% /details %}}

{{% details title="Πώς ανοίγω τα αρχεία μου σε έναν browser;" closed="true" %}}
1. Στις **Ρυθμίσεις → Κοινή χρήση → Συνδέσεις**, βεβαιωθείτε ότι το **Browser (HTTP)** είναι ενεργό.<br>
2. Πατήστε **Έναρξη** και αντιγράψτε τη διεύθυνση **Browser** (ή εμφανίστε τον κωδικό QR της).<br>
3. Στην άλλη συσκευή, ανοίξτε οποιονδήποτε browser και πληκτρολογήστε αυτή τη διεύθυνση.<br><br>

Ο άλλος μπορεί να περιηγηθεί σε πλέγμα ή λίστα, να δει φωτογραφίες σε συλλογή πλήρους οθόνης, να ακούσει μουσική και να κατεβάσει αρχεία - συμπεριλαμβανομένης της λήψης ολόκληρου φακέλου ως ένα **Archive.zip**. Αν ενεργοποιήσατε την **Επεξεργασία αρχείων**, μπορεί επίσης να σας μεταφορτώσει αρχεία πίσω. Τίποτα δεν χρειάζεται να εγκατασταθεί στην πλευρά του.
{{% /details %}}

{{% details title="Πώς χρησιμοποιώ τη συσκευή μου ως δικτυακό δίσκο στο Finder;" closed="true" %}}
1. Στις **Ρυθμίσεις → Κοινή χρήση → Συνδέσεις**, βεβαιωθείτε ότι το **Υπολογιστής (WebDAV)** είναι ενεργό, και έπειτα **Έναρξη**.<br>
2. Στο Mac, ανοίξτε το Finder και επιλέξτε **Μετάβαση → Σύνδεση με διακομιστή** (ή πατήστε **⌘K**).<br>
3. Εισάγετε τη διεύθυνση **Υπολογιστής (WebDAV)** που εμφανίζεται στο Everdisk και κάντε κλικ στο **Σύνδεση**.<br>
4. Εισάγετε το όνομα χρήστη και τον κωδικό σας αν έχετε ορίσει κάποιον, διαφορετικά συνδεθείτε ως επισκέπτης.<br><br>

Η συσκευή σας προσαρτάται σαν οποιοσδήποτε δικτυακός δίσκος. Με την **Επεξεργασία αρχείων** ενεργή μπορείτε να σύρετε αρχεία και προς τις δύο κατευθύνσεις, με αυτήν ανενεργή ο δίσκος είναι μόνο για ανάγνωση.
{{% /details %}}

{{% details title="Πώς συνδέομαι από Windows ή Linux;" closed="true" %}}
Χρησιμοποιήστε τη διεύθυνση **Υπολογιστής (WebDAV)**.<br><br>

- **Windows:** ανοίξτε την Εξερεύνηση αρχείων → κάντε δεξί κλικ στον **Αυτόν τον υπολογιστή** → **Προσθήκη θέσης δικτύου** (ή αντιστοιχίστε έναν δικτυακό δίσκο), και εισάγετε τη διεύθυνση WebDAV.<br>
- **Linux:** στον διαχειριστή αρχείων σας επιλέξτε **Σύνδεση με διακομιστή** και εισάγετε τη διεύθυνση WebDAV (για παράδειγμα με πρόθεμα `davs://` ή `dav://`).<br><br>

Εισάγετε το όνομα χρήστη και τον κωδικό αν έχετε ορίσει κάποιον.
{{% /details %}}

{{% details title="Λειτουργεί το Everdisk χωρίς Wi-Fi;" closed="true" %}}
Ναι, με ένα **Mac** και ένα καλώδιο. Συνδέστε το iPhone ή το iPad σας στο Mac, πατήστε **Να επιτραπεί** αν σας ζητηθεί, και πατήστε **Έναρξη**. Μια διεύθυνση **Σύνδεση μέσω καλωδίου** που τελειώνει σε `.local` εμφανίζεται στην οθόνη Κοινή χρήση, συνδεθείτε σε αυτήν από το Finder (**⌘K**). Αυτό λειτουργεί χωρίς καθόλου Wi-Fi - ιδανικό σε αεροπλάνο, σε ξενοδοχείο ή σε κλειδωμένο δίκτυο - και είναι πιο γρήγορο και πιο ιδιωτικό από το Wi-Fi.
{{% /details %}}

{{% details title="Μπορώ να χρησιμοποιήσω το καλώδιο USB με ένα Windows PC ή Android;" closed="true" %}}
Όχι. Η σύνδεση μέσω καλωδίου λειτουργεί μόνο με **Mac**. Τα Windows PC και οι συσκευές Android συνδέονται μέσω **Wi-Fi**. (Στα Windows μπορείτε ακόμα να σύρετε αρχεία στον φάκελο του Everdisk χρησιμοποιώντας την εφαρμογή Apple Devices ή το iTunes μέσω του καλωδίου, κάτι που είναι ξεχωριστό από τη ζωντανή κοινή χρήση.)
{{% /details %}}

{{% details title="Γιατί πρέπει να κρατάω την εφαρμογή ανοιχτή κατά την κοινή χρήση;" closed="true" %}}
Το iPhone ή το iPad σας είναι ο διακομιστής, και το iOS δεν επιτρέπει στις εφαρμογές να κρατούν έναν δικτυακό διακομιστή να τρέχει στο παρασκήνιο. Έτσι η κοινή χρήση λειτουργεί μόνο όσο το Everdisk είναι **ανοιχτό στην οθόνη**. Για μεγάλες μεταφορές, κρατήστε την εφαρμογή στο προσκήνιο, συνδέστε τη στο ρεύμα και ορίστε το **Αυτόματο κλείδωμα** σε **Ποτέ** στην εφαρμογή Ρυθμίσεις του iOS. Μπορείτε επίσης να ενεργοποιήσετε το **Ειδοποίηση πριν την αποσύνδεση** ώστε το Everdisk να σας υπενθυμίζει πριν το σύστημα το θέσει σε παύση.
{{% /details %}}

{{% details title="Τι είναι πιο γρήγορο - το Wi-Fi ή το καλώδιο;" closed="true" %}}
Το **καλώδιο USB προς ένα Mac** είναι πιο γρήγορο και πιο αξιόπιστο από το Wi-Fi, επειδή τα δεδομένα περνούν απευθείας από το καλώδιο. Είναι επίσης η πιο ιδιωτική επιλογή, αφού τίποτα δεν περνά από το router ή το διαδίκτυο. Χρησιμοποιήστε το για μεγάλες μεταφορές φωτογραφιών και βίντεο.
{{% /details %}}

{{% details title="Ποια είναι η διαφορά μεταξύ των τεσσάρων διακομιστών (DLNA, HTTP, WebDAV, FTP);" closed="true" %}}
Όλοι μοιράζονται το ίδιο περιεχόμενο αλλά ταιριάζουν σε διαφορετικές συσκευές:<br><br>

- **Τηλεόραση & κέντρο πολυμέσων (DLNA)** - για smart TV και media players.<br>
- **Browser (HTTP)** - για οποιονδήποτε browser, χωρίς εγκατάσταση.<br>
- **Υπολογιστής (WebDAV)** - κάνει τη συσκευή σας δικτυακό δίσκο σε Finder/Windows/Linux.<br>
- **Άλλες εφαρμογές & συσκευές (FTP)** - για εφαρμογές αρχείων και εργαλεία για έμπειρους χρήστες.<br><br>

Μπορείτε να ενεργοποιήσετε ή να απενεργοποιήσετε οποιονδήποτε από αυτούς στις **Ρυθμίσεις → Κοινή χρήση → Συνδέσεις**.
{{% /details %}}

{{% details title="Πώς προστατεύω τα αρχεία μου με κωδικό;" closed="true" %}}
Πηγαίνετε στις **Ρυθμίσεις → Κοινή χρήση → Πρόσβαση** και ορίστε ένα **Όνομα χρήστη** και έναν **Κωδικό**. Οι συνδέσεις Browser, Υπολογιστής και Άλλες εφαρμογές θα ζητούν τότε αυτά τα στοιχεία. Αφήστε και τα δύο κενά για ανοιχτή πρόσβαση.<br><br>

Σημείωση: η σύνδεση **DLNA** (τηλεόραση) δεν μπορεί να προστατευτεί με κωδικό, οπότε είναι ανοιχτή σε οποιονδήποτε στο ίδιο Wi-Fi όσο είναι ενεργή. Απενεργοποιήστε την αν θέλετε μόνο προστατευμένες συνδέσεις.
{{% /details %}}

{{% details title="Μπορώ να εμποδίσω άλλους να αλλάζουν τα αρχεία μου;" closed="true" %}}
Ναι. Ο διακόπτης **Επεξεργασία αρχείων** στις **Ρυθμίσεις → Κοινή χρήση → Πρόσβαση** το ελέγχει αυτό. Με αυτόν **ενεργό** (η προεπιλογή), οι συνδεδεμένες συσκευές μπορούν να μεταφορτώνουν, να μετονομάζουν και να διαγράφουν. Απενεργοποιήστε τον για να κάνετε τα κοινόχρηστα αρχεία σας **μόνο για ανάγνωση** - οι άλλοι μπορούν να τα δουν και να τα κατεβάσουν αλλά όχι να αλλάξουν τίποτα.
{{% /details %}}

{{% details title="Πώς αποκλείω μια συσκευή που δεν αναγνωρίζω;" closed="true" %}}
Στην οθόνη **Κοινή χρήση**, βρείτε τη συσκευή στο **Ποιος είναι συνδεδεμένος**, πατήστε το κουμπί περισσότερων ενεργειών της, και επιλέξτε **Αποκλεισμός αυτής της συσκευής**. Διαχειριστείτε τις αποκλεισμένες συσκευές στις **Ρυθμίσεις → Κοινή χρήση → Πρόσβαση → Αποκλεισμένες συσκευές**, όπου μπορείτε να καταργήσετε τον αποκλεισμό μίας ή να κάνετε **Κατάργηση αποκλεισμού όλων**.
{{% /details %}}

{{% details title="Αν κάποιος διαγράψει ένα κοινόχρηστο αρχείο, χάνεται για πάντα;" closed="true" %}}
Όχι από προεπιλογή. Τα διαγραμμένα αρχεία πηγαίνουν σε έναν ανακτήσιμο κάδο ώστε να μπορείτε να τα πάρετε πίσω. Αν προτιμάτε την άμεση διαγραφή χωρίς δυνατότητα ανάκτησης, ενεργοποιήστε το **Οριστική διαγραφή αρχείων** στις **Ρυθμίσεις → Διαχειριστής αρχείων → Διαγραφή αρχείων**.
{{% /details %}}

{{% details title="Είναι ιδιωτικό και ασφαλές το Everdisk;" closed="true" %}}
Ναι. Το Everdisk μοιράζεται μόνο μέσω του **τοπικού σας δικτύου** - τίποτα δεν πηγαίνει στο διαδίκτυο και δεν υπάρχει λογαριασμός cloud. Για τη μέγιστη ιδιωτικότητα, μοιραστείτε σε ένα οικιακό ή ιδιωτικό Wi-Fi που εμπιστεύεστε, προσθέστε όνομα χρήστη και κωδικό, και προσέχετε στα δημόσια Wi-Fi. Το **καλώδιο USB προς ένα Mac** είναι η πιο ιδιωτική επιλογή από όλες. Το Everdisk χρειάζεται την άδεια **Τοπικό δίκτυο** του iOS ώστε οι κοντινές συσκευές να μπορούν να το βρουν.
{{% /details %}}

{{% details title="Μπορεί το Everdisk να συνδεθεί στο NAS μου ή σε άλλους διακομιστές;" closed="true" %}}
Ναι. Η καρτέλα **Συσκευές** συνδέεται **σε** άλλους διακομιστές στο δίκτυό σας. Πατήστε **Νέα σύνδεση** και επιλέξτε **DLNA / UPnP**, **WebDAV**, **FTP** ή **SFTP**, εισάγετε τη διεύθυνση και τυχόν στοιχεία σύνδεσης, και μπορείτε να περιηγηθείτε, να κάνετε μετάδοση και να κατεβάσετε. Σε διακομιστές WebDAV, FTP και SFTP μπορείτε επίσης να δημιουργήσετε φακέλους, να μεταφορτώσετε, να μετονομάσετε, να μετακινήσετε και να διαγράψετε. Οι διακομιστές DLNA είναι μόνο για ανάγνωση.
{{% /details %}}

{{% details title="Μπορώ να συνδεθώ σε cloud storage όπως το Google Drive ή το Dropbox;" closed="true" %}}
Το Everdisk δεν συνδέεται σε λογαριασμούς cloud όπως το iCloud Drive, το Google Drive, το Dropbox ή το OneDrive. Συνδέεται μόνο σε διακομιστές **τοπικού δικτύου και με απευθείας διεύθυνση** (DLNA, WebDAV, FTP, SFTP). Μια υπηρεσία cloud είναι προσβάσιμη μόνο αν προσφέρει μια διεύθυνση **WebDAV** που μπορείτε να πληκτρολογήσετε σε μια νέα σύνδεση WebDAV.
{{% /details %}}

{{% details title="Για τι χρησιμεύει η καρτέλα Συσκευές;" closed="true" %}}
Είναι η πλευρά πελάτη του Everdisk: οι **Συνδέσεις** εμφανίζουν τους διακομιστές που έχετε αποθηκεύσει, και οι **Διαθέσιμες συσκευές** εμφανίζουν διακομιστές που βρέθηκαν αυτόματα στο δίκτυό σας. Πατήστε έναν για να περιηγηθείτε, να κάνετε μετάδοση ή να κατεβάσετε τα αρχεία του, ή πατήστε **Νέα σύνδεση** για να προσθέσετε χειροκίνητα έναν διακομιστή DLNA, WebDAV, FTP ή SFTP.
{{% /details %}}

{{% details title="Πώς κατεβάζω αρχεία από έναν διακομιστή στη συσκευή μου;" closed="true" %}}
Ανοίξτε τον διακομιστή στην καρτέλα **Συσκευές**, περιηγηθείτε σε αυτό που θέλετε, και επιλέξτε **Λήψη** (επιλέξτε πολλά στοιχεία για μαζική λήψη). Οι λήψεις τρέχουν στο παρασκήνιο, εμφανίζονται στο **Μεταφορές αρχείων** (πάνω αριστερά στην καρτέλα Έγγραφα), και καταλήγουν στον φάκελο **Έγγραφα** σας.
{{% /details %}}

{{% details title="Έχει διαχειριστή αρχείων το Everdisk;" closed="true" %}}
Ναι. Η καρτέλα **Έγγραφα** είναι ένας πλήρης διαχειριστής αρχείων. Μπορείτε να περιηγηθείτε σε λίστα ή πλέγμα, να δημιουργήσετε φακέλους, να μετονομάσετε, να μετακινήσετε, να αντιγράψετε, να μεταφορτώσετε και να διαγράψετε, και να ανοίξετε την οθόνη **Πληροφορίες** για οποιοδήποτε αρχείο. Οι λήψεις καταλήγουν εδώ, και ο φάκελος Έγγραφα είναι κοινόχρηστος από προεπιλογή.
{{% /details %}}

{{% details title="Πώς κάνω zip (αρχειοθέτηση) αρχεία;" closed="true" %}}
Στην καρτέλα **Έγγραφα**, επιλέξτε ένα ή περισσότερα στοιχεία και επιλέξτε **Αρχειοθέτηση**. Ένα μεμονωμένο στοιχείο συμπιέζεται μόνο του, πολλά στοιχεία ομαδοποιούνται σε ένα **Archive.zip**. Σε έναν browser μπορείτε επίσης να κατεβάσετε ολόκληρο φάκελο ή πολλά επιλεγμένα στοιχεία ως ένα ενιαίο zip.
{{% /details %}}

{{% details title="Πώς κάνω unzip ένα αρχείο;" closed="true" %}}
Πατήστε ένα αρχείο **.zip** ή **.rar** στην καρτέλα **Έγγραφα** και το Everdisk το εξάγει στον τρέχοντα φάκελο, με μια μπάρα προόδου που μπορείτε να ακυρώσετε.
{{% /details %}}

{{% details title="Πώς σαρώνω ένα έγγραφο σε PDF;" closed="true" %}}
Στην καρτέλα **Έγγραφα**, ανοίξτε το μενού περισσότερων ενεργειών (•••) και επιλέξτε **Σάρωση εγγράφων**. Στρέψτε την κάμερα σε κάθε σελίδα - το Everdisk εντοπίζει τα άκρα και ισιώνει τη σελίδα αυτόματα - και όλες οι σελίδες αποθηκεύονται μαζί ως ένα **PDF πολλών σελίδων** στον τρέχοντα φάκελο. Χρειάζεστε μια συσκευή με κάμερα.
{{% /details %}}

{{% details title="Ποια εργαλεία PDF περιλαμβάνει το Everdisk;" closed="true" %}}
Το Everdisk διαθέτει μια ενσωματωμένη σουίτα **Εργαλείων PDF**. Ανοίξτε το μενού **•••** οποιουδήποτε PDF (ή την οθόνη Πληροφοριών του) στην καρτέλα **Έγγραφα** και πατήστε **Εργαλεία PDF**. Είναι ομαδοποιημένα σε τρεις τομείς:<br><br>

**Βελτιστοποίηση**<br>
- **Συμπίεση** - μικραίνει ένα PDF. Βλέπετε το τρέχον μέγεθος και ένα εκτιμώμενο μέγεθος αποτελέσματος για κάθε επιλογή πριν την αποθήκευση.<br>
- **Αναγνώριση κειμένου (OCR)** - μετατρέπει ένα σαρωμένο PDF σε **PDF με δυνατότητα αναζήτησης**, ή εξάγει μόνο το κείμενο σε αρχείο **.txt**.<br>
- **Ισοπέδωση** - ενσωματώνει επισημειώσεις και καταχωρήσεις φόρμας στη σελίδα ώστε να μην μπορούν πλέον να επεξεργαστούν.<br><br>

**Ασφάλεια**<br>
- **Κωδικός** - ορίστε, αλλάξτε ή αφαιρέστε τον κωδικό που απαιτείται για το άνοιγμα του PDF.<br>
- **Δικαιώματα** - ελέγξτε τι επιτρέπει το PDF (αντιγραφή, εκτύπωση, σχολιασμό και άλλα).<br><br>

**Μεταδεδομένα**<br>
- **Επεξεργασία μεταδεδομένων** - αλλάξτε ή διαγράψτε τον τίτλο, τον συγγραφέα, το θέμα, τις λέξεις-κλειδιά και άλλες πληροφορίες του εγγράφου.<br><br>

Τα Εργαλεία PDF περιλαμβάνονται δωρεάν. Αν ένα PDF είναι προστατευμένο με κωδικό, το Everdisk ζητά τον κωδικό του πριν μπορέσετε να χρησιμοποιήσετε τα εργαλεία.
{{% /details %}}

{{% details title="Πώς συμπιέζω ένα PDF;" closed="true" %}}
Ανοίξτε το μενού **•••** του PDF → **Εργαλεία PDF** → **Συμπίεση**. Το Everdisk εμφανίζει το τρέχον μέγεθος αρχείου και ένα εκτιμώμενο μέγεθος για κάθε επιλογή:<br><br>

- Η **Τυπική** διατηρεί το κείμενο επιλέξιμο και επανασυμπιέζει μόνο τις εικόνες.<br>
- Οι **Υψηλή**, **Μεσαία**, **Μικρή** και **Μικρότερη** αναπαράγουν τις σελίδες ως εικόνες σε χαμηλότερη ανάλυση - ιδανικές για σαρώσεις και φωτογραφίες, αλλά το κείμενο δεν είναι πλέον επιλέξιμο.<br><br>

Πατήστε την επιλογή που θέλετε και το Everdisk αποθηκεύει το μικρότερο PDF.
{{% /details %}}

{{% details title="Πώς κάνω ένα σαρωμένο PDF αναζητήσιμο (OCR);" closed="true" %}}
Ανοίξτε το μενού **•••** του PDF → **Εργαλεία PDF** → **Αναγνώριση κειμένου**. Επιλέξτε **PDF με δυνατότητα αναζήτησης** για να προσθέσετε ένα κρυφό επίπεδο κειμένου ώστε να μπορείτε να αναζητάτε και να επιλέγετε το κείμενο (οι σελίδες φαίνονται ακριβώς ίδιες), ή **Αρχείο κειμένου (.txt)** για να αποθηκεύσετε μόνο το αναγνωρισμένο κείμενο δίπλα στο PDF. Μεγάλα ή σαρωμένα αρχεία μπορεί να πάρουν λίγο χρόνο.
{{% /details %}}

{{% details title="Πώς προστατεύω ένα αρχείο PDF με κωδικό;" closed="true" %}}
Ανοίξτε το μενού **•••** του PDF → **Εργαλεία PDF** → **Κωδικός**. Αν το PDF δεν είναι ακόμα προστατευμένο, εισάγετε έναν νέο κωδικό και επιβεβαιώστε τον για να τον ορίσετε. Αν είναι ήδη προστατευμένο, εισάγετε τον τρέχοντα κωδικό για να τον **αφαιρέσετε** ή να τον **αλλάξετε**. Κρατήστε τον κωδικό σε ασφαλές μέρος - ένα προστατευμένο PDF δεν μπορεί να ανοίξει χωρίς αυτόν.<br><br>

Αυτό προστατεύει το **αρχείο** PDF το ίδιο, κάτι που είναι διαφορετικό από το **όνομα χρήστη και τον κωδικό** που προστατεύουν ολόκληρη τη συνεδρία κοινής χρήσης σας (δείτε τις ερωτήσεις ασφάλειας παραπάνω).
{{% /details %}}

{{% details title="Μπορώ να σχεδιάσω πάνω ή να υπογράψω ένα PDF στο Everdisk;" closed="true" %}}
Ναι. Πατήστε ένα PDF (ή μια φωτογραφία) στην καρτέλα **Έγγραφα** για να το ανοίξετε στον ενσωματωμένο προβολέα, και έπειτα χρησιμοποιήστε τα εργαλεία **Επισημείωση** για να **σχεδιάσετε, να επισημάνετε, να προσθέσετε κείμενο και σχήματα, και να υπογράψετε** με το δάχτυλό σας. Οι αλλαγές σας αποθηκεύονται απευθείας πίσω στο αρχείο.<br><br>

Αν θέλετε να κάνετε αυτά τα σημάδια μόνιμα ώστε να μην μπορούν να επεξεργαστούν αργότερα, ανοίξτε το **••• → Εργαλεία PDF → Ισοπέδωση** του PDF. Για να προσθέσετε κωδικό, να τρέξετε OCR, να συμπιέσετε ή να επεξεργαστείτε τις πληροφορίες του εγγράφου, χρησιμοποιήστε τα άλλα **Εργαλεία PDF** (δείτε την ερώτηση παραπάνω).
{{% /details %}}

{{% details title="Μπορώ να συνδέσω έναν φάκελο που βρίσκεται κάπου αλλού στη συσκευή μου;" closed="true" %}}
Ναι. Στην καρτέλα **Έγγραφα**, ανοίξτε το μενού ••• και επιλέξτε **Σύνδεση φακέλου**, και έπειτα διαλέξτε οποιονδήποτε φάκελο στη συσκευή σας. Εμφανίζεται στην κορυφή με μια ετικέτα **Συνδεδεμένος** και μπορεί να μοιραστεί στο δίκτυο σαν οποιοσδήποτε άλλος φάκελος. Χρησιμοποιήστε το **Αποσύνδεση** από τις Πληροφορίες του για να τον αποσυνδέσετε - ο φάκελος και τα αρχεία παραμένουν στη συσκευή σας.
{{% /details %}}

{{% details title="Μπορούν άλλοι να μεταφορτώσουν αρχεία πίσω στη συσκευή μου;" closed="true" %}}
Ναι, όταν η **Επεξεργασία αρχείων** είναι ενεργή. Σε έναν browser εμφανίζεται ένα πλαίσιο **Μεταφόρτωση**, σε μια σύνδεση WebDAV ή FTP μπορούν να αντιγράψουν αρχεία στη συσκευή σας. Απενεργοποιήστε την **Επεξεργασία αρχείων** (στις Ρυθμίσεις → Κοινή χρήση → Πρόσβαση) για να κάνετε την κοινή χρήση μόνο για ανάγνωση.
{{% /details %}}

{{% details title="Γιατί μια φωτογραφία ή ένα βίντεο μεταφέρεται αργά;" closed="true" %}}
Αν η **Μορφή** των Φωτογραφιών ή των Βίντεο είναι ρυθμισμένη σε **Πιο συμβατή** ή η **Ποιότητα** είναι κάτω από **Αρχική**, το Everdisk μετατρέπει κάθε αρχείο καθώς μοιράζεται, κάτι που είναι πιο αργό και καταναλώνει περισσότερη μπαταρία. Ρυθμίστε τη **Μορφή** και την **Ποιότητα** σε **Αρχική** στις **Ρυθμίσεις → Κοινή χρήση** για τις πιο γρήγορες μεταφορές, και αλλάξτε σε Πιο συμβατή μόνο αν μια συγκεκριμένη τηλεόραση ή browser δεν μπορεί να ανοίξει ένα αρχείο.
{{% /details %}}

{{% details title="Μια συσκευή δεν εμφανίζεται ή δεν συνδέεται. Τι μπορώ να ελέγξω;" closed="true" %}}
- Βεβαιωθείτε ότι και οι δύο συσκευές είναι στο **ίδιο δίκτυο Wi-Fi** (ή χρησιμοποιήστε το καλώδιο του Mac).<br>
- Επιβεβαιώστε ότι η κοινή χρήση έχει **ξεκινήσει** και ότι ο σωστός διακομιστής είναι **ενεργός** στις Ρυθμίσεις → Κοινή χρήση → Συνδέσεις.<br>
- Πληκτρολογήστε τη διεύθυνση ακριβώς όπως εμφανίζεται στην οθόνη Κοινή χρήση, μέσω Wi-Fi χρησιμοποιήστε την εμφανιζόμενη IP, και μέσω καλωδίου χρησιμοποιήστε το όνομα **`.local`** (ποτέ `localhost`).<br>
- Αν ορίσατε όνομα χρήστη και κωδικό, εισάγετέ τα στην άλλη συσκευή.<br>
- Ελέγξτε ότι η άδεια **Τοπικό δίκτυο** επιτρέπεται για το Everdisk στην εφαρμογή Ρυθμίσεις του iOS.<br>
- Βεβαιωθείτε ότι η άλλη συσκευή δεν είναι στις **Αποκλεισμένες συσκευές**.
{{% /details %}}

{{% details title="Μπορώ να αλλάξω το όνομα που εμφανίζει η συσκευή μου στο δίκτυο;" closed="true" %}}
Το Everdisk δίνει στη συσκευή σας ένα φιλικό όνομα και avatar αυτόματα, και μπορείτε να τα **Επαναδημιουργήσετε** δωρεάν. Ο ορισμός **προσαρμοσμένου** ονόματος, εικονιδίου, ντεγκραντέ ή avatar φωτογραφίας είναι μέρος της λειτουργίας Premium **Προσαρμογή συσκευής**.
{{% /details %}}

{{% details title="Μπορώ να αλλάξω τις θύρες σύνδεσης;" closed="true" %}}
Οι προεπιλογές είναι **HTTP 80**, **WebDAV 8080** και **FTP 2121** (το DLNA επιλέγει τη θύρα του αυτόματα). Μπορείτε να τις δείτε δωρεάν, και ο ορισμός **προσαρμοσμένων θυρών** είναι λειτουργία Premium (**Για προχωρημένους** στις Ρυθμίσεις → Κοινή χρήση).
{{% /details %}}

{{% details title="Είναι δωρεάν το Everdisk, και τι προσθέτει το Premium;" closed="true" %}}
Το Everdisk είναι **δωρεάν** λήψη. Μπορείτε να τρέξετε και τους τέσσερις διακομιστές, να προστατέψετε την πρόσβαση με κωδικό, να μοιραστείτε ολόκληρη τη συλλογή Photos και Music σας, να χρησιμοποιήσετε τον διαχειριστή αρχείων, να σαρώσετε σε PDF και να συνδεθείτε σε άλλους διακομιστές. Η δωρεάν έκδοση μοιράζεται έως **5 φακέλους** και αποθηκεύει έως **10 συνδέσεις διακομιστών**.<br><br>

Μια εφάπαξ αγορά **Premium Lifetime** (όχι συνδρομή) προσθέτει: **Απεριόριστους φακέλους**, **Απεριόριστες συνδέσεις**, **Μετατροπή φωτογραφιών & βίντεο** (ποιότητα εκτός από Αρχική), **Προσαρμοσμένες θύρες**, **Αυτόματη έναρξη κοινής χρήσης** και **Προσαρμογή συσκευής**.
{{% /details %}}

{{% details title="Είναι το Premium συνδρομή; Λειτουργεί στις άλλες μου συσκευές;" closed="true" %}}
Το Premium είναι **εφάπαξ αγορά**, όχι συνδρομή - πληρώνετε μία φορά και δεν ανανεώνεται ποτέ. Είναι συνδεδεμένο με το Apple ID σας, οπότε μπορείτε να χρησιμοποιήσετε την **Επαναφορά αγορών** για να το ξεκλειδώσετε στις άλλες σας συσκευές που είναι συνδεδεμένες με το ίδιο Apple ID.
