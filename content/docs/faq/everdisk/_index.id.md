<div class="hx:mt-6"></div>

Everdisk mengubah iPhone atau iPad Anda jadi drive nirkabel yang membagikan file, foto, video, dan musik ke perangkat apa pun di jaringan lokal Anda - smart TV, Mac atau PC, browser web, atau ponsel lain - tanpa akun, tanpa cloud, dan tanpa perlu memasang apa pun di sisi lain. FAQ ini menjawab pertanyaan yang paling sering diajukan dan membahas skenario dunia nyata yang umum. Untuk instruksi langkah demi langkah, lihat [Panduan Pengguna Everdisk](/docs/guide/everdisk/).

<div class="hx:w-full">

{{% details title="Apa itu Everdisk?" closed="true" %}}
Everdisk adalah aplikasi **drive nirkabel** untuk iPhone dan iPad. Aplikasi ini mengubah perangkat Anda jadi pusat yang membagikan file, foto, video, dan musik yang Anda pilih ke apa pun di jaringan lokal Anda, dan juga terhubung ke server lain sehingga Anda bisa menjelajah dan streaming file mereka.<br><br>

Everdisk menjalankan lima server sekaligus - **DLNA** untuk TV, **HTTP** untuk browser web, **WebDAV** untuk Finder/Windows/Linux, **SMB** untuk network drive di Mac, Windows, dan Linux dengan enkripsi opsional, dan **FTP** untuk aplikasi file - jadi setiap perangkat terhubung dengan caranya sendiri. Tanpa akun dan tanpa cloud: Anda tinggal ketuk **Mulai** dan siap. Everdisk juga menyertakan pengelola file, pemutar media, galeri foto, scan dokumen ke PDF, serta zip/unzip.
{{% /details %}}

{{% details title="Bagaimana cara kerja Everdisk?" closed="true" %}}
Saat Anda mengetuk **Mulai**, Everdisk mengubah perangkat Anda jadi server di jaringan lokal Anda dan membagikan konten yang Anda pilih. Lima metode koneksi berbeda berjalan sekaligus agar berbagai perangkat bisa terhubung dengan cara yang mereka sukai:<br><br>

- **DLNA** - smart TV dan pemutar media menemukan perangkat Anda secara otomatis dan menampilkan media Anda dengan thumbnail.<br>
- **HTTP** - siapa pun membuka tautan di browser web untuk menjelajah dan mengunduh file Anda.<br>
- **WebDAV** - perangkat Anda muncul sebagai network drive biasa di Finder, Windows, atau Linux.<br>
- **SMB** - network drive untuk Mac, Windows, dan Linux, dibangun di atas berbagi file yang sudah ada di sistem tersebut; di Mac muncul dengan sendirinya di bilah samping Finder. Ini satu-satunya koneksi yang bisa Anda enkripsi (enkripsi SMB3, AES).<br>
- **FTP** - aplikasi file dan alat tingkat lanjut terhubung lewat FTP.<br><br>

Semuanya berlangsung lewat Wi-Fi lokal Anda (atau kabel USB ke Mac) dan tidak pernah menyentuh internet.
{{% /details %}}

{{% details title="Apakah saya perlu akun, login, atau internet?" closed="true" %}}
Tidak. Everdisk tidak butuh akun dan tidak butuh koneksi internet. Aplikasi ini bekerja sepenuhnya di **jaringan lokal** Anda, atau lewat **kabel USB** ke Mac. Tidak ada yang diunggah ke cloud mana pun. Satu-satunya login opsional adalah yang bisa **Anda** atur untuk melindungi berbagi Anda sendiri dengan kata sandi.
{{% /details %}}

{{% details title="Bagaimana cara mulai berbagi?" closed="true" %}}
Buka tab **Berbagi**, ketuk **Apa yang Dibagikan** dan pilih file, foto, dan/atau musik Anda, lalu ketuk tombol besar **Mulai**. Bagian **Cara Menghubungkan** kemudian menampilkan alamat persis yang dipakai perangkat lain untuk terhubung. Ketuk **Berhenti** untuk menonaktifkan semuanya kembali.
{{% /details %}}

{{% details title="Apa saja yang bisa saya bagikan?" closed="true" %}}
Tiga jenis konten, dalam kombinasi apa pun:<br><br>

- **Berkas dan Folder** - folder Dokumen aplikasi (dibagikan secara default), plus folder atau file individual mana pun yang Anda tambahkan dengan **Tambah Folder** dan **Tambah Berkas**.<br>
- **Foto dan Video** - seluruh koleksi Foto Anda dengan **Izinkan akses ke seluruh Pustaka Foto**, atau hanya item terpilih dengan **Tambah Foto**.<br>
- **Musik** - seluruh koleksi Musik Anda dengan **Izinkan akses ke seluruh Pustaka Musik**, atau lagu terpilih dengan **Tambah Lagu**.<br><br>

Anda harus memilih setidaknya satu hal sebelum berbagi bisa dimulai. Lagu berproteksi (DRM) dan lagu yang hanya ada di cloud tidak bisa dibagikan.
{{% /details %}}

{{% details title="Bagaimana cara berbagi foto dengan komputer saya?" closed="true" %}}
1. Di layar **Berbagi**, buka **Apa yang Dibagikan → Foto dan Video** dan aktifkan **Izinkan akses ke seluruh Pustaka Foto** (atau tambahkan foto tertentu).<br>
2. Ketuk **Mulai**.<br>
3. Di komputer, buka alamat **Peramban** di browser web mana pun lalu unduh, atau sambungkan ke alamat **Komputer (WebDAV)** dari Finder (Mac) atau File Explorer (Windows) dan seret fotonya.<br><br>

Tips: pertahankan **Format** Foto pada **Asli** untuk transfer tercepat.
{{% /details %}}

{{% details title="Bagaimana cara menonton video atau foto saya di TV?" closed="true" %}}
1. Di **Pengaturan → Berbagi → Koneksi**, pastikan **TV & Media Center (DLNA)** aktif.<br>
2. Ketuk **Mulai**.<br>
3. Di TV, buka pemutar media bawaannya atau aplikasi media-server, lalu pilih perangkat Anda berdasarkan namanya dari daftar media server.<br>
4. Jelajahi dan putar. Thumbnail pratinjau muncul secara otomatis.<br><br>

Jika TV lawas tidak bisa memutar video, turunkan kualitas di **Pengaturan → Berbagi → Video** agar Everdisk mengonversinya ke format yang lebih kompatibel.
{{% /details %}}

{{% details title="Bagaimana cara mendengarkan musik saya?" closed="true" %}}
Aktifkan **Izinkan akses ke seluruh Pustaka Musik** (atau tambahkan lagu) di bawah **Apa yang Dibagikan**, lalu **Mulai**. Setelah itu Anda bisa memutar musik dari browser web perangkat lain (ada pemutar bawaan dengan antrean, acak, dan ulang), dari TV DLNA, atau di Everdisk sendiri lewat mode **Dokumen → Musik**. Musik selalu dibagikan dalam kualitas aslinya.
{{% /details %}}

{{% details title="Bagaimana cara menonton film di dalam Everdisk?" closed="true" %}}
Ketuk video mana pun - di Dokumen Anda, folder yang terhubung, atau server di tab Perangkat - dan video diputar **layar penuh** menggunakan pemutar sistem bawaan, dengan kontrol standar termasuk **AirPlay**, **Picture in Picture**, dan **kecepatan pemutaran**. Audio diputar di **mini player** yang tetap berada di bagian bawah aplikasi dengan antrean, acak, dan ulang.
{{% /details %}}

{{% details title="Bagaimana cara membuka file saya di browser web?" closed="true" %}}
1. Di **Pengaturan → Berbagi → Koneksi**, pastikan **Peramban (HTTP)** aktif.<br>
2. Ketuk **Mulai** dan salin alamat **Peramban** (atau tampilkan kode QR-nya).<br>
3. Di perangkat lain, buka browser web mana pun dan ketik alamat itu.<br><br>

Orang lain bisa menjelajah dalam grid atau daftar, melihat foto di galeri layar penuh, memutar musik, dan mengunduh file - termasuk mengunduh seluruh folder sebagai satu **Archive.zip**. Jika Anda mengaktifkan **Pengeditan Berkas**, mereka juga bisa mengunggah file kembali ke Anda. Tidak ada yang perlu dipasang di sisi mereka.
{{% /details %}}

{{% details title="Bagaimana cara memakai perangkat saya sebagai network drive di Finder?" closed="true" %}}
1. Di **Pengaturan → Berbagi → Koneksi**, pastikan **Komputer (WebDAV)** aktif, lalu **Mulai**.<br>
2. Di Mac, buka Finder dan pilih **Go → Connect to Server** (atau tekan **⌘K**).<br>
3. Masukkan alamat **Komputer (WebDAV)** yang ditampilkan di Everdisk dan klik **Connect**.<br>
4. Masukkan login dan kata sandi Anda jika Anda mengaturnya; jika tidak, sambungkan sebagai tamu.<br><br>

Perangkat Anda terpasang layaknya network drive mana pun. Dengan **Pengeditan Berkas** aktif, Anda bisa menyeret file ke dua arah; jika nonaktif, drive bersifat hanya-baca.
{{% /details %}}

{{% details title="Bagaimana cara menyambung dari Windows atau Linux?" closed="true" %}}
Gunakan alamat **Komputer (WebDAV)**.<br><br>

- **Windows:** buka File Explorer → klik kanan **This PC** → **Add a network location** (atau petakan network drive), lalu masukkan alamat WebDAV.<br>
- **Linux:** di pengelola file Anda pilih **Connect to Server** dan masukkan alamat WebDAV (misalnya dengan awalan `davs://` atau `dav://`).<br><br>

Masukkan login dan kata sandi jika Anda mengaturnya.
{{% /details %}}

{{% details title="Bagaimana cara menyambung lewat SMB?" closed="true" %}}
1. Di **Pengaturan → Berbagi → Koneksi**, pastikan **Komputer (Lanjutan)** (koneksi SMB) aktif, lalu **Mulai**.<br>
2. Salin alamat **SMB** yang ditampilkan di layar Berbagi - alamatnya tampak seperti `smb://192.168.1.20:4455/Share`.<br>
3. Sambungkan dari komputer Anda:<br>
&nbsp;&nbsp;- **Mac:** perangkat Anda muncul dengan sendirinya di **bilah samping Finder** di bawah **Locations** (Network) - cukup klik. Untuk menyambung secara manual, pilih **Go → Connect to Server** (**⌘K**) dan masukkan alamatnya.<br>
&nbsp;&nbsp;- **Windows:** di File Explorer, klik kanan **This PC** lalu pilih **Map network drive**, kemudian masukkan `\\<address>\Share`, atau ketik alamat `smb://` di bilah alamat.<br>
&nbsp;&nbsp;- **Linux:** di pengelola file Anda pilih **Connect to Server** dan masukkan alamatnya.<br>
4. Masukkan login dan kata sandi jika Anda mengaturnya; jika tidak, sambungkan sebagai tamu.<br><br>

Share tersebut bernama **Share**. Dengan **Pengeditan Berkas** aktif, Anda bisa menyalin file ke dua arah; jika nonaktif, drive bersifat hanya-baca.
{{% /details %}}

{{% details title="Bisakah saya mengenkripsi koneksi SMB saya?" closed="true" %}}
Ya - dan SMB adalah **satu-satunya** koneksi yang bisa dienkripsi Everdisk. Di **Pengaturan → Berbagi**, aktifkan **Wajibkan enkripsi SMB** untuk melindungi setiap transfer SMB dengan **enkripsi SMB3 (AES)**, sehingga tidak ada orang lain di jaringan yang sama yang bisa membaca file Anda. Ini pilihan yang bagus di Wi-Fi yang tidak sepenuhnya Anda percaya.<br><br>

Beberapa persyaratan:<br>
- Anda harus mengatur **login dan kata sandi** terlebih dahulu - koneksi terenkripsi tidak bisa anonim.<br>
- Klien harus mendukung **SMB3** - Finder di Mac modern, atau **Windows 10 dan yang lebih baru**.<br>
- Perubahan berlaku saat Anda mulai berbagi berikutnya.<br><br>

Enkripsi SMB adalah bagian dari pembelian sekali bayar **Premium Lifetime**.
{{% /details %}}

{{% details title="Apakah Everdisk bisa dipakai tanpa Wi-Fi?" closed="true" %}}
Ya, dengan **Mac** dan kabel. Colokkan iPhone atau iPad Anda ke Mac, ketuk **Trust** jika diminta, lalu ketuk **Mulai**. Alamat **Koneksi Kabel** yang berakhiran `.local` muncul di layar Berbagi; sambungkan ke alamat itu dari Finder (**⌘K**). Cara ini bekerja tanpa Wi-Fi sama sekali - cocok di pesawat, di hotel, atau di jaringan terkunci - dan lebih cepat serta lebih privat daripada Wi-Fi.
{{% /details %}}

{{% details title="Bisakah saya memakai kabel USB dengan PC Windows atau Android?" closed="true" %}}
Tidak. Koneksi kabel hanya bekerja dengan **Mac**. PC Windows dan perangkat Android terhubung lewat **Wi-Fi**. (Di Windows Anda tetap bisa menyeret file ke folder Everdisk menggunakan aplikasi Apple Devices atau iTunes lewat kabel, yang terpisah dari berbagi langsung.)
{{% /details %}}

{{% details title="Mengapa saya harus terus membuka aplikasi saat berbagi?" closed="true" %}}
iPhone atau iPad Anda adalah servernya, dan iOS tidak mengizinkan aplikasi menjalankan server jaringan di latar belakang. Jadi berbagi hanya bekerja selama Everdisk **terbuka di layar**. Untuk transfer panjang, biarkan aplikasi di latar depan, colokkan ke daya, dan atur **Auto-Lock** ke **Never** di aplikasi Pengaturan iOS. Anda juga bisa mengaktifkan **Notify before disconnecting** agar Everdisk mengingatkan Anda sebelum sistem menjedanya.
{{% /details %}}

{{% details title="Mana yang lebih cepat - Wi-Fi atau kabel?" closed="true" %}}
**Kabel USB ke Mac** lebih cepat dan lebih andal daripada Wi-Fi, karena datanya mengalir langsung lewat kabel. Cara ini juga paling privat, karena tidak ada yang melewati router atau internet Anda. Pakai untuk transfer foto dan video berukuran besar.
{{% /details %}}

{{% details title="Apa bedanya kelima server (DLNA, HTTP, WebDAV, SMB, FTP)?" closed="true" %}}
Kelimanya membagikan konten yang sama tapi cocok untuk perangkat yang berbeda:<br><br>

- **TV & Media Center (DLNA)** - untuk smart TV dan pemutar media.<br>
- **Peramban (HTTP)** - untuk browser web mana pun, tanpa perlu memasang apa pun.<br>
- **Komputer (WebDAV)** - menjadikan perangkat Anda network drive di Finder/Windows/Linux.<br>
- **Komputer (Lanjutan)** (SMB) - network drive untuk Mac, Windows, dan Linux; di Mac muncul dengan sendirinya di bilah samping Finder, atau sambungkan secara manual dengan alamat `smb://`. Ini satu-satunya koneksi yang bisa Anda enkripsi (SMB3, AES).<br>
- **Aplikasi dan perangkat lain (FTP)** - untuk aplikasi file dan alat tingkat lanjut.<br><br>

Anda bisa mengaktifkan atau menonaktifkan salah satunya di **Pengaturan → Berbagi → Koneksi**.
{{% /details %}}

{{% details title="Bagaimana cara melindungi file saya dengan kata sandi?" closed="true" %}}
Buka **Pengaturan → Berbagi → Akses** dan atur **Info Masuk** serta **Kata Sandi**. Koneksi Peramban, Komputer, Komputer (Lanjutan), dan Aplikasi Lain kemudian akan meminta detail tersebut. Kosongkan keduanya untuk akses terbuka.<br><br>

Catatan: koneksi **DLNA** (TV) tidak bisa dilindungi kata sandi, jadi koneksi ini terbuka untuk siapa pun di Wi-Fi yang sama selama aktif. Nonaktifkan jika Anda hanya menginginkan koneksi yang terlindungi.
{{% /details %}}

{{% details title="Bisakah saya mencegah orang mengubah file saya?" closed="true" %}}
Ya. Sakelar **Pengeditan Berkas** di **Pengaturan → Berbagi → Akses** yang mengaturnya. Dengan sakelar **aktif** (default), perangkat yang terhubung bisa mengunggah, mengganti nama, dan menghapus. Nonaktifkan untuk membuat file yang Anda bagikan **hanya-baca** - orang lain bisa melihat dan mengunduh tapi tidak bisa mengubah apa pun.
{{% /details %}}

{{% details title="Bagaimana cara memblokir perangkat yang tidak saya kenali?" closed="true" %}}
Di layar **Berbagi**, temukan perangkat di bawah **Siapa yang Terhubung**, ketuk tombol lebih banyak tindakan-nya, lalu pilih **Blokir perangkat ini**. Kelola perangkat yang diblokir di **Pengaturan → Berbagi → Akses → Perangkat Diblokir**, tempat Anda bisa membuka blokir satu perangkat atau **Buka Blokir Semua**.
{{% /details %}}

{{% details title="Jika seseorang menghapus file yang dibagikan, apakah hilang selamanya?" closed="true" %}}
Tidak secara default. File yang dihapus masuk ke tempat sampah yang bisa dipulihkan sehingga Anda bisa mengambilnya kembali. Jika Anda lebih suka penghapusan langsung tanpa pemulihan, aktifkan **Hapus File Secara Permanen** di **Pengaturan → Pengelola Berkas → Menghapus Berkas**.
{{% /details %}}

{{% details title="Apakah Everdisk privat dan aman?" closed="true" %}}
Ya. Everdisk hanya berbagi lewat **jaringan lokal** Anda - tidak ada yang menuju internet dan tidak ada akun cloud. Untuk privasi terbaik, berbagilah di Wi-Fi rumah atau pribadi yang Anda percaya, tambahkan login dan kata sandi, dan berhati-hatilah di Wi-Fi publik. **Kabel USB ke Mac** adalah opsi paling privat dari semuanya. Everdisk memerlukan izin **Jaringan Lokal** iOS agar perangkat di sekitar bisa menemukannya.
{{% /details %}}

{{% details title="Bisakah Everdisk menyambung ke NAS atau server lain saya?" closed="true" %}}
Ya. Tab **Perangkat** menyambung **ke** server lain di jaringan Anda. Ketuk **Koneksi Baru** dan pilih **DLNA / UPnP**, **WebDAV**, **FTP**, **SFTP**, atau **SMB** (untuk Mac, PC Windows, mesin Linux, dan drive NAS yang berbagi folder melalui SMB / CIFS), masukkan alamat dan login apa pun, lalu Anda bisa menjelajah, streaming, dan mengunduh. Di server WebDAV, FTP, SFTP, dan SMB Anda juga bisa membuat folder, mengunggah, mengganti nama, memindahkan, dan menghapus. Server DLNA bersifat hanya-baca.
{{% /details %}}

{{% details title="Bisakah saya menyambung ke penyimpanan cloud seperti Google Drive atau Dropbox?" closed="true" %}}
Everdisk tidak masuk ke akun cloud seperti iCloud Drive, Google Drive, Dropbox, atau OneDrive. Everdisk hanya menyambung ke server **jaringan lokal dan yang dialamatkan langsung** (DLNA, WebDAV, FTP, SFTP, SMB). Layanan cloud hanya bisa dijangkau jika menyediakan alamat **WebDAV** yang bisa Anda ketikkan ke koneksi WebDAV baru.
{{% /details %}}

{{% details title="Untuk apa tab Perangkat?" closed="true" %}}
Ini adalah sisi klien Everdisk: **Koneksi** mencantumkan server yang Anda simpan, dan **Perangkat Tersedia** mencantumkan server yang ditemukan otomatis di jaringan Anda. Ketuk salah satunya untuk menjelajah, streaming, atau mengunduh filenya, atau ketuk **Koneksi Baru** untuk menambahkan server DLNA, WebDAV, FTP, SFTP, atau SMB secara manual.
{{% /details %}}

{{% details title="Bagaimana cara mengunduh file dari server ke perangkat saya?" closed="true" %}}
Buka server di tab **Perangkat**, jelajahi ke item yang Anda inginkan, lalu pilih **Unduh** (pilih beberapa item untuk sekumpulan). Unduhan berjalan di latar belakang, muncul di **Transfer Berkas** (kiri atas tab Dokumen), dan mendarat di folder **Dokumen** Anda.
{{% /details %}}

{{% details title="Apakah Everdisk punya pengelola file?" closed="true" %}}
Ya. Tab **Dokumen** adalah pengelola file lengkap. Anda bisa menjelajah dalam daftar atau grid, membuat folder, mengganti nama, memindahkan, menyalin, mengunggah, dan menghapus, serta membuka layar **Info** untuk file mana pun. Unduhan mendarat di sini, dan folder Dokumen dibagikan secara default.
{{% /details %}}

{{% details title="Bagaimana cara zip (mengarsipkan) file?" closed="true" %}}
Di tab **Dokumen**, pilih satu item atau lebih lalu pilih **Arsipkan**. Satu item di-zip sendiri; beberapa item digabungkan jadi satu **Archive.zip**. Di browser web Anda juga bisa mengunduh seluruh folder atau beberapa item terpilih sebagai satu zip.
{{% /details %}}

{{% details title="Bagaimana cara unzip sebuah arsip?" closed="true" %}}
Ketuk file **.zip** atau **.rar** di tab **Dokumen** dan Everdisk mengekstraknya ke folder saat ini, dengan bilah kemajuan yang bisa Anda batalkan.
{{% /details %}}

{{% details title="Bagaimana cara scan dokumen ke PDF?" closed="true" %}}
Di tab **Dokumen**, buka menu lebih banyak tindakan (•••) dan pilih **Pindai Dokumen**. Arahkan kamera ke setiap halaman - Everdisk menemukan tepinya dan meluruskan halaman secara otomatis - dan semua halaman disimpan bersama sebagai satu **PDF multi-halaman** di folder saat ini. Anda memerlukan perangkat dengan kamera.
{{% /details %}}

{{% details title="Alat PDF apa saja yang disertakan Everdisk?" closed="true" %}}
Everdisk punya rangkaian **Alat PDF** bawaan. Buka menu **•••** PDF mana pun (atau layar Info-nya) di tab **Dokumen** dan ketuk **Alat PDF**. Alat ini dikelompokkan jadi tiga area:<br><br>

**Optimalkan**<br>
- **Kompres** - perkecil PDF. Anda melihat ukuran saat ini dan perkiraan ukuran hasil untuk setiap opsi sebelum menyimpan.<br>
- **Pengenalan Teks (OCR)** - ubah PDF hasil scan jadi **PDF yang bisa dicari**, atau ekspor teksnya saja ke file **.txt**.<br>
- **Ratakan** - satukan anotasi dan entri formulir ke halaman agar tidak bisa lagi diedit.<br><br>

**Keamanan**<br>
- **Kata Sandi** - atur, ubah, atau hapus kata sandi yang diperlukan untuk membuka PDF.<br>
- **Izin** - tinjau apa yang diizinkan PDF (menyalin, mencetak, memberi komentar, dan lainnya).<br><br>

**Metadata**<br>
- **Edit Metadata** - ubah atau kosongkan judul, penulis, subjek, kata kunci, dan info dokumen lainnya.<br><br>

Alat PDF disertakan gratis. Jika sebuah PDF dilindungi kata sandi, Everdisk meminta kata sandinya sebelum Anda bisa memakai alat-alat itu.
{{% /details %}}

{{% details title="Bagaimana cara mengompres PDF?" closed="true" %}}
Buka menu **•••** PDF → **Alat PDF** → **Kompres**. Everdisk menampilkan ukuran file saat ini dan perkiraan ukuran untuk setiap opsi:<br><br>

- **Standard** mempertahankan teks tetap bisa dipilih dan hanya mengompres ulang gambarnya.<br>
- **High**, **Medium**, **Small**, dan **Smallest** merender ulang halaman jadi gambar dengan resolusi lebih rendah - paling cocok untuk hasil scan dan foto, tapi teksnya tidak lagi bisa dipilih.<br><br>

Ketuk opsi yang Anda inginkan dan Everdisk menyimpan PDF yang lebih kecil.
{{% /details %}}

{{% details title="Bagaimana cara membuat PDF hasil scan bisa dicari (OCR)?" closed="true" %}}
Buka menu **•••** PDF → **Alat PDF** → **Pengenalan Teks**. Pilih **PDF yang Dapat Dicari** untuk menambahkan lapisan teks tersembunyi agar Anda bisa mencari dan memilih teksnya (tampilan halaman tetap persis sama), atau **Berkas Teks (.txt)** untuk menyimpan teks yang dikenali saja di samping PDF. File yang besar atau hasil scan bisa memakan sedikit waktu.
{{% /details %}}

{{% details title="Bagaimana cara melindungi file PDF dengan kata sandi?" closed="true" %}}
Buka menu **•••** PDF → **Alat PDF** → **Kata Sandi**. Jika PDF belum dilindungi, masukkan kata sandi baru dan konfirmasi untuk mengaturnya. Jika sudah dilindungi, masukkan kata sandi saat ini untuk **menghapus** atau **mengubahnya**. Simpan kata sandi di tempat yang aman - PDF yang dilindungi tidak bisa dibuka tanpanya.<br><br>

Ini melindungi **file** PDF itu sendiri, yang berbeda dari **login dan kata sandi** yang melindungi seluruh sesi berbagi Anda (lihat pertanyaan keamanan di atas).
{{% /details %}}

{{% details title="Bisakah saya menggambar di atau menandatangani PDF di Everdisk?" closed="true" %}}
Ya. Ketuk PDF (atau foto) di tab **Dokumen** untuk membukanya di penampil bawaan, lalu gunakan alat **Markah** untuk **menggambar, menyorot, menambah teks dan bentuk, serta menandatangani** dengan jari Anda. Perubahan Anda tersimpan langsung kembali ke file.<br><br>

Jika Anda ingin membuat tanda itu permanen agar tidak bisa diedit nanti, buka **••• → Alat PDF → Ratakan** pada PDF. Untuk menambahkan kata sandi, menjalankan OCR, mengompres, atau mengedit info dokumen, gunakan **Alat PDF** yang lain (lihat pertanyaan di atas).
{{% /details %}}

{{% details title="Bisakah saya menyambungkan folder yang ada di tempat lain di perangkat saya?" closed="true" %}}
Ya. Di tab **Dokumen**, buka menu ••• dan pilih **Hubungkan Folder**, lalu pilih folder mana pun di perangkat Anda. Folder itu muncul di bagian atas dengan label **Terhubung** dan bisa dibagikan lewat jaringan seperti folder lainnya. Gunakan **Putuskan** dari Info-nya untuk melepasnya - folder dan filenya tetap ada di perangkat Anda.
{{% /details %}}

{{% details title="Bisakah orang mengunggah file kembali ke perangkat saya?" closed="true" %}}
Ya, saat **Pengeditan Berkas** aktif. Di browser web mereka mendapat panel **Unggah**; di koneksi WebDAV atau FTP mereka bisa menyalin file ke perangkat Anda. Nonaktifkan **Pengeditan Berkas** (di Pengaturan → Berbagi → Akses) untuk membuat berbagi jadi hanya-baca.
{{% /details %}}

{{% details title="Mengapa transfer foto atau video berjalan lambat?" closed="true" %}}
Jika **Format** Foto atau Video diatur ke **Paling Kompatibel** atau **Kualitas** di bawah **Asli**, Everdisk mengonversi setiap file saat dibagikan, yang lebih lambat dan lebih boros baterai. Atur **Format** dan **Kualitas** ke **Asli** di **Pengaturan → Berbagi** untuk transfer tercepat, dan beralih ke Paling Kompatibel hanya jika TV atau browser tertentu tidak bisa membuka sebuah file.
{{% /details %}}

{{% details title="Sebuah perangkat tidak muncul atau tidak mau terhubung. Apa yang bisa saya periksa?" closed="true" %}}
- Pastikan kedua perangkat berada di **jaringan Wi-Fi yang sama** (atau gunakan kabel Mac).<br>
- Pastikan berbagi sudah **dimulai** dan server yang tepat sudah **aktif** di Pengaturan → Berbagi → Koneksi.<br>
- Ketik alamatnya persis seperti yang ditampilkan di layar Berbagi; lewat Wi-Fi gunakan IP yang ditampilkan, dan lewat kabel gunakan nama **`.local`** (jangan `localhost`).<br>
- Jika Anda mengatur login dan kata sandi, masukkan di perangkat lain.<br>
- Periksa izin **Jaringan Lokal** diizinkan untuk Everdisk di aplikasi Pengaturan iOS.<br>
- Pastikan perangkat lain tidak ada di **Perangkat Diblokir**.
{{% /details %}}

{{% details title="Bisakah saya mengubah nama yang ditampilkan perangkat saya di jaringan?" closed="true" %}}
Everdisk memberi perangkat Anda nama dan avatar yang ramah secara otomatis, dan Anda bisa **Buat Ulang** keduanya secara gratis. Mengatur nama, ikon, gradien, atau avatar foto **kustom** adalah bagian dari fitur Premium **Penyesuaian Perangkat**.
{{% /details %}}

{{% details title="Bisakah saya mengubah port koneksi?" closed="true" %}}
Nilai defaultnya adalah **HTTP 80**, **WebDAV 8080**, **SMB 4455**, dan **FTP 2121** (DLNA memilih portnya secara otomatis). Anda bisa melihatnya secara gratis, dan mengatur **port kustom** adalah fitur Premium (**Lanjutan** di Pengaturan → Berbagi).
{{% /details %}}

{{% details title="Apakah Everdisk gratis, dan apa yang ditambahkan Premium?" closed="true" %}}
Everdisk **gratis** diunduh. Anda bisa menjalankan kelima server, melindungi akses dengan kata sandi, membagikan seluruh koleksi Foto dan Musik Anda, memakai pengelola file, scan ke PDF, dan menyambung ke server lain. Versi gratis membagikan hingga **5 folder** dan menyimpan hingga **10 koneksi server**.<br><br>

Pembelian sekali bayar **Premium Lifetime** (bukan langganan) menambahkan: **Folder Tak Terbatas**, **Koneksi Tanpa Batas**, **Konversi Foto & Video** (kualitas selain Asli), **Enkripsi SMB** (SMB3/AES), **Port Kustom**, **Mulai Berbagi Otomatis**, dan **Penyesuaian Perangkat**.
{{% /details %}}

{{% details title="Apakah Premium sebuah langganan? Apakah berfungsi di perangkat saya yang lain?" closed="true" %}}
Premium adalah **pembelian sekali bayar**, bukan langganan - Anda membayar sekali dan tidak pernah diperpanjang. Pembelian ini terikat pada Apple ID Anda, jadi Anda bisa memakai **Pulihkan Pembelian** untuk membukanya di perangkat Anda yang lain yang masuk dengan Apple ID yang sama.
{{% /details %}}
