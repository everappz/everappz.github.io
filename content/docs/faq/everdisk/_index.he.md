<div class="hx:mt-6"></div>

Everdisk הופכת את ה-iPhone או ה-iPad שלכם לכונן אלחוטי שמשתף קבצים, תמונות, סרטונים ומוזיקה עם כל מכשיר ברשת המקומית שלכם - טלוויזיה חכמה, Mac או PC, דפדפן או טלפון אחר - בלי חשבונות, בלי ענן ובלי שום דבר שצריך להתקין בצד השני. השאלות הנפוצות האלה עונות על השאלות שאנשים שואלים הכי הרבה ועוברות על תרחישים נפוצים מהחיים. להוראות שלב אחר שלב, ראו את [המדריך למשתמש של Everdisk](/docs/guide/everdisk/).

<div class="hx:w-full">

{{% details title="מה זה Everdisk?" closed="true" %}}
Everdisk היא אפליקציית **כונן אלחוטי** ל-iPhone ול-iPad. היא הופכת את המכשיר שלכם למרכז ששולח את הקבצים, התמונות, הסרטונים והמוזיקה שאתם בוחרים לכל מה שנמצא ברשת המקומית שלכם, והיא גם מתחברת לשרתים אחרים כך שתוכלו לעיין ולהזרים את הקבצים שלהם.<br><br>

היא מריצה ארבעה שרתים בו זמנית - **DLNA** לטלוויזיות, **HTTP** לדפדפנים, **WebDAV** ל-Finder/Windows/Linux ו-**FTP** לאפליקציות קבצים - כך שכל מכשיר מתחבר בדרך שנוחה לו. אין חשבונות ואין ענן: מקישים **התחלה** ואתם מוכנים. היא כוללת גם מנהל קבצים, נגן מדיה, גלריית תמונות, סריקת מסמכים ל-PDF ודחיסה ופתיחת ארכיונים.
{{% /details %}}

{{% details title="איך Everdisk עובדת?" closed="true" %}}
כשאתם מקישים **התחלה**, Everdisk הופכת את המכשיר שלכם לשרת ברשת המקומית שלכם ומשתפת את התוכן שבחרתם. ארבע שיטות חיבור שונות פועלות בו זמנית כך שמכשירים שונים יכולים להתחבר בדרך שהם מעדיפים:<br><br>

- **DLNA** - טלוויזיות חכמות ונגני מדיה מוצאים את המכשיר שלכם אוטומטית ומציגים את המדיה שלכם עם תמונות תצוגה מקדימה.<br>
- **HTTP** - כל אחד פותח קישור בדפדפן כדי לעיין ולהוריד את הקבצים שלכם.<br>
- **WebDAV** - המכשיר שלכם מופיע ככונן רשת רגיל ב-Finder, ב-Windows או ב-Linux.<br>
- **FTP** - אפליקציות קבצים וכלים מתקדמים מתחברים דרך FTP.<br><br>

הכול קורה דרך ה-Wi-Fi המקומי שלכם (או בכבל USB ל-Mac) ולעולם לא נוגע באינטרנט.
{{% /details %}}

{{% details title="האם אני צריך חשבון, שם משתמש או אינטרנט?" closed="true" %}}
לא. Everdisk לא צריכה חשבון ולא צריכה חיבור לאינטרנט. היא עובדת כולה על ה**רשת המקומית** שלכם, או בכבל **USB** ל-Mac. שום דבר לא מועלה לשום ענן. שם המשתמש היחיד שאפשר להזין הוא כזה ש**אתם** יכולים להגדיר כדי להגן על השיתוף שלכם בסיסמה.
{{% /details %}}

{{% details title="איך מתחילים לשתף?" closed="true" %}}
פתחו את לשונית **שיתוף**, הקישו **מה לשתף** ובחרו את הקבצים, התמונות ו/או המוזיקה שלכם, ואז הקישו על כפתור **התחלה** הגדול. אזור **איך להתחבר** מציג אז את הכתובות המדויקות שמכשירים אחרים משתמשים בהן כדי להתחבר. הקישו **עצירה** כדי להוציא הכול מחוץ לרשת שוב.
{{% /details %}}

{{% details title="מה אפשר לשתף?" closed="true" %}}
שלושה סוגי תוכן, בכל שילוב:<br><br>

- **קבצים ותיקיות** - תיקיית המסמכים של האפליקציה (משותפת כברירת מחדל), בתוספת כל תיקייה או קובץ בודד שאתם מוסיפים עם **הוספת תיקייה** ו**הוספת קובץ**.<br>
- **תמונות וסרטונים** - כל ספריית התמונות שלכם עם **אפשרות גישה לכל ספריית התמונות**, או רק פריטים נבחרים עם **הוספת תמונות**.<br>
- **מוזיקה** - כל ספריית המוזיקה שלכם עם **אפשרות גישה לכל ספריית המוזיקה**, או שירים נבחרים עם **הוספת רצועות**.<br><br>

צריך לבחור לפחות דבר אחד לפני שהשיתוף יכול להתחיל. רצועות מוגנות (DRM) ורצועות שקיימות רק בענן לא ניתנות לשיתוף.
{{% /details %}}

{{% details title="איך משתפים תמונות עם המחשב שלי?" closed="true" %}}
1. במסך **שיתוף**, פתחו **מה לשתף → תמונות וסרטונים** והפעילו **אפשרות גישה לכל ספריית התמונות** (או הוסיפו תמונות ספציפיות).<br>
2. הקישו **התחלה**.<br>
3. במחשב, פתחו את כתובת ה**דפדפן** בכל דפדפן והורידו, או התחברו לכתובת **מחשב (WebDAV)** מ-Finder (Mac) או מ-File Explorer (Windows) וגררו את התמונות.<br><br>

טיפ: השאירו את **הפורמט** של התמונות על **מקורי** להעברה המהירה ביותר.
{{% /details %}}

{{% details title="איך צופים בסרטונים או בתמונות שלי בטלוויזיה?" closed="true" %}}
1. ב**הגדרות → שיתוף → חיבורים**, ודאו ש-**טלוויזיה ומרכז מדיה (DLNA)** מופעל.<br>
2. הקישו **התחלה**.<br>
3. בטלוויזיה, פתחו את נגן המדיה או אפליקציית שרת המדיה המובנים ובחרו את המכשיר שלכם לפי השם שלו מרשימת שרתי המדיה.<br>
4. עיינו ונגנו. תמונות תצוגה מקדימה מופיעות אוטומטית.<br><br>

אם טלוויזיה ישנה לא מנגנת סרטון, הורידו את האיכות ב**הגדרות → שיתוף → סרטונים** כך ש-Everdisk תמיר אותו לפורמט תואם יותר.
{{% /details %}}

{{% details title="איך מאזינים למוזיקה שלי?" closed="true" %}}
הפעילו **אפשרות גישה לכל ספריית המוזיקה** (או הוסיפו רצועות) תחת **מה לשתף**, ואז **התחלה**. אז תוכלו לנגן את המוזיקה שלכם מדפדפן במכשיר אחר (יש נגן מובנה עם תור, ערבוב וחזרה), מטלוויזיית DLNA, או ב-Everdisk עצמה במצב **מסמכים → מוזיקה**. מוזיקה תמיד משותפת באיכות המקורית שלה.
{{% /details %}}

{{% details title="איך צופים בסרטים בתוך Everdisk?" closed="true" %}}
הקישו על כל סרטון - במסמכים שלכם, בתיקייה מחוברת או בשרת בלשונית מכשירים זמינים - והוא מתנגן ב**מסך מלא** באמצעות הנגן המובנה של המערכת, עם פקדים סטנדרטיים כולל **AirPlay**, **Picture in Picture** ו**מהירות ניגון**. אודיו מתנגן ב**נגן מוקטן** שנשאר בתחתית האפליקציה עם תור, ערבוב וחזרה.
{{% /details %}}

{{% details title="איך פותחים את הקבצים שלי בדפדפן?" closed="true" %}}
1. ב**הגדרות → שיתוף → חיבורים**, ודאו ש-**דפדפן (HTTP)** מופעל.<br>
2. הקישו **התחלה** והעתיקו את כתובת ה**דפדפן** (או הציגו את קוד ה-QR שלה).<br>
3. במכשיר האחר, פתחו כל דפדפן והקלידו את הכתובת הזו.<br><br>

האדם השני יכול לעיין ברשת או ברשימה, לצפות בתמונות בגלריה במסך מלא, לנגן מוזיקה ולהוריד קבצים - כולל הורדת תיקייה שלמה כ-**Archive.zip** יחיד. אם הפעלתם **עריכת קבצים**, הוא יכול גם להעלות קבצים בחזרה אליכם. אין מה להתקין בצדו.
{{% /details %}}

{{% details title="איך משתמשים במכשיר שלי ככונן רשת ב-Finder?" closed="true" %}}
1. ב**הגדרות → שיתוף → חיבורים**, ודאו ש-**מחשב (WebDAV)** מופעל, ואז **התחלה**.<br>
2. ב-Mac, פתחו את Finder ובחרו **Go → Connect to Server** (או הקישו **⌘K**).<br>
3. הזינו את כתובת **מחשב (WebDAV)** שמוצגת ב-Everdisk ולחצו **Connect**.<br>
4. הזינו את שם המשתמש והסיסמה שלכם אם הגדרתם כאלה; אחרת התחברו כאורח.<br><br>

המכשיר שלכם מתחבר כמו כל כונן רשת. כש-**עריכת קבצים** מופעלת אתם יכולים לגרור קבצים לשני הכיוונים; כשהיא כבויה הכונן הוא לקריאה בלבד.
{{% /details %}}

{{% details title="איך מתחברים מ-Windows או מ-Linux?" closed="true" %}}
השתמשו בכתובת **מחשב (WebDAV)**.<br><br>

- **Windows:** פתחו את File Explorer → לחצו לחיצה ימנית על **This PC** → **Add a network location** (או מפו כונן רשת), והזינו את כתובת ה-WebDAV.<br>
- **Linux:** במנהל הקבצים שלכם בחרו **Connect to Server** והזינו את כתובת ה-WebDAV (למשל עם קידומת `davs://` או `dav://`).<br><br>

הזינו את שם המשתמש והסיסמה אם הגדרתם כאלה.
{{% /details %}}

{{% details title="האם Everdisk עובדת בלי Wi-Fi?" closed="true" %}}
כן, עם **Mac** וכבל. חברו את ה-iPhone או ה-iPad שלכם ל-Mac, הקישו **Trust** אם תישאלו, והקישו **התחלה**. כתובת **חיבור בכבל** שמסתיימת ב-`.local` מופיעה במסך השיתוף; התחברו אליה מ-Finder (**⌘K**). זה עובד בלי Wi-Fi בכלל - מעולה במטוס, במלון או ברשת נעולה - וזה מהיר ופרטי יותר מ-Wi-Fi.
{{% /details %}}

{{% details title="האם אפשר להשתמש בכבל USB עם מחשב Windows או Android?" closed="true" %}}
לא. חיבור הכבל עובד עם **Mac** בלבד. מחשבי Windows ומכשירי Android מתחברים דרך **Wi-Fi**. (ב-Windows אתם עדיין יכולים לגרור קבצים לתיקיית Everdisk באמצעות אפליקציית Apple Devices או iTunes דרך הכבל, וזה נפרד מהשיתוף החי.)
{{% /details %}}

{{% details title="למה צריך להשאיר את האפליקציה פתוחה בזמן השיתוף?" closed="true" %}}
ה-iPhone או ה-iPad שלכם הוא השרת, ו-iOS לא מאפשר לאפליקציות להריץ שרת רשת ברקע. לכן השיתוף עובד רק כש-Everdisk **פתוחה על המסך**. להעברות ארוכות, השאירו את האפליקציה בחזית, חברו לחשמל והגדירו **Auto-Lock** ל-**Never** באפליקציית ההגדרות של iOS. אפשר גם להפעיל **התראה לפני ניתוק** כדי ש-Everdisk תזכיר לכם לפני שהמערכת משהה אותה.
{{% /details %}}

{{% details title="מה מהיר יותר - Wi-Fi או הכבל?" closed="true" %}}
**כבל ה-USB ל-Mac** מהיר ואמין יותר מ-Wi-Fi, כי הנתונים עוברים ישירות דרך הכבל. זו גם האפשרות הפרטית ביותר, שכן שום דבר לא עובר דרך הראוטר או האינטרנט. השתמשו בו להעברות גדולות של תמונות וסרטונים.
{{% /details %}}

{{% details title="מה ההבדל בין ארבעת השרתים (DLNA, HTTP, WebDAV, FTP)?" closed="true" %}}
כולם משתפים את אותו תוכן אבל מתאימים למכשירים שונים:<br><br>

- **טלוויזיה ומרכז מדיה (DLNA)** - לטלוויזיות חכמות ולנגני מדיה.<br>
- **דפדפן (HTTP)** - לכל דפדפן, בלי צורך בהתקנה.<br>
- **מחשב (WebDAV)** - הופך את המכשיר שלכם לכונן רשת ב-Finder/Windows/Linux.<br>
- **אפליקציות ומכשירים אחרים (FTP)** - לאפליקציות קבצים ולכלים מתקדמים.<br><br>

אפשר להפעיל או לכבות כל אחד מהם ב**הגדרות → שיתוף → חיבורים**.
{{% /details %}}

{{% details title="איך מגנים על הקבצים שלי בסיסמה?" closed="true" %}}
עברו ל**הגדרות → שיתוף → גישה** והגדירו **שם משתמש** ו**סיסמה**. חיבורי הדפדפן, המחשב והאפליקציות האחרות יבקשו אז את הפרטים האלה. השאירו את שניהם ריקים לגישה פתוחה.<br><br>

לתשומת לבכם: חיבור ה-**DLNA** (טלוויזיה) לא ניתן להגנה בסיסמה, ולכן הוא פתוח לכל מי שנמצא באותו Wi-Fi בזמן שהוא מופעל. כבו אותו אם אתם רוצים רק חיבורים מוגנים.
{{% /details %}}

{{% details title="האם אפשר למנוע מאנשים לשנות את הקבצים שלי?" closed="true" %}}
כן. המתג **עריכת קבצים** ב**הגדרות → שיתוף → גישה** שולט בזה. כשהוא **מופעל** (ברירת המחדל), מכשירים מחוברים יכולים להעלות, לשנות שם ולמחוק. כבו אותו כדי להפוך את הקבצים המשותפים שלכם ל**קריאה בלבד** - אחרים יכולים לצפות ולהוריד אבל לא לשנות כלום.
{{% /details %}}

{{% details title="איך חוסמים מכשיר שאני לא מזהה?" closed="true" %}}
במסך **שיתוף**, מצאו את המכשיר תחת **מי מחובר**, הקישו על כפתור עוד הפעולות שלו ובחרו **חסימת מכשיר זה**. נהלו מכשירים חסומים ב**הגדרות → שיתוף → גישה → מכשירים חסומים**, שם אפשר לבטל חסימה של אחד או **לבטל חסימה של הכול**.
{{% /details %}}

{{% details title="אם מישהו מוחק קובץ משותף, האם הוא אבד לתמיד?" closed="true" %}}
לא כברירת מחדל. קבצים שנמחקו עוברים לאשפה שניתן לשחזר ממנה כדי שתוכלו להחזיר אותם. אם אתם מעדיפים מחיקה מיידית בלי שחזור, הפעילו **מחיקת קבצים לצמיתות** ב**הגדרות → מנהל קבצים → מחיקת קבצים**.
{{% /details %}}

{{% details title="האם Everdisk פרטית ובטוחה?" closed="true" %}}
כן. Everdisk משתפת רק דרך ה**רשת המקומית** שלכם - שום דבר לא הולך לאינטרנט ואין חשבון ענן. לפרטיות מיטבית, שתפו ב-Wi-Fi ביתי או פרטי שאתם בוטחים בו, הוסיפו שם משתמש וסיסמה והיזהרו ב-Wi-Fi ציבורי. **כבל ה-USB ל-Mac** הוא האפשרות הפרטית ביותר מכולן. Everdisk זקוקה להרשאת **רשת מקומית** של iOS כדי שמכשירים סמוכים יוכלו למצוא אותה.
{{% /details %}}

{{% details title="האם Everdisk יכולה להתחבר ל-NAS שלי או לשרתים אחרים?" closed="true" %}}
כן. לשונית **מכשירים זמינים** מתחברת **אל** שרתים אחרים ברשת שלכם. הקישו **חיבור חדש** ובחרו **DLNA / UPnP**, **WebDAV**, **FTP** או **SFTP**, הזינו את הכתובת ואת שם המשתמש אם יש, ותוכלו לעיין, להזרים ולהוריד. בשרתי WebDAV, FTP ו-SFTP תוכלו גם ליצור תיקיות, להעלות, לשנות שם, להעביר ולמחוק. שרתי DLNA הם לקריאה בלבד.
{{% /details %}}

{{% details title="האם אפשר להתחבר לאחסון ענן כמו Google Drive או Dropbox?" closed="true" %}}
Everdisk לא נכנסת לחשבונות ענן כמו iCloud Drive, Google Drive, Dropbox או OneDrive. היא מתחברת רק לשרתי **רשת מקומית ומכתובת ישירה** (DLNA, WebDAV, FTP, SFTP). שירות ענן נגיש רק אם הוא מציע כתובת **WebDAV** שאפשר להקליד בחיבור WebDAV חדש.
{{% /details %}}

{{% details title="למה משמשת לשונית מכשירים זמינים?" closed="true" %}}
זהו צד הלקוח של Everdisk: **חיבורים** מציג שרתים ששמרתם, ו**מכשירים זמינים** מציג שרתים שנמצאו אוטומטית ברשת שלכם. הקישו על אחד כדי לעיין, להזרים או להוריד את הקבצים שלו, או הקישו **חיבור חדש** כדי להוסיף שרת DLNA, WebDAV, FTP או SFTP ידנית.
{{% /details %}}

{{% details title="איך מורידים קבצים משרת למכשיר שלי?" closed="true" %}}
פתחו את השרת בלשונית **מכשירים זמינים**, עיינו למה שאתם רוצים ובחרו **להוריד** (בחרו כמה פריטים לאצווה). ההורדות רצות ברקע, מופיעות ב**העברות קבצים** (בפינה השמאלית העליונה של לשונית מסמכים) ונוחתות בתיקיית **מסמכים** שלכם.
{{% /details %}}

{{% details title="האם ל-Everdisk יש מנהל קבצים?" closed="true" %}}
כן. לשונית **מסמכים** היא מנהל קבצים מלא. אפשר לעיין ברשימה או ברשת, ליצור תיקיות, לשנות שם, להעביר, להעתיק, להעלות ולמחוק, ולפתוח את מסך ה**מידע** של כל קובץ. הורדות נוחתות כאן, ותיקיית המסמכים משותפת כברירת מחדל.
{{% /details %}}

{{% details title="איך דוחסים (יוצרים ארכיון) קבצים?" closed="true" %}}
בלשונית **מסמכים**, בחרו פריט אחד או יותר ובחרו **ארכיון**. פריט יחיד נדחס בפני עצמו; כמה פריטים נארזים ל-**Archive.zip** אחד. בדפדפן אפשר גם להוריד תיקייה שלמה או כמה פריטים נבחרים כ-zip יחיד.
{{% /details %}}

{{% details title="איך פותחים ארכיון?" closed="true" %}}
הקישו על קובץ **.zip** או **.rar** בלשונית **מסמכים** ו-Everdisk מחלצת אותו לתיקייה הנוכחית, עם סרגל התקדמות שאפשר לבטל.
{{% /details %}}

{{% details title="איך סורקים מסמך ל-PDF?" closed="true" %}}
בלשונית **מסמכים**, פתחו את תפריט עוד הפעולות (•••) ובחרו **סריקת מסמכים**. כוונו את המצלמה לכל עמוד - Everdisk מזהה את הקצוות ומיישרת את העמוד אוטומטית - וכל העמודים נשמרים יחד כ-**PDF מרובה עמודים** אחד בתיקייה הנוכחית. צריך מכשיר עם מצלמה.
{{% /details %}}

{{% details title="אילו כלי PDF כוללת Everdisk?" closed="true" %}}
ל-Everdisk יש ערכת **כלי PDF** מובנית. פתחו את תפריט ה-**•••** של כל PDF (או את מסך המידע שלו) בלשונית **מסמכים** והקישו **כלי PDF**. היא מחולקת לשלושה אזורים:<br><br>

**אופטימיזציה**<br>
- **דחיסה** - הקטינו קובץ PDF. אתם רואים את הגודל הנוכחי וגודל תוצאה משוער לכל אפשרות לפני השמירה.<br>
- **זיהוי טקסט (OCR)** - הפכו PDF סרוק ל-**PDF שאפשר לחפש בו**, או ייצאו רק את הטקסט לקובץ **.txt**.<br>
- **שיטוח** - הטמיעו הערות ורשומות טופס בעמוד כך שלא ניתן יהיה לערוך אותן יותר.<br><br>

**אבטחה**<br>
- **סיסמה** - הגדירו, שנו או הסירו את הסיסמה הדרושה לפתיחת ה-PDF.<br>
- **הרשאות** - עיינו במה שה-PDF מאפשר (העתקה, הדפסה, הערות ועוד).<br><br>

**מטאדטה**<br>
- **עריכת מטאדטה** - שנו או נקו את הכותרת, המחבר, הנושא, מילות המפתח ומידע אחר על המסמך.<br><br>

כלי ה-PDF כלולים בחינם. אם PDF מוגן בסיסמה, Everdisk מבקשת את הסיסמה שלו לפני שתוכלו להשתמש בכלים.
{{% /details %}}

{{% details title="איך דוחסים קובץ PDF?" closed="true" %}}
פתחו את תפריט ה-**•••** של ה-PDF → **כלי PDF** → **דחיסה**. Everdisk מציגה את גודל הקובץ הנוכחי וגודל משוער לכל אפשרות:<br><br>

- **רגיל** שומר על הטקסט ניתן לבחירה ורק דוחס מחדש את התמונות.<br>
- **גבוה**, **בינוני**, **קטן** ו**הקטן ביותר** מרנדרים מחדש את העמודים כתמונות ברזולוציה נמוכה יותר - הכי טוב לסריקות ולתמונות, אבל הטקסט כבר לא ניתן לבחירה.<br><br>

הקישו על האפשרות שאתם רוצים ו-Everdisk שומרת את ה-PDF הקטן יותר.
{{% /details %}}

{{% details title="איך הופכים PDF סרוק לניתן לחיפוש (OCR)?" closed="true" %}}
פתחו את תפריט ה-**•••** של ה-PDF → **כלי PDF** → **זיהוי טקסט**. בחרו **PDF שאפשר לחפש בו** כדי להוסיף שכבת טקסט נסתרת כך שתוכלו לחפש ולבחור את הטקסט (העמודים נראים בדיוק אותו הדבר), או **קובץ טקסט (.txt)** כדי לשמור רק את הטקסט שזוהה לצד ה-PDF. קבצים גדולים או סרוקים יכולים לקחת קצת זמן.
{{% /details %}}

{{% details title="איך מגנים על קובץ PDF בסיסמה?" closed="true" %}}
פתחו את תפריט ה-**•••** של ה-PDF → **כלי PDF** → **סיסמה**. אם ה-PDF עדיין לא מוגן, הזינו סיסמה חדשה ואשרו אותה כדי להגדיר אותה. אם הוא כבר מוגן, הזינו את הסיסמה הנוכחית כדי **להסיר** או **לשנות** אותה. שמרו את הסיסמה במקום בטוח - אי אפשר לפתוח PDF מוגן בלעדיה.<br><br>

זה מגן על **קובץ** ה-PDF עצמו, וזה שונה מ**שם המשתמש והסיסמה** שמגנים על כל סשן השיתוף שלכם (ראו את שאלות האבטחה למעלה).
{{% /details %}}

{{% details title="האם אפשר לצייר על PDF או לחתום עליו ב-Everdisk?" closed="true" %}}
כן. הקישו על PDF (או על תמונה) בלשונית **מסמכים** כדי לפתוח אותו במציג המובנה, ואז השתמשו בכלי ה**סימון** כדי **לצייר, להדגיש, להוסיף טקסט וצורות ולחתום** עם האצבע. השינויים שלכם נשמרים ישירות בחזרה לקובץ.<br><br>

אם אתם רוצים להפוך את הסימונים האלה לקבועים כך שלא יהיה אפשר לערוך אותם מאוחר יותר, פתחו את ה-**••• → כלי PDF → שיטוח** של ה-PDF. כדי להוסיף סיסמה, להריץ OCR, לדחוס או לערוך את פרטי המסמך, השתמשו בשאר **כלי PDF** (ראו את השאלה למעלה).
{{% /details %}}

{{% details title="האם אפשר לחבר תיקייה שנמצאת במקום אחר במכשיר שלי?" closed="true" %}}
כן. בלשונית **מסמכים**, פתחו את תפריט ה-••• ובחרו **חיבור תיקייה**, ואז בחרו כל תיקייה במכשיר שלכם. היא מופיעה בראש עם תווית **מחובר** וניתן לשתף אותה ברשת כמו כל תיקייה אחרת. השתמשו ב**ניתוק** מהמידע שלה כדי לנתק אותה - התיקייה והקבצים נשארים במכשיר שלכם.
{{% /details %}}

{{% details title="האם אנשים יכולים להעלות קבצים בחזרה למכשיר שלי?" closed="true" %}}
כן, כש-**עריכת קבצים** מופעלת. בדפדפן הם מקבלים לוח **העלאה**; בחיבור WebDAV או FTP הם יכולים להעתיק קבצים למכשיר שלכם. כבו את **עריכת קבצים** (בהגדרות → שיתוף → גישה) כדי להפוך את השיתוף לקריאה בלבד.
{{% /details %}}

{{% details title="למה תמונה או סרטון עוברים לאט?" closed="true" %}}
אם ה**פורמט** של התמונות או הסרטונים מוגדר ל-**תואם ביותר** או ה**איכות** נמוכה מ-**מקורי**, Everdisk ממירה כל קובץ בזמן השיתוף, וזה איטי יותר ומשתמש ביותר סוללה. הגדירו את ה**פורמט** ואת ה**איכות** ל-**מקורי** ב**הגדרות → שיתוף** להעברות המהירות ביותר, ועברו ל-תואם ביותר רק אם טלוויזיה או דפדפן מסוימים לא מצליחים לפתוח קובץ.
{{% /details %}}

{{% details title="מכשיר לא מופיע או לא מתחבר. מה כדאי לבדוק?" closed="true" %}}
- ודאו ששני המכשירים נמצאים ב**אותה רשת Wi-Fi** (או השתמשו בכבל ה-Mac).<br>
- ודאו שהשיתוף **התחיל** ושהשרת הנכון **מופעל** בהגדרות → שיתוף → חיבורים.<br>
- הקלידו את הכתובת בדיוק כפי שהיא מוצגת במסך השיתוף; דרך Wi-Fi השתמשו ב-IP המוצג, ודרך הכבל השתמשו בשם ה-**`.local`** (לעולם לא `localhost`).<br>
- אם הגדרתם שם משתמש וסיסמה, הזינו אותם במכשיר האחר.<br>
- בדקו שהרשאת **רשת מקומית** מאושרת ל-Everdisk באפליקציית ההגדרות של iOS.<br>
- ודאו שהמכשיר האחר לא נמצא ב**מכשירים חסומים**.
{{% /details %}}

{{% details title="האם אפשר לשנות את השם שהמכשיר שלי מציג ברשת?" closed="true" %}}
Everdisk נותנת למכשיר שלכם שם ידידותי ואווטאר אוטומטית, ואתם יכולים **ליצור אותם מחדש** בחינם. הגדרת שם, אייקון, מעבר צבעים או אווטאר תמונה **מותאמים אישית** היא חלק מתכונת **התאמה אישית של המכשיר** ב-Premium.
{{% /details %}}

{{% details title="האם אפשר לשנות את פורטי החיבור?" closed="true" %}}
ברירות המחדל הן **HTTP 80**, **WebDAV 8080** ו-**FTP 2121** (DLNA בוחר את הפורט שלו אוטומטית). אפשר לראות אותם בחינם, והגדרת **פורטים מותאמים אישית** היא תכונת Premium (**מתקדם** בהגדרות → שיתוף).
{{% /details %}}

{{% details title="האם Everdisk בחינם, ומה Premium מוסיף?" closed="true" %}}
את Everdisk אפשר להוריד **בחינם**. אתם יכולים להריץ את כל ארבעת השרתים, להגן על הגישה בסיסמה, לשתף את כל ספריות התמונות והמוזיקה שלכם, להשתמש במנהל הקבצים, לסרוק ל-PDF ולהתחבר לשרתים אחרים. הגרסה החינמית משתפת עד **5 תיקיות** ושומרת עד **10 חיבורי שרת**.<br><br>

רכישת **Premium Lifetime** חד פעמית (לא מנוי) מוסיפה: **תיקיות ללא הגבלה**, **חיבורים ללא הגבלה**, **המרת תמונות ווידאו** (איכות שאינה מקורית), **פורטים מותאמים אישית**, **התחלת שיתוף אוטומטית** ו**התאמה אישית של המכשיר**.
{{% /details %}}

{{% details title="האם Premium הוא מנוי? האם הוא עובד במכשירים האחרים שלי?" closed="true" %}}
Premium הוא **רכישה חד פעמית**, לא מנוי - משלמים פעם אחת והוא לעולם לא מתחדש. הוא משויך ל-Apple ID שלכם, כך שתוכלו להשתמש ב**שחזור רכישות** כדי לפתוח אותו במכשירים האחרים שלכם שמחוברים עם אותו Apple ID.
{{% /details %}}
