{{- /* responsive-image.html - universal responsive with a multi-resolution webp srcset. Emits one with a `srcset` (width descriptors) + `sizes`, so the browser downloads the right resolution for the screen size AND device pixel ratio (Retina gets a 2x asset instead of upscaling an 800px one). Params (dict): image (Resource, required) source image resource (resources.Get / .Page.Resources.Get). specs (slice of strings) one Hugo image Process spec per intrinsic width, ascending, e.g. "Resize 800x q80 webp" or "Fill 1030x400 Center q82 webp". Callers MUST keep each spec <= the source dimensions (Hugo upscales otherwise). At least one spec required. sizes (string) the sizes attribute. Default "100vw". fallback (int) preferred width for the plain `src` fallback. Default 800. fallbackFormat (string) if set (e.g. "png" / "jpg"), wrap the output in a with a webp and an fallback rendered in this widely-supported format — so browsers without webp support (and any without srcset) still get a correct image. The uses display:contents so it never alters layout. alt, class, style, title (strings) loading (string) default "lazy" (use "eager" for above-the-fold heroes). decoding (string) default "async". SVG sources are emitted untouched (no processing, no srcset). */ -}} {{- $img := .image -}} {{- $specs := .specs -}} {{- $sizes := .sizes | default "100vw" -}} {{- $fallback := .fallback | default 800 -}} {{- $fallbackFormat := .fallbackFormat -}} {{- $alt := .alt | default "" -}} {{- $class := .class -}} {{- $style := .style -}} {{- $title := .title -}} {{- $loading := .loading | default "lazy" -}} {{- $decoding := .decoding | default "async" -}} {{- if $img -}} {{- if eq $img.MediaType.SubType "svg" -}} {{- else if $specs -}} {{- /* Primary (usually webp) variants. */ -}} {{- $variants := slice -}} {{- range $specs -}} {{- $variants = $variants | append ($img.Process .) -}} {{- end -}} {{- $srcset := slice -}} {{- $largest := index $variants 0 -}} {{- $fb := index $variants 0 -}} {{- range $variants -}} {{- $srcset = $srcset | append (printf "%s %dw" .RelPermalink .Width) -}} {{- if gt .Width $largest.Width -}}{{- $largest = . -}}{{- end -}} {{- if and (le .Width $fallback) (gt .Width $fb.Width) -}}{{- $fb = . -}}{{- end -}} {{- end -}} {{- if $fallbackFormat -}} {{- /* Universal fallback: same widths in a broadly-supported raster format (png/jpg), derived from $specs by stripping the quality token and swapping the format. */ -}} {{- $fbSpecs := slice -}} {{- range $specs -}} {{- $s := replaceRE `\s*q\d+` "" . -}} {{- $s = replaceRE `\s*(webp|jpe?g|png|gif|tiff|bmp)` "" $s -}} {{- $fbSpecs = $fbSpecs | append (printf "%s %s" (trim $s " ") $fallbackFormat) -}} {{- end -}} {{- $fbVariants := slice -}} {{- range $fbSpecs -}} {{- $fbVariants = $fbVariants | append ($img.Process .) -}} {{- end -}} {{- $fbSrcset := slice -}} {{- $fbLargest := index $fbVariants 0 -}} {{- $fbSrc := index $fbVariants 0 -}} {{- range $fbVariants -}} {{- $fbSrcset = $fbSrcset | append (printf "%s %dw" .RelPermalink .Width) -}} {{- if gt .Width $fbLargest.Width -}}{{- $fbLargest = . -}}{{- end -}} {{- if and (le .Width $fallback) (gt .Width $fbSrc.Width) -}}{{- $fbSrc = . -}}{{- end -}} {{- end -}} {{- $type := printf "%s/%s" $largest.MediaType.MainType $largest.MediaType.SubType -}} {{- else -}} {{- end -}} {{- end -}} {{- end -}}
